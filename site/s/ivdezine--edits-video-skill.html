About edits-video-skill

A Claude Code skill for driving the Edits video editor for macOS through the local MCP (Model Context Protocol) server the app exposes, registered as metapilot-native. With it, Claude can open projects, cut, trim, split on beats or shots, reframe, add text, captions, filters, transitions, LUTs, speed curves and music, check loudness, inspect frames, confirm that beat-synced cuts land on the beat, and export.

The video below was cut in Edits by Claude with this skill, from scene renders to export:

https://github.com/user-attachments/assets/02225140-ad35-4ce3-80b6-6262c665d020

Not affiliated with, endorsed by, or supported by Meta. Edits is a Meta product; this repository contains only notes and scripts written against the app's local server.

- Tested against Edits 454.0.0 for macOS (server metapilot-native 1.0.0) on 2026-11-08. The beat-synced cut recipe was retested on 2026-11-09. - The server is not publicly documented and may change with any app update. Where the live server disagrees with these notes, the server wins: regenerate the references (below) and recheck.
