About lava-mcp

熔岩（Lava） 提供 A 股股票和概念板块的消息面热度监测 结构化只读数据——支持 量化交易工具 与 AI Agent 股市研究 接入，通过远程 MCP / REST 调用。

只读 · 结构化要点 + 机构/大V ID（agencyid）· 新闻命中不含标题与正文

① 开通并复制 API Key（登录熔岩 → 左侧「AI数据服务」→ API Key → 新建；首次登录通常已自动生成「默认」Key）

② 装 Skill，或在豆包办公 / WorkBuddy / 千问办公填 MCP 地址 https://lava.ai-dolphin.com/subscribe/v1/mcp

③ 用中文问「某某股票最近消息面热不热」，或「最近 24 小时全市场哪些股票消息面最热」

项 值 --- --- 传输 Streamable HTTP Endpoint https://lava.ai-dolphin.com/subscribe/v1/mcp 鉴权 请求头 Authorization: Bearer （或 X-API-Key）；亦支持 OAuth 2.1（PKCE S256 + DCR） 客户端 豆包办公、WorkBuddy（BUDDY）、千问办公（QwenWork）等支持自定义 HTTP MCP 的客户端

proxy/server.py 是可运行的薄代理（Python 3.9+，仅标准库）。它不实现熔岩的查询接口，只把 MCP 的 Streamable HTTP / JSON-RPC 原样转到官方端点，并附上 Authorization: Bearer 。个股、概念和热榜数据仍来自 https://lava.ai-dolphin.com。

直接连接官方端点仍然是推荐方式。本地代理适合需要在本机审计转发代码，或客户端不方便单独配置远程请求头的时候。

环境变量 说明 --- --- LAVAAPIKEY 熔岩 API Key。设置后，每个转发请求都带 Authorization: Bearer LAVAPROXYPORT 监听端口，默认 8787 LAVAPROXYHOST 监听地址，默认 127.0.0.1。监听非本机地址时还要设置 LAVAPROXYALLOWREMOTE=1 LAVAMCPUPSTREAM 上游地址，默认 https://lava.ai-dolphin.com/subscribe/v1/mcp LAVAPROXYTIMEOUT 上游超时（秒），默认 180；0 表示不限制

客户端把 MCP 地址填成 http://127.0.0.1:8787/mcp，传输选 Streamable HTTP。Key 放在启动代理的环境里即可。未设置 LAVAAPIKEY 时，才会原样转发客户端自己的 Authorization 头。

GET /health 只检查代理进程，不访问上游。本地测试：python3 -m unittest proxy.testserver。

仓库内 SKILL.md 与线上官方模板对齐（含全市场热榜、加权、首提、多时间窗、加速榜、日频面板、机构覆盖度与新闻点名）。官方模板：
