About codeidx

Codeidx 用 Rust 为项目建立索引。你可以找出跨文件的相关符号、读取实现片段，或借助本机语言服务器查询定义和引用。MCP 服务和终端界面使用同一套引擎，各自维护索引。

能力 用途 ------ 代码结构 用 RepoMap 看仓库里的关键符号，用文件大纲查看声明和行号 关键词和语义搜索 挂载后即可按关键词搜索。启用向量索引后可做语义搜索或混合排序 定义和引用 查询源码位置时按需启动本机语言服务器 按需索引 挂载时在内存中建索引，默认监听改动，卸载时释放项目索引

需要 Rust stable 与本机 C 编译、链接工具链。源码构建可能下载 ONNX Runtime。Windows 使用 Rust MSVC 工具链、C++ Build Tools 和 Windows SDK 10.0.19041 或更新版本。

可执行文件位于 target/release/，Windows 文件带 .exe 后缀。MCP 和终端界面运行时无需 Python 或 Node.js。语言服务器按需单独安装。

在支持 stdio 的 MCP 客户端中添加以下配置。配置位置与键名以客户端文档为准。将 command 换成构建产物的绝对路径。Windows 的路径可写作 C:/path/to/codeidx-mcp.exe。

先用 mountproject 挂载项目的绝对路径。已挂载随仓示例项目后，给 searchcode 传入下列参数即可查到示例函数。

结果按文件分组，保留全局排名、行范围、分数和代码片段。正文位于 content[0].text，格式可选 compact（默认）、json 或 md。tools/list 一次返回全部 11 个工具。挂载后可直接调用任意查询工具。

查询目标 工具 ------ 项目生命周期 mountproject、unmountproject、listmountedprojects、syncproject 仓库与文件结构 getrepomap、getfileoutline 找代码与读取实现 searchcode、readsymbol 定义、引用和类型信息 lspdefinition、lspreferences、lsphover

path 为项目根目录的绝对路径，filepath 为项目内相对路径。LSP 行号从 1 开始，列号使用 UTF-16 代码单元计数，从 0 开始。stdio 使用逐行 JSON-RPC，日志走 stderr。详见架构与协议。

Windows PowerShell 中运行 .\target\release\codeidx-tui.exe。输入项目路径并按 Enter 挂载。用 F1 至 F5 切换仓库概览、搜索、文件大纲、LSP 和项目列表。在搜索页输入关键词并按 Enter，再用方向键选中符号，按 Enter 查看源码。按 ? 查看按键。

在同一匿名仓库中关闭向量索引，单次挂载用时 399 ms，索引了 187 个文件、4,821 个符号。表中只统计 MCP 正文，以 o200kbase 实际分词。
