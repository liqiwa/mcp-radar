About tearsheet

A free library of 98 interface components, printed as a risograph zine. Every component comes in HTML + CSS, React, Vue and Svelte, with a note on why it is built the way it is, plus a web design guide of dos and don'ts.

Free forever. MIT-0: copy, change and ship anything, commercially or not, with no attribution.

Three ways to hand the library to an AI coding assistant. All serve the same components, tokens and design rules.

A link. Any agent that can read a web page can start from llms.txt. Behind it: api/components.json and every component as api/components/.md or .json, in all four formats.

A command. Node 18+, nothing to install (tearsheet on npm):

add detects React, Vue or Svelte from package.json (plain HTML otherwise), writes each component into its own folder plus tokens.css, and never overwrites a file unless you pass --force.

An MCP server. Add this to your editor or agent app's MCP settings:

Tools: searchcomponents, listcomponents, getcomponent (any format), getdesigntokens, getdesignrules. Some apps name the top-level key differently (for example servers). On Windows, if npx is not found, use "command": "cmd" and put "/c", "npx" at the start of args.

- Receipts. Every part publishes the evidence from CI: axe in light and dark, the tightest text contrast, the tab order, the accessibility tree, and what moves under reduced motion. See the receipt under any part, or api/receipts.json. - Right-to-left and long text.
