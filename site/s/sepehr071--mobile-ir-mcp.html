About mobile-ir-mcp

mobile-ir-mcp: Mobile.ir (مرجع موبایل ایران) phone specs, prices and SIM numbers MCP server for AI agents

mobile-ir-mcp is an unofficial, read-only MCP server that gives AI agents Mobile.ir (mobile.ir), Iran's oldest phone database. Its 17 tools search phones, filter them by brand, price, OS and camera, read full specs, compare models, list what each shop charges now, show price history, read user comments, news and expert reviews, browse used-phone ads and search numbered SIM cards. No API key or account is needed. It works in Claude, Cursor, Copilot and any other MCP client.

For AI agents · Quick start · What it can do · Tools · FAQ · فارسی

- What: unofficial MCP server (model context protocol) for mobile.ir: phone, tablet and smartwatch search and filters, full specifications, current shop prices (Toman) with each shop's note, price history, newest market price rows, users' used and new phone ads, and numbered SIM cards for sale. - Install: uvx mobile-ir-mcp or claude mcp add mobile-ir -- uvx mobile-ir-mcp. Transport: stdio. Needs uv (Python 3.10+). - Auth: none, no API key or account. Optional MOBILEIRMCPPROXY (HTTP proxy URL, or a comma-separated list); system proxy settings are ignored. - Access: read-only. It cannot log in, post ads or contact sellers, so no confirmation is needed before calling any tool. - Tools: 17, all prefixed mi. Typical sequences: misearch - miphone or mishopprices - mipricehistory; mifind (budget, brand) - miphone - micompare; micomments, miarticles - miarticle; mishop; miusedsearch - miusedad; misimsearch, misimsummary. - Use when: the use
