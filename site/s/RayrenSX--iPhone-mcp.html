About iPhone-mcp

让 AI 通过 MCP 观察和控制真实 iPhone/iPad。独立 Git 项目，从 iPhoneMirror 的初版 MCP 适配器发展而来，复用 iPhoneMirror 本地 Automation API，不另建 USB/无线传输。

已在 Windows 上完成 Codex CLI → stdio MCP → 本地 API → USB iPhone 的实测， 验证了截图、OCR、点击、触控、文字、键盘和剪贴板。详细证据与能力对照见 实测报告和 Windows MCP 能力对照。

安装 https://github.com/RayrenSX/iPhone-mcp 。先读取 AGENTS.md 和 docs/SETUP.md， 自动检测依赖与 iPhoneMirror、执行配置、接入 MCP，并实际调用工具验证截图。 完成所有电脑端步骤；若需要手机连接、信任或解锁，再告诉我具体动作。

脚本检测 Python，缺失时通过 winget 安装；没有运行中的兼容 iPhoneMirror 时，自动下载并 校验本仓库 runtime-v0.2.1 后台运行包。随后安装 MCP 依赖、注册 Codex， 通过 MCP 启动隐藏主窗口的应用、启用 API、准备投屏和反控，执行真实截图/OCR 诊断。 驱动安装改为命令行，AI 根据 actionRequired 提示连接、拔插 USB、解锁和管理员确认。 健康驱动直接跳过；缺失或异常组件由原生安装器诊断、安装或修复。完成后调用 startiphonemirror 和 snapshot 验证。此流程需要包含 driverSetupVersion: 1 的新版原生驱动程序，runtime-v0.2.1 包含此入口和手机系统动作 API。 旧 runtime-v0.2.0 会返回升级要求，不打开 GUI。 实测证据见 无界面驱动安装验证。 密钥留在当前用户 DPAPI，不写入 Codex 配置。 详细参数、主程序获取和排错见 自动配置指南。 手机连接、信任、解锁、开发者模式重启及 Windows 管理员确认仍可能需要人操作。 已有主程序可继续使用 scripts/setup.ps1 -EnableAutomationApi。

- Python 3.11+；OCR 和本地密钥读取需要 Windows。 - 本仓库后台运行包；startiphonemirror 自动启用本地 Automation API（默认 127.0.0.1:17890）。 - 已连接、信任的设备；MCP 自动准备投屏与反控，手机开发者模式等首次步骤仍需完成。 - Windows OCR 语言包；本机实测有 en-US、zh-Hans-CN。

--local-key-store 读取当前 Windows 用户的 iPhoneMirror DPAPI 密钥及设置端口。 密钥不写进 Codex 配置、不返回模型；只读取当前用户。后台应用负责创建密钥和启用 API。 显式环境变量 IPHONEMIRRORAPIKEY 和 IPHONEMIRRORAPIURL 可以覆盖上述配置。

新会话会读取新 MCP 配置；已启动会话需要刷新 MCP 连接或重新打开会话。 本机 Codex CLI 的只读测试可以截图、查询，控制工具因权限策略被拒绝； Full access 测试成功完成获取控制、点击、再次截图与释放。不需要在项目中保存模型 API 密钥。
