About rwkv-prompt-format

A format checker and auto-fixer for RWKV G1/G1x prompts. It is independent of the inference runtime: it takes plain text, never loads a model, never touches a GPU, and never reads or writes files. Six ways to consume it:

Form Best for Artifact --------- JSON CLI Any language, scripts, CI rwkv-pf(.exe) C ABI C/C++/Rust or any FFI wrapper rwkvpromptformat.dll / .so / .dylib Thin bindings Python / Node / Go / Java / C see bindings/ WASM Node / browsers / edge / any WASM host wasm/rwkvpromptformat.wasm + wasm/index.mjs MCP Qoder, Claude Desktop, and other AI agents mcp/server.mjs (zero-dependency stdio) Skill Trigger rules and workflow for AI agents skills/rwkv-prompt-format/

The rules come from the official templates (BlinkDL/RWKV-LM · RWKV7-G1x-templates.txt), not from guesses. The essentials:

- Blocks are separated by exactly one blank line (\n\n); a blank line must never appear inside block content. - Labels and keywords are case-sensitive: System: / User: / Assistant: / Instruction: / Input: / Response: / Tools: / y is safe.

Findings are printed one per line as L [severity] , followed by a │ line with the original evidence.

The human-readable summary and finding messages are currently in Chinese. Use --json and findings[].code for locale-independent automation.

- format: plainchat / materialqa / instruction / instructionchat / systemtools / chatml / markdown / jsonl / continuation / unknown. - line is 1-based; 0 means a whole-text finding. - severity: error / warn / info. ok == (errorcount == 0). - code is a stable rule code (for example MULTIPLESYSTEM, BLANKLINEINCO
