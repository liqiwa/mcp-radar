About hypr-computer

Computer use for any MCP-capable AI agent on Linux with Hyprland. It's a single stdio MCP server that lets the model see the screen (screenshots) and drive the mouse and keyboard. It works with Claude Code, Codex, Gemini CLI, Cursor, VS Code, opencode and any other client that supports local MCP servers.

It was built and tested on a 16-inch MacBook Pro with an M3 Max, running Omarchy 4.5 and Hyprland 0.56 on Arch Linux ARM with the linux-aurora 7.2.11 kernel.

Run this one command on the Linux machine:

It shows what it will do and asks before starting. Then it:

1. Downloads this repo to ~/.local/share/hypr-computer. 2. Uses sudo once to install grim, wtype, ydotool (and uv if it's missing), let your user use /dev/uinput, load uinput at boot and enable the ydotool user service. 3. Runs a read-only self-check. 4. Registers the server with each supported agent you've used (it checks for the agent's config folder): Claude Code, Codex, opencode, Gemini CLI and Cursor.

Then restart your agent. To update later, run the same command again.

Options go after bash -s --, for example curl -fsSL malik-na.github.io/hypr-computer bash -s -- --clients=claude --yes:

Option Effect --- --- --yes Don't ask for confirmation --dry-run Show every step and change nothing --clients=claude,codex Only register these agents (none to skip) --no-system Skip the sudo step (already done, or not on Arch) --dir=PATH Install somewhere other than ~/.local/share/hypr-computer
