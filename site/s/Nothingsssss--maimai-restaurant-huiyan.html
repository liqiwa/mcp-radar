About maimai-restaurant-huiyan

麦当劳 2026 年 1024 程序员创意开发大赛参赛项目 用 WorkBuddy 开发的 MCP 餐品数据驱动的配餐与优惠服务练习网页游戏。

⭐ 如果这个小游戏让你觉得有点意思，欢迎点右上角的 Star 支持一下 —— 本次比赛按 Star 数排名，你的一个 Star 对我们很重要，谢谢老板！🙏

无需下载、无需安装，浏览器打开就能玩。也可以下载仓库里的 maimai-restaurant.html 双击离线运行。

「麦麦餐厅」是一款单人上帝视角俯视餐厅的轻量出餐游戏：观察顾客订单 → 推荐更划算组合 → 按配方点材料 → 整盘交餐 → 获得餐费、小费与评价 → 升级餐厅。游戏在浏览器中即可运行，离线也能玩；麦当劳真实餐品营养数据通过本地同步脚本接入，数据脱敏后嵌入游戏侧栏。

- 喜欢轻量模拟经营小游戏的玩家 - 想练习餐品认知、配餐组合与优惠服务表达的服务人员/爱好者 - 对 MCP（Model Context Protocol）数据如何驱动前端游戏感兴趣的开发者

生成： - dist/maimai-restaurant.html - maimai-restaurant.html（项目根目录，可直接双击打开） - docs/index.html（在线试玩页 / GitHub Pages 发布源）

同步成功后，data/mcd-menu.json 会更新，构建时自动嵌入游戏。本次开发已真实同步 160 条餐品营养数据。无 Token 或网络失败时保留旧缓存，游戏仍可离线运行。

1. 双击 maimai-restaurant.html 或在浏览器中打开。 2. 选择「开始营业（3 分钟）」或「自由练习（不计时）」；可输入固定种子复现相同顾客。 3. 顾客出现在画面上方，面前悬浮订单卡：有优惠提示时可选「推荐优惠」赚取额外小费，也可「直接接单」。 4. 点击顾客卡选中本单，右侧侧栏显示游戏简化配方与麦当劳 MCP 营养数据。 5. 点击下方厨房材料入口制作汉堡（如：面包 + 牛肉饼 + 芝士 = 吉士汉堡包），小食/饮料直接点击取餐。 6. 配齐后点击顾客卡上的「整盘出餐」，正确且完整交付可获得收入；漏掉优惠可能被投诉。

- 默认营业 3 分钟，失焦自动暂停。 - 八种基础餐品，支持单点、套餐、同款多份。 - 推荐优惠成功：收入 = 原价 + 优惠节省额 × 小费倍率。 - 漏掉优惠且顾客投诉：收入 = 原价 − 原价 × 补偿倍率，差评 −1。 - 错误/多余餐品：扣原价，差评 −1。 - 餐厅规模与评价独立升级；余额可为负，继续营业。

⚠️ 游戏内价格、配方、小费、投诉补偿均为游戏设定，不代表现实餐厅售价、实际配方或真实交易。

见 .env.example 与 mcp-config.example.json。真实 Token 仅用于本地同步脚本，不进入前端、GitHub 或部署包。

- 在线试玩页：docs/index.html（即 maimai-restaurant.html 的副本，已发布到 ） - GitHub Pages：仓库已内置 docs/，在 Settings → Pages 里把 Source 选为 main 分支的 /docs 即可 - Netlify / Vercel / Cloudflare Pages：直接上传 dist/maimai-restaurant.html
