About KuroCat

超轻量级全状态键鼠桌面萌猫 · 原生跨平台 (macOS / Windows / Linux / 统信 UOS)

简体中文 English · 🌐 官方首页（网页试玩） · 🎨 皮肤工坊 &amp; 广场 · 🎥 OBS 直播指南 · ⬇️ GitHub 下载 · ⚡ 国内高速下载

Native macOS (Swift + CoreGraphics + IOHIDManager) · Windows (C++17 + GDI+ + Raw Input) · Linux / 统信 UOS (C++17 + GTK3/Cairo + XInput2/evdev)

对比维度 🐱 KuroCat 传统 Electron / Web 桌宠 :--- :--- :--- 安装包体积 ~802 KB（Windows 单文件零依赖） 80 MB ~ 150 MB+（捆绑 Chromium） 内存 / CPU 占用 原生 Swift / C++17，空闲自适应降帧至 10fps 常驻渲染进程，内存占用高 游戏内按键捕获 硬件级真全键无冲 (NKRO)，支持 DirectX / Vulkan 游戏 易受输入法、游戏焦点或管理员权限拦截 2.5D 视觉表现 Live2D 同款球面投影转头 + 捕猎大圆眼 + 长猫拖拽 多为静态贴图切换 皮肤与生态 在线 2.5D 皮肤工坊 + AI MCP Server 改图门槛高，需手动替换资源 隐私安全 100% 本地内存实时处理，绝不记录按键与写日志 闭源软件难以审计

- 🎮 打字 & 游戏全状态捕获（真全键无冲 NKRO） - macOS：双层 IOHIDManager（内核 HID 硬件层）+ CGEventTap，不受中英文输入法干扰，完整支持 WASD 长按、组合键、独立修饰键（⌘ / ⇧ / ⌥ / ⌃ / Fn）、方向键与 F1–F12。 - Windows：原生 Raw Input API (RIDEVINPUTSINK) 硬件扫描码监听，支持 DirectX/Vulkan 游戏内按键与锁视角鼠标微动。 - Linux & 统信 UOS / 麒麟：双层 XInput2 + 内核 evdev，UOS / Deepin / Ubuntu X11 下双击即用、免 sudo；纯 Wayland 加入 input 组即可开启硬件级监听。 - 🌀 2.5D 球面转头 & 捕猎大圆眼 - 猫头、双耳、双眼与胡须随鼠标光标产生真实的 2.5D 透视转头；键盘与鼠标 180° 朝向小猫摆放，左手键盘右手鼠标自然不交叉。 - 快速晃动鼠标触发捕猎模式：瞳孔扩张为超大圆润黑瞳 + 白色高光，身子压低伏击、尾巴加快抽动。 - 🐾 趣味交互彩蛋 - 3 键「用脚按」 & 4 键「用尾巴按」：同时按下第 3、第 4 个键时，小猫会翘起后脚或甩出尾巴去按！ - 键盘跑马灯流光：彗星追光沿键盘对角线扫过，按键越多速度越快、尾迹越长，色相每圈轮转（可在右键菜单单独开关）。 - 摸头互动 & 打瞌睡：轻撸猫头触发惬意闭眼 — — 与微光粒子，闲置久了自动打瞌睡冒 z。 - 游戏防误触穿透 & 开机自启：透明区域自动穿透，支持「完全鼠标穿透」、开机自启与自动更新检测。 - 🎨 皮肤工坊、多配色 & 统计 - 内置多款原生皮肤（经典小黑猫 / 挖煤暹罗猫 / 美短 / 橘白猫 / 狸花猫），支持导入社区 .kurocat 皮肤与 .kurokb 键盘。 - 3 套键盘配色、6+ 种瞳色、5 档尺寸缩放，自带今日击键数与实时 KPM 统计。
