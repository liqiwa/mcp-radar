About moodle-mcp

The Moodle® logo is used only to show which platform this project connects to.This project is unofficial: it is not made, endorsed or approved by Moodle Pty Ltd.

Your Moodle, in your AI. Deadlines, assignments, grades, attendance, materials and announcements, with your tokens and your model. 55 tools · what is validated · contributing

A community, independent project, not affiliated with UFSC, Moodle, Anthropic or OpenAI. The first target is UFSC's Moodle "Presencial"; the architecture supports other institutions (guide).

Illustrative example with synthetic data.

You say The server does --- --- "What is due next week?" combines assignments + quizzes + calendar; returns the exact window (calendar week ≠ 7 days) "Read the statement, use the slides and do the assignment." getassignment → readmaterial (PDF/DOCX/PPTX/ODF with page references) → you generate the file "Submit my assignment." upload → draft → submit → reads it back and shows the evidence "Can I skip Tuesday? How many classes can I still miss?" exact count by class hours, pending roll calls, critical meetings "What do I need on the P2 to pass?" deterministic simulation; a grade not yet posted ≠ zero "Join group 3 if there is room." group choice with a seat check and a read-back "Any new announcements since yesterday?" changessince with snapshots

Option A — Claude Code plugin (recommended)

Claude Code asks for your Moodle URL and token (kept in secure storage, never shown to the model). Create the token at /user/managetoken.php (service Moodle mobile web service). Then use the guided skills: /moodle-academic:se
