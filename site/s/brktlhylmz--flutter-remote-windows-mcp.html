About flutter-remote-windows-mcp

A zero-dependency Model Context Protocol (MCP) server written in pure Dart that automates wireless Flutter Windows Desktop development, flutter custom-devices provisioning, native C++ runner building, and live Interactive Session 1 GUI debugging (with sub-second Hot Reload and VS Code F5 debugging) directly from macOS or Linux onto any remote Windows 10/11 machine, laptop, or cloud VM.

Flutter does not support cross-compiling Windows desktop executables (.exe + Win32/DirectX C++ plugins) directly on macOS or Linux. While Flutter provides an experimental custom-devices mechanism, wiring it up to a real Windows 11 device over Wi-Fi/SSH hits six major Windows-specific roadblocks that this MCP server solves automatically:

1. Passwordless SSH on Windows Hello / Microsoft Account Machines (generatesshpairing) - Windows 11 machines signed in with a Microsoft Account + PIN often reject standard SSH password authentication. - OpenSSH on Windows requires C:\ProgramData\ssh\administratorsauthorizedkeys to have strict ACL permissions for Administrators and SYSTEM. Using localized group names (icacls ... /grant "Administrators:F") fails on non-English Windows installations. - Solution: Spins up a temporary local HTTP pairing server and gives you a single 1-line PowerShell command (irm http://:8765 iex) that installs OpenSSH Server, registers your ided25519.pub key, and applies locale-independent security identifiers (S-1-5-32-544:F and S-1-5-18:F).
