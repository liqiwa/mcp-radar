About antigravity-pet

A native Windows & macOS pixel desktop companion plugin for Google Antigravity — zero third-party runtime dependencies.

Antigravity Pet brings a lightweight, reactive pixel-art companion directly to your Windows & macOS desktop while you work with Google Antigravity. Powered by a native transparent overlay (C WPF on Windows / Swift AppKit on macOS), Antigravity lifecycle hooks, a standalone desktop Settings window, and an integrated Aux Pane / MCP App panel, it works out of the box with zero external SDKs or runtimes.

- Standalone Settings Window & 5-Tab Modern UI - Right-click Settings on the pet to launch a dedicated standalone settings window (460×800 app-mode window) directly — no need to switch to Antigravity; also available inside Antigravity via ... Sidecar or MCP App. - Reorganized into 5 clean tabs (Characters, Behavior, Bubbles, System, Updates) with a compact fixed overview header, 0.33x–3.00x logarithmic scale slider, collapsible Developer Debug accordion, and live GitHub Releases viewer + one-click self-updater. - 11-Locale Full-Stack Localization - Full UI, pet pack names, approval bubble buttons, and right-click context menu translations for 11 locales: English, 简体中文, 繁體中文 (TW), Français, Deutsch, 日本語, 한국어, हिन्दी, ไทย, Español (ES), and Español (MX). - Procedural Animation Engine, Tiered Boredom & Privacy-First Typing Rhythm - Smooth procedural breathing, parabolic roaming hops, damped squash-and-stretch bounce, BitmapScalingMode.HighQuality anti-aliasing, and a 3-tier boredom state machine (0–2m breathing → 2–10m roaming & pixel cues ... / ? / ♪ → 10m+ sl
