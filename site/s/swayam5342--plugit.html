About plugit

Turn any REST API into a curated, safe MCP server from your terminal.

PlugIt reads an OpenAPI 3.0/3.1 or Swagger 2.0 spec (or a Postman v2 collection) and serves the operations you pick as MCP tools over stdio, for Claude Desktop, Claude Code, OpenAI Codex, Cursor, VS Code (GitHub Copilot), Windsurf, Gemini CLI, LM Studio and any other stdio MCP client.

- Local only. One binary. No accounts, no hosted backend, no LLM calls, no telemetry. - Safe by default. Read-only mode, private-network blocking, credentials bound to the base URL you pin, secrets only from the OS keyring or env vars, and redaction everywhere. - Curated. Pick, rename and describe tools in a terminal UI with a live token budget, so a 1,000-operation API doesn't flood the model's context. Keep only the response fields you need, and lint every description for instructions hidden in a spec. - Observable. A live call inspector, per-tool stats and a one-shot try command, all with secrets masked.

Status: v0.1.0, the first release. The CLI and the plugit.yaml format may still change before 1.0; config changes come with a version bump and an automatic migration.

This needs Go (any recent version fetches the 1.26.7 toolchain plugit asks for) and puts plugit in ~/go/bin (%USERPROFILE%\go\bin on Windows), which should be on your PATH. Without Go, download the archive for your platform from the latest release and put plugit on your PATH. Builds exist for Windows, macOS and Linux on amd64 and arm64.
