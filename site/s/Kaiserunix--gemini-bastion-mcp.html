About gemini-bastion-mcp

Built for Web Gemini (gemini.google.com) Connected Apps, Claude.ai Custom Connectors & ChatGPT MCP Connectors — NOT Gemini-Only.

Live Showcase · Why This Exists · Architecture · 10 Tools & Memory · Gem Prompt & MCP Prompts · CI Watchdog · Quick Start · Security v2 · MCP Registry · Docs

- 100% Standard Remote MCP for Web Gemini, Claude.ai & ChatGPT: Named GeminiBastionMCP because it conquered gemini.google.com Connected Apps' strict OAuth 2.1 DCR rules first (16 redirect URIs, 8KB state, RFC 8707/9728) — while speaking pure MCP 2025-11-25 Streamable HTTP for Claude.ai Custom Connectors, ChatGPT MCP Connectors, Cursor & MCP Inspector. - Code, Test & Deploy from Mobile or Any Browser: Sync GitHub repos, explore AST/files (ripgrep, ast-grep, repomix), apply atomic multi-file patches, and run L0/L1/L2 checks inside a per-workspace bwrap FS & network jail (--unshare-net by default). - Pluggable Multi-Agent Drivers & 1-Gate Blast Radius: Delegate background tasks to OpenAI Codex SDK, Claude Code CLI, Gemini CLI, or OpenCode CLI (workspaceexec auto-promotes after 15s), with zero gateway secret leakage and every external write funneled through one single approval gate (publishchanges).

[!TIP] Skip the build! Pull pre-built multi-variant GHCR images (ghcr.io/kaiserunix/gemini-bastion-mcp:lite ~350MB or :full) and launch in under 60 seconds with docker compose pull && docker compose up -d.
