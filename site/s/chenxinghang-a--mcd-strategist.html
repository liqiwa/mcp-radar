About mcd-strategist

能力 命令 说明 --------- 🎯 省钱雷达 mcd radar --budget 30 菜单 + 麦麦省券 + 门店券，自动生成候选组合并逐个调 calculate-price 比价，给出预算内最优方案 🧾 一句话点餐 mcd order "来份巨无霸套餐加薯条" 自然语言解析 → 选店 → 计价，默认 dry-run，--confirm 才真实 create-order 🥗 营养把关 mcd nutrition 麦辣鸡腿堡套餐 基于 list-nutrition-foods 的能量/钠/脂肪阈值评估 + 同类替换建议 📰 麦门日报 mcd brief 活动日历 + 可领券 + 积分 + 积分抽奖，一站式早报 🎰 积分抽奖 mcd lottery 活动状态 + 奖池 + 我的奖品；--draw 抽奖（默认 dry-run，--confirm 才真实消耗积分） 🛠️ 连通自检 mcd tools 列出麦当劳 MCP 全部 33 个工具 🎬 离线演示 mcd demo 没有 Token 也能预览全部能力（内置模拟 MCP）

- "预算 30，吃什么最划算？" → radar 直接给出排序结果和券的用法 - "巨无霸套餐加薯条，多少钱？帮我下单" → dry-run 先看价，确认后才真下单 - "汉堡套餐都超热量参考值吗？" → nutrition 逐项把关，还给替换建议

打开 麦当劳 MCP 开放平台 → 手机号验证登录 → 右上角「控制台」→ 点「激活」→ 复制 Token。

麦门军师本身也是一个 WorkBuddy Skill。把本仓库克隆到本地后，在 WorkBuddy 的连接器配置里加入麦当劳 MCP（配置见 mcp-config.example.json），即可在对话里直接说：

- 价格以 MCP 为单一真源：所有"多少钱、省多少"都由麦当劳 calculate-price 算，本地只做候选生成和排序，不自己造轮子。 - 限流友好：官方限额 600 次/分钟。客户端内置 8 QPS 限速 + 429 退避重试；雷达按券面估算价值先排序、每个组合最多试 6 张券，mock 菜单实测约 77 次 calculate-price（具体次数随真实菜单和券包变化）。 - 字段宽松解析：MCP 未公开各 Tool 的 JSON schema，models.py 对字段名做多候选容错（如 totalPrice/originalPrice/totalAmount…），换字段名不崩。 - 默认安全：create-order 必须显式 --confirm；auto-bind-coupons 必须显式 --bind；Token 只从环境变量读，仓库里只有占位符。 - 离线可测：内置 mock MCP（测试替身），77 条 pytest 全离线运行，CI 无需任何密钥。

本项目真实调用麦当劳 MCP（https://mcp.mcd.cn）的工具共 15 个，覆盖点餐全链路。每个工具的用途、参数与调用时机详见 MCPINTEGRATION.md。
