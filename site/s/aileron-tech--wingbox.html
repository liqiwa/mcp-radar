About wingbox

Wingbox: Code Graph and Blast Radius Analysis for AI Coding Agents

AI agents should know what their changes will break before editing code.

Wingbox builds a local code graph of your repository so that AI coding agents and developers can see dependencies, call flows, architecture boundaries and the blast radius of a change before editing code. It works as an agent skill in Claude Code, Codex, Gemini CLI, Cursor and GitHub Copilot, as an MCP server for any MCP client, and from the command line. It supports Python, TypeScript, Rust, C, Java, Go, Ruby, Rails, PHP, Laravel (Blade, Livewire), Dart, Flutter, Free Pascal, and Lazarus.

Runs fully locally: no network access, no model, no telemetry. It can be used inside a security perimeter and on a machine with no internet.

Website: wingbox.dev: benchmarks with charts, a sample report and the live map.

Install: pipx install wingbox && wingbox install PyPI: the command, then the skill, an always-on block and a search hook for every coding assistant on the machine. Then type /wingbox in your agent.

The graph keeps itself fresh: in Claude Code a hook marks every edited file, and the next search patches only those files into the graph (about a second on a 1,200-file project); changes made by git or an editor are found too. See Keeping the graph fresh.

Skill only: npx skills add aileron-tech/wingbox skills.sh
