About Skills_MX

Plugins de Claude Code, skills y MCP servers para operar una PyME o profesión en México: CFDI 4.0, SAT, nómina e IMSS, pagos, marketplaces, trámites estatales y municipales, y 40 verticales por industria.

------ Plugins verticales 40, cada uno con sus skills, comandos, agentes y MCPs Skills 342 (6 base en shared/ sincronizadas a cada plugin) MCP servers 83 en Python + FastMCP, 417 tools Workflows ejecutables 26 (.workflow.js) Hooks de Claude Code 17 scripts, 12 registrados en .claude/settings.json (validación de timbrado, bitácora, alertas) Webhook receiver FastAPI con 12 handlers (Stripe, Mercado Pago, Conekta, Facturama, WhatsApp…) Calidad 1,900 tests, 285 evals de triggering, casos golden de cálculo fiscal, CI en cada PR
