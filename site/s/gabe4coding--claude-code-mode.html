About claude-code-mode

Stop flooding Claude's context with MCP results.

code-mode is a Claude Code plugin. Claude writes one JavaScript program that calls your MCP tools in a sandbox, filters and joins the data there, and sends back only the answer.

Install · Demo · Example · How it works · Config

Needs Claude Code and Node.js 22.13+. No dependencies. In a Claude Code session:

Start a new session and ask for anything that needs several MCP calls. Using auto mode? Add allow rules first: Permissions.

https://github.com/user-attachments/assets/468c412f-ecae-4e04-a53b-8a291561a052

Without code-mode With code-mode --- --- Claude calls tools one by one Claude writes one program Every full result lands in context Results are filtered in a sandbox Context fills with raw JSON Only the answer comes back

- Fewer tokens. Intermediate data never enters the context. - Sandboxed. Separate Node process, no file system, CPU limit. No network on macOS and on Linux where unshare -rn works. - Learns your tools. Hints per MCP server (formats, required args, limits). Claude proposes fixes. You approve. - Reusable functions. Programs that work can become saved functions for later sessions, after you read and approve the code. - Your permissions still apply. Every MCP call inside the program gets the normal permission check.

"Which of my open Jira issues have no update in the last 14 days?"

Claude sees a short list of keys and titles, not every full issue.
