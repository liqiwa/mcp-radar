About poo

Find and safely free the disk space your dev work eats.

A menu bar app and CLI for macOS, with an MCP server and skill for your coding agent.

Website · Download · Install · Rules and mods · Contributing

App: download Poo.app, unzip it and move it to Applications. macOS 15 or later, Apple silicon or Intel. Signed and notarized by Apple.

Installs poo into ~/.local/bin (sha256-verified). Add POOAPP=1 before sh to install Poo.app too. Already have the app? Use Poo › Install Command-Line Tool instead: it links the app's own CLI, which updates with the app. The CLI also runs on Linux.

These links always point at the latest release.

------ Poo.app (universal, CLI included) Poo.app.zip CLI, macOS Apple silicon poo-aarch64-apple-darwin.tar.gz CLI, macOS Intel poo-x8664-apple-darwin.tar.gz CLI, Linux x8664 poo-x8664-unknown-linux-gnu.tar.gz CLI, Linux arm64 poo-aarch64-unknown-linux-gnu.tar.gz Checksums SHA256SUMS

Updates are automatic. The app checks daily and installs updates through Sparkle when it's idle (or Poo › Check for Updates). The script-installed CLI updates itself in the background once a day; poo update updates now, and poo config set updates.auto false turns that into a one-line hint.

- App: open Poo. Setup takes about a minute: confirm the folders that hold your projects, optionally grant Full Disk Access, and choose whether to run nightly cleanups.
