About MDTI

12 道题，测出你的麦当劳点餐人格。 测完不是给你一个标签，是给之后每一次点餐换一个 agent。

MDTI（McDonald's Type Indicator）是一个跑在麦当劳 MCP 上的 Agent Skill：12 道二选一题 → 四轴十六型 → 四个策略开关直接改变 agent 点餐时的候选池、排序键和说话方式。

1. 类型是算出来的，不是编的。 12 个答案进确定性脚本，同一组答案永远得到同一个类型，模型无权改判。 2. 类型是配置，不是装饰。 四个轴各自对应一组 MCP tool 调用：算型必须走券 + 实算价，感型只给结论；控型必须核算热量，纵型不看热量。 3. 价格必须落地。 任何金额都来自 calculate-price，不口算、不估算、不编优惠。

它解决的不是「吃什么」，是「每次都要重新做二十个决定」。测一次，以后这类决定交给一个有你性格的 agent。

- 每天中午纠结五分钟的打工人：想要一个替自己做决定的东西，而不是再刷一遍菜单。 - 在意热量但懒得算的人：控型人格会在预算内挑热量更低的组合，并把每一层的热量摊开给你核对。 - 预算敏感的学生党 / 刚毕业的人：滑块定预算，方案贴着预算走，还能自动用掉可用的券。 - 一群人点餐时的组织者：群型人格按「人均」和「份量」出方案，避免一个人替全桌做二十个决定。

类型 默认预算 ------ 热量会计（控·算） ¥26 麦星吞噬者（纵·感） ¥58 团餐管家（群·算控） ¥120

性格还决定四个方案落在预算的哪一侧：控型扎堆在下方，纵型贴着或略微超；算型把落点收紧到预算附近，感型铺开。
