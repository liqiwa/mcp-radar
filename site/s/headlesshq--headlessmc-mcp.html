About headlessmc-mcp

HeadlessMc - MCP An MCP server for HeadlessMc: install, launch and control Minecraft: Java Edition from AI agents.

[!WARNING] This is a prototype. We are looking forward to feedback and feature requests.

With this MCP server, Claude Code, Codex, Cursor and other MCP clients can:

- install vanilla, Fabric, Forge and NeoForge versions, Java, and mods from Modrinth (everything HeadlessMc can do), - launch several clients and servers at the same time, optionally headless (no display or GPU, e.g. in CI or Docker), each client in its own profile (game directory with its own mods, config and worlds), - control running clients: read the screen, click buttons, type, chat, run commands, connect to servers, etc. - read the logs of every instance and send console commands to servers.
