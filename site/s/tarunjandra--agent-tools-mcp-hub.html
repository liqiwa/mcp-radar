About agent-tools-mcp-hub

A curated, plug-and-play collection of AI Agent Tools, Model Context Protocol (MCP) servers, and integration connectors for modern AI agents (LangChain, CrewAI, AutoGen, OpenAI Swarm).

Building AI agents requires connecting them to real-world APIs, tools, and databases. This repository provides: - 🧩 Zero-conflict Modular Tools: Every tool lives in its own standalone directory (tools//). - ⚡ Multi-Language Support: Implementations in Python, TypeScript/Node.js, or Go. - 🔌 Universal Compatibility: Compatible with Model Context Protocol (MCP), OpenAI Function Calling, and LangChain Tools. - 🤝 Beginner-Friendly Open Source: Ideal for first-time and seasoned contributors alike.
