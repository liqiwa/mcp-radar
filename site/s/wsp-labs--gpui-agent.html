About gpui-agent

See and drive a GPUI app from the command line, the way agent-browser drives a web page. Built for coding agents that need to check the UI they just wrote.

Every line names the source location that built the element, so an agent goes straight from what it sees to the code that drew it.

Recorded with gpui-agent record under Xvfb, from the app's own frames.

A GPUI window is one GPU surface. There is no DOM, no Chrome DevTools Protocol, nothing for Playwright to attach to, and GPUI's accessibility tree only lists elements an app has labelled by hand. gpui-agent adds a small record to GPUI of what each frame drew, serves it from inside the app, and gives agents the commands they know from browser automation:

- an outline of the screen with refs, roles, text, states and source locations - clicks, typing through the app's own text input handlers, keys, scrolling, drags - waits for elements, text and a still frame - screenshots and recordings rendered by the app itself, so they work under Xvfb, on a locked Mac, and in CI without a GPU - prompts and open or save panels the agent can answer - GPUI actions by name, and probes for app state - a command line for scripts and tests, and the same commands as an MCP server

The command line does not depend on GPUI and builds in under a minute.

Headless runs start a private Xvfb, and recordings use ffmpeg:

For software rendering on machines with no GPU, also install mesa-vulkan-drivers (lavapipe).
