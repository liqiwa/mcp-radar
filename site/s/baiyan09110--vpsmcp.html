About vpsmcp

Two MCP connectors for your own VPS: one that lets an LLM look, and one that lets it fix things — with the second one wrapped in every guardrail we could think of.

中文摘要：給你的 LLM 一雙眼睛和一雙手。vps-look 是只讀的狀態連接器 （固定工具、白名單、輸出打碼）；vps-do 是能執行命令的工作連接器， 但默認關閉、開工前先備份、每條命令執行前先 Telegram 報備（發不出去 就拒絕執行）、兩小時自動停止、全程審計。另附可選的 Telegram 門鈴， 發數字暗號即可開關 vps-do。細節見各子目錄的 README。

Most of us who run a personal server eventually want the same two things from an AI assistant:

1. "Is everything OK on my box?" — a question that needs eyes. 2. "It's broken — go in and fix it." — a request that needs hands.

The naive version of (2) is a root shell behind a chat window. The naive version of (1) quietly becomes (2) the first time someone adds "just one little write tool". This repo keeps them separate, on purpose:

vps-look vps-do --------- purpose status, logs, health diagnose & repair powers fixed read-only tools, allowlists everywhere one shell tool, full sudo runs always on off by default, 2h auto-stop before acting — backup + Telegram report, or it refuses to start per command call log (tool + params only) Telegram announcement before (fail-closed), report after, append-only audit log worst accident it reads something it shouldn't (outputs are secret-redacted) it does something it shouldn't — see the warnings in do/README.md

And an optional third piece, the doorbell: send a numeric code to your Telegram alert bot to start/stop vps-do without an SSH session. It only listens to your chat id, ignores stale messages, and announces everything it does.
