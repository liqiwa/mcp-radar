About Stringhand

一把由本地浏览器持续演奏、Agent 提前交付乐句意图的吉他。包含完整前端 PWA、九个 MCP 工具、规则式 Guitar Brain、真实采样、听唱反射、曲谱库、录音与离线原创谱渲染。

0.2 更新：共享实时/离线编配器、持续低音与空弦共鸣、逐颗冲突日志、17 根音完整尾音采样、柔化勾弦/滑音，以及离线并联房间混响。见 编配指南 与 音色说明。编配自然度仍有改进空间。

需要 Node.js 22+、Python 3.10+、FFmpeg（带 libmp3lame）在 PATH。采样已包含，无需下载或调用音乐生成 API。

打开 http://localhost:3072/guitar/，输入 GUITARBROWSERKEY。浏览器只保存 HttpOnly 会话 cookie，不把控制密钥放到前端。选择曲目或即兴，然后点击递琴，首次点击解锁音频。麦克风拒绝授权时仍可手动等我、继续、结束。

可选 Docker：配置 .env 后 docker compose up --build -d。容器包含 Node、Python、FFmpeg，数据通过独立 volume 持久化。Docker 配置随包提供；验证范围见 docs/VALIDATION.md。

手机需要 HTTPS。把 GUITARORIGIN 改成实际 HTTPS origin，使用 ops/nginx.conf.example 将 /guitar/ 反代至本机3072，保留 Host/Origin 与 WebSocket。勿将 /control/ 暴露到公网。已有网站可用普通菜单链接 /guitar/ 嵌入；无需原作者的主页或登录服务。

复制并修改 mcp.example.json 中 Python 和脚本的绝对路径，在客户端设置单独的 GUITARCONTROLKEY，它必须与服务端一致。MCP 的 GUITARCONTROLURL 默认 http://localhost:3072；浏览器使用公网 HTTPS 时，MCP 仍可走本机地址。远程 Agent 可通过 SSH 隧道访问控制端；浏览器反代需保持配置的 Host。

九个工具：start / intent / wait / state / stop / fill / hold / tease / score。

页面递琴后，Agent 调用 state 读取 songId、sessionId 与和声预览，再 start。即兴建议一次提交开场：

Agent 只提前排未来一两句；错过边界即拒绝。没有新意图，重复上一句而不停止。wait 使用 cursor 与长等待，可加 untilphrase/sessionid。守拍、扫弦、反射全部本地执行。stop(style="natural") 自然收尾。

递琴通知为可配置功能：设 GUITARHANDOFFURL，可另设 GUITARHANDOFFTOKEN。点击后服务端 POST {"text":"演奏上下文与工具用法"}，接收方返回2xx表示成功。没有 webhook 时页面仍能递琴，Agent 手动 state/start；不伪造通知送达。含糊失败不自动重复发送。通知不含私人歌词。测试与示例不会向真实 Agent 发消息。
