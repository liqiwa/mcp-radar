About mcd-calorie-architect

🍟 麦门卡路里精算师（McDonald's Calorie Architect）

输入「热量预算 + 想吃什么」，AI 用麦当劳官方 MCP 的真实营养数据，算出在热量、蛋白质、预算三重约束下的最优配餐， 再告诉你这顿吃完要跑几公里。

基于 麦当劳中国官方 MCP 服务 开发的参赛 Skill —— 2026 麦当劳程序员创意开发大赛。

⭐ 本仓库正在参加 2026 麦当劳程序员创意开发大赛，比赛排名唯一依据就是 GitHub Star 数。 如果这个配餐求解器的思路对你有用，麻烦点一下页面右上角的 Star —— 这是支持它的唯一方式，也是决定它排名的那一票。 看完感兴趣的话，Issue 区欢迎聊约束求解和营养数据的对齐问题。

「吃麦当劳」和「控卡健身」一直是两件打架的事。大家讨论得最多的是怎么点最省钱， 但另一批人真正的问题是：怎么点才不胖。

官方 MCP 里有一个 list-nutrition-foods（餐品营养信息列表），官方描述写着 「需要帮助用户搭配指定热量套餐时使用此工具」——零参数调用，一次性给出 160 条常见品的完整营养明细 （能量 / 蛋白 / 脂肪 / 碳水 / 钠 / 钙）。

所以差别不在「要不要算热量」，而在怎么算：让模型凭印象给一个热量数字是免费的， 但那个数字不可复算。这里把真实营养数据作为输入，在本地做一道带约束的组合优化—— 结果可复算、可验证，并用 20 项自测兜底。

和其他配餐 Skill 的区别：第一约束是热量和蛋白质，价格是第二约束，钠始终跟着输出；三者的取舍会被显式算出来，而不是被藏起来。

模式 你说 它做 --------- 🧮 卡路里配餐 "午餐 600 大卡怎么吃" "今天练腿，蛋白要 40g" 拉真实营养数据 → 约束求解 → Top3 方案（热量/蛋白/脂肪/碳水/钠/价格全列出） 🔥 运动换算 "这顿要跑几公里" 翻译成跑步/快走/骑车/游泳/跳绳的分钟数、公里数、步数 💰 双目标 "600 大卡以内，最好别超 35 块" 热量与预算同时约束 🛒 确认下单 "就按方案 2 下单" 复核价格 → 明细确认 → 确认后才下单 ☀️ 每日轻食播报 "麦麦轻食早报"（可挂定时任务） 今日活动 + 低卡推荐 + 积分提醒
