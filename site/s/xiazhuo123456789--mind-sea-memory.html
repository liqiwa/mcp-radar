About mind-sea-memory

记忆星海：给任何 AI 机器人的跨会话长期记忆 + 3D 记忆星海可视化。不绑定某一款机器人——SnowLuma / NapCat / qq-bridge / SurfCore / DSH / AstrBot，能发 HTTP 就能接。

v1.2.0：五路混合召回 + 2 跳图扩散 + 双时间线 + 分层遗忘（频率感知 / 干扰加速 / 情绪巩固）+ 规则自动冲突检测 + 永久规则层 + 承诺自动认领与闭环（中文时间解析）+ 开机包 /boot + 反思洞察 + 证据链溯源 + 时间窗口召回 + 违规巡查。核心机制见 docs/FEATURES.md，完整接口见 docs/INTEGRATION.md。

给 AI QQ 机器人一副跨会话的长期记忆。 零依赖 · 单文件部署 · 自带"大脑"可视化面板。

她不再隔一天就忘了你。她记得你不吃香菜、记得约好周五开黑、记得她上周读《三体》—— 而且群里绝不知道你们私聊说过什么。

现状 装上本引擎 --- --- 隔一天就失忆 跨会话记住长期事实、约定、偏好 上下文越滚越长，越来越贵 每轮只注入 ≤1400 字节的相关记忆，成本恒定 群里随口说出私聊的秘密 owner + visibility 双重隔离，隐私红线写进引擎 "最近/怎么样"这类虚词干扰检索 停用词 + IDF 加权，问"团子最近怎么样"就命中团子

与链路无关：只要求"客户端能把请求发给我"，不管你用 SnowLuma / NapCat / Lagrange， 不管桥接是 qq-bridge 还是 SurfCore。

- 完整部署手册：docs/DEPLOY.md - 丢给 AI 让它帮你装：docs/AIDEPLOYPROMPT.md（整段复制给任意 AI 即可） - 接口与接入：docs/INTEGRATION.md

接入（OpenAI 兼容代理）：在 config.json 里填 upstream（你的 DeepSeek Key）， 然后把客户端的 baseurl 改成 http://127.0.0.1:8790/v1。之后每一轮对话：

1. 自动检索相关记忆，注入 system prompt 2. 转发给真正的模型 3. 自动把值得记的内容写回记忆库

请求必须带 user（如 "qq:10001"），群聊另带 x-channel: group 与 x-group: 群号。 不带 user 会返回 400——这是为了不让所有人的记忆混在一起。

- 力导向实时图：记忆按类型着色（事件/事实/偏好/关系/技能/元记忆），实体按提及次数变大 - 拖拽节点、滚轮缩放、点节点看她记得的原文 - 顶栏 KPI：记忆数 / 实体 / 关系 / 被想起次数 / 已遗忘 - 一键夜巡：衰减 → 归档 → 合并 → 清除，当场报数字

1. 被想起 = 续命：命中的记忆刷新 lasthit，半衰期重新计算（间隔重复效应） 2. 性格底色永不淘汰：pin 的记忆（称呼/账号/约定）不参与衰减；夜间整理跳过 3. 隐私优先：visibility=private 的记忆在任何群聊场合都召不回——这条在引擎里，不靠提示词

kind 含义 例 --- --- --- episode 发生了什么 周五晚九点约好开黑 fact 事实 养了只叫团子的橘猫 preference 偏好 不吃香菜 relation 关系 小美是老王的妹妹 skill 学会的做法 他说困了就该劝睡觉 digest 元记忆 【昨日三件事】…（夜巡产物，永不衰减）
