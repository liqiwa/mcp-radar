About nimbalyst-wiki

A local wiki your coding agents write for you, so you can think, organize, and set direction.

A Claude Code and Codex plugin that turns your sessions into a markdown wiki in your repo, with every decision recorded in the page it affects.

Get started &nbsp;·&nbsp; Demo &nbsp;·&nbsp; Features &nbsp;·&nbsp; Teams &nbsp;·&nbsp; FAQ &nbsp;·&nbsp; Reference &nbsp;·&nbsp; Contribute &nbsp;·&nbsp; Website

Overwhelmed and disorganized working with agents? Your agent distills what you worked on into a wiki of plain markdown files: a Home page, the decisions you made and why, open questions with owners, and the things you track. You read and edit it in your browser, and every agent you use works on the same files.

Files in your repoText pages are markdown files in your project. By default the wiki lives in nimbalyst-local/wiki, kept out of git so it stays private to you. Put it in a checked-in folder like docs/wiki to diff and commit it like code. Stays on your machineA local wiki needs no account and no server. The browser view listens on your machine only and is protected by a token.

One wiki across every agentClaude Code, Codex, Cowork, Cursor and VS Code all use the same tools on the same files, so you can switch agents without losing what they wrote. Drawings, sheets and mockups tooDrawings, mind maps, spreadsheets, data models, mockups and canvases are pages too. Each keeps its own file, such as .excalidraw, .csv, .prisma or .mockup.html, so other tools can still open it.
