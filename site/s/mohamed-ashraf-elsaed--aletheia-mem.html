About aletheia-mem

A free, local memory and rules hub for AI coding tools.One store on your machine. Any tool reads it over MCP, REST or the CLI.

Install and run. Bun 1.1 or newer is required; the CLI runs on Bun, not Node.

~~~bash npm install -g aletheia-mem aletheia-server open http://127.0.0.1:37790 ~~~

Status: alpha. The memory engine and the installers work in tests. The real Claude Code, Command Code, Codex CLI and OpenCode listed the generated MCP config, but no hook or session has run inside any tool yet, and answer accuracy is not measured. CI runs on Linux and macOS; Windows is not supported yet and not tested.

Aletheia is a free, local memory and rules hub for AI coding tools. One SQLite store is read by any tool over MCP, REST or the CLI, and your rules are written into each tool's own instruction file.

Every coding agent forgets between sessions, and each one remembers differently. Aletheia keeps the memory and the rules once, on your machine, and lets each tool read them in the format it already understands. There is no account, no telemetry and no network call unless you configure a model provider. It listens on loopback only.
