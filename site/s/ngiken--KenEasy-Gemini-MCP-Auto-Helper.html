About KenEasy-Gemini-MCP-Auto-Helper

An intelligent automation extension tailored for Google Gemini web UI: auto-approves MCP tool permissions with "Always allow", auto-clicks "Continue / Yes" follow-up chips, supports 4 languages (简体/繁體/EN/日本語) and Dark/Light theme modes, features a hold-to-drag floating HUD, one-click desktop notifications, multi-window &amp; non-chat guards, and a 6-layer anti-loop circuit breaker.

[!WARNING] ⚠️ Beta Release Notice (v0.3 Beta Preview) This extension is currently in Public Beta Preview (v0.3 Beta). While the core automation engine, 6-layer circuit breaker, hold-to-drag HUD, multi-language &amp; dark/light themes, multi-window guards, and desktop notification subsystems have passed 100% of the automated & VM end-to-end test suites (64/64), Google Gemini (gemini.google.com) continuously updates its Material Web Components and DOM layouts. - If you encounter unrecognized confirmation dialogs or unexpected behavior, please submit feedback or screenshots on GitHub Issues, or add custom terms in the "Custom Keywords" section of the popup settings. - Star 🌟 and PR contributions are warmly welcomed!
