About restic-tray

Pure-Rust Windows system tray app for client-side encrypted periodic backups to Cloudflare R2 with Restic and a built-in 22-tool MCP server.

English 日本語 &nbsp;&middot;&nbsp; Website &nbsp;&middot;&nbsp; Documentation

Restic Tray periodically backs up your working folders — including uncommitted changes, binary assets, and non-Git projects — to your own Cloudflare R2 bucket, encrypted client-side on your PC by restic before upload. Because the destination is a standard restic repository, you can inspect and restore your backups directly with the restic CLI even if this app no longer exists.

[!NOTE] - Unofficial software: Restic Tray is an independent open-source project and is not affiliated with, endorsed by, or sponsored by restic or Cloudflare. - UI language: The desktop GUI and built-in MCP tool descriptions are currently Japanese only. Localization is not yet implemented. - Platform: Windows 10 / Windows Server 2016 or later (x64) only, with TLS 1.2 or later required (required by bundled restic.exe v0.18.0+). - AI-operated maintenance: This repository is managed by AI maintainers under the owner's (@nayuengin) direction (see AGENTS.md). AI-assisted contributions are welcome with PR disclosure (see CONTRIBUTING.md).
