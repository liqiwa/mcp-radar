About secret-mask

Mask the secrets in a project before AI agents (or anyone) see it, and restore them exactly afterwards.

- Detects secrets with gitleaks, embedded as a library (one static binary, no external tools), plus strict rules for passwords people choose themselves. Your .gitleaks.toml and .gitleaksignore are honored. - Masks every occurrence with a stable placeholder such as SECRETMASK8656926daa6d6f8c; the same value gets the same placeholder everywhere. - Encrypts the originals into .secret-mask.vault with your password (AES-256-GCM, PBKDF2-SHA256 600k). - Restores byte-for-byte, even if placeholders were moved to other files, while keeping other edits. - Guards AI agents (Claude Code, Codex, Gemini CLI, Cursor, VS Code / Copilot): secret-mask install adds a hook that blocks reading files that still contain unmasked secrets, an MCP server that tells the agent what to ask you (mask first, unseal at the end) and lets it read and add detection rules, and a skill with the rules. - Guards commits: secret-mask protect adds a git pre-commit hook that refuses, or masks, staged secrets.

One line (macOS, Linux; Windows via Git Bash) — downloads the release binary, verifies it against SHA256SUMS, installs it to ~/.local/bin and runs secret-mask install to set up your coding agents:

Options (after sh -s --): --dir PATH, --version vX.Y.Z, --clients claude,codex, --no-hooks, --skip-config (binary only).
