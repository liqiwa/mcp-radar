About Mac-health-mcp

Asks your Mac what's wrong and tells you in plain English. The explanation comes first, then the numbers behind it.

A Model Context Protocol server that lets Claude Desktop, Claude Code and other MCP clients check your Mac's health: uptime, memory, disk, busy processes, Spotlight, heat, battery and startup items. Ask "Why is my Mac slow?" and Claude gets a ranked list of likely causes, each with a plain explanation, the number behind it and what you can do. Local, read-only, zero dependencies.

Option A: Claude Desktop, one click (recommended)

1. Download mac-health-x.y.z.mcpb from the latest release on GitHub. 2. Double-click the file (or drag it into Claude Desktop, or use Settings → Extensions → Install Extension…). 3. Click Install, then ask Claude: "Why is my Mac slow?"

Claude Desktop runs the extension with its own built-in Node.js, so nothing else needs to be installed.

Download or clone the repository to a permanent folder. No npm install is needed (there are no dependencies). Replace /path/to/mac-health-mcp below with the real folder.
