About mcp-spec-nav

mcp-spec-nav — MCP Server for AI Code Search and Navigation

mcp-spec-nav is a local MCP server for AI coding agents to search code, discover reusable functions, and find callers before making changes. Use it with Claude Code to explore logic across services and shared packages in your repository.

Giúp AI tìm hàm có sẵn trước khi viết code mới, đọc implementation và tìm các nơi gọi hàm trước khi sửa code trong repo.

帮助 AI 在编写新代码之前查找已有函数，阅读实现，并在修改代码之前找出仓库中的调用方。

Example: Before adding an order fee calculation, ask your agent to find and read existing fee functions. Before changing a function's parameters, ask it to find callers and report any unresolved references.

Benchmarks: See the benchmark methodology and limitations (Tiếng Việt · 简体中文) and recorded results for comparisons with a Grep/Read/Edit baseline. These benchmarks use deterministic agent policies, not live LLM sessions.

Get started: Claude Code setup · Claude Desktop extension

Scenario Value of the MCP ------ Logic is spread across multiple services High: searches broadly and helps reduce missed code. You want to reuse functions instead of rewriting them High, when the query finds the right candidates. You change function parameters and need to find callers Useful. You make a simple edit within one file Limited benefit; may add tool calls.

Trường hợp Giá trị của MCP ------ Logic nằm rải ở nhiều service Cao: giúp tìm rộng, giảm bỏ sót Muốn tái sử dụng hàm thay vì viết lại Cao, nếu truy vấn tìm đúng ứng viên. Sửa tham số hàm, cần tìm callers Hữu ích. Sửa đơn giản trong một file Lợi ích ít, có thể thêm lượt gọ
