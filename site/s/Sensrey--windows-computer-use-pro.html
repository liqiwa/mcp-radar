About windows-computer-use-pro

Windows Computer Use Pro (Enhanced Windows-MCP v3.1)

高精度、零锁死、工程级安全的 Windows 桌面自动化 MCP 服务端与 Agent Skill 套件。 High-precision, zero-lockout Windows desktop automation MCP server & agent skill kit — built for Google Antigravity, Claude Code, OpenAI Codex CLI, Cursor, and any MCP-compatible AI agent.
