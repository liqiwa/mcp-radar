About android-use

Your agent. Now on Android.Use it in Dim Agent. Follow the live screen. Add Jev when you need it.

English · 简体中文 Use in Dim Agent → · Download v0.7.0 · Set up Jev · User guide · Report an issue

Android Use brings your own Android phone or emulator into Dim Agent, with standard MCP support for other compatible clients. Read the screen, find a control, tap, type, scroll, and check the result. Follow the process in a live phone view.

For workflows that need repeated UI decisions, enable Jev. Your Agent keeps planning and final verification; Jev selects the next candidate; Android Use validates and executes it.

“Open Settings, find Battery, and read the current usage.”

“Fill in the profile with the text I provide, verify it, and save a local draft.”

No root, Appium, signing setup, or keyboard APK. The compiled UI is included. Use USB or already-authorized wireless ADB.

The standalone runtime is optional. The Agent inspects the environment and chooses the appropriate route; a working installation is reused.

Environment Installation choice --- --- Existing healthy Android Use / MCP Reuse it and verify the connection. Python/uv, ADB and ffmpeg already available Use the source installation and existing tools. Dependencies missing, matching verified native assets available Use the optional standalone runtime to avoid installing dependencies individually. Offline, unsupported native target, or no native release assets yet Use a suitable local archive or source setup; report any missing prerequisites.
