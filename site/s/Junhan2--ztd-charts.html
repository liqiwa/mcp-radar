About ztd-charts

33 animated, interactive charts for React. Pure SVG, zero runtime dependencies. Draw from a single JSON spec, and let AI use it right away through the CLI, the MCP server and the agent skill.

Site: charts.ztd.app · Docs and gallery: charts.ztd.app/docs

Renamed from @junhanlee/chart-kit in 0.2.0. Install ztd-charts (and ztd-charts-cli, ztd-charts-mcp), and change CSS names from --ck-, .ck- and data-ck-theme to --ztd-, .ztd- and data-ztd-theme.

- One highlight tells the story. Only the item you highlight gets the accent color; the rest stay neutral. Every card has a number, a title, a gray subtitle, a small square legend, a bold one-line takeaway and a level badge (Basic, Intermediate, Advanced). - Motion shows the reading order. Charts sweep, fill and flow in when they scroll into view. When the data changes, they move on from where they are (a critically damped spring, so velocity carries over even mid-change). - Real data, right away. Connect with field names or functions, load from a URL or an async function, and get loading, error and empty states along with it. - English and Korean. English (en-US) by default. With locale="ko-KR" you get ko-KR number and date formats (1.2만, 3.4억, ₩5,000) and Korean chart text. Layout is tuned for Pretendard. - Accessible. Keyboard navigation, screen reader descriptions and data tables, reduced motion, and WCAG AA for all text.

The two default themes use the same colors as the landing page. Dark (the default) has ink cards with a lime accent; light has white cards with a sky-blue accent.
