About code-context-engine

Local-first MCP context engine that cuts AI coding-agent token cost by ~90% — a per-project code graph + folding for Cursor, Claude Code, Codex, and every MCP client. Built for web and ML codebases. Status: early — building P0: project isolation on top of the NeuroMesh v0.9.0 baseline.

Derivative of NeuroMesh by yoosef alipour (MIT). See NOTICE · ATTRIBUTION.md · ROADMAP.md.

Upstream NeuroMesh README (baseline v0.9.0)

Local-first MCP context engine for Cursor, VS Code, Claude, Codex, and every MCP client. NeuroMesh indexes your repo into a graph, routes your prompt to the right symbols, and sends a folded evidence packet — not thousand-line file dumps.

The pain · Fold · Galaxy · Measured · Install · Connect · Docs · Site

You ask a simple question in a large project. The editor copies two or three thousand-line files and ships them to the model.

1. Tokens you never needed — dollar cost on every turn 2. Seconds of fake loading while the window fills with helpers you will not touch 3. Lost in the middle — the model drowns in unrelated bodies and invents bugs
