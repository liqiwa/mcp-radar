About cloudpuls

Agentic multi-cloud FinOps, security auto-remediation and AI observability. MCP-native, with corrective RAG, a CNN anomaly detector, an LLM firewall and a human-approved agent swarm.

Live site (after you deploy): https://nikhil-creat.github.io/cloudpulse-ai/

CloudPulse Studio (new) Open studio.html: build apps from a prompt, generate and edit images, research with sources, track tasks, automate workflows, and run an agent that uses all of them. See docs/STUDIO.md.

Deploy live (Vercel, Cloudflare Pages or Render) See docs/HOSTINGOPTIONS.md, docs/VERCELDEPLOY.md and docs/CLOUDFLAREDEPLOY.md.

Vercel See docs/VERCELDEPLOY.md. Import the repo with Root Directory site, add GROQAPIKEY and GEMINIAPIKEY, deploy. The assistant then works for every visitor with keys kept server-side.

What's new in v2.2 Serverless LLM proxy, strict CSP, credentials section, live GitHub activity, command palette (Ctrl K), voice in and out, offline service worker, login lockout, audit-chain verification, AI alert explanations and weekly executive report.

What's new in v2 - Agentic AI: LangGraph swarm with a policy-as-code critic and one self-correction pass; conversation memory in Redis. - Corrective RAG: Qdrant retrieval, relevance grading, query rewrite and retry, seeded runbook knowledge base, offline recall eval. - CNN: PyTorch heatmap classifier plus a training script; the site shows layer-1 feature maps. - Security: LLM firewall (injection and secret redaction), indirect-injection fencing, TOTP MFA, rate limits, nginx edge, hash-chained audit log, STRIDE model. - FinOps: EWMA forecast, robust
