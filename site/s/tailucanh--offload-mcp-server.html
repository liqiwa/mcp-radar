Let your main coding agent delegate heavy reading to a second agent, and read back only the answer.

Claude Code asks. The Antigravity CLI reads 37 files. Claude reads 500 tokens.

Quick start · How it works · What to offload · Setup · Results · Troubleshooting · FAQ · Security

[!IMPORTANT] The official source is github.com/tailucanh/offload-mcp-server. The npm package is offload-mcp-server. A package or repository with a similar name is not this project.

Coding agents spend most of their context reading: walking a source tree, scanning logs, opening a minified bundle to find one function. When the answer is a paragraph and the reading is 40,000 tokens, that is a poor trade.

offload-mcp-server is a small MCP server that gives your main agent four tools to hand that reading to a second agent CLI running in the background, by default Google's Antigravity CLI (agy) with a read-only worker agent. The worker reads the files on its own quota and writes a fixed-format report. Your main agent reads the Summary (a few hundred words), and pulls the Findings with path:line evidence only when it needs them.

- Asynchronous. Submit a job, keep working, collect it later. Several jobs can run in parallel. - Read-only by design. The worker agent has file-reading tools only, and the server reports any file whose git status changed while a job ran. - Scoped.
