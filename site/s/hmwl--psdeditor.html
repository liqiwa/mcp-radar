About psdeditor

PSD Editor 是一个面向 PSD / PSB 文件的浏览器编辑器，同时提供 REST API、MCP 服务和本地 CLI。项目采用前后端同构的 PSD 内核：浏览器负责可视化编辑，Node 服务端负责文件处理、渲染、自动化接口与 AI 能力。

本项目仅供学习、研究与技术参考。请遵守当地法律法规、Adobe 软件许可协议及知识产权规定；严禁用于任何非法用途。详见文末免责声明。

PSD Editor 可以在浏览器中打开、编辑并导出 PSD / PSB 文档，也可以作为无头服务被脚本、自动化平台或 AI Agent 调用。

- 编辑器：图层、组、蒙版、混合模式、图层样式、文字、矢量路径、调整图层、滤镜、智能对象、画板、色彩管理、选区、画笔、修饰、液化、消失点等。 - 素材替换：替换智能对象源图，按覆盖模式渲染回智能对象；支持常规放置网格与画布变换。 - 导出：PSD / PSB、PNG、JPEG、WebP、TIFF，以及 PDF、GIF、BMP、TGA、HDR、EXR 等格式。 - API：基于 Express 的 REST 接口，覆盖解析、编辑、渲染、导出、字体、档位与权限。 - MCP：标准 Model Context Protocol Streamable HTTP 端点，方便 Claude、Cursor、VS Code 等客户端接入。 - CLI：不启动浏览器即可执行 inspect、render、batch、convert 等操作，也可作为 stdio MCP 使用。 - 本地 AI：可选的“重新打光”功能，模型在浏览器本地推理，不上传图片。

本项目只保留 编辑器、MCP 服务、API 服务 三项核心能力，不包含官网、文档站、在线调试台或示例 PSD 下载入口。

- 运行时：Node.js 20.11+ - 服务端：Express 5、Sharp、Multer - PSD 内核：纯 JavaScript，浏览器与 Node 共用 - 前端：原生 ES Modules、Canvas、WebGL / WebGPU、Web Worker - 接口：REST、OpenAPI 3.1、MCP Streamable HTTP - 测试：Node 内置测试脚本、Playwright（可选浏览器测试） - 本地 AI：ONNX Runtime Web、MediaPipe Tasks Vision

- Node.js = 20.11.0 - npm - 可选：Playwright + Chromium（运行浏览器测试） - 可选：ImageMagick、Python 3 等（部分测试会使用）

PSDEDITORAUTH=off 只允许在本机或可信内网使用。部署到公网前必须配置 API Key、HTTPS 与反向代理。

环境变量通过 shell、systemd、Docker 或进程管理器注入，.env.example 是完整变量清单模板。常用变量：

变量 说明 默认 --- --- --- PORT 服务端口 8787 MAXUPLOADMB 单文件上传上限（MB） 200 PSDEDITORAUTH off 关闭鉴权，仅限本机调试 空 PSDEDITORAPIKEYSFILE API Key 配置文件 server/api-keys.json PSDEDITORPLANSFILE 档位/权限配置文件 server/plans.json PSDEDITORSTATEDIR 运行状态落盘目录 server/data/state PSDEDITORPUBLICURL 对外访问地址，用于生成 MCP 下载链接 空 PSDEDITORCORSORIGINS 允许跨域的来源，逗号分隔 同源 PSDEDITORMAXCONCURRENT 重接口
