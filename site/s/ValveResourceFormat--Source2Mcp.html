About Source2Mcp

An MCP server that drives Source 2 games (CS2, Deadlock, Dota 2 and Half-Life: Alyx) through VConsole2, the console protocol of the engine. It injects no code into the game.

You need Windows, the .NET SDK and the game installed through Steam.

The default port is 13339. Add the server to Claude Code:

Tool What it does ------ launch Starts the game, loads a map and runs the setup. With tools, it starts the game in tools mode. map Loads a map and waits until the player is in the game. console Runs console commands and returns their output. camera Moves the camera and reads it back with getpos. In Dota 2, it only reads the camera. screenshot Saves what the game renders to a PNG file. cvars Finds cvars and commands, and marks hidden ones. getlog Returns recent log lines. getstatus Reports the process and the connection. quit Stops the game.

- The game always starts with -insecure and svcheats 1. - The server loads local maps only. console refuses connect, map, changelevel and quit. - The server does not change game files or the user's config.

1. Run noclip one time. 2. Run cldrawhud 0, rdrawviewmodel 0 and rdrawpanorama 0. 3. Set mattonemapforcemin and mattonemapforcemax to the same value. 4. Set hostframerate. Do not set hosttimescale 0.

The server uses the same position, angle and FOV conventions as the vrf server of Source 2 Viewer. To compare a frame:

1. Open dedust2 in Source 2 Viewer, and launch CS2 with dedust2. 2. Give the same position, angles and fov to camera in the two servers. 3. Take a screenshot in each, then use vrf.comparescreenshots.
