About McpNet

Windows 桌面網路分析與協定除錯工具，整合封包檢視、規則處理、插件擴充與本機 MCP 服務。

最新穩定版 平台 直接下載 全部版本 ------------ v1.1.2 · 啟動相容性修正（恢復穩定初始化、補強日誌） Windows x64 下載 McpNet-v1.1.2-windows-x64.exe 全部版本

下載成品請使用上表的 EXE 連結；GitHub 頁面上的 Source code ZIP/TAR.GZ 是原始碼，不是安裝程式。首次使用前請查看下方的系統需求及安全提醒。

McpNet 由 Go/Wails 桌面後端、Vue 3 介面與 McpNet 網路核心組成。它可檢視和處理 HTTP(S)、WebSocket、TCP、UDP 流量，並提供規則、腳本、使用者插件及本機 MCP 整合。程式啟動不會自動開始全系統攔截：流量監聽與系統代理由使用者分別控制。

新版採用方形透明底圖示，將「Net」字樣直接融入封包路徑與 MCP 連接節點；青綠漸層為主色，搭配白色連接點、黃色訊號段與深色描邊，讓網路抓包與 MCP 元素更清晰易辨。build/appicon.png 是預覽來源，Windows/Wails 使用的 .ico 資源同步更新為同一設計。

類別 功能 ------ 流量分析 HTTP/HTTPS 請求與回應、WebSocket 訊息、TCP/UDP 連線與資料檢視 規則與處理 Hosts、轉送／替換、請求與回應處理、憑證及腳本設定 擴充能力 Yaegi Go 插件、腳本範本、協定內容處理 hook MCP 整合 本機 HTTP MCP、狀態查詢、監聽控制、系統代理及 UI 命令工具 桌面介面 Windows、Wails v2、Vue 3、WebView2；繁體中文、簡體中文與英文

以下產品截圖用來直觀展示主要功能：進程攔截與附近應用清單、程式設定、多色系主題、本機 Go 插件編輯，以及 MCP 服務設定。

協定／介面 支援功能 條件與限制 --------- HTTP 請求／回應檢視、規則處理、插件 hook、內容編輯 流量須經過已啟用的監聽路徑 HTTPS / TLS TLS/HTTPS 處理、憑證管理 解密取決於 CA 信任、憑證釘選及應用程式行為 WebSocket 連線與訊息檢視、訊息 hook、編解碼處理 取決於代理路徑及啟用的規則／插件 TCP 連線與資料事件、轉送及腳本處理 取決於 Windows 驅動或代理設定 UDP 收送事件與插件 hook 擷取可能需要驅動、程序設定或代理 MCP JSON-RPC、工具呼叫、SSE、健康檢查 預設僅綁定 127.0.0.1:2026

MCP 端點：http://127.0.0.1:2026/mcp；健康檢查：http://127.0.0.1:2026/health。支援 initialize、ping、tools/list、tools/call，並提供狀態查詢、監聽啟停、系統代理、UI 命令及說明工具。mcpnetlistcaptures 可列出捕獲會話，mcpnetgetcapture 與 mcpnetgetmessages 可讀取詳情和訊息；URL 查詢值、使用者資訊與片段會遮蔽。封包標頭與本文預設不回傳，需明確傳 includebody=true（本文 Base64，每段最多 64 KiB）。查詢不會自行開啟監聽；本機其他程式也可能連線至 loopback MCP。
