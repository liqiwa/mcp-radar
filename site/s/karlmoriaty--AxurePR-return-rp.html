About AxurePR-return-rp

Axure RP 9 / RP 11 · AI 原生画布 · CLI 与 MCP

开始使用 · 30 秒了解 · Studio · RP/1 · 版本对齐 · 常见问题 · English

栖羽 / QIYU 从探索、鸟种详情，到留下自己的观鸟手记。 9 页原生原型示例 · 文字、按钮与输入保留为独立元件 · 识别与统计使用演示数据 · 素材与案例说明

一句话：把截图、需求描述或 RP/1 源码，变成可继续编辑的 Axure 原生工程，而不是一张原型截图。

你给它 它交给你 :--- :--- 一张截图、一段需求、一份 PRD，或一份 RP/1 源码 原生 .rp、浏览器预览、HTML / CSS / JS 导出，以及检查报告

AI 起稿 人来精修 原生交付 :--- :--- :--- 用自然语言或 RP/1 生成多页流程，按图层与语义局部改稿。 在 Studio 里双击改字、框选、拖拽、测距、撤销重做。 文字、按钮与输入框保持独立元件，在 Axure 中继续编辑。

对比项 多数截图转代码工具 returnrp :--- :--- :--- 输出物 HTML、图片或不可编辑稿 原生 .rp，也可导出 HTML / CSS / JS 设计源码 一次性生成，难以 diff 与回改 RP/1 文本源码，可版本管理、按图层局部修改 Agent 协作 往往只能整页重来 按图层、语义与范围查询，改具体对象 Axure 版本 通常只覆盖一个版本 RP 9 / RP 11 双向能力对齐 验证方式 看截图 结构检查 + 浏览器交互 + Axure 保存重开 / 预览

1. 把意图写成源码。 截图走临摹管线，需求与 PRD 直接写成 RP/1；页面、组件、变量、交互都在同一份文本里。 2. 在画布里推敲。 Agent 搭第一版，你直接点选、改字、调整布局；也可以把局部交还 AI，继续探索另一种构图。 3. 在交付前验证。 真实截图、交互场景、结构检查分别运行，确认跳转、状态与保存回显。 4. 带回 Axure。 生成原生工程，或导出浏览器可运行版本；继续编辑、继续迭代。

Studio 是一块 AI 和人都能编辑的自由画布。让 Agent 搭好第一版，再直接点选、改字、调整布局；也可以把局部交还 AI，继续探索另一种构图。

AI 起稿。 RP/1 或命令创作，按图层、语义和范围查询，局部改稿。 人来精修。 双击改字、Shift 框选、Option / Alt 悬停测距，撤销重做。 一起验证。 查看真实截图、运行交互场景，再交付原型。

RP/1 把页面、布局、组件、变量和交互写在一起。AI 改动有明确目标，设计也能保留结构、版本和继续迭代的起点。

从一个页面到完整流程，reviseprototype 继续改稿；已有原生修改也能在支持范围内合并回源码。

生成原生 .rp，在 Axure 中继续修改支持的文字、控件和布局。页面、变量、动态面板与跳转可以一起交付，源稿、预览和检查报告也一并保留。

从哪里继续 可以做什么 :--- :--- Studio 和 AI 共用设计文档、事务与撤销历史 Axure 打开原生工程，继续编辑元件与支持的交互 浏览器 运行预览；也可导出独立 HTML / CSS / JS

交付物 说明 :--- :--- 原生 .rp 默认目标 RP 11；target=9 或 AXURETARGETVERSION=9 切到 RP 9 浏览器预览 真实交互场景，可复现点击、跳转与状态变化 代码导出 独立 HTML / CSS / JS，便于评审或嵌入 结构与验收报告 三零检查（未解析记录、悬空引用、问题数均为 0）、浏览器断言与 Axure 往返结果分开记录
