About mcd-what-to-eat

一个基于麦当劳中国官方 MCP 开发的 Skill：把「今天吃什么」这个世纪难题，变成一次有仪式感的抽签——先摇今日运势，再随机搭配一整套麦当劳套餐。价格、热量、商品图全部来自官方实时数据。

🏆 2026 麦当劳程序员创意开发大赛参赛作品（使用 WorkBuddy 开发）

- 今日运势：6 级签等，各配专属 emoji——🎉 大吉 / ✨ 吉 / 😊 中吉 / 🍀 小吉 / 🌤️ 末吉 / 😐 平；附签诗、宜/忌、幸运数字、幸运色、幸运时段 - 确定性抽签：种子 = SHA256(日期 + 签主 + 重抽序号)。同一天同一个人永远抽到同一支签，不会刷一次变一次；想换签点「再抽一签」 - 真实菜单：拉取指定门店的官方实时菜单——餐品名、现价、划线价、官方商品图 - 热量诚实：官方营养表按规格拆分（可乐中杯 147 / 大杯 224 / 小杯 107），多命中时输出区间而不是猜一个数；总热量只要有一项不详就标 ≥ N kcal - 像素风视觉：星露谷（Stardew Valley）风格界面，金拱门像素 Logo + 漂浮的汉堡/冰淇淋像素装饰，全部内联 SVG 绘制，无外部图片依赖 - 单文件交付：最终产物是一个零依赖 HTML，可直接发给别人打开 - 优雅降级：没有 Token 或断网时自动切到内置参考菜单，页面底部标注数据来源

参照仓库内的 mcp-config.example.json，把 ${MCDMCPTOKEN} 换成你的真实 Token：

在 WorkBuddy 中的路径：左侧边栏【连接器】→ 右上角【自定义连接器】→【配置 MCP】→ 粘贴上述配置 → 保存并启用。

其他客户端（Cursor / Cherry Studio / Trae / VSCode）配置方式相同。

重启 WorkBuddy，然后直接说 「今天吃什么」 即可触发；也可以输入 /mcd-what-to-eat 激活。

打开生成的 麦门运势.html：选口味（随便 / 吃辣 / 不吃辣 / 清淡点）、填预算和签主名，点「今天吃什么」走摇签动画，即出运势 + 套餐两栏结果。

无 Token 也能跑：python3 scripts/buildpage.py -o demo.html，会自动降级到内置参考菜单并在页面标注。

人群 用法 ------ 选择困难症 每天中午不知道吃什么的人，一句话获得有仪式感的答案 麦门信徒 想要抽签仪式感和「麦门人格」氛围的麦当劳爱好者 MCP 开发者 想了解「商业 MCP 数据 → 有趣应用」怎么落地的参考实现（含 7 个实测踩坑） Skill 开发者 想了解 Skill 结构（SKILL.md + scripts + references）如何组织的模板

- Token 只通过环境变量 MCDMCPTOKEN 传入，仓库内不含任何真实凭证 - 只调用 4 个只读工具（query-nearby-stores、query-meals、list-nutrition-foods、now-time-info） - 绝不调用 create-order、cancel-order、auto-bind-coupons、draw-lottery 等写操作——尤其 draw-lottery 会真实扣减积分，与页面上的「今日运势」（纯本地算法）毫无关系 - 生成的 HTML 单文件已校验不含 Token
