About KuroCatWork

陪你打字，也陪 AI 干活的原生桌面萌猫。 普通陪伴与工作模式 · Codex / Claude · 任务泡泡 · 共通皮肤

基于 KuroCat 开发，为桌面小猫加入 Codex / Claude 工作模式。

让小猫继续当主角。双击就在普通桌宠和 AI 工作小搭档之间切换，额度、任务与提醒都围绕它的键盘展开；也能听着敲击声，感知任务有没有在忙。

对比维度 🐱 KuroCatWork 常见 Electron / Web 桌宠实现 :--- :--- :--- 安装包体积 macOS 通用版约 2.1 MB、Windows x64 约 1.5 MB、Linux 便携版约 1.2 MB，包含四款皮肤与声音素材 通常需要额外打包浏览器或其他运行时，体积取决于具体实现 内存 / CPU 占用 原生 Swift / C++17 绘制；切回普通模式即停止 AI 额度与任务轮询 资源占用取决于页面、渲染进程和后台逻辑 游戏内按键捕获 macOS IOHIDManager、Windows Raw Input、Linux XInput2 / evdev，按平台授权后驱动全局键鼠动作 网页内按键事件通常受焦点限制，全局输入需额外桥接 2.5D 视觉表现 鼠标跟随转头、捕猎大圆眼、圆润团睡，以及带惯性的拎猫、键盘与鼠标 / 数位板 表现形式取决于项目，可采用贴图、骨骼或 3D 渲染 皮肤与生态 四款内置皮肤；兼容原作 2.5D 皮肤工坊 的 .kurocat / .kurokb 格式，导入后可用于工作模式 素材格式由各项目定义，跨项目使用通常需要适配 隐私安全 开源，本地处理键鼠动画；工作模式读取已连接工具的额度与任务状态，本地保存设置和任务元数据 数据处理方式与网络连接范围需查看各项目说明 普通陪伴 / AI 工作 双击小猫切换；普通模式陪你打字，工作模式才亮起键盘流光并检查 AI 任务 是否具备任务监测与模式切换，取决于项目 Codex / Claude 额度 蓝色 / 橙色额度泡泡，显示剩余用量与重置时间；支持单工具、双工具及自动识别 通常需自行接入工具账户与额度来源 任务与处理提醒 运行黄、等待紫、完成绿、失败或终止红；点击跳转对应聊天，等待时小猫抬头提醒 是否展示任务生命周期与聊天入口，取决于项目 声音与工作节奏 青轴 / 茶轴 / 红轴、气泡弹出声与拎起喵叫；敲击声的开始和暂停帮助感知任务动静，音量独立可调 音色、任务联动与音量控制取决于项目 互动与彩蛋 自主双手打字、短暂停顿思考、随机小情绪、等待催促，以及甩动约 1.2 秒的眩晕眼 互动规则与动画由各项目分别设计

体积为 v1.4.6 各平台完整下载包的近似值。Windows x64、Linux x8664 / ARM64 现提供原生工作模式安装包；兼容要求见下方平台说明。

- ⌨️ 双击，切换普通／工作模式 - 普通模式陪你打字、跟随鼠标、摸头、打瞌睡；工作模式才亮起 RGB 跑马灯，让工作状态一眼可辨。 - 小猫按下空格，气泡先像普通按键一样升起，再变成键盘下方的立体长条；方向与键盘下缘平行，缩放时文字与泡泡一起等比例变化。 - 可随时手动切回；没有运行或等待处理的任务满 30 分钟后自动回普通模式。工作模式不因闲置睡着，回普通模式后按原规则入睡。

- 🔵🟠 Codex ＋ Claude 额度，一眼看见 - 支持只显示 Codex、只显示 Claude、同时显示，或自动识别；单工具使用全宽额度条，识别到另一个工具后自动补上。 - 主填充显示短周期剩余额度，细条显示本周剩余；外圈七段连续倒计时显示距离本周重置的时间，空段保留白色轮廓。 - 悬停显示百分比、更新时间及准确倒计时。按账户实际可用的额度窗口显示；未提供的窗口显示为不可用。 - 额度约每 60 秒刷新；断网或登录失效时保留上次
