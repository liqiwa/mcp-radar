About nasa-data-spaceapps

One semantic search for NASA + ESA + JAXA + ISRO + CSA + 11 more agencies — with a one-click MCP server builder for any AI app.

Open index.html in any browser. No install, no server, no build. That's the whole app.

Feature Detail ------ Semantic search Plain English ("rover on red planet") → Mars Photos. Synonym graph (SYNONYMS), concept matching, ranked results with Why this matched explanations. Modes: Semantic / Keyword / Exact. Faceted catalog 50+ datasets · filters by agency, theme, format, date range · sort · Grid/List · favorites (persisted) · history · export JSON/CSV · filter pills (remove with ✕) Intuitive UX Journey stepper (6 steps, persisted) · Welcome banner · “Best for…” + ✨ Start-here badges on cards · plain-English hints everywhere · mobile menu · ❓ Help modal · Non-tech mode in Builder · presets (Beginner/Earth/Deep Space/My search) Dataset detail 3-step drawer (What it is → Try it → Use in AI) + sticky actions + DCAT metadata, resources, sample I/O, related API Playground Live-run real endpoints. Pre-filled examples per field (date→today, sol→1000…), plain-English labels, “What am I seeing?” explainer, CORS fallback to sample + MCP tip. MCP Builder Progress bar (“Step X of 5”) + live summary (datasets/tools/key status) + validation warnings. Language + transport + client with plain-English explanations (stdio=“on this computer”). Complete runnable code + config + install + test prompts. Guide 6-step interactive checklist (persisted, with 📋 copy buttons per step) + worked 5-minute example, inline Analytics Live counts by agency & theme (bar charts), stat
