About Lookup

Lookup is a lightweight MCP server for web and torrent search, page reading, research, news, weather, time, calculations, and unit conversion. It is designed for LM Studio and other MCP clients that work with local models.

Lookup is not installed as a Python package. LM Studio launches Search.py directly with a Python interpreter. Keyless mode uses only Python's standard library.

The setup script supports macOS and Linux. It installs uv for the current user when needed, lets uv install Python when needed, creates .venv, and checks Search.py directly. It does not build or install Lookup, and no lockfile is required.

No sudo is required. The bootstrap needs either curl or wget and an internet connection the first time it runs.

At the end, the script prints an MCP configuration containing the exact executable path for this checkout. It looks like this:

Copy that configuration into LM Studio or your MCP client, then restart or reload the client.

The updater downloads only the newest Search.py from the repository's main branch, validates it, performs an MCP startup check, and then replaces the local source. It does not use GitHub Releases or modify .venv, mcp.json, API keys, the README, or other local files.

If Python 3.9 or newer is already installed, uv and .venv are optional. Use the path returned by command -v python3 as command, with the absolute path to Search.py in args.
