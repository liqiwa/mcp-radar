About inkling

Notion-style databases and Obsidian-style links, graph and JSON Canvas in one self-hosted app, with real-time collaboration and a built-in MCP server for AI agents. MIT, everything free.

Using an Inkling server someone else runs? Start with the user guide (한국어).

Write - Block editor (BlockNote): slash menu, tables, code blocks with highlighting, checklists, callouts, images and file drops - Math with KaTeX, as display blocks or inline. Type $x^2$ or press ⌘/Ctrl+Shift+E, then click an equation to edit its LaTeX with a live preview - [[wikilinks]] with autocomplete, tags, @mentions and daily notes - Templates for a page or a whole structure (sub-pages, databases with views, canvases): variables, prompts and Obsidian Templater basics, a searchable gallery, .md/.zip import and export (docs/TEMPLATES.md) - Version history with named snapshots that you can compare with the current page, comments, trash with restore, PDF export (print CSS) - English and Korean UI; installable PWA; light and dark themes

Organize & databases - Nested pages and folders, shared and private (🔒) pages per workspace, drag-and-drop ordering - Databases with table, board, calendar, gallery and timeline views; text, number, select, multi-select, date, checkbox, person, URL, relation and rollup properties; sort, filter and group - Due dates and tasks across the workspace (Due view, global calendar), ⌘K search over titles and bodies - Each person picks which sidebar menus (Search, Graph, Tags, Web shares, Due, Calendar, Activity, Today) to show and in what order.
