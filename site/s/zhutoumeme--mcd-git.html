About mcd-git

git mcd add 放进购物车，git mcd rebase 自动凑套餐、挑最省的券，git mcd push 才真正下单，终端里直接出支付二维码。基于麦当劳中国 MCP Server（mcp.mcd.cn）。

动图和下面所有截图都是 --demo 合成数据：门店、价格、订单号、券都是编的，支付链接指向 example.com。

- 开发者：在终端里敲 git mcd。git-mcd 在 PATH 里，git 就会把 git mcd … 交给它，任何目录都能用，不碰你代码仓库的 .git。 - 普通用户：把 SKILL.md 装进 WorkBuddy / Claude Code / Kiro，用大白话点餐，Agent 在后台跑 git mcd --json。

和普通 Skill 的区别：确认由代码强制执行。 普通 Skill 只是一段提示词，Agent 手里有 MCP 连接器就能随时直接调 create-order。mcd-git 的 Skill 不需要给 Agent 配 MCP 连接器，Token 只给 mcd-git 用，Agent 手里只有 git mcd 这一套命令：下单必须先出确认摘要，再用 --confirm 执行；哈希、参数、重新算出的应付金额，任何一项和预览时对不上，代码都会拒绝。代码保证的是这三件事：一定先出预览，确认时不能换参数，价格会复核。至于 Agent 有没有先把摘要拿给你看、等你点头，代码分辨不出来，这一步靠 SKILL.md 的规则约束 Agent。

- 麦门天际线（skyline，默认）：等距 3D 的 53 周 × 7 天，每天吃了几次就叠几层汉堡（底面包、肉饼、芝士、生菜、顶面包），超过 4 层只画 4 层、顶上标一个「+」；10-24 那格插一面「0x400」小旗。打开时汉堡按周从左到右落下叠好，只播一次、3 秒内停在完整状态，系统开了「减弱动态效果」就直接显示完成状态。默认深色夜景，浅色模式下换成奶油底。宽版，适合贴在 GitHub 个人主页。 - 年度吃麦小票（receipt）：竖版热敏小票，最常点 TOP 5 当商品行，中间一块点阵热力图（红圈是 10-24），下面是时段分布、TOTAL 和一根装饰条形码。适合发朋友圈、小红书。 - 平面格子（grid）：GitHub 风格的 7 行 × 53 周格子，颜色深浅表示那天吃了几单，10-24 那格单独描边。最朴素，放进文档里也不扎眼。

终端里先出预览（终端画不出 3D，天际线和格子都用格子预览；小票直接打印文字版），同时在本机写一个 SVG：自包含（不引用外部字体、图片和脚本，重复的图形用 + 复用），跟着系统切换浅色 / 深色，二三十 KB。同样的数据每次生成的文件都一样。

--with-savings 的数是下限：order-list 不返回优惠明细，只有 push 过或 show 过的单才知道省了多少。天际线和小票上有单缺明细时会写「只算有优惠明细的 N 单，是下限」，终端里也会提示。

1. 建一个和用户名同名的仓库 /，GitHub 会把它的 README 显示在你的个人主页上； 2. 在本机运行 git mcd card -o /mcd-contributions.svg； 3. 在那个仓库的 README.md 里加一行 ； 4. 自己 git add、git commit、git push。
