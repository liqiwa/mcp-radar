About mekugi-mcp

Python FastMCP server backed by a Rust HTTP/2 gRPC clustering transport (crates/mekugi-transport, compiled via PyO3/maturin) exposing Mekugi's functions.exec (V8 code-mode via prebuilt codex-code-mode-host), wait, and listboxes across one or more persistent devboxes, secured with Google Cloud OAuth and exposed over Cloudflare Tunnel for Gemini Web.

- Zero-contention keep-alive transport: Each configured devbox owns an isolated Rust tonic HTTP/2 channel (or poolsize round-robin channels) with L7 HTTP/2 keep-alive pings (20s interval / 5s timeout, keepalivewhileidle=true), adaptive flow control, and TCPNODELAY. Concurrent exec, wait, and listboxes calls multiplex on independent HTTP/2 streams so one slow command never blocks others. - Stateless cell routing: Yielded cellids are namespaced as : by the Rust transport, so wait automatically routes to the right machine even across MCP container restarts. - Tools: Annotated with readOnlyHint=True by default (NOCONFIRMATIONGATE=true) so Gemini Web does not prompt for approval on every call. - yieldtimems is capped at 45000 ms to stay within Gemini Web's ~60s tool timeout; longer scripts yield a cellid for wait.
