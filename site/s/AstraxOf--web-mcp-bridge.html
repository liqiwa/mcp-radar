About web-mcp-bridge

Use your local MCP servers with ChatGPT, Gemini, Claude Web and DeepSeek: no API keys, no extra subscriptions.

Web MCP Bridge lets the free web versions of ChatGPT, Gemini, Claude and DeepSeek use tools on your own computer: read files, control programs, query your data… with no API keys and no extra subscriptions. You approve every action.

[!IMPORTANT] Only connect MCP servers you trust. A tool with filesystem access can read whatever you allow it to.

Jump to: Install · First use · Add my MCPs · Troubleshooting

Piece What it is Where it lives --------- 🌐 The extension Installed in your browser. It reads what the AI asks for and shows you the buttons and permissions. Chrome, Edge or Brave 🌉 The bridge A small Python program that connects the extension to your tools (MCP servers). Your computer, in the background

1. You ask the AI something in the chat. 2. The AI answers with an "order" (a JSON block) asking for a tool. 3. The extension asks if you allow it → runs it on your PC → pastes the result back into the chat so the AI can continue.

🔒 Everything happens on your computer. Nothing is sent to third-party servers.

Requirement How to check ------ Chrome, Edge or Brave (version 116 or newer) Menu → About. Python 3.9 or newer Open a terminal and type python --version. If missing, get it from python.org/downloads and tick “Add Python to PATH” during setup. This project downloaded Green Code → Download ZIP button on GitHub, then unzip (or git clone). Keep it in a permanent folder: the extension loads from there, so don't delete or move it afterwards.
