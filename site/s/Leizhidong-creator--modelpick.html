About modelpick

The model router for AI agents — with cost per solved task. Coding, image, video, 3D, and audio. One CLI, one MCP server, every agent.

Website · intro video (93s) · How value is defined · Ecosystem

Your agent can write code, call tools, and ship a feature. Then it picks one model for everything — a frontier model to classify a support ticket, to generate a barrel prop, to draft a thumbnail.

The result is predictable: 60–95% of the spend goes to work that did not need a frontier model, and the hard nodes still fail because the model was chosen for the wrong modality.

ModelPick is a router and cost calculator, not another gateway. Before each node, it answers three questions in one call:

1. Which model? Ranked for this exact task, with hard capability filters (context, text-in-image, rigging, clip length, open weights). 2. What will it really cost? Cost per solved task — list price × expected attempts, not $/M tokens. 3. How do I connect it? The env var, key URL, docs, and API model id.

▶ Watch the intro video with English + 中文 captions · direct MP4 · script &amp; storyboard · English + 中文 captions

Three things are broken in model selection today:

1. Token prices hide the real bill. A model that is 10× cheaper per token but needs 1.8× the attempts and 2× the output tokens is not 10× cheaper. ModelPick computes the denominator that matters: dollars per usable output.

2. A coding agent defaults to one model, even for creative nodes. A 3D pipeline is not a text problem. Text-in-image is not image generation. A 30-second video is not a 5-second clip. ModelPick models 20
