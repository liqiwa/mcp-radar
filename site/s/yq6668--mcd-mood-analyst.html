About mcd-mood-analyst

一个基于麦当劳 MCP Server 的开源 Skill。它读取你的真实订单记录，结合下单时间、餐品构成和消费金额，推断你下单时的心情，同时给出账单统计、营养画像与每日/每月开支分析。

麦当劳情绪食鉴官不评判你该不该吃麦当劳，它做的是另一件事：把你的订单翻译成情绪语言，让你看见自己的消费习惯背后的状态。

维度 你能得到什么 ------ 💰 账单统计 笔数、总支出、客单价、最高单笔、门店榜、时段分布 💗 情绪解读 情绪标签 + 强度分数 + 具体触发因子（点名是哪些餐品） 🥗 营养画像 能量/脂肪/钠/蛋白质/钙五项评级 + 可追溯的改进建议 📅 开支账本 日均/月均开支、环比变化、下月预测、建议预算 📈 趋势洞察 消费周期规律、高频单品、情绪-时间关联模式

1. WorkBuddy 智能体客户端 2. 已完成麦当劳 MCP Server 授权（连接器面板中完成麦当劳账号授权） 3. Python 3.8+（仅使用标准库，无需 pip 安装任何依赖）

将 mcp-config.example.json 中的配置合并到你的 MCP 配置文件，敏感信息用环境变量占位符替换（详见 MCPINTEGRATION.md）。

Windows 用户可手动将目录复制到 %USERPROFILE%\.workbuddy\skills\mcd-mood-analyst\。

用户类型 典型场景 ------ 🧑‍💻 程序员/学生 工作日深夜加班后的例行下单，想了解自己的压力曲线 🧠 情绪管理需求者 通过饮食记录观察自己的情绪触发点 🏃 健身/控卡人群 需要精确的能量与钠摄入参考，辅助日常决策 💰 记账习惯者 希望把餐饮消费纳入月度预算管理 🍔 麦当劳重度用户 好奇自己的口味画像和消费规律

因子 权重 逻辑 --------- 🕐 深夜因子 30% 22:00 后下单为满分，20:00-22:00 线性衰减 🍟 高糖高脂因子 30% 甜品占当日热量比，50% 记满分 💸 金额冲动因子 25% 当日总额 / 客单价，2 倍记满分 🔁 频次因子 15% 单日订单数，≥3 笔记满分

营养评级依据《中国居民膳食指南（2022）》成年人日参考值。完整定义见 references/moodmodel.md 与 references/nutritionreference.md。

- 订单数据仅保存在用户本地 mcddata/ 目录，不上传任何第三方服务器 - 不收集手机号、地址、会员卡号等个人敏感信息 - 报告输出前自动检查敏感信息泄露 - 随时说"删掉我的数据"即可清除本地记录 - 营养建议为一般性参考，不构成医疗建议 - 情绪分析为基于订单的推测，不构成心理诊断
