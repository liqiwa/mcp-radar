About mcp4lms

Connect Claude (or any MCP client) to your university's LMS. Works with Moodle™.

Students connect once with a bookmark, get a personal key, and add one URL to Claude. Claude then gets read-only access to their courses, deadlines, assignments, grades, announcements and the text of course files.

[!NOTE] Mcp4Lms is an experimental, non-profit, volunteer-run open-source project. It is not affiliated with or endorsed by any university, Moodle HQ, Anthropic, OpenAI, Google or Anysphere.

Where What ------ D1 accounts Account id, LMS URL and user id, an HKDF key verifier, the LMS token encrypted with AES-256-GCM under a key derived from the user key, and the chosen expiry KV OAUTHKV OAuth clients, grants and token hashes. Grant props are encrypted with token-derived keys D1 downloadlinks Per link: the file URL and LMS token, encrypted under a secret only the link holds. Deleted on use, after 5 minutes, or on reconnect, revoke or deletion Nowhere The user key, the LMS password, plaintext tokens, names, emails, course data

- Expiry. Students choose 24 hours, 7, 30 or 90 days (default 90). After that the account is refused, and an hourly cron revokes its grants and deletes the row. - Lost key. Connecting again issues a new key, invalidates the old one and revokes all grants. - No access logs. Workers invocation logs are off and the code writes no request logs.
