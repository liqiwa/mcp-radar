About awesome-magento-ai

A curated list of AI tooling for Magento 2, Adobe Commerce and Mage-OS — agent skills, MCP servers, store modules, CLIs, starter kits and services.

Entries are grouped by what kind of thing a tool is, not by who made it — so you can jump straight to the layer you need: skills for your coding agent, an MCP server for your store, a module your merchant will actually click on.

Every description here comes from the project's own repository or site. Star counts are live badges, never stale.

Meaning ------ 🎓 Agent skills / subagents (Claude Code, Codex, OpenCode, Copilot…) 🔌 MCP server 🧩 Magento module (installs into the store) 🖥 CLI or standalone tool 📦 Starter kit / template ☁️ Hosted or commercial product 🧭 Not Magento-specific, but useful in a Magento workflow

- 🎓 Agent Skills & Subagents - 🔌 MCP Servers - 🧩 Magento Modules — AI in the Store - 🔍 SEO, AEO & LLM Discoverability - 🖥 CLI & Developer Tooling - 📦 Starter Kits & Templates - ☁️ Hosted & Commercial - 📚 Reading & Resources - Contributing - License

Prompt packs, skills and subagent definitions that teach a coding agent how Magento works. Drop-in — nothing installs into the store.

- claude-code-magento-agents — Collection of Claude Code subagents designed to be used for Magento 2 development. - claude-code-magento-agents (NobreTakeshi) — 30+ specialized agents for Magento 2 development, built around expert collaboration and task delegation. - claude-skills (df2k2) — Heavyweight, load-on-demand reference packs for ecommerce and web development: Magento 2 (~2,700 official doc files), Hyvä, Akeneo PIM + connector, Ord
