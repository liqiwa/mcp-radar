About iran-jobs-mcp

iran-jobs-mcp: Iran jobs (استخدام) MCP server for AI agents, IranTalent + Jobinja + Jobvision

iran-jobs-mcp is an unofficial, read-only MCP server that lets an AI agent search Iranian job ads, companies and pay on three job sites at once: IranTalent (ایران‌تلنت, irantalent.com), Jobinja (جابینجا, jobinja.ir) and Jobvision (جاب‌ویژن, jobvision.ir). Its 37 tools search jobs on all three sites in one call, compare companies, employee reviews and interview reports, and compare pay for a role from IranTalent's salary survey and the pay in Jobinja and Jobvision ads. No API key or account is needed; it works in Claude, Cursor, Copilot and any other MCP client.

For AI agents · Quick start · Tools · Limits · فارسی

- What: unofficial MCP server (model context protocol) for irantalent.com, jobinja.ir and jobvision.ir, merged: job search, companies, top employers, market counts and pay from all three, plus each site's own tools. - Install: uvx iran-jobs-mcp or claude mcp add iran-jobs -- uvx iran-jobs-mcp. Transport: stdio. Needs uv (Python 3.10+). - Auth: none. Optional IRANJOBSMCPPROXY (HTTP proxy URL, or a comma-separated list) applies to all three sites; system proxy settings are ignored. - Access: read-only. It cannot log in, apply, post, save jobs or write reviews. - Tools: 37, all prefixed job. Five merged tools take site (all default, irantalent, jobinja, jobvision) and answer with one block per site; if one site fails its block holds an error and the others still answer. The other 32 are one site's own tools (jobirantalent, jobjobinja, jobjobvision). - Use when: the user lo
