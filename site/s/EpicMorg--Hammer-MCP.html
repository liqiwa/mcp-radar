About Hammer-MCP

Let AI agents see and edit maps in Valve Hammer Editor — live. An MCP server for Hammer (Source 1), Hammer++ and friends.

Ask your agent "put a warm light at each corner of the room and name them by the scheme" — and watch the entities appear in the Hammer you already have open. No plugins, no patched editor: Hammer-MCP talks to Hammer through the shell channel that Valve built into the editor 20 years ago (WorldcraftShellMessageWnd, the mechanism behind editorsendcommand.cpp in the Source SDK) and through Hammer's own menu commands.

An agent spawns a propdynamic in Hammer++ and spins it - live, over MCP (video).

Verified live on Hammer++ 8873 x64 (TF2 Classified) and x86 (Source SDK 2013 SP mod), from an agent on another machine over the LAN:

------ ✅ Create point entities with keyvalues (light, infotarget, propdynamic with a model, …) ✅ Rotate entities (a spinning locker at ~28 edits/s, Hammer stays responsive) ✅ Set keyvalues, delete entities ✅ Edits land in Hammer's undo history — Ctrl+Z works ✅ Save / undo / redo / Run Map / Check for Problems via menu commands ✅ Map summary from the saved .vmf (entities, brushes, classes, skybox…) ✅ Recognises the running Hammer build by hash (registry of 179 known builds) ✅ Token auth, localhost by default ✅ Map knowledge: entities, outputs, I/O graph, validation against the game's FGD ✅ Compile with Hammer's own Run Map sequences, parsed log, leak trace, compiled .bsp entities
