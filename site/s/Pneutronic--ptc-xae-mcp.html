About ptc-xae-mcp

Technical name: ptc-xae-mcp (repository, ptc-xae-mcp.exe, install folder, %LOCALAPPDATA%\ptc-xae-mcp).

An MCP server that gives an AI coding assistant (Claude Code or any other MCP client) direct control of a Beckhoff TwinCAT 3 XAE (eXtended Automation Engineering) instance — the engineering environment for TwinCAT PLC/motion projects — through its COM Automation Interface. It runs as a small WinForms host application with an embedded local HTTP server; the GUI and the MCP tools drive the same underlying TwinCAT session.

Typical uses: read and write PLC source (POUs, GVLs, DUTs), build a project and parse the compiler output, manage library references, drive online/login and download, read ADS variables, inspect EtherCAT/fieldbus topology, and more — see docs/mcp-capabilities.md for the full, generated list of tools with their parameters.

Independent project. Pneutronic XAE MCP is developed and maintained by Pneutronic AG, an official Beckhoff Solution Provider. The software itself is not a Beckhoff product: it is not endorsed, certified or supported by Beckhoff Automation GmbH & Co. KG, and it is not affiliated with Anthropic PBC. Please do not contact Beckhoff support about this software; use the issue tracker instead. You need your own licensed TwinCAT installation; this project does not include or redistribute any Beckhoff software.
