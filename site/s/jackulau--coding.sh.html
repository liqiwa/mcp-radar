About coding.sh

coding.sh is open-source, local-first observability and evals for any AI agent. Coding agents first-class. Your sessions stay on your machine.

Docs · Quickstart · Supported agents · Changelog · Discussions · Report a bug

A first run of npx coding.sh 0.1.2 in a fresh home, on sample sessions from sample-sessions.mjs.

Run npx coding.sh again to open the viewer on your sessions.

What it costs: nothing. MIT licensed, runs on your machine, no account.

One Claude Code session in the local viewer, with the diff it made and the tests it ran. Sample data, generated by sample-sessions.mjs.

coding.sh records what your agents do: prompts, tool calls, file changes, model calls, latency and tokens. It goes into a SQLite index on your machine. You browse it in a local viewer, query it from the CLI or from your agents over MCP, turn failures into evals, and compare changes with paired statistics. Capture, storage and the viewer stay on your machine unless you add a remote sink.

No runtime dependencies, Node 22.15 or newer.

npx coding.sh runs the latest release from npm without installing it. In a terminal, the first run is coding.sh init and later runs open the viewer. The install command above installs the release, runs init, opens the viewer, and puts coding.sh on your PATH for the commands below. init finds your agents, shows one plan and asks once. It points their hooks at coding.sh, registers the MCP server where the agent supports it, and backs up every config file it edits. coding.sh init --dry-run prints the plan without writing anything (--diff adds the edits), and coding.
