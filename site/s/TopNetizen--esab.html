About esab

ESAB — Engineering Software Agent Bridge

ESAB is a Model Context Protocol server. It connects Cursor, WorkBuddy, Claude Desktop, or any agent that supports MCP or can load MCP plugins/connectors, to engineering software that is already installed and licensed on the machine:

SAP2000 · ETABS · STAAD.Pro · MIDAS GEN NX · Abaqus · Tekla Structures · Rhino · AutoCAD / GstarCAD / ZWCAD / BricsCAD · SketchUp · PKPM · PKPM-CAE · SAUSG · PlantS · BIMBase · GBP

15 products, 22 bundled API skills. The agent issues the calls, the installed program runs its own solver, and design responsibility stays with the engineer.

ESAB ships no modelling or solving of its own and does not handle licensing. The agent models and solves by driving the installed software: ESAB forwards the calls to each program's own automation interface and checks what comes back.

15 products, across structural analysis, FEA, detailing, drafting, plant and BIM:
