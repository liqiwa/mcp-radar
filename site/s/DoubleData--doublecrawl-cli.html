About doublecrawl-cli

Ask for a page. Get the page. From your terminal, your scripts or your AI agent, and pay only for pages that arrive.

500 free credits when you sign up, no card required. Earn up to 850 more in your first session, including +250 for starring this repo (how).

- Pages, not proxy plumbing. Send a URL, get the page back. DoubleCrawl handles the route to the target; you pick an exit country with one flag when you need one. - Failed pages cost 0. You pay for pages that arrive (and for a truthful "page missing" answer). Failed tries, timeouts and our own retries are on us. - Built for agents. Every command speaks --json, exit codes are documented, and the same account works from the CLI, the hosted MCP server and the Claude Code plugin. - One account everywhere. Sign in once in the browser. Credits, API keys, usage and request logs are the same in the terminal and in the console. - One static binary. No runtime, no daemon. Credentials live in your OS keychain, and every release is signed with Sigstore and ships with SBOMs.

- Install - Quickstart - Commands - Scripting and JSON output - Use with AI agents - Configuration - Exit codes - Free credits and pricing - Security - Troubleshooting
