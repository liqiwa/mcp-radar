About cedr

cedr is the command line tool behind cedr.dev. It picks which AI coding agent, model and effort should take each kind of work, merges reviews from several vendors into one pass or block decision, and pins the skills and MCP servers your agents load. It works with Claude Code, Codex, Cursor and Gemini, and any agent that speaks MCP can call it directly.

[!NOTE] cedr is in preview. Commands and file formats may still change before 1.0.

Picks the agent, model and effort for each kind of work from your routes.toml. Equally suited work goes to the plan with the most room left, and plans near their limits are skipped. Starts one reviewer per vendor, merges their reports, groups findings that point at the same place and decides the gate. Any P0 or P1 blocks; too few reports is never a silent pass. Lints your agent setup, pins every skill and MCP server in .cedr/guard.lock, and fails CI when a server's tools, descriptions or network hosts change after you pinned it.

Download the archive for your platform from the latest release, unpack it and put cedr on your PATH.

Linux builds need glibc 2.34 or newer (Ubuntu 22.04, Debian 12, RHEL 9 or later). Every release lists SHA-256 checksums in SHA256SUMS and carries signed build provenance you can check with gh attestation verify --repo Sheernox/cedr.
