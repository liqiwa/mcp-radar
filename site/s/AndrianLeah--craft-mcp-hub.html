About craft-mcp-hub

One shared, windowless MCP server per ArtCraft app, for every AI client session.

Unofficial. This project is not affiliated with ArtCraft or its apps.

The ArtCraft apps (PhotoCraft, VectorCraft, LightCraft, PdfCraft, FigCraft, WordCraft, DeckCraft, GridCraft, Craft Anything, …) each ship a command-line tool with an mcp command, so an AI client such as Claude Code can drive them. Wiring that up by hand has rough edges:

- you either keep each desktop app open, or every client session starts its own copy of the engine; - with one engine per session, sessions can't see each other's documents, and a photo library can only be opened by the first session (the others fail with "library is already open"); - every app has to be registered in the client by hand, and again when an app is renamed or moved.

Craft MCP Hub fixes that. For each app you turn on it runs one engine, without a window, on its own local port, and every client session connects to that same engine. A control panel (and a command-line tool) turns apps on and off, picks ports, and tells you why something doesn't connect.

- It works with Claude Code, Claude Desktop, Cursor, VS Code and Codex; sessions of all of them share the same engine. - crafthub connect is what the client launches. It starts the app's server if none is running, so nothing has to be open beforehand, and reconnects on its own when the server restarts. - crafthub serve is the shared server. It keeps the engine running, forwards each session's requests and returns the answers to whoever asked. - The list of apps comes from the ArtCraft launcher's
