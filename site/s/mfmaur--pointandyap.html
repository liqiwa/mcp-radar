About pointandyap

Free · macOS 26 on Apple silicon · or curl -fsSL https://pointandyap.com/install.sh sh

Point and Yap is a small Mac app for showing your coding agent what to change. Press Control twice, talk while you point at things on screen, press Control twice again. Each recording becomes an item in a local queue, with what you said, the element under the cursor and a cropped screenshot. Claude Code, Codex or Cursor pick it up over MCP, fix it and mark it done.

Install · How it works · MCP tools · FAQ · License

Requires macOS 26 or later and a Mac with Apple silicon.

or with Homebrew (trust the tap once, then install):

or by hand: download PointAndYap.dmg from pointandyap.com or the latest release and drag Point and Yap into Applications. Every build is signed and notarized by Apple; the install script checks the DMG with spctl before it copies anything.

Then open it, allow the three permissions it asks for, and answer one question: it lists the coding agents it found and asks before connecting them. Connect, or Skip and do it later in Settings.

- Microphone: records what you say while you point. - Screen Recording: takes the screenshots at each point and click. The recording pill is never in them. - Accessibility: reads the element under the cursor (role, label, window, app), so an agent can find it in code.
