About imnotarobot

A free-first captcha solver for macOS. A drop-in replacement for the 2Captcha / RuCaptcha API that tries free solvers first — a local model, then any vision model you choose, then an invisible browser — and pays human workers only when nothing else worked. Comes with a menu bar app and an MCP server for AI agents.

- Any model, free if you like. Bring a key of any vision model — GPT, Claude, Gemini, Qwen, DeepSeek, Grok, OpenRouter, a reseller or a local model via Ollama. The best one for captchas switches on by itself. With a free-tier key or a local model most captchas never reach the paid step. - No code changes. Any program that speaks the 2Captcha or RuCaptcha API works after changing one address. - A ladder, not a single bet. Local model → vision model → backup vision model → browser → humans. A step that is unsure, wrong or silent hands the captcha to the next one. - It learns from mistakes. Report a wrong answer and the step is no longer used on that picture; a step that keeps failing on a kind of captcha is skipped for that kind; complaints about human answers go to the service, which refunds them. - You see everything. Journal of every captcha with the picture, the answer and the path it took; daily money limits; side-by-side model comparison. - Agents welcome. An MCP server lets Claude, Cursor and other agents solve captchas through the app.
