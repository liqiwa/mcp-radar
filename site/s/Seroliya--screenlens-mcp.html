About screenlens-mcp

配好就能用，不需要打开任何窗口——它在后台以无 GUI 服务运行，Agent 调用时才拉起。

- 🖥 screencapture — 截取屏幕，返回带坐标网格的图片 - 📷 cameracapture — 拍一张摄像头画面（每次都会弹窗请你确认） - ✏️ annotate — 在真实屏幕上画框 / 圈 / 箭头 / 文字气泡，默认 5 秒后自动消失 - 👁 watchnext — 阻塞观察，画面出现变化才返回截图，本地检测不花 token - 🗂 listdisplays / listcameras / listwindows — 枚举屏幕、摄像头、窗口

想自己写配置的话（以 Claude Code / Codex 的 stdio 格式为例）：

首次调用工具时，它会自动在后台启动 ScreenLens 服务（无窗口、无托盘弹窗）， 之后所有调用都走这个常驻服务。你也可以手动启动：

坐标一律是归一化 0~1000：图片左上角 (0,0)，右下角 (1000,1000)，与分辨率无关。 返回的图片默认叠加半透明橙色网格（每 100 一条），用来精确读坐标，网格不属于画面内容。

工具 作用 关键参数 --------- screencapture 截屏 display（cursor/primary/序号）、grid、maxside cameracapture 摄像头取一帧 reason（显示在确认框里）、deviceid annotate 在屏幕上标注 annotations[]、seconds（默认 5，0 = 直到按 Esc） clearannotations 清除标注 — watchnext 阻塞观察画面变化 window、sensitivity、timeoutsec watchstop 停止观察 — listdisplays 列出显示器 — listcameras 列出摄像头（不打开设备） — listwindows 列出窗口 —

text 是独立文字气泡：at 是气泡中心，自动折行、超出屏幕自动内收，to 可选， 画一条引线指向目标。适合直接在画面上写解释和改法。

- 摄像头必须确认：每次 cameracapture 都会弹出系统对话框，可选「拒绝 / 仅这一次 / 10 分钟内允许」， 60 秒不选视为拒绝。拒绝后 30 秒内的重复请求直接被拒，防止 Agent 反复弹窗。 授权只存在内存里，服务重启即失效，托盘菜单可随时撤销。 - 标注不会挡住观察：watchnext 会忽略屏幕上标注所覆盖的区域，所以标注挂着也能继续观察， 且标注的出现/消失本身不会触发提醒。 - 数据不出本机：截图、摄像头画面只回传给调用你的那个 Agent，ScreenLens 自己不做任何上传。 - 隐私黑名单：可在设置里配置程序名单，这些程序在前台时自动观察一律暂停。

- mcp/screenlens-mcp.mjs 是零依赖的 stdio MCP 服务，只做协议转换。 - 干活的 ScreenLens 服务是个 Electron 进程，但以 --service 模式运行：窗口永不显示， 只保留托盘图标（打开设置 / 撤销摄像头授权 / 退出）。 - 两者通过 %APPDATA%\ScreenLens\bridge.json 里的端口和一次性 token 通信，只监听 127.0.0.1。 - 服务没起来时，MCP 会自动拉起它，用户无需手动启动。
