About mcd-points-butler

麦管家是一个基于麦当劳中国官方 MCP Server（https://mcp.mcd.cn）开发的 WorkBuddy 专家（Expert）。它不替你花钱，只帮你管资产——把散落在麦当劳 App 各处的积分、优惠券、商城订单当作一个整体来打理，让每一分资产都有去向。

- 积分悄悄过期：账户里的积分有有效期，过期即归零，但很少有人盯着。麦管家每次对话都会检查「即将过期积分」，并给出最优兑换建议。 - 优惠券领了就忘：麦麦省的券一键可领，但领完不用等于没领。麦管家区分「可领 / 已领未用 / 临期」三种状态，临期券会提醒你下次点餐优先用。 - 商城兑换拍脑袋：积分商城商品那么多，换哪个最划算？麦管家用「价值密度 = 商品价值 ÷ 所需积分」排序，结合你的历史偏好给建议，下单前出确认单。 - 抽奖全凭心情：先看奖品池和消耗规则，粗算期望价值，再决定抽不抽——不怂恿，只参谋。

剧本 触发语 做什么 --------- 资产巡检 「检查我的积分和优惠券」 一次盘点三类资产，输出资产速览 + 行动清单 积分急救 「帮我把即将过期的积分换成最划算的商品」 临期积分 → 商城核验 → 价值密度排序 → 确认单 → 兑换 领券规划 「领取今天的可用优惠券并规划点餐优惠」 一键领券 → 复核到账 → 临期券用券节奏建议 抽奖参谋 「现在抽奖划算吗？」 读活动规则与奖品池 → 期望价值粗算 → 抽/不抽建议 资产月报 「给我一份麦当劳资产月报」 积分 + 券 + 订单汇总：复盘、到期风险、下月建议

1. 一台装有 WorkBuddy 的设备 2. 麦当劳中国 MCP Token：登录 open.mcd.cn/mcp → 右上角「控制台」→ 点击「激活」申请

专家已上架 WorkBuddy 开放平台。打开 WorkBuddy，左侧边栏【专家·技能·连接器】→【专家】，在顶部搜索框输入「麦管家」即可找到该专家，点击安装并启用，按引导连接麦当劳 MCP（专家包内置凭证表单，填入 Token 即可）。若搜索不到或安装后提示工具未挂载，改用方式二手动配置连接器。

1. WorkBuddy：左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置MCP】，粘贴仓库根目录 mcp-config.example.json 的内容，将 ${MCDMCPTOKEN} 替换为你的真实 Token，保存并启用。 2. 其他 MCP 客户端：Cherry Studio / Cursor / Trae / VSCode 等支持 Streamable HTTP 的客户端可直接导入同一份示例配置；个别客户端要求 type 写作 http，按客户端文档微调即可。

- 本项目为麦当劳程序员节创意开发大赛参赛作品，由参赛者独立开发，非麦当劳官方产品。 - 项目输出仅供参考，不构成医疗、营养或其他专业建议；餐品信息、价格、优惠、积分规则及供应状态以麦当劳官方渠道的实时结果为准。 - 涉及积分兑换的操作执行前会输出确认单并征求同意；支付类操作一律不在本专家内进行。 - 麦当劳 MCP 有 600 次/分钟的 Token 限流，请合理使用。 - 请妥善保管你的 MCP Token，不要提交到任何仓库（本仓库配置文件仅使用占位符）。
