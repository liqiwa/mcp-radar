About medmlx

One Python API, command line and MCP server for native medical imaging on Apple Silicon. Run TotalSegmentator, nnU-Net, MedSAM2, SynthSeg and more through their independent MLX runtimes.

Apple Silicon · Metal · Python 3.13 · uv

This README describes the 0.4.2 release. The PyPI documentation describes the same release; source-only features are tracked in the release notes.

Install the latest published CLI and MCP server with all model families:

For a Python project, use uv add "medmlx[all,mcp]" instead.

Choose segment, generate or vision instead of all for a smaller install. The segment extra includes SAM 3 image and video support; generate includes NV-Reason-CT and the weight-free FDG PET adapter. Model weights download automatically on first use and keep their own terms. MedGemma uses a provisional bridge to a separate MedVLM environment; checkpoint inference and numerical accuracy are unqualified. See the bridge setup and limits.

For unreleased runtime changes, use the locked source workspace described in the MCP setup guide. The dependency definitions record the runtime versions used by that workspace.

For models with automatic assets, omit weightspath: the runner downloads its configured Hub repository or model files, reuses the cached folder afterwards, and records its revision in the run details. For your own weights, pass a local folder as weightspath. MedGemma and MRSegmentator currently require local weights; multi-model workflows can require separate asset paths.
