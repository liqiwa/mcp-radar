About apollo-11

The React incident workspace after an offline S8 run with a scripted model: seller price typo, coupon ruled out, measured recovery and human closure after approved SellerOS reverts.

Eye of the System monitors a marketplace's metric graph, ranks unusual changes by business impact, investigates explanations with evidence, and publishes incidents for human review. Deterministic warehouse tools compute the numbers; agents decide what to investigate and how to explain it. The included continuous simulator supplies S8: a seller's price typo during a planned electronics coupon day.

- sim → hourly Parquet lake → eye-data (DuckDB, metric registry, graph and deterministic tools). - eye-core (FastAPI, DBOS workflows and incident control) with postgres for durable workflow/control state. - sentinel, detective, skeptic, reporter, cartographer: independently served A2A agents using PydanticAI and agentruntime. - eye-specialists: Growth, Marketplace and Discovery A2A endpoints; selleros: independent seller-side service. - web: React workspace behind nginx; eye-mcp: MCP facade over Core. - lgtm: Grafana, logs, metrics and traces; egress-proxy: allowlisted agent internet access. - auth: OAuth client-credentials issuer and signing authority for A2A agent cards.

See the architecture and documentation index.

Requires Docker with Compose v2 (including !reset/!override support). For the host demo CLI and development, install uv; the workspace uses Python 3.13.
