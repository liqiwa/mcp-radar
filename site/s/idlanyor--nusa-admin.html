About nusa-admin

Docs: https://idlanyor.github.io/nusa-admin/ · Live demo: https://idlanyor.github.io/nusa-admin/demo/ · npm: nusa-admin

A reusable admin template kit for Vue 3 + Vite, run with Bun. Think AdminLTE, but as typed Vue components with no CSS framework and no jQuery: one layout shell, 77 components, dependency-free SVG charts, light/dark themes, and a single file of design tokens to re-skin it.

One generator feeds everything: bun run meta reads the component sources (via vue-component-meta) and the demo pages, and writes packages/ui/meta/components.json plus the skill's reference files. The docs site, the MCP server and llms.txt all read that file, so they can't drift from the code (CI fails if the committed output is stale).

CI (.github/workflows/ci.yml) runs the same steps on every push and pull request.

Choose starter (shell, dashboard, users CRUD, settings, auth and error pages) or full (the whole demo). Projects include the Claude Code skill, .mcp.json and AGENTS.md unless you pass --no-ai. See docs/guide/cli.md.

- Skill: skills/nusa-admin (also linked at .claude/skills/nusa-admin in this repo) teaches Claude Code the components, page recipes and conventions. - MCP server: packages/mcp — tools listcomponents, getcomponent, search, getguide, gettokens, scaffoldpage (list/form/detail/dashboard pages that type-check against the kit). This repo's .mcp.json runs it from source; generated apps run the published nusa-admin-mcp. - llms.txt: the docs site serves /llms.txt and /llms-full.txt.
