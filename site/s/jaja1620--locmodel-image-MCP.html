About locmodel-image-MCP

GitHub repository: jaja1620/locmodel-image-MCP — the installable package, the CLI command and the MCP server are still named locmodel-image.

Turn your local LocModel / stable-diffusion.cpp image engine into a first-class tool for AI agents — offline, free, scriptable.

locmodel-image is a zero-dependency bridge that exposes the image engine bundled inside LocModel (an sd-server built on stable-diffusion.cpp) through two interfaces:

Interface Entry point Use it when --- --- --- MCP server (recommended) scripts/locmodelmcp.py — tools generateimage, locmodelstatus, listmodels, enginedoctor, enginediscover Your AI client speaks Model Context Protocol (Claude Desktop, Cursor, Marvis, Continue, …). The model gets a typed tool instead of memorising shell commands. CLI bridge scripts/locmodelimage.py Scripts, batch jobs, CI, or clients without MCP support.

Both share the same engine layer: port auto-discovery, VRAM-aware size guard, failure classification with retry, cross-process generation lock, structured JSON output and meaningful exit codes.
