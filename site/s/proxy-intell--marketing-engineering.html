About marketing-engineering

one thumb doomscrolling. one hand clauding. campaign shipped somehow

Vote with your usage · See the ranking · Friday drops · Add a tool by hand

what other marketers are actually using. turns out it's not what twitter says…

tools for running marketing like software: ads, SEO and AEO, organic social, analytics, email, billing and the AI agents that drive them

marketers opened a terminal. engineers got asked to "make it go viral". same person now. this is their toolbox

give this to your agent (Claude Code, Cursor, Codex, ChatGPT, any agent that can open a link). paste it as a message, not into a terminal:

it checks which of these tools you actually use, shows you exactly what it will send, and waits for a yes. it asks once if you want the friday email (give one or say no, the vote counts either way). tools more people use climb. tools nobody uses sink. tools we don't list yet get proposed once 3 people use them. live ranking: marketingengineering.dev

only tool names and usage ratings leave your machine. never code, paths, keys or prompts. how voting works

want it permanent? run this in a terminal. it installs the skills for Claude Code, Cursor, Codex, Copilot and other agents: vote, find a tool for a job ("what should i use for X?"), and one per setup. more ways

every entry says what it does and how you plug in: MCP server, API, CLI, SDK, plugin, skill or web app. skills and plugins for coding agents are listed too, with an install line. agents can skip the prose and read llms.txt or catalog.json, remote MCP URLs included
