About awesome-iran-mcp

Give your AI agent the Iranian web. 19 unofficial, open-source Persian-web MCP servers for Digikala, Snappfood, Jabama, MrBilit, Paziresh24, Taaghche and more. Search, compare prices in Toman, find free slots and today's deals from Claude, Cursor, GitHub Copilot in VS Code or any MCP client. Install them as Claude Code plugins with skills, or as Agent Skills for Codex, Cursor, Antigravity and Grok Build.

Quick start · The servers · For AI agents · All tools · FAQ

Iranian websites are not built for AI agents. Most have no public API, prices come in Rial on one page and Toman on the next, and every site hides its best deals behind a different menu. Each server here maps one site's real (undocumented) API, tests it, and exposes it as clean MCP tools with prices in Toman.

Put a few of them together and one sentence does a day of tab-hopping (illustrative example):

You: I'm flying Tehran to Kish next Thursday for 3 nights. Cheapest flight, a villa under 4 million Toman a night, and a dermatologist on the island with a free slot.

Agent: calls mrbilit for flights → jabama and otaghak for stays → paziresh24 for doctors

Pick Price (Toman) ---------: Flight Thursday 07:40, economy, 2 seats left 2,180,000 Stay 2-bedroom villa near the beach, 4.8 stars 3,650,000 / night Doctor Dermatologist, Saturday 10:30, in-person 450,000

Every server is a small Python package on PyPI, run with uvx. No API key and no install step, except payping-mcp and bale-mcp, which act on your own account.
