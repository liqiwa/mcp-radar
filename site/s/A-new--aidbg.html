About aidbg

aidbg 是一个为 AI 辅助逆向分析 设计的命令行调试器。它的核心目标不是人类交互体验，而是 让程序（AI agent）能可靠地驱动调试会话并解析结果：

- 每条命令可输出 一行 JSON（JSONL），字段稳定、可直接解析 - 支持 批处理（-c 连续命令）与 脚本文件（--script） - 同一个 exe 自动识别并调试 x86 与 x64 目标（WOW64），无需换工具 - 所有地址/64 位值以 十六进制字符串 返回，避免 JSON 数字精度丢失 - 输出可控（max=N、条目上限），不会撑爆上下文窗口 - 错误结构化返回，便于 agent 判断重试或换策略

技术栈：C++20 / MSVC、Zydis 4.1.1（反汇编，与 x64dbg 同款）、DbgHelp（PDB 符号）。 架构参考多个开源调试器：x64dbg 的命令层与引擎解耦、raddebugger 的模块化引擎、 GDB 的请求-响应模型、Z0BDbgCli 的条件断点与异常策略、Nanomite 的状态视图完备性。

构建配置：/MT 静态链接 C++ 标准库 + VC-LTL（D:\vc\VC-LTL-Binary，ucrt 模式）把 C 运行时 重定向到系统 ucrtbase.dll。若 VC-LTL 不存在，CMakeLists.txt 会自动退回纯静态 CRT（/MT）， 两者都能达到"零 VC 运行时依赖"的效果，区别只是体积与 CRT 更新方式。

产物只依赖系统自带的 KERNEL32.dll、dbghelp.dll、ucrtbase.dll， 不需要 Visual C++ Redistributable（无 MSVCP140.dll / VCRUNTIME140.dll / api-ms-win-crt-）， 拷贝到 Windows 10+ 的机器上即可直接运行。

交互模式（人类使用）：直接运行 aidbg.exe，help 查看命令，quit 退出。

此时 aidbg 通过 stdio 上的换行分隔 JSON-RPC 2.0（MCP 标准 stdio transport）提供工具， 直到 stdin 关闭才退出。调试会话在整个连接期间保持：一次 aidbgsession(action=run) 启动的目标， 后续任何 tool call 都还在同一个会话里。

暴露 11 个工具，全部返回与命令行 完全相同 的 JSON 信封（见 §2）：

工具 对应命令 用途 --------- aidbgsession file / run / attach / detach / kill / restart / info 会话管理 aidbgexecute continue / step / next / finish / until / stepuntil / rununtil / autostep 执行控制与追踪（continue 可带 timeoutms） aidbgbreakpoint break / hbreak / mbreak / cond / bl / be / bd / bc 三类断点与条件 aidbgregisters regs / setreg 寄存器读写 aidbgmemory read / mem / write / search / regions / alloc / free / protect 内存 aidbgdisasm disasm 反汇编 aidbgcfg flow 函数控制流图（基本块 + 边） aidbgstack stack 调用栈 aidbgmodules modules / threads / thread / symbols 模块、线程、符号 aidbgeval eval 表达式求值 aidbg
