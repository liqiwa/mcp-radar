About JuniorRocha-MCP-for-Adobe-Creative-Cloud-Apps

JuniorRocha MCP for Adobe Creative Cloud

A local Model Context Protocol server that lets Claude, and other MCP clients, operate Photoshop, Illustrator, InDesign, Lightroom Classic, After Effects and Premiere Pro on your own computer. You describe the job, the apps do the work, and you keep editable files.

Download the latest release and pick the zip for your assistant. Each one has every installer and an INSTALL.txt in the right order:

Zip For Server install --------- JuniorRocha-MCP--claude.zip Claude Desktop Settings → Extensions → install the .mcpb JuniorRocha-MCP--chatgpt.zip ChatGPT desktop app Double-click INSTALL-CHATGPT.bat (macOS: INSTALL-CHATGPT.command); needs Node.js 20+

Folder What it is How to install --------- 1-server The server As in the table above 2-plugins Plug-ins for Photoshop, Premiere Pro and InDesign (.ccx) Double-click each one you need; Creative Cloud installs it 3-bridges-kit Bridges for After Effects, Illustrator and Lightroom Classic Close those apps, then double-click INSTALL-BRIDGES.bat (Windows) or INSTALL-BRIDGES.command (macOS)

Install only the parts for the apps you use. Then open your apps and ask: "Check the status of my creative apps." Step by step, with requirements and troubleshooting: Install. Prefer to build it yourself? See Install from source.

Updating only one part? The same release also has each installer as a separate file (jr-adb-mcp-bridge-.mcpb, the three .ccx files and jr-adb-mcp-bridge-bridges-kit-.zip).
