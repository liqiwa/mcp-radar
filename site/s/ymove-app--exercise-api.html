About exercise-api

The Your Move Exercise API is an exercise database API with 2,005+ exercises and 2,600+ HD videos, filmed with trainers and physiotherapists. No AI-generated clips, no GIFs. Every exercise ships with an HD video (HLS + MP4), thumbnails, step-by-step instructions and primary and secondary muscle data, across 15 muscle groups and 37 equipment types.

On the same key: workout generation, multi-week training programs and AI posture analysis.

- Docs: ymove.app/exercise-api/docs - OpenAPI spec: exercise-api.ymove.app/api/v2/openapi.json - Get an API key: ymove.app/exercise-api (trial key in minutes)

Base URL: https://exercise-api.ymove.app/api/v2. Send your key in the X-API-Key header.
