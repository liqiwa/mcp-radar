About table-bro

Pixel-perfect Material data tables for Angular, and more.\ A Web Components table engine on top of existing UI components.

The table is the Custom Element : pages, sort, search, row details, a filter drawer, a server mode, light and dark themes, a kinetic page scroll and animated row details. A skin gives it the look and the controls of a UI library: Angular Material, Bootstrap 5, or plain HTML. The core has no runtime dependencies and works with any framework or none; Angular gets its own wrapper.
