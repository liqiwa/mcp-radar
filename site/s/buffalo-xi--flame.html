About flame

A Go-based, multi-tenant AI agent platform. It manages agents, skills, tools and workflows as first-class build artifacts, exposes them as callable endpoints (MCP / RPC), and shows everything currently running in a single runtime ledger.

Ships with a Vue 3 admin console (desktop/), shared by the tenant side and the platform side.

Want to run the whole thing? deploy/poc/ is a two-container demo (the product stack + the LiteLLM gateway) that starts with docker compose and listens on a single port — see deploy/poc/README.md. A prebuilt image is published on every push, so running it needs no toolchain. It is a proof of concept, not a production deployment.

- Agents — prompt + model + tools + skills, with knowledge bases, tool permissions and a per-agent default reply language - Skills — a capability package of SKILL.md plus scripts, executed inside the sandbox - Tools — a tool catalog (MCP / RPC and other inbound capabilities), plugins, and custom tools - Workflows — visual orchestration (nodes / edges / variables) with a debugger, versions and releases

- Runtime ledger — a cross-instance view of what is running (agents + workflows), filterable by type / duration, and cancellable - Run history — persisted records, queryable by workflow / status / time range, exportable as CSV, cleanable per record or by filter - Endpoints — expose an agent or a workflow as an MCP or RPC entry point, with a per-tenant "expose / retract" switch - Sandbox — scripts and commands run in isolated units (docker / nsjail / none) with resource limits and a network kill switch
