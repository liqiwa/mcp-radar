About Understand

A CLI and an MCP server over one engine: security, defects, architecture, dependencies and an interactive code map. Every finding carries the file, the line and the reason it fired.

Report a bug · Request a feature · Discussions · Support this project

That is the whole setup. It reads the repository you are in, runs the sixteen analysis stages, prints each finding with its evidence, and keeps the scan so the other commands can work with it.

- Evidence, not vibes. Each finding names the rule, the file, the line and the reasoning, so you can check it and disagree with it. - No cloud, no account. It runs locally. Nothing is uploaded and nothing phones home. - The same engine over MCP. Ten tools and three resources, so an assistant can scan a repository and cite what it found.
