About McSmart

基于麦当劳 MCP Server 的 AI Agent Skill — 用自然语言完成"懂营养、懂优惠、懂你"的智能点餐

McSmart（麦智点餐官）是一个 AI Agent Skill：它不是又一个点餐页面，而是一个能听懂自然语言、自主规划工具调用、综合多方数据给出决策建议的智能体技能。

McSmart 就会自动完成：意图识别 → MCP 工具规划 → 麦当劳 MCP 真实调用 → 数据融合 → 综合评分 → 推荐方案，全程无需用户查菜单、算热量、找优惠券。

项目同时包含 Skill 定义层（skill/SKILL.md + 触发词 + 营养规则参考）与 代码实现层（src/），评委可同时审视 Prompt 工程与代码工程。

模式 触发示例 调用工具数 输出 --------------------------------- 健康推荐 "500卡以内，30元以内的套餐" 6 营养/价格/优惠三维评分 Top 3 方案 省钱优化 "今天吃麦当劳怎么最划算" 6-7 原价 / 优惠金额 / 最终价格 / 节省比例 门店查询 "附近哪里可以买" 1 距离 / 营业状态 / 推荐理由

健康推荐支持 7 种目标：减脂 · 增肌 · 儿童 · 低糖 · 低脂 · 省钱 · 普通。

- 点餐决策过载：麦当劳 SKU 数百个，用户面对"想吃得健康/划算"的诉求时，需要自己查热量表、比价、凑优惠券，决策成本高。 - 营养信息不对称：官方营养数据（160+ 餐品的能量/蛋白/脂肪/碳水/钠）存在但没有被"翻译"成普通用户可执行的点餐建议。 - 优惠规则复杂：平台券、门店券、促销活动分散在不同入口，"怎么买最划算"需要逐个试算。 - MCP 让数据可用：麦当劳官方开放 MCP Server（mcd-mcp v1.0.0，35 个工具），让 AI Agent 第一次能以标准化协议实时触达菜单、营养、优惠、门店、价格与交易数据——但工具是原子化的，价值在编排。

McSmart 的定位就是这最后一环：把 35 个原子工具，编排成一个"说一句话就办好一顿饭"的智能技能。

用户说 McSmart 做 实测效果 ----------------------------- "500卡以内，30元以内" 营养表×在售餐品交叉筛选 + 券后试算 培根蔬萃双层牛堡 442kcal / ¥24.50 "怎么最划算" 我的券+门店券+活动全量试算排序 麦咖啡美式 ¥19 → ¥9.90（省 47.9%） "控糖" 碳水 ≤50g 硬过滤 218kcal / 碳水 8g 三件组合 "附近哪里可以买" 单工具轻量查询 29米 · 营业中 · "步行即可到达"

- 营养数据从"官网查询页"变成驱动消费决策的实时过滤器，健康人群点餐转化提升 - 优惠券从"入口曝光"变成逐组合精确试算，核销率提升（Agent 主动匹配最优券） - 门店/预约/时段数据被组织成可解释的推荐理由，引导错峰到店

- "LLM 只在两端"架构：意图理解与话术润色用 LLM，中间的工具规划、数据融合、评分全部是确定性代码——Demo 可复现、报价零幻觉、失败可降级 - 报价零幻觉：所有价格数字只来自 calculate-price 实时返回，LLM 不接触数字运算——这是 AI 点餐场景可信度的底线设计 - 高危操作硬门控：create-order 等工具在代码层确认门之后，LLM 无权绕过 - 该范式（意图→DAG 规划→并行调用→融合评分）可直接迁移到奶茶、咖啡、商超等任意 MCP 化的零售场景
