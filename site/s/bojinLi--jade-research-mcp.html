About jade-research-mcp

Windows MCP server for local MDI JADE 9 GUI control and independent, reproducible powder XRD calculations. 32 tools · MIT license · Python 3.11+

面向材料研究的本地 MCP：通过对话控制已安装的 JADE，并完成谱图处理、峰拟合、晶格和尺寸/应变计算。已在 Windows、JADE 9 中文版、Python 3.12 环境验证；其他版本和语言需要适配。

本项目是独立开发的界面桥接工具，不是 JADE 官方产品，不提供 JADE 软件、许可证、ICDD/ICSD 数据库或厂商示范数据。使用者需要自行安装并合法使用相应软件和数据库。

类别 工具 ------ 连接与观察 jadelaunch、jadestate、jadewaitready、jadescreenshot 实时菜单和科研入口 jademenus、jadefindmenu、jadeworkflows 界面参数控制 jadeclickcontrol、jadesettext、jadecontrolitems、jadeselectitem、jadekey、jadeclick 文件与表格 jadeopenfile、jadeexportpattern、jadereadtable、jadeselectrow 能力与限制 jadecapabilities 数据检查、背景、寻峰 xrdinspect、xrdanalyze、xrdbatchanalyze 联合伪 Voigt 峰拟合 xrdfitpeaks：峰位、峰宽、面积、协方差、形式误差和残差 晶粒与微应变 xrdscherrer、xrdwilliamsonhall 晶格与单位换算 xrdrefinelattice、xrdconvert 本地结构模拟与候选对比 xrdsimulatecif、xrdmatchcifs 图表、文件和结果 xrdcomparepatterns、xrdexportxy、xrdreadresult

jade 由已安装的 JADE 执行。真实菜单可进入背景、定相、PDF 检索、分峰、晶格、WPF/Rietveld、定量和宏处理；需要逐步观察和设置参数，不能把“菜单已发送”当成分析成功。相关模块受安装版本、授权与数据库配置限制。

xrd 由 NumPy/SciPy/pymatgen 独立计算，结果不是 JADE 的内部计算。独立引擎没有实现 Rietveld、物相定量、Kα₂ 剥离或残余应力分析。

需要 Windows、Python 3.11+（已测 3.12），以及使用 JADE 界面控制时所需的 JADE 安装。桌面需要保持解锁。安装脚本使用 uv。

锁定文件记录验证环境的依赖版本。需要另行解析依赖时，可使用 pip install ".[test]"；这会安装满足 pyproject.toml 的版本，不等同于已验证的锁定环境。

服务器采用 stdio。客户端启动 runserver.py，不需要手动开启网页或额外的模型 API Key。
