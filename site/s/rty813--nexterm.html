About nexterm

Nexterm is a fast, modern Windows terminal client supporting SSH, local shells (PowerShell / CMD / WSL), Telnet, raw TCP, and serial ports—built with Rust, Tauri v2, React, and xterm.js.

It keeps WindTerm's familiar workflow (session tree, nested split panes, quick commands, one-click import from WindTerm, Xshell and MobaXterm) and adds several built-in capabilities:

- Remote File Workflow: Side-by-side SFTP browser (with automatic SCP fallback), parallel transfer queue, instant previews, and local edit with auto-upload on save. - AI Agent Awareness & Control: Live tab badges for Claude Code / Codex / Gemini CLI; desktop notifications when an agent finishes, needs permission approval, or errors out (click to jump straight to the pane); plus a built-in MCP server for human-approved terminal delegation. - E2EE Remote Access & Session Sharing: Scan a QR code or open a link to view and control desktop terminals from any browser (phone or computer), adapt terminal dimensions to a phone screen, manage sessions, transfer files, or share a single session through a one-off link (read-only until you grant control), all with zero-knowledge encryption. - Full Scrollback History: Every line a pane ever printed stays available, compressed in the background. Scroll, search and export all of it, back to the start of the session. - Installable Plugins: Extend Nexterm with your own commands, views and dynamic session lists without modifying the host. Start with the Hello counter.
