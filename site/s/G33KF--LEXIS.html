About LEXIS

LEXIS is a Windows graphical analysis environment for ALEAPP (Android) and iLEAPP (iOS). LEAPP parses the extraction and reports each artifact on its own; LEXIS brings those results together, so you can search, correlate and tag across artifacts and across devices. Both tools are bundled in a single portable exe: open an existing LEAPP report, or load a new extraction and LEXIS runs the right tool for you. No Python, nothing to install.

On top of the LEAPP reports it adds: - LEAPP artifacts, organized: every artifact from the LAVA output, sorted into categories and data types (Messages › SMS, Calls › Call Log, ...), or grouped by application. Tables load as you scroll, with column filters, /regex/ search, inline media and export. Cells holding JSON, XML, plists or protobuf (decoded by recognized schema) open as a tree - Multi-device cases: joint timeline and map, co-presence, common contacts, search across devices - Chats, timeline, map and media gallery in one window, with one search syntax - The extraction file system: file browser, SQLite reader with WAL and free-page carving, plist reader - Indicators: matching of STIX2 indicators and hash sets, root/jailbreak traces, crypto addresses and seed phrases - Verifiable exports: tags and notes, SHA-256 manifests, signed portable cases - AI analysis: off by default. Plug in Ollama, LM Studio or any OpenAI-compatible model to analyze, explain, summarize and translate, read images (OCR) and transcribe audio, with every answer citing the records it used. A built-in MCP server lets any MCP client query the open case
