About mcd-fortune-ordering

麦门抽签 McDonald's Fortune-Telling Ordering

麦门抽签 是一个基于麦当劳 MCP（Model Context Protocol）能力开发的创意 Skill，将麦当劳点餐与中国传统抽签文化巧妙结合。

1. 自动查询麦当劳餐品和价格 2. 在预算范围内随机搭配套餐 3. 为搭配结果生成一份有趣的"运势解读"——签号、宜忌、财运/桃花运/事业运星级、幸运色、幸运数字、签文解语 4. 检查可用优惠券，给出省钱建议

每一次抽签都是独一无二的。不同的预算、不同的搭配、不同的运势——吃个麦当劳，也能吃出命运的仪式感。

1. 申请麦当劳 MCP Token（参考麦当劳 MCP Server GitHub 使用指南） 2. 安装 Python 3.8+（仅使用标准库，无需额外依赖）

1. 打开 WorkBuddy，在左侧边栏【专家·技能·连接器】→【连接器】→【自定义连接器】→【配置 MCP】 2. 填入以下配置（替换 YOURMCPTOKEN 为实际 Token）：

3. 启用 mcd-mcp 连接器 4. 在对话框中说："帮我抽个麦签，预算 30 元"

试不同预算：python3 src/fortuneengine.py 15 / 30 / 50 / 100

除了命令行输出，我们还提供了一个可视化抽签卡片（fortunecard.html），让抽签体验更具仪式感：

- 麦当劳红黄配色：经典品牌视觉，金色签筒 + 红色卡片 + 黄色点缀 - 竹筒摇签动画：模拟传统抽签的竹筒晃动，签条从筒中滑出 - 金光爆发特效：签条落地瞬间，金色光晕向外扩散 - 卡片翻转揭示：运势卡片以 3D 翻转效果登场 - 星级弹出动画：财运/桃花运/事业运星级依次弹入 - Web Audio API 音效： - 摇签音效（白噪声模拟竹筒晃动声） - 揭示音效（C-E-G-C 上行琶音） - 星级弹出音效（高频清脆叮声） - 一键下载图片：使用 html2canvas 将运势卡片导出为 PNG 图片，可分享到朋友圈

选择预算金额（15/30/50/100 元），点击「抽签」按钮，享受完整的视听抽签体验！

预算范围 搭配策略 ------------------ < 20 元 小食为主（薯条/麦乐鸡/玉米杯等） 20-30 元 汉堡 + 小食 或 汉堡 + 饮料 30-40 元 汉堡 + 薯条/小食 + 饮料 40-50 元 汉堡 + 薯条 + 小食 + 饮料 50 元+ 丰富组合（优先选套餐 + 额外小食/甜品）

- 汉堡/套餐 → 事业运、财运（力量与决断） - 小食 → 财运（小确幸与积累） - 饮品类 → 灵感、人际运（情绪与流动） - 甜品 → 桃花运（甜蜜与惊喜）

运势解读包含：签号、签名、今日宜/忌、财运/桃花运/事业运星级（1-5星）、幸运色、幸运数字、签文解语、附加运势短句。

- MCP 全链路调用：门店查询 → 餐品列表 → 优惠券 → 价格计算，真实使用 5 个麦当劳 MCP 工具 - 预算感知搭配算法：根据预算智能选择搭配策略，保证不超支 - 40+ 餐品运势模板：每个餐品都有独特的运势文案，组合生成千变万化的签文 - WorkBuddy Skill 集成：支持在 WorkBuddy 中直接对话使用 - 可视化抽签卡片：纯前端实现（HTML/CSS/JS），麦当劳红黄品牌配色，竹筒摇签动画 + 金光特效 + Web Audio API 音效 + html2canvas 图片导出，零依赖开箱即用
