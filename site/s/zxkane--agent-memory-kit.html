About agent-memory-kit

agent-memory-kit keeps the memory notes of coding agents in a private Git repository and syncs them between your machines. Each machine works on its own clone, so a note written on one machine shows up on the others within a few minutes.

Each machine keeps a clone of a private notes repository at ~/agent-memory. Notes live in two places:

- global/ holds facts that apply everywhere. - projects// holds one folder of notes per repository.

- Clone and links. The SessionStart hook points Claude Code's per-repository memory folder at the matching project folder in the clone through a symlink. Notes already in that folder are copied over first, and the old folder is kept as a backup. The hook also prints the global index into the session. - Codex and Kiro. Their session-start hook prints the same kind of summary as plain text, without linking anything: the global index, the project's index when the repository has project notes, where to write new notes and the sync warnings. See "Codex and Kiro". - Write guard. The PreToolUse hook refuses to write content that looks like a credential into the clone. - Sync. A systemd user timer runs a sync every two minutes. The sync scans for credentials, commits, merges the remote and sends the result to the remote. Sessions never run Git on the clone; only the sync does, and it holds a lock while it runs. - Same result on every machine. The sync commits with a fixed identity (agent-memory-sync).
