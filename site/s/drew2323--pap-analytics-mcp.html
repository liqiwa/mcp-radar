About pap-analytics-mcp

Ask your AI agent how you slept on CPAP – and get answers grounded in your own device data.

An MCP server that turns PAP therapy data (CPAP / APAP / BiPAP / ASV) into small, aggregate tools an AI agent can call. The agent gets usage, AHI, events, leak, pressure and SpO2 – not megabytes of raw waveforms – so you can simply ask:

- "How was last night?" - "Which parts of the night had the most events, and what kind?" - "Analyse the hypopnea at 3:12 – what happened right before it?" - "Did my SpO2 drop after the events?" - "Compare this week with last week."

Add the server as an MCP connector to a voice assistant (ChatGPT Voice, or other voice apps with MCP support such as Dots, Muse or Grok) and ask the same questions out loud instead of reading charts. The assistant answers from your own device data. Setup: run the HTTP server and make it reachable for the app (e.g. via a tunnel); see client integration.

- 🌙 Night summaries, time windows and period comparisons: from a whole night down to single breaths, or one week against another. - 🔎 Anomaly finder that points at event clusters, large leak, desaturations and pressure at maximum. - 🫁 Oximetry (SpO2, pulse, T90, ODI) when an oximeter is connected. - 🏷️ Clear provenance: every number says whether it came from the device or was computed here. - 🔒 Local and read-only: source data is never modified, and everything is stored on your machine (DuckDB + Parquet). - 🧩 Device-agnostic core: vendors plug in as adapters. ResMed is available today.
