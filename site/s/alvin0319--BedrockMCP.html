About BedrockMCP

BedrockMCP An MCP server implementation for Minecraft (Windows), Inspired by mcpelauncher-agent.

Features - A DLL injected into Minecraft.Windows.exe (GDK build) that serves MCP over HTTP at 127.0.0.1:18080/mcp. - Screenshot capture via Windows.Graphics.Capture. - Mouse input through the game's MouseDevice::feed function, which registers clicks that SendInput and PostMessage do not. - Keyboard input through PostMessage for menus and in-world movement. - Tools: screenshot, state, move, click, look, scroll (menus only, not hotbar), key, holdkey (hold a key for a duration), type, chat, batch (several actions in one call for precise timing, e.g. double-tap to fly or holding two keys at once), wait, focus, openuri, ping.

Setup Download bedrockmcp.dll, bedrockmcpinjector.exe, findfeedsignature.py, and config.example.json from the latest release, and keep them in the same folder. The server reads config.json from that folder and creates it with defaults on first run, so copying config.example.json to config.json is optional (do it to customize port, auth, or keybinds).

Both mouse and keyboard input work without window focus. However, single-player pauses when the window loses focus, so in-world play requires the window to be focused. Open a world and move the mouse once before using the mouse tools. state will report feedready: true when ready. Re-inject after each game restart. After a game update, regenerate feedsignature with findfeedsignature.py
