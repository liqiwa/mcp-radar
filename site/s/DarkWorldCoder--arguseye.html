About arguseye

Arguseye — component previews for agents and VS Code

See your component. Change it. Inspect the consequences.

Watch the 58-second film · Claude Code setup guide · Agent setup and downloadable skill · VS Code extension

Arguseye gives coding agents eyes on real React (React Router and Remix included), Next.js, Vue 3 and Nuxt, Svelte 5 and SvelteKit, Preact and Solid components, without starting your app or writing stories. It uses your source, installed packages, discovered usage props, and supported layout context. Each render returns a cropped PNG, accessibility text, and structured evidence—including unresolved inputs, warnings, and errors.

Requires Node.js 22+, installed project dependencies, and Chromium or Google Chrome. Run this in your project, then restart your agent. Replace claude with codex, cursor, gemini, windsurf, vscode, antigravity, or copilot.

If Arguseye saves you a dev-server restart, a star helps other developers find it.
