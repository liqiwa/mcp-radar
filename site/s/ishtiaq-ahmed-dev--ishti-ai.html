About ishti-ai

A private, local-first personal AI assistant for Windows

Talk or type. ISHTI remembers, reminds, searches, reads your files, runs 120+ skills and plugs into any MCP tool, on a local model or the cloud API you choose. Nothing is sent, deleted or paid without your yes.

Quick start · Features · Screenshots · How it works · Compare · Contribute

🔒 Private by default ⚡ Fast and frugal 🧩 Open to the ecosystem --------- Runs on your PC and listens on 127.0.0.1. Keys live in Windows Credential Manager. Secrets you type are masked in history and never reach a cloud prompt. Deterministic rules answer what they can with zero model calls; everything else takes at most one. Typical replies take about 0.3 s, plus model time. Any MCP server becomes ISHTI tools, ISHTI is an MCP server itself, and Agent Skills (SKILL.md) install from a folder or a URL.

You need: Windows 10 or 11 and Python 3.11. For local models, an NVIDIA GPU (8 GB minimum, 16 GB recommended). For cloud mode, an API key from any OpenAI-compatible provider.

On first start ISHTI asks how it should think, On this PC (Ollama) or Cloud API, and remembers the choice. Then just ask:

Everyday assistant - Reminders, timers, calendar, notes, lists, habits and a spending log - Weather, prices, news and web search with sources - Reads PDFs, Word, Excel and slides; charts, OCR, media tools - English, Urdu and Pashto, typed or Roman script - Searches your past conversations, not just saved facts
