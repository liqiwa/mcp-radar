About elysium-chain-mcp

MCP server so AI agents can read and interact with the Elysium chain (Kinetiq's Arbitrum Orbit L2 for Hyperliquid).

An agent can read blocks, balances, contracts, and logs over JSON-RPC, and can query the block explorer when that API is configured. Sending transactions is a separate switch, and it accepts only Elysium testnet (chain ID 99801).

Reads follow ELYSIUMRPCURL. Write tools stay unregistered until ENABLEWRITES=true, and the process accepts them only on chain ID 99801.

For a first connection, follow Start here, then the prompts in Examples.

The RPC URL and chain ID below are the public testnet values from the chain specifications.

Claude Desktop (claudedesktopconfig.json) and Cursor (mcp.json) both use this mcpServers object. The default transport is MCP over stdio. The process reads environment variables from the client and does not load a .env file. Every variable is listed in .env.example.

Export ELYSIUMRPCURL and ELYSIUMCHAINID before npm start.

Set MCPTRANSPORT=http to serve MCP over HTTP. The process binds 127.0.0.1:3000, accepts POST /mcp, and GET /health returns { "status": "ok" }.

MCPHTTPTOKEN (at least 16 characters) is required when the bind address is not loopback, and whenever writes are enabled over HTTP.

Eight read tools are always registered. Inputs, outputs, and error codes are in Tools.
