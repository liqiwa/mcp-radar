About loopcut

Loopcut's cloud tools for Claude Code, Codex, Cursor, Claude Desktop and the shell. Render .blend files on cloud RTX 4090s, search free asset libraries, turn images into 3D models, remesh meshes, make sound effects and voice lines, and turn a video or a sentence into character animation on your own rig. Results come back as files the agent imports with Blender's Python. Everything is paid from your Loopcut account's credits. You don't need the Loopcut app; any Blender install packs the scene.

It's one MCP server plus a CLI with the same verbs. The tools come from Loopcut's catalog, so a cloud tool that opens on Loopcut shows up without a new release.
