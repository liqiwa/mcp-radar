About bobbeori-mcp-server

Connect Bobbeori food-management tools to ChatGPT, Codex, Claude, and other MCP clients with OAuth and preview-first write actions.

- View refrigerator inventory and expiring ingredients. - Recommend recipes from ingredients you already have. - Look up food storage, handling, and nutrition guidance. - Preview and save shopping lists. - Preview and stock reviewed receipt items. - Preview and create Google Calendar events or reminders.

Claude Desktop-style remote server config:

For ChatGPT, create a connector/plugin with:

- "Show my Bobbeori refrigerator ingredients that expire this week." - "Recommend dinner recipes using ingredients I already have." - "Preview adding these receipt items to my refrigerator." - "Create a shopping list for missing ingredients from recipe 175." - "Preview a calendar reminder to use tofu tomorrow at 9 AM KST."
