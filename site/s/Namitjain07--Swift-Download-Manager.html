About Swift-Download-Manager

Free, open-source download manager and download accelerator for Windows, Linux and macOS.

Split every file into up to 32 connections, pause and resume (even after a restart), queue and schedule downloads, and send downloads from Chrome, Edge, Firefox, Brave and Opera straight to the app. A modern, fast alternative to Internet Download Manager (IDM), written in Rust.

Download the latest release · Features · Screenshots · Browser add-on · Web interface and Docker · FAQ

The main window, light and dark (it follows your system), with the app's built-in sample data (--demo mode).

It adapts to the window: full layout, an icon rail at medium widths, a drawer and one menu button when narrow. Right: the Options window.

Browsers download each file over a single connection, so a fast line often sits mostly idle, and a dropped connection can mean starting over. Swift Download Manager is a free download accelerator: it splits every file into several parts, downloads them at the same time, re-splits as parts finish, and keeps going when a connection drops. Big files finish sooner, and a broken connection never means starting over.

- Free and open source (Apache License 2.0). No ads, no account, and no telemetry or update pings: the program only talks to the servers you download from. - Cross-platform: one program for Windows 10/11, Ubuntu, Debian and Linux Mint, and macOS (built on a Mac). - Fast and light: written in Rust. On Windows it is one self-contained .exe that needs no installer. - Built for everyday use: pause and resume, queues with schedules, categories, batch downloads,
