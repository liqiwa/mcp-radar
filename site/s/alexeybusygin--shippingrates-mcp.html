About shippingrates-mcp

A local MCP server for UPS, FedEx, USPS, and DHL rate quotes, backed by the ShippingRates NuGet package.

- One structured tool for multi-package quotes across every configured carrier. - UPS, FedEx (including optional SmartPost), USPS, and DHL configuration through environment variables. - Provider status and carrier-service discovery without revealing credentials. - Metric and US customary package inputs. - Native, self-contained Windows and macOS binaries.

The server retrieves rates only. It does not buy postage, create labels, book pickups, or track shipments.

Demo Mode: No carrier credentials yet? The server falls back to Pigeon Post: a fictional demo that geocodes cities or postcodes, measures the as-the-pigeon-flies distance, estimates the required flock, and quotes prices in Pigeon Coins.

The tap chooses the Intel or Apple-silicon binary automatically.
