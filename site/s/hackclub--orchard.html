About orchard

Turn a Linux server into a private hosting platform.

Hack Club Orchard is an open-source, self-hosted platform as a service (PaaS). Connect a repository from GitHub, GitLab, Gitea or another Git host, and Orchard builds it and runs it behind HTTPS, with a Postgres database that has point-in-time restore from S3-compatible storage, logs, metrics and rollbacks. Use the dashboard, the CLI, or your AI agent through the MCP server.

Orchard runs on Kubernetes, but you do not have to touch Kubernetes. One command turns a single Linux server into a k3s cluster with everything Orchard needs, which suits a home lab, a side project, a small team, or a trial. For production, run the Helm chart on a multi-node cluster such as Talos Linux, with components you operate, such as Harbor for the registry. Hack Club runs Orchard this way, on six Talos Linux nodes. Choose how to run Orchard explains the difference.

Orchard is free and licensed under AGPL-3.0 (the graft SDK for extensions is MIT). Hack Club runs its own apps on it. What is Orchard · Features · FAQ · Compare

Please follow the install guide. It covers every step in detail.

For the command alone, you need a Linux server with systemd, an IPv4 address and 20 GB of free disk. Orchard runs on 2 GiB of RAM, and 8 GiB is recommended. On a smaller server, the installer trims Orchard to leave memory for your apps.
