About repofit

Stop scrolling trending. Ask the agent that has watched you work.

Every week another wave of repositories hits ten thousand stars, and every "tools you should try" list is written for everyone at once. Meanwhile your coding agents have been taking notes on you for months: what you build, what keeps breaking, what you complained about at 2 a.m. repofit reads those notes on your own machine, from Claude Code, Codex, Cursor and a dozen more, and turns them into picks you have not heard of and will actually use. Every pick shows you the moment in your own history that earned it.

https://github.com/user-attachments/assets/c7ac0bcf-74ed-4a09-9295-b6d06e6d67c1

Then point the agents you use at repofit mcp. Most of them read the same MCP config:

That line goes in ~/.cursor/mcp.json for Cursor, ~/.gemini/settings.json for Gemini CLI, ~/.qwen/settings.json for Qwen Code, and the MCP settings of Cline, Windsurf or Claude Desktop. Codex reads TOML, and Claude Code adds servers from the command line:

repofit runs inside your agent, so your agent's own model does the thinking: no API key, no account, nothing to host. To skip the install step, use uv and make the command uvx repofit mcp.

Open a new session in any agent you connected and talk to it like a colleague who has read your history:

- "Use repofit to recommend some GitHub projects for me." - "Does github.com/owner/name fit me?" - "Is there a good tool for turning PDFs into Markdown?" - "Which of my installed skills do I never use?"
