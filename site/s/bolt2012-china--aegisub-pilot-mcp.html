About aegisub-pilot-mcp

通过 MCP (Model Context Protocol) 读写 ASS 字幕并控制本机 Aegisub 窗口。

项目初衷是让不会用 Aegisub 的人能通过 AI 完成打轴、填词、套样式和写特效。它本质上只是一个操作 Aegisub 的 MCP 接口，不带语音识别，也不会帮你做外语翻译。台词需要你自己提供，或者由你当前对话里的 AI 生成，这个工具只负责把切空轴、填台词、改样式和同步到 Aegisub 窗口这些步骤做掉。

兼容 OpenAI Codex CLI、Claude Code、Claude Desktop、Cursor、Windsurf、Cline、Roo Code 和 OpenCode。

1. 按音频波形打空轴 (aegisubblankcues) - 开头贴住出声点，结尾默认多留 300ms (tailms=300)。 - 如果两句话之间的间隔小于 300ms，自动把前一句的结尾连到后一句的开头，后一句的开头不动。 - 默认开启 180Hz 到 3800Hz 的人声频段滤波 (speechbandpass=True)，过滤低频底噪，音量高于 -30 dBFS 才算说话。800ms 以内的停顿默认合并在同一条轴里。 - 单条轴默认不超过 10 秒 (maxcuems=10000)。遇到超过 10 秒的连续说话时，会在 5 到 10 秒之间找能量最低的换气波谷切开，避免切在词中间。

2. 批量字幕与样式处理 - 打开或新建字幕时可以直接传入 videopath、audiopath 和 templateass，自动写入 [Aegisub Project Garbage]。Aegisub 打开该文件时会自动挂上视频画面和音频波形。 - aegisubbatchupdate 支持一次修改多行，也支持传入 texts 列表按顺序填入空轴。如果台词带 角色：台词 前缀，会自动拆出说话人并匹配同名样式。 - aegisubimportstyles 可以从现成的 .ass 模板里把全部样式和分辨率直接导进当前工程。 - aegisubmakecontinuous 用于连接相邻行时间，aegisubsplitjoin 用于拆行或合并行，aegisubseteffect 用于写入 \pos、\move、\fad、\clip、\t、卡拉 OK 和矢量绘图标签。

3. Windows 实机自动同步 - Aegisub 没有官方的远程控制接口。本仓库通过 automation/mcp-bridge.lua 读写本地命令队列，并在 Windows 下用 WMINITMENUPOPUP 和 WMCOMMAND 直接触发 Aegisub 菜单里的 Apply Pending，不需要手动去点菜单。 - 修改类工具都可以传 syncgui=True，改完文件后直接刷新正在运行的 Aegisub 窗口。 - 也可以用 aegisubtriggermenu 直接调用 Aegisub 的原生菜单项，或者用 aegisubuiactions 查询当前机器的快捷键配置（hotkey.json）和面板焦点要求。

工程与文件 工具 说明 ------------ aegisubopen 打开 ASS，可同时绑定视频、音频和帧位置 aegisubcreate 新建 ASS，可指定模板 ASS 导入样式并关联音视频 aegisubsave 保存 ASS (UTF-8 with BOM) aegisubsummary 查看文档信息、样式列表和已绑定的音视频路径 aegisubsetscriptinfo 修改 [Script Info] 和 [Aegisub Project Garbage] aegisubexport 导出 ass、srt、vtt、txt
