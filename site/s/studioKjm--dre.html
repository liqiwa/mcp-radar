About dre

Analyze the business and domain side of a reference site, platform, or product: business model, positioning, marketing, ads, tech stack, financials, and pricing history — with evidence and explicit uncertainty on every claim. The business-side counterpart to REA, which covers the technical side.

Status: pre-release. 11 MCP tools built and tested; AC-008 (independent accuracy benchmark) is still pending real user labeling. See docs/adr.yaml for the design decisions behind each feature and .harness/ouroboros/ for the spec/eval history.

Auto-detects installed agents (Claude Code, Cursor, Gemini CLI, Codex, Grok Build) and registers the DRE MCP server with each. Open a new session and the tools below appear automatically.

Options: - npx dre-agents setup --agent=claude,cursor,gemini,codex,grok — skip detection, target specific agents (or --agent=all) - npx dre-agents setup --project — register Claude Code/Cursor/Grok Build for the current project only (default: all projects; Gemini CLI and Codex are user-scope only)
