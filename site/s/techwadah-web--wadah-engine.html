About wadah-engine

Wadah indexes your Git repository per commit (symbols, imports and structural changes) and serves that knowledge to AI coding assistants through a local MCP server. It runs entirely on your machine. When Wadah cannot analyze something, it says so instead of returning an empty result.

Wadah also packages and runs AI agents the way Docker packages apps (.wpkg packages, OCI push/pull, execution traces). That part is experimental; see Status.

Prebuilt binaries for macOS (Apple Silicon and Intel), Linux (x64 and arm64) and Windows (x64) are attached to every GitHub Release, with SHA-256 checksums. The commands below work from the first release, v0.1.0.

Every method installs the wadah command. Check it with wadah --version. git is required; python3 and go are optional and enable the Python and Go adapters (without them those files are reported as unsupported, never as empty).

The MCP server is read-only by default. Tools that write to the local knowledge store are only exposed when you pass --write.

Run wadah --help or wadah --help for every command and option. Most commands accept --json or --plain for scripting and CI.
