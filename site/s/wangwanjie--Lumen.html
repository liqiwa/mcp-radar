About Lumen

iOS / macOS 界面调试工具：3D 分层查看界面层级，并提供命令行与 MCP 接口，让脚本、CI 与 AI 助手也能读取界面。

https://github.com/user-attachments/assets/145638f3-5af4-4100-ad07-fdfa3a7fb970

一行命令后，Claude Code、Codex、ChatGPT 桌面 App、Cursor 等 AI 助手就能读取运行中 App 的层级、截图、审计、改属性、定位源码。模拟器、USB 真机、任意 Mac 应用、未加壳的第三方 ipa 都能直接调试，UIKit、SwiftUI、AppKit 全支持。

Lumen 用来查看运行中 App 的视图层级，并把同一套能力开放给命令行与 AI 助手，支持 macOS AppKit 程序与零改动注入。

能力 说明 ------ 2D / 3D 层级画布 Metal 渲染，平面与分层 3D 视图切换（透视投影，3D 分层跟随大纲的展开与折叠），可调层间距（⌘[ / ⌘]）、相机复位，显示隐藏节点与边框线；间距测量分关闭、父视图边距、锁定两节点三档；按 layer.mask 裁剪，不画被遮罩挡住的内容；搜索结果在画布上着色、其余淡化；无内容图层可选透明、只描边框或淡色底板；“定位”后目标图层闪烁高亮；还原 iOS 26 / 27 标签栏的液态玻璃底板与选中镜片，以及网页、Metal、视频、Lottie、SwiftUI 列表图标与 foregroundStyle 着色、OpenGL 绘制的窗口（如 Qt 5 App）、Electron / Chromium 网页等图层的内容；液态玻璃按真实的模糊半径还原；3D 下展开 / 折叠时层栈以中间为基准对称伸缩，各层平滑移到新深度；画布控件是可停靠在上 / 下 / 左 / 右边缘的悬浮胶囊（左右时竖排，拖动或右键切换位置）、底部路径栏（从根到所选节点，逐段可点）与缩放百分比；状态栏显示加载阶段、纹理进度与耗时 层级大纲 树形大纲与画布联动选中，悬停行时画布同步高亮；按类名、文本等过滤，搜索结果可继续下钻；键入类名或控制器名前缀直接定位；层级深度预设（⌥⌘1…⌥⌘5）按窗口与 ViewController 展开；聚焦模式只看某个节点的子树（Esc 退出）；按 App 记住展开状态；顶层列出 UIWindowScene 与 Layout Guide；层级很深时缩进自动收窄，深层节点也能看全；可在设置中调整字号、行高与层级引导竖线 屏蔽的类 在设置中维护要屏蔽的类，画布不渲染命中的节点及其子树，大纲灰显标识，可临时显示、重新屏蔽或一键屏蔽此类 SwiftUI 在宿主视图之下给出 SwiftUI 的逻辑视图树：Text 的文字、Button / Toggle / TextField 等控件、修饰符链与参数、调试数据中的属性值（含 @State），可按文本查找；集成 LumenServer 或注入后自动开启。逻辑节点渐进加载：首次读取慢的宿主先显示平台层级，空闲时在后台逐个补读并自动推送，iOS“设置”这类大型 App 首屏从约 26 秒缩短到 0.4 秒 属性检查器 几何读数卡（父视图与所选节点的尺寸、四边边距、原点与窗口坐标）；按类分组的属性、继承链（悬停显示所在的 framework）、所属 ViewController、实例变量名及其持有者、accessibilityIdentifier；contentMode、textAlignment 等枚举显示名称并可下拉修改；控件的“事件处理”栏列出 target-action 与 UIAction 运行时改属性 在检查器中直接修改可编辑属性（数值拖动微调、取色、文本等），值为 nil 的颜色与文本同样可改；大纲与画布的右键菜单可直接
