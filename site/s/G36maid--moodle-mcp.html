About moodle-mcp

English 繁體中文 简体中文 日本語 Español Deutsch Português Français

A Model Context Protocol server that lets LLM agents use a real Moodle LMS — read courses, fetch assignment PDFs, write code, upload and submit — through a single static binary.

Built in Rust on the official MCP SDK (rmcp). Validated live against Moodle 3.7 → 5.x.

A generic chatbot has no way into your Moodle, so every study task stays manual:

- ❌ Five browser tabs open just to answer "what's due this week?" - ❌ Assignment PDFs downloaded by hand, then re-uploaded into a chat window - ❌ Forum threads and grades copy-pasted one page at a time

The agent signs in as you. 22 typed tools cover the full student journey just like a real human — from a quick deadline check to fully automated assignment assistance, without ever opening a browser:

The agent chains the tools itself: course map → assignment brief → PDF → markdown → solution → upload → draft submission → read-back verification. Full journeys in Prompt examples and How the agent works.

- Batteries included — document conversion (anydoc), HTML → markdown (htmd), auth CLI and the escape hatch ship in the box: no plugins, no helper scripts, no second runtime - Agent-native — tools take and return local file paths instead of base64; results embed the IDs for the next tool; defaults come with hints ("pass courseids to filter"); errors are plain-language and suggest the fix - 22 curated tools, human-shaped — each one mirrors a step you'd actually take clicking through Moodle: courses, course map, assignments, submission, forums, files (fetch/convert/download/uploa
