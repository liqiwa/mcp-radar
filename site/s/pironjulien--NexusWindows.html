About NexusWindows

Windows computer use in the background for AI agents: your desktop apps observed through UI Automation and driven without taking your mouse, keyboard or foreground, with every action read back and outward actions (send, pay, publish, delete) held for your explicit yes. One repository, one common engine, three profiles:

Profile Folder For --------- Claude claude/ Claude Code and Claude Desktop Codex codex/ the OpenAI Codex desktop app Antigravity agy/ Google Antigravity

For current MCP requests, native file dialogs, UTF-8 stdio and blank Chromium pages, use the shared MCP cookbook.

Windows 10 or 11, x64 or ARM64; nothing else to install (one self-contained native program, no Python, Node.js or .NET runtime needed).

Let your AI install it: NexusSystem detects your AI apps and sets up the right profile.

Or get the NexusSystem app from the Microsoft Store (winget install --id 9NSH2P3QLWT1 --source msstore). By hand, from the release files (no administrator rights):

get.ps1 downloads NexusWindows-win-x64.zip or NexusWindows-win-arm64.zip from the latest release, checks its SHA-256 against SHA256SUMS.txt, installs the engine under %USERPROFILE%\.nexus\nexus-windows and declares it to Claude Code, Claude Desktop, Codex and Antigravity when they are present. Every client starts the same stable path, %USERPROFILE%\.nexus\nexus-windows\NexusWindows.exe --mcp --agent ; updates never change it. Release files carry a build provenance attestation (gh attestation verify --repo pironjulien/NexusWindows --signer-repo pironjulien/NexusSystem). The Claude Desktop extension is nexus-wind
