About mcd-1024-skill

饭点选套餐：几个人吃、每个人想吃几分饱、人均预算多少、前两天的主食要不要再吃？先比较完整套餐的优惠价，再让圆盘揭晓这一餐。AI 饭搭子用明确口味记忆、当地天气与节令挑选；麦当劳雷达用历史订单点亮用餐热力图。

参赛者独立开发，非麦当劳官方产品。2.3.0 · 无业务后端的浏览器扩展，附带无需 Token 的静态体验页。

直接体验历史样本 · 下载 2.3.0 扩展 · 安装与更新 · WorkBuddy 实际开发记录

活动申请已提交至 官方 Issue 398，报名结果以官方回复为准。发布验证见 验证记录。

适合午餐选择困难、想在预算内吃完整套餐、或需要一起选餐的 1–4 人。无需 AI key 就能体验圆盘和示例热力图；实时选餐使用自己的麦当劳 Token，AI 饭搭子另用自己的 DeepSeek API key。

例如：1 人、7 分饱、人均 30 元，勾选前两天吃过的主食 → 官方核价 → 转盘揭晓，或请饭搭子按口味与天气挑选。喜欢的组合可以主动记住，下次推荐会参考这些反馈。

1. 从 GitHub Release 下载扩展 ZIP，解压得到 mcd-wheel-extension 文件夹。 2. Chrome 打开 chrome://extensions，或 Edge 打开 edge://extensions；开启开发者模式，选择“加载已解压的扩展程序”，选中该文件夹。 3. 点击扩展图标 → “连接我的账号” → 填写自己的 麦当劳 MCP Token，选择营业中的门店，开始核价。 4. 顶部“AI 搭子与记忆”可配置 DeepSeek key、风格、Agent 和 prompt；两种 key 都能分别选择在本机长期保存。

这是 GitHub 下载发布，扩展尚未上架 Chrome / Edge 商店。在线体验页只展示历史样本与虚构雷达，不接收真实凭证；实时 MCP 与 DeepSeek 功能在扩展中使用。

- 默认 1 人、7 分、人均 30 元，支持 1–4 人。每个人都有主餐，显示整顿上限、完整内容、总价和人均价。 - 套餐优先：随心配、三件套餐、分享餐与多份完整套餐；前两天吃过的主食可以手动勾选，或从雷达读取后主动加入避开项，本页记住。 - 麦当劳雷达：全年 / 近 12 周热力图、年份切换、日期餐单和常点餐品；只计已完成或已评价订单。接口没有分页参数，未返回的日期标为未知，不等于没吃过。 - 扩展直接连接麦当劳。用户可自行勾选“在这个浏览器长期记住凭证”，将 Token 和上次门店保存在本机扩展中，刷新或重开自动连接；不进入开发者服务器、日志或浏览器同步。 - 输入城市和地址 / 地标查找附近门店，或主动读取、选择麦当劳已保存的地址作为搜索位置；展示官方营业状态和时段，可随时换店。恢复上次门店前会向官方重新确认营业情况。 - DeepSeek V4.1 Flash：推荐 Agent、优化 Agent 或最多两轮协作；可编辑口味与两个 prompt，选择温柔 / 节省 / 惊喜的搭子风格、偏好 / 省钱 / 换口味目标。key 与麦当劳凭证独立，长期保存默认关闭，刷新不自动请求 AI。 - 明确喜欢 / 少推荐反馈可选择本机长期记忆，支持查看、忘掉和清空，旧偏好逐渐减弱；城市天气、月份和已核验的 2026 年节假日 / 调休进入推荐。AI 只选已核价候选 ID，卡片价格与餐品来自原报告；无 key 时仍可用本地偏好推荐。见 AI 饭搭子说明。 - 先查可领券、持有券、门店适用范围和活动日历，再比较各餐单的官方整单报价，最后按预算入盘。 - “领取全部可领券”有明确确认窗口；官方一次领取全部，无法指定单张。领取后重新查券、核价，写请求不自动重试。 - 暖色卡片、人数与食量切换、预算快捷选项、优惠口袋、核价进度、套餐
