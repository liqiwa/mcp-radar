About halfnine

A small, calm PostgreSQL client for macOS and Windows, light enough to leave open all day.

It is early: ROADMAP.md says where things stand.

Download the installer from Releases. The builds aren't signed yet, so each system asks once before opening them:

- macOS (Apple silicon, macOS 13 or later): open the .dmg and drag Halfnine to Applications. Open it once, then choose System Settings › Privacy & Security › Open Anyway. Or run xattr -dr com.apple.quarantine /Applications/Halfnine.app. - Windows (x64): run the -setup.exe. At the SmartScreen warning choose More info › Run anyway. It installs for the current user, without administrator rights.

When a connection saves its password, macOS asks once before Halfnine first reads it, and again after each update until the app is signed. Choose Always Allow.

Halfnine is also an MCP server, so Claude Code, Codex, Cursor, VS Code and Claude Desktop can use your connections through it. Open Agents, at the foot of the sidebar or the connections screen, choose Connect next to your tool, and Halfnine shows what it will change before it adds itself. Or add it by hand; on macOS:

For Claude Desktop, install Halfnine first, then open the .mcpb file from the same release to add it as an extension. It is also listed in the official MCP Registry as io.github.notinferred/halfnine.

Each connection sets what agents may do there, under Agents in its settings: Off, Read, Read with approved writes, or Full. Red-labelled connections start at Off and every other at Read. At Read with approved writes, an agent's change opens in Halfnine as staged r
