About knock

Stop Claude Code from burning your usage limit on big repos.

On a large codebase, Claude Code spends much of each session searching and reading files, often through a sub-agent, before it answers you. knock gives it a map of the code up front: the functions that matter, their exact line ranges, and who calls what. It runs on your machine and needs no API key.

Same question, 8 runs each, on a 4,776-file repo: median cost $0.42 → $0.25 (−40%).Without knock, Claude spawned a sub-agent in 5 of 8 runs. With knock, in none.

Full code map for Python and JavaScript/TypeScript; functions and classes for Go, Rust, Java and more.

Two real Claude Code sessions on Saleor, abridged: each side's median-cost run out of three. Results vary between runs and repositories; on a small, well-known repo the difference was within noise. Full numbers: docs/benchmark.md · how it was measured: the write-up.

Every new chat with a coding agent starts with amnesia. To answer "where is X?" or "how do we deploy?" it greps, opens big files, reads them... and next session it does it all over again.
