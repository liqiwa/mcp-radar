About runidbg

[!WARNING] 免责声明：本项目（runidbg）仅用于二进制安全研究、逆向工程学习、性能评测及经授权的安全测试。严禁将本项目用于任何违反法律法规或未经授权的用途；因使用本项目产生的任何后果与法律责任均由使用者自行承担。

Rust + unidbg = runidbg · 纯 Rust 实现的高性能 Android ARM64 .so 仿真器、零拷贝二进制 Tracer 与 QuickJS 脚本引擎 内置异步多核 RPC 服务 · MCP AI 逆向闭环 · GDB RSP 远程调试 · 统一设备画像模拟

🚀 冷启动速度 🔥 全模块 Trace 吞吐 💾 单实例 RPC 内存 ⚙️ 多核 RPC 吞吐 📦 单条 Trace 体积 :---: :---: :---: :---: :---: 77 ms (22.6× vs unidbg) 17.03 M insns/s (114× vs unidbg) 21.7 MB (省 82%) 1,141 QPS (10 核) 32 B / insn (省 3.7×)

runidbg 仍在快速演进中，非常欢迎通过 Issue / PR 提交在仿真中遇到报错、缺失符号/系统调用/JNI 或结果不一致的 Android ARM64 .so 样本与最小复现脚本，帮助我们持续完善兼容性与生态覆盖！

反馈时请先脱敏去除真实 Cookie / Token 等敏感凭据，推荐附带： 1. 最小复现脚本（QuickJS 脚本或 Rust 用例）与脱敏测试输入； 2. EnvDiag 诊断输出（JSON.stringify(emu.diag.report(), null, 2)，自动列出缺失文件、系统属性、Syscall 与 JNI）； 3. 崩溃现场报告（如发生异常，附 emu.lastCrash()?.formatted 输出的寄存器、反汇编、调用栈与面包屑）。

- 🦀 Android ARM64 原生仿真底座：基于 Unicorn 2.1 + goblin，完整支持 ELF 动态链接（.initarray、IRELATIVE、符号重定位、DTNEEDED 递归加载、TLS TPIDREL0）、高频 libc/libm HLE 加速（含真实 AAPCS64 vsnprintf/snprintfchk/sscanf/asprintf/atoll）、VMA/MMU 内存管理与防反调试。 - 📱 统一设备画像与双模式时钟（DeviceProfile）：内置 pixel5 / pixel8pro / s24ultra / xiaomi14 真机画像与任意字段覆盖，一处配置自动联动 30+ 系统属性、/proc/cpuinfo、/proc/meminfo、/proc/version、/sys/devices/system/cpu/online 与 uname；支持确定性虚拟时钟与宿主机实时时钟（realClock）一键切换。 - 🧬 JNI 1.6 完整环境：支持 JNIOnLoad、RegisterNatives、容器安全的引用生命周期管理、内置常用 Java 模型（String 构造与方法、Thread.currentThread()、基础类型装箱 valueOf 等）以及可插拔 JS/Rust JNI Hook。 - ⚡ 零拷贝二进制 Tracer：支持 fast / regdelta / full 三级分层追踪、mmap 双流落盘（.idx + .ext，结束时精确截断无尾部零填充）、毫秒级离线检索（dump / search）以及 IDA Pro / Binary Ninja 覆盖率脚本一键导出。 - 📜 QuickJS 零配置脚本引擎 + TypeScript 智能提示：写 JS 即可完成逆向分析，内置
