About inkbone

English · 在线试跑台 / 整书体检 · npm 包 · 社区讨论 · 9 个题材包 · 简繁自动识别 · MCP 三件套 · VS Code 实时扩展 · 66 项测试

不管你是只在网页里用 DeepSeek / Claude 写连载的作者，还是在 Claude Code / Cursor 里全流程跑 Agent 的重度用户，v2.0 都有一条零废话的上手路径：

你平常用什么写小说？ 直接怎么开始 你能立刻拿到什么 :--- :--- :--- 网页端 DeepSeek / Claude / Gemini / 豆包（不想装任何环境） 打开 在线试跑台 & 整书体检 拖入单章或整个 chapters/ 文件夹（纯浏览器本地运行，正文绝不上传）→ 词级高亮 + 跨章回声榜 + 一键复制精准改稿 Prompt + 起点/番茄/七猫/晋江纯净 .txt 导出 Claude Code / Codex / Antigravity / OpenCode npx skills add blankym/inkbone 8 阶段完整写作工作流 + 活账本防剧透 + 本地自动质检 + 9 份题材剧本卡 Claude Desktop / Cursor / Windsurf（MCP） 配一段 npx -y inkbone mcp 一个配置拿齐 9 Tools + 8 Prompts + 11 Resources，连 Skill 都免装 VS Code / Cursor 实时写手 & 终端 CLI npx inkbone audit ch01.md 或启用 VS Code 扩展 零克隆整书体检 / 安全拆书定风格 / 边写边划波浪线（中文小说 ESLint）

- 前面埋的伏笔写到第 40 章自己忘了，或者把第 60 章才揭的底提前漏在旁白里，甚至第 12 章已经阵亡的配角在第 38 章又走出来说话； - 仙侠文里突然冒出“降维打击”“寅时十刻”，每章必来一遍“瞳孔骤缩”“嘴角露出一丝苦笑”； - 上一句主语是配角，下一句省了主语直接写动作，读者读成配角动的手； - 让模型自己审稿，它张口就编一段原文里找不到的引文，顺手劝你“多加五感描写和形容词”，结果越改 AI 味越重。

靠把 Prompt 越写越长管不住这些毛病——模型自己写完就忘了。InkBone 把“会忘事的生成”与“不会忘事的硬检查”拆开：写前由脚本编排防剧透上下文与分阶段节拍，写完由零依赖本地引擎按词表、台账、历法与主语链逐行卡死。

Tab 1 单章体检支持本地 .md/.txt 拖入、简繁自动识别（含港台網文繁體規則）、原文词级 高亮、段落节奏心电图，以及一键复制精准改稿 Prompt（直接粘回任意网页大模型只改命中行，不破坏原节奏）。

Tab 4 整书体检（Browser Doctor）支持一次选入整个 chapters/ 文件夹：自动按中/数字章号排序，测出每章跨章回声率与全书高频套话 Top 10，一键下载自动挖掘好人物名单的 ledger.json，并一键导出起点 / 番茄 / 七猫 / 晋江纯净投稿 .txt。

维度 常见纯 Prompt 写作提示词 InkBone v2.0 :--- :--- :--- 去 AI 味与语域检查 靠大模型自我约束，几千字后必然漂移 确定性代码引擎逐行扫描，支持简繁自动识别、9 个题材包与项目级自定义规则 长篇防吃书与防剧透 把大纲全塞进上下文，越长越容易提前漏底 活账本闭环（packet + settle + check-ledger）：未到 revealChapter 自动 [REDACTED]，已退场/阵亡角色再出场直接预警 AI 审读可靠性 容易编造原文里没有的句子，越权乱改文风 verify-review 硬核验：原文找不到逐字引文
