About fastdown

一条公开分享链接 → 无水印直链。 网页粘贴即用，CLI 一行装好，REST API 一个 POST 接入，MCP 让 Codex / Claude Code / Cursor 直接会下载。

Fastdown turns a public short-video share link into a no-watermark media URL. Use it in the browser, from the fast-download CLI, through the REST API, or as an MCP tool for your agent.

只处理公开分享链接 · 与各内容平台无隶属关系 · 请确保你对下载内容拥有合法权利

这个项目叫 Fastdown，官网就是入口： —— 打开网页、粘贴链接、拿到文件，不需要安装任何东西。

你会看到的叫法 指的是什么 ------ Fastdown / fastdown.pro 产品名与官网，网页版入口，手机浏览器同样可用 fast-download 命令行可执行文件名，同时也是 MCP stdio 服务端 Fastdown API https://fastdown.pro/api 下的 REST 接口，给服务和 CI 用 TK无水印下载 / TikTok无水印 / 抖音无水印 / 小红书无水印 大家搜索这类需求时的说法，落到同一个解析服务 MCP video downloader / Agent video downloader 给 AI Agent 用的接入形态

本仓库是「用法仓库」，不是服务端源码。 这里放的是 CLI、MCP、REST API 的调用示例与文档（examples/、docs/），解析服务本身的实现不在本仓库内。

短视频平台只给你「在 App 里看」，不给你「把文件拿走」。想把一条公开视频存下来做素材、做备份、做二次创作，通常得装客户端、看广告、或者忍受带水印的低码率版本。

Fastdown 把这条链路做成了一个接口：你只负责贴链接，平台识别、清晰度选择、去水印、直链签发都在云端完成，几秒后返回一条可下载的地址。

传统做法 Fastdown ------ 装客户端、看广告、导出还带水印 贴链接，直接给无水印直链 在手机上折腾文件管理器 网页版手机可用，CLI 落到本地 每个平台一套工具、一套登录 7 类平台一个入口、一份配额 写脚本要自己抓包、逆向、处理签名 一个 POST /v1/parse，Bearer 鉴权 让 Agent 帮忙下载，它只会打开浏览器 MCP 工具 downloadvideo，Agent 直接落盘

和「下载器客户端」的区别：Fastdown 是解析服务，不是伪装成播放器的下载器。它不代理视频流量、不落盘源文件，只把平台已经公开发出的媒体地址解析出来交给你 —— 所以它能在网页、CLI、API、Agent 四种形态里用同一套配额。

你的场景 用什么 怎么开始 --------- 偶尔下一条，手机/电脑都行 网页版 打开 ，粘贴链接，点 Parse 批量、脚本化、要落到指定目录 CLI curl -fsSL https://fastdown.pro/cli \ sh 接进自己的服务、CI、工作流 REST API POST https://fastdown.pro/api/v1/parse，Bearer 鉴权 让 Codex / Claude Code / Cursor 自己会下载 MCP 一条带 key 的命令装好，Agent 里直接说「下载这个链接」
