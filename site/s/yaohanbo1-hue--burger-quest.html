About burger-quest

输入预算、心情、口味和用餐偏好，RPG 游戏主持人替你从麦当劳中国官方 MCP Server 的真实菜单里，组出一份不超预算的点餐方案，并生成一张可以分享的任务成就卡。

非麦当劳官方项目 —— 本项目为「麦当劳程序员创意开发大赛」参赛作品，由参赛者独立开发。餐品信息、价格及供应状态以麦当劳官方渠道的实时结果为准。

痛点：「今天吃什么」每天都在发生，但预算、口味、营养、优惠券四个约束同时成立的最优解，人脑算不动——问通用 AI，它不知道麦当劳此刻卖什么、多少钱、你有哪张券。

方案：把点餐变成一场 RPG 冒险。说一句话（预算/口味/人数/用餐方式），游戏主持人调用麦当劳中国官方 MCP Server 拉取真实菜单与权威价格，给出最多 3 个可比较方案 + 一张可分享成就卡。

- 官方 MCP 全链路：10 个在用只读工具（7 个常规主链路 + 1 个餐品详情回退 + 2 个第一阶段扩展：活动日历/可领券；代码 TOOLSUSED 注册表为权威，并非每次任务全调）走官方 Streamable HTTP + 官方 mcp SDK；分工具超时、有限退避、429 降速、401 不重试、连续失败断路（重试/熔断细节有专项测试）； - 不编造铁律：总价只认 calculate-price 权威返回；菜单价缺失的餐品直接出局；缺 Token 明确失败（退出码 2），绝不回退演示数据； - 工程完成度：657 个测试、覆盖率 91.44%、mypy 0 error、bandit 0 finding、pip-audit 0 漏洞——四道质量门禁（覆盖率 ≥85% / mypy 零 error / bandit 零 finding / pip-audit 零漏洞）；当前最新提交的 CI 通过 7/7 个 job：Linux ×4（Python 3.10/3.11/3.12/3.13：全量测试 + 覆盖率门禁 + wheel 打包自检 + 空白检查）、Quality gates ×1（密钥扫描 / skill 文档一致性 / mypy / bandit / pip-audit / 离线演示可复现性）、Windows ×2（Python 3.11/3.12：全量测试 + PowerShell 脚本解析 + 无 Token 路径行为 + CLI 入口与离线演示）； - 安全边界：本地 Web 界面 Host 白名单 + Origin 同源校验（挡 DNS rebinding 与跨站代打，Origin: null 一律拒绝）；Token 不落审计/日志/卡片/进度存档任何一处。

深读：MCP 集成与联调实测 → MCPINTEGRATION.md；架构与数据流 → §8；质量门禁 → §6。

「麦门异世界」是一个游戏化点餐规划 Skill：把「今天吃什么」变成一场 RPG 冒险。

- 你（冒险者）说出预算、口味、心情、人数、用餐方式； - AI（游戏主持人）调用麦当劳中国官方 MCP Server 查询真实可售菜单、真实价格、真实优惠券和营养数据； - 主持人生成任务书：任务名称、故事背景、推荐装备（真实餐品）、选择理由、总价与剩余预算； - 一键生成分享成就卡（HTML / Markdown）。
