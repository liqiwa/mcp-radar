About genkan

The AI-native start page for your homelab. Tell your AI assistant to organize your services and Genkan applies it instantly. Wallpaper, frosted-glass UI, ~11 MB.

Genkan is built to be driven by an AI assistant. Point Claude, Cursor or any AI agent at it and just say what you want:

"Group my services by type and pin the five I use most."

"Add Jellyfin, Sonarr and Radarr at nas.lan to Media and enable health checks."

"Find dead links and move them to an Archive category."

Changes land immediately and the open page updates live. There are two alternative ways to connect an agent: an Agent Skill (source in skills/genkan/; it uses the REST API with curl, no MCP setup needed) or the built-in MCP server with 13 tools. Live updates use SSE, and everything stays local on your own server.

Pick one (Settings → AI shows both with your real values; one API token covers everything):

1. Skill (recommended): Settings → AI → copy the setup prompt and send it to your AI assistant; it installs the Skill and your token (or download the package there and unzip it into ~/.claude/skills/). 2. MCP (alternative): claude mcp add --transport http genkan http://:8080/mcp --header "Authorization: Bearer " (a generic JSON snippet is there too).

[!WARNING] The token is full admin access and is embedded in the setup prompt and MCP snippets. Never share or commit them; regenerate the token if it leaks.

The REST API (which the Skill uses) and the MCP tools are described in docs/SPEC.md.
