About dsh-gitea-search

DeepSeek Harness (DSH) 高性能 Gitea 代码与文档全文检索 MCP 插件。

- 毫秒级文档与历史会话检索：基于 SQLite FTS5 引擎与 Jieba 中文分词，支持 BM25 智能加权与类型软分区（doc, session, config, script），完整索引用户提问与助手回复正文。 - 极速代码搜索与智能多词回退：支持全分支内容、文件路径、提交信息的毫秒级 git grep 检索；当多词短语字面量连写 0 命中时，自动回退为「同行多词 AND」检索（--and）。 - 低开销增量索引：内置 headcommit 变更门控，未发生提交的仓库自动跳过遍历，日常增量扫描耗时压至 1 秒级。 - 安全四层护栏与行窗口：严格防范单行溢出（2000B）、总体缓冲区溢出（128KB）、默认返回 5 条命中、readgiteafile 默认 400 行窗口与 UTF-8 字符跨块截断乱码（U+FFFD）。 - 多主体自适应：支持按 Token 自适应探测可访问仓库，或显式指定多租户 GITEAOWNERS 白名单。 - 细粒度会话归档：配套 session-export-incremental.py 会话增量导出工具（支持 v1~v4，完整提取用户消息与助手文本块并跳过思维链，基于 os.scandir(followsymlinks=False) 防软链环死循环），单会话独立文件，精准追踪历史故障排查记录。

- 耗时与磁盘 I/O 自动监测与阈值判定：内置 IoTracker 与 evaluateperfbudget（采集墙钟耗时、CPU 时间、/proc/self/io 的 rchar/wchar/readbytes/writebytes/syscr/syscw），落盘 state/perf-metrics.jsonl 并自动判定 OK / WARN / CRITICAL。 - 宿主 DSH 会话存储代数预检与无损迁移（零修改 DSH 官方代码）：提供 scripts/dsh-session-health.mjs（--check / --fix）与 gts --doctor，在安装期与运行期主动识别旧版（32MB 自动在线 walcheckpoint(TRUNCATE)）及 nodemodules/.pnpm 软链环风险，防止 historicalCorpusRevision 冷迁移风暴。

在 DSH 的 profile patch（cordis.patch.yml）中插入一条 @deepseek-ai/dsh-mcp-client 条目。

⚠️ 配置格式（实测，勿凭记忆写） cordis.patch.yml 的顶层必须是 YAML 数组，每项是一个 loader patch。 dsh-mcp-client 的 config 是单个 MCP 实例的扁平配置，按 transport 字段区分 stdio / streamable-http（serverName + command + args …），没有 servers 这一层。 写成顶层 mcpServers: 或 plugins: → servers: 映射都会在启动时被拒： overlay ... must be a top-level YAML array of loader patch entries。
