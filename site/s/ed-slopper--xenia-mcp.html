About xenia-mcp

An MCP server that lets an AI assistant read and write the memory of a game running in Xenia (the Xbox 360 emulator), with GTA IV helpers for the large-steal-car-4 port: any address can be looked up in the port's function index and decompiled C.

It works with a stock Xenia: no patched build. Xenia reserves the 360's 4 GB guest address space as one block of its own memory (normally at host 0x100000000), so guest address g is base + g. The server attaches to the Xenia process with the Windows debugging APIs (ReadProcessMemory / WriteProcessMemory) and finds the base by looking for the game's executable image, which a 360 title loads at 0x82000000.

It can also watch a guest address with a hardware data breakpoint (xeniawatch): the small native helper native/xwatch.exe attaches to Xenia as a debugger for the time asked, counts every access to the field, and detaches again. Each access is named by the guest function that made it, through Xenia's own indirection table (at host address a, the 32-bit word is the host address of guest function a's compiled code). Code breakpoints, registers and stepping are still to come.

Needs Windows, Node.js 18 or later, and Xenia (Canary) with your own copy of the game.
