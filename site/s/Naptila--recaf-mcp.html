About recaf-mcp

recaf-mcp exposes headless Recaf analysis and patching through the Model Context Protocol (MCP). A Python stdio Bridge manages isolated Recaf JVMs; a Java plugin performs the actual analysis.

The Bridge uses your installed Recaf generic JAR in headless mode. No Recaf source checkout, modified Recaf build, or published Python package is needed.

Area Capabilities --- --- Browse Workspace summary, classes, archive files, Android manifest/resources Decompile One class or all selected classes to a ZIP; CFR, Procyon, Vineflower, or another installed Recaf decompiler Search Strings, JVM/DEX instructions, decompiled source, member declarations/references, call graphs Rename Classes, methods, and fields; import/export seven Recaf mapping formats Patch JVM Compile replacement Java source, run safe Recaf transforms, edit exact method instructions Analyze APK/DEX Android classes, decoded binary XML, DEX strings/instructions/members/calls, reconstructed single-class DEX Automate Compile and run version-matched Recaf Java scripts for custom deobfuscation Manage sessions Multiple isolated Workers, save/reopen, idle autosave, cancellation, cleanup, and recovery

All 26 tools are advertised before a target is opened, so clients do not need dynamic tool-list support. The complete tool catalog is shown below.

- JDK 25 for the checked-in Gradle toolchain and Worker processes. The plugin emits Java 22-compatible bytecode; patchclass requires a JDK with javac, not a JRE. - A Recaf 4 generic executable JAR, which bundles Recaf's runtime dependencies. - Python 3.11 or newer. - uv for the locked
