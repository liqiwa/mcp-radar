About MCP_Image_to_3D

One image of an object in, one 3D Gaussian-splat .ply out. A small Docker service around the speridlabs/idol model: web gallery, in-browser 3D viewer, HTTP API and an MCP server. No accounts, no cloud — it runs fully offline once the weights are downloaded once.

The installer checks Docker and Python, downloads the weights, builds the image and waits until the service is ready. Then open .

You need: an NVIDIA GPU with ~10 GB free VRAM (measured on a 10 GB RTX 3080), Docker, ~16 GB disk, and a Hugging Face account that has accepted the DINOv3 terms.

Tag objects, search, download or zip them. Trash is soft until purged, and tags are what make a library findable.

1. Get an image of one object. Keep the whole object inside the frame, on a plain light background or as a transparent cut-out. MCP Image Generator can make one from a sentence; see Need object photos?. 2. Open and press Create. 3. Choose a file or paste an image URL, pick a quality, and press Create. 4. Wait for the job to finish, about 44 s on a 10 GB RTX 3080 at the medium preset. The new object then appears in the gallery; open it to see it in 3D.
