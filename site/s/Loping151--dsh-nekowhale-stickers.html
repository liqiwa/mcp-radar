About dsh-nekowhale-stickers

给 DeepSeek Harness 的表情包知识库 逐张标注的使用场景、画面描述、梗出处与互动方向 · 按需检索 · 本地出图

表情包作者：B站 可以叫我云大人/雾雪 · kiriyuki.com 制作 · 欢迎约原稿同款表情包！ 套组：大肥鱼 · 大肥鱼和GPT娘

📚 表情知识库 逐张标注：场景标签、动作描述、关联梗，双人表情含对象方向，对模型自身视觉依赖低。常驻上下文占用约 60 token。

🎨 本地模板 想 / 举牌 / 葱卷 / 上联 / 下联 / 抱，本地制作文字表情包。

🎛️ 自选表情 允许 agent 可以自己浏览、开关，或只用挑中的一小组；用户配置的黑 / 白名单始终优先。

🔌 通用接口 cordis 服务 stickers、[sticker:名字] 回复标记、MCP server、CLI 与公开 JSON，不绑定框架。

🐋 网页桌宠 dsh 网页界面右下角会出现 kiriyuki.com 的 大肥鱼网页桌宠。桌宠在独立的跨域 iframe 里运行，不接触 dsh 的会话；配置 pet: false 可关闭。

大肥鱼想 下班 大肥鱼举牌 今天也要摸鱼 大肥鱼上联 代码一遍过 大肥鱼抱 + 头像

大肥鱼形象基于 ZipZipPipe 与 上善无形 提供的形象；GPT娘形象基于 ZipZipPipe。 大肥鱼：拟人化的 DeepSeek 鲸鱼娘。深蓝长发、呆毛、女仆头饰。 GPT娘：拟人化的 ChatGPT，双人套组里的白色角色，白发龙娘，有龙角和 OpenAI 发饰。 双人表情的 dir 字段记录方向，例如 大肥鱼→GPT娘。

重启 dsh web 即可。dsh 0.2 也可以在网页侧栏 插件 → 添加插件 里填 dsh-nekowhale-stickers。也可以安装本地打包的 .tgz（pnpm pack）。

最简单的方式：dsh 网页侧栏打开 插件 → 大肥鱼表情包（dsh 0.1.x 在 设置 → 插件 → 大肥鱼表情包），改完点保存，立即生效、无需重启。

也可以在 profile 的 cordis.patch.yml 里写默认值，网页里的设置会覆盖它：

项 默认 说明 --------- packs 两套 要使用的套组 autoSync lazy startup 启动时后台全量同步 · lazy 用到才下载 · off 完全离线 persona self self：模型就是大肥鱼，表情是它自己的表情（适合 DeepSeek）；neutral：当作第三方表情包 promptMode skill 常驻提示的多少；index 会列出已启用表情，适合配合 allowlist 只挑几十张 agentCuration true 允许 agent 用 stickermanage 自选表情 templates / banwords true 模板开关；与网站一致的屏蔽词过滤 returnImageToModel false 把图片附给模型看（消耗图像 token） pet true 网页界面里显示大肥鱼桌宠；false 关闭 petHeight / petBubbles 211 / true 桌宠大小（高度，像素）、对话气泡（关掉可少加载约 1.5 MB）

工具 作用 ------ stickersearch 按情绪 / 场景找表情，每条一行：名字｜情绪｜标签｜方向 stickersend 返回一行 Markdown 图片，模型原样放进回复；传情绪词则随机取一张 memerender 用模板生成表情 stickermanage 浏览、详情、开关、模式、出处、同步
