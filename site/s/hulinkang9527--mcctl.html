About mcctl

The kubectl for McDonald's China · 麦当劳中国 MCP 的命令行控制面

⬆ 10 秒真实流程：8 题测人格 → 麦籍卡 → 命定套餐 → 好友匹配度（网页为离线演示，预置数据）

普通点餐页只把菜单搬上屏幕；mcctl 把决策做成可编程的：8 题测出的人格不是标签，而是一套可计算的营养 / 口味 / 社交权重，直接驱动配餐组合搜索、券后到手价精算、派对场次约束求解——全部能在终端复现，--json 可直接接管道与 Agent。

▶ 在线体验（手机零安装） hulinkang9527.github.io/mcctl 8 题出结果 · 可下载麦籍卡 · 可算好友匹配度（离线 Playground） ⚡ 一行装上就跑 pip install git+https://github.com/hulinkang9527/mcctl.git &amp;&amp; mcctl whoami 🧭 一条命令串演全部能力 mcctl demo — 人格 → 配餐 → 省钱 → 下单演练 → 积分

mcctl 把麦当劳中国官方 MCP 开放的 35 个工具（CLI 已全量集成）编排成一套程序员命令：人格测试、控卡配餐、一键领券凑单、安全下单、积分兑换、派对预约，还能作为 Agent Skill 装进 WorkBuddy / Cursor。

网页 vs CLI 的边界，先说清楚：网页 Playground 是离线演示（纯静态、预置菜单与价格，不调用官方 MCP）； 想要实时菜单 / 库存 / 到手价请用 CLI —— mcctl --live（需在 open.mcd.cn/mcp 申请 Token，连不上会自动降级并明确提示）。

- 🃏 麦麦人格测试：8 题麦门人格测试（前 7 题二选一 + 第 8 题终局四选一）测出 8 型 McPersona，生成可下载、可分享的像素风麦籍卡；人格是一套可计算的营养 / 口味权重，直接驱动配餐。 - 💸 真·省钱引擎：一键领券 → 逐券试算 → 智能凑单，给你"基线 → 优惠 → 实付"和节省百分比，拒绝伪优惠。 - 🛒 安全下单闭环：到店 / 外送全链路，所有交易默认演练，必须 --confirm，真实环境跳转官方支付、不自动扣款。 - 🎉 麦麦派对策划师（主打）：mcctl party plan 把「城市 → 门店 → 日期 → 场次」做成约束求解——人数 / 预算 / 期望日期 / 名额硬约束卡死，输出 Top3 方案，--confirm 一键预约。 - 🔌 CLI 已集成 35 个 MCP 工具：真实 Client + 离线 Mock 自动降级，clone 即零配置体验，配 Token 切实时数据。四种形态：Python 包 + CLI、Agent Skill、离线网页 Playground、可复用 SDK。

方式一（零安装 · 手机点开即玩）：打开 网页 Playground（手机也能玩）：8 题测人格 → 命定套餐 → 下载 / 分享麦籍卡。

网页 Playground 为离线演示（纯静态、内置示例菜单与价格），用于展示人格测试与配餐逻辑； 真实 MCP 工具调用请在 CLI 实时模式下验证（方式二 / 方式四）。

也可以免 clone 一行安装：pip install git+https://github.com/hulinkang9527/mcctl.git。
