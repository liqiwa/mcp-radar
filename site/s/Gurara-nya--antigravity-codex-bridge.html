About antigravity-codex-bridge

Antigravity Codex Bridge 原生级 Google Antigravity ↔ OpenAI Codex 双引擎协同编排、强制总工转达闭环、UI 无感同步与可视化统计插件

English Documentation · 快速开始 (ZIP 安装) · 核心优势 · 可视化面板 · 功能参考

1. 环境准备 - Python 3.11 或更高版本（仅使用标准库，无需 pip install 任何第三方依赖；Windows 安装脚本会自动跳过旧版 Python 并寻找本机已安装的 Python 3.11+）。 - Google Antigravity（IDE / Desktop 2.0 / CLI 任一形态）。 - OpenAI Codex（已安装并完成账号登录的 Codex Desktop 桌面端 或 Codex CLI）。

2. 下载并解压正式发布 ZIP 前往 GitHub Releases 最新版本页面（或直接查看 v1.2.1 发布资产列表），下载 antigravity-codex-bridge-v1.2.1.zip 并解压。解压后会得到 codex-bridge 文件夹。

3. 运行安装脚本 进入解压后的 codex-bridge 目录，运行对应系统的安装脚本：

安装器会严格区分 “插件文件落盘” 与 “Bridge 连通就绪”，并在末尾明确打印以下 三种结果之一： 1. 安装完成，自检通过：Python 3.11+、Codex 可执行文件、登录凭证与 codex app-server --stdio JSON-RPC 握手全部通过，插件立即可用（若尚未打开过 Codex Desktop 项目库，会单独列出非阻塞的功能受限提示）。 2. 文件已安装，自检未通过：插件文件已就位，但找不到 Codex、未登录或 app-server 握手失败；终端会直接给出对应的下一步修复动作（自动化/CI 场景可加 --strict-doctor 让自检未通过时返回退出码 1）。 3. 文件已安装，跳过自检：传入 --skip-doctor 时仅安装文件并跳过连通性检查。

4. 如何单独重跑 doctor 自检 修复 Codex 登录或升级客户端后，无需重新解压安装，随时可单独重跑 doctor（全部核心项通过返回退出码 0，否则返回 1）：

5. 首次在 Antigravity 中确认插件真的可用 1. 查看插件管理页：在 Antigravity 聊天框或地址栏打开 customization://codex-bridge，确认 Codex Bridge 处于启用（Enabled）状态，且列出了 codex-bridge MCP 服务与 codex-commander 技能。 2. 发起首条只读连通验证：新开一轮对话（或在当前对话下一轮）发送： 请调用 codexbridgedoctor 检查 Codex Bridge 状态，并调用 codexbridgeoverview 告诉我当前发现了多少个 Codex 项目与实时剩余配额。 当 Antigravity 返回 "healthy": true 及你的本机项目数/配额百分比时，即代表 Antigravity ↔ Codex Bridge ↔ Codex 全链路已打通！

Antigravity Codex Bridge (codex-bridge) 将 Google Antigravity 打造成你的 “总工程师 + 需求翻译官 + 强制验收转达中枢”，把本机已安装的 OpenAI Codex（Desktop 桌面端 / CLI） 变成随时待命的 “二号执行与独立审查引擎”。
