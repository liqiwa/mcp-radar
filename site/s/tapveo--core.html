About core

If a human eye can see it and a finger can tap it, your code can drive it.

Open-source 6.8ms local vision + 71Hz physical USB/BLE HID closed-loop control for stock iOS. Bring any $6 ESP32-S3 board · No jailbreak · No Developer Mode · 100% local · Native MCP Server

Website · Web Flasher · Architecture · HID Protocol · Rust Host · Wi-Fi &amp; USB-C Link

Traditional iOS automation tools either run inside the OS debug stack (XCUITest / Developer Mode / Xcode) or rely on turn-based cloud vision loops (1–5s per step). Those approaches are great for white-box CI or exploratory browsing, but leave a gap when you need real-time closed-loop control on a stock, unjailbroken iPhone inside your own LAN.

Tapveo Core operates completely outside the mobile OS: - Eyes: Live AirPlay screen mirroring (UxPlay - local TCP stream) + fast local Rust computer vision (iphone-mcp-vision) tracking the AssistiveTouch ring cursor. - Hands: An ESP32-S3 (Seeed Studio XIAO ESP32-S3) enumerating as a standard USB HID or Bluetooth LE HID mouse + keyboard — zero software footprint on the phone. - Brain / Interface: A Rust host CLI & MCP Server (host/) exposing safe, foreground-verified actions to Claude, Cursor, Codex, or custom local vision loops.
