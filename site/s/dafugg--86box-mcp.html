About 86box-mcp

Let an AI agent, or your test suite, play, test and debug software on a vintage PC emulated by 86Box, with emulated time frozen between moves.

86box-mcp is an MCP server that drives an emulated PC at the hardware level: keys on the emulated keyboard, the emulated mouse, frames from the emulated video card, physical memory. Nothing runs inside the guest, so it works from BIOS POST on, in any video mode, under any OS. Its main targets are DOS games and tools. It runs headless (good for servers and CI), or with the normal 86Box window if you want to watch.

It is built on an opt-in automation socket in 86Box itself, merged upstream in 8365. It's off by default: build 86Box with -D AUTOMATION=ON to get it.

Automating Windows 9x? Use V9x Remote Agent instead. See how they compare.

An agent takes seconds to decide what to do; a DOS game runs at 35 or 70 frames per second. In held mode no emulated time passes between tool calls, so a real-time game becomes turn-based:

The agent thinks as long as it needs, and the game never moves without it. The same control makes runs repeatable: two cold boots driven by the same inputs produce byte-identical frames, whenever they run. Steps run as fast as the host allows (about 2× real time for a 486DX2-66 on an older Xeon).

- The guest's clock starts from the VM's saved CMOS, not the host's clock (timesync = disabled, in the [Machine] section of 86box.cfg).
