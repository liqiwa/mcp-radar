About coolapk-mcp-pro

纯只读的酷安社区资料检索 MCP Server——让 Claude Desktop / Cursor / dsh 等 AI 助手直接检索酷安帖子、话题与用户资料。

声明：本项目基于 Lniosy/coolapk-mcp（经 zjy2968466837/coolapk-mcp 增强后平铺引入）二次增强，详见 NOTICE.md。感谢两位上游作者。登录态复用的「酷安桌面端」同样是第三方社区项目，声明见下节。

登录态复用酷安第三方桌面端（见下方准备清单）、失效检测与重登、风控回落、图片读取。Python 3.10+（实测 3.14）+ FastMCP。

仅用于学习与测试，请勿滥用酷安官方接口。本服务不提供任何写操作（点赞 / 回复 / 关注 / 发帖）。

- 13 个只读工具：搜索、帖子详情、话题、用户资料、用户动态、首页动态、图片读取、登录状态、搜索联想词、URL 透传、作者画像、作者深挖聚合、图片外链中转 - 风控回落：帖子详情接口被验证码拦截时自动改从作者动态列表取全文（fetchsource 字段标注来源），回复走独立接口 - 请求节制：全局限速（相邻请求 ≥1.2 s）、GET 按 TTL 缓存、瞬态错误指数退避重试、验证码端点负缓存冷却 - 搜索净化：严格关键词过滤 + 去重 + 疑似广告标记，滤掉酷安搜索混入的不相关结果 - 登录态增强（0.2.0）：auto 模式直接复用酷安第三方桌面端的登录态（官方没有桌面端，此为社区项目），失效时结构化 authexpired 报错，支持 login --web / --sms / --cookie / --adb 重登

酷安官方只有手机 App，没有桌面端。本 MCP 的登录态能力依赖社区维护的第三方桌面客户端，需要自行准备：

你的情况 需要准备 - - 路径一（推荐）：安装桌面端 ① 下载并安装酷安第三方桌面端（Windows / macOS / Linux / Android / iOS 均有安装包；原项目 daimiaopeng/coolapk-desktop 已归档，由社区组织接续维护）→ ② 打开桌面端完成登录（官方授权页扫码或短信）→ ③ 没了，auto 模式自动复用其登录态 路径二：不装桌面端 ① 一个酷安安卓 APK（任意渠道版本，改名 coolapk.apk 放到 ~/.coolapk-mcp/，用于提取签名 blob）→ ② 用下文短信登录或 Cookie 导入建立登录态

说明：桌面端登录解决的是登录态（accounts.json），签名 blob 仍需安卓 APK（见下节前置）——桌面端的 exe/dmg 安装包提不了 blob。已装桌面端的用户可以顺手把手机上的酷安 APK 也放进来，两步就绪。

前置：token V3 签名需要设备指纹 blob（~/.coolapk-mcp/authblob.bin），仓库不携带该二进制，登录命令本身不会生成 blob。获取方式任选其一： 1. 把酷安 APK 改名为 coolapk.apk 放到 ~/.coolapk-mcp/，客户端启动后自动提取 blob 并缓存； 2. 从已有可用环境把 authblob.bin 复制到 ~/.coolapk-mcp/。

方式 命令 说明 - - - auto 模式（默认） 无需操作 优先读酷安第三方桌面端 %APPDATA%\com.coolapk.desktop\accounts.json 中 lastLoginUid 对应账户的完整 Cookie（含 SESSID），无效时回落 ~/.coolapk-mcp/config.json 的原生三键 token；设备码优先复用 accounts.json 的 deviceCode 网页登录 .venv\Scripts\coola
