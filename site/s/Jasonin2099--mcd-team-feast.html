About mcd-team-feast

开团 → 实时同步 → 确认锁单。发一个链接，全组各点各的；它帮你挑最省的券、算好每人转多少，再出一张 git log 风账单卡。

示例（真实麦当劳 MCP 计价）：5 人早餐拼单，原价 ¥139.50 → 实付 ¥125.30，人均 ¥25.06。

↑ 三个浏览器并排录制：团长开团 → 两位成员打开链接加入 → 各点各的实时同步 → 团长锁单 → 最终分账（演示数据）

① 开团 ② 实时同步 ③ 确认锁单 --------- 填个团名，点「开启实时同步」，得到房间链接和二维码 成员填昵称加入；谁在线、谁选好了、谁还在选，所有人实时可见；团长看汇总和每人小计，可设截止倒计时 团长一键锁单，成员只读并看到最终分账；需要改可以解锁

- 断网、切后台会自动重连；同步服务连不上时自动退回链接模式（数据全在链接里），界面上始终标明当前模式。 - 服务器只存昵称和点单，房间 24 小时自动删除。服务端零依赖，源码在 server/，可以自己部署。

--------- ⚡ 实时同步在线状态、选好了、截止倒计时、锁单 🎟 自动挑最优券枚举券组合逐一调 calculate-price，取实付最低 🧮 公平分账按原价占比分摊优惠，精确到分，总额守恒 🧾 三种账单卡git log / GitHub PR / 小票，字体内嵌，导出处处一致 🌐 网页即用中/英/日，深浅色跟随系统，微信长按保存 📋 一键收款消息“@小李 转 老王 ¥24.90”，复制即发 🤖 MCP Server + Skill一句话让 Agent 帮你拼单 🔍 feast blame钱包担当、热量担当（list-nutrition-foods） 🛡 绝不误下单下单要确认码；MCP Server 不暴露下单工具

↑ 接入真实麦当劳 MCP，在上海福州路餐厅实时计价生成（成员为化名，仅计价未下单）

git 提交记录 pr 合并请求 receipt 小票 :---::---::---:

✍️ 梗签名：每张卡片底部有一句程序员梗（按时段、人数、省钱比例、热量自动挑选），可 🎲 换一句、从列表选或自己写；CLI 用 --sign random / --sign '文案'。卡角附项目短链和二维码。

- 从不自动下单：网页只做计价和分账；CLI 下单必须带 checkout 生成的确认码；MCP Server 根本没有下单工具。 - Token 只在你本机：麦当劳 MCP Token 只从本机环境变量读取，不上传、不进仓库，网页版完全不需要 Token。 - 只存昵称：实时房间只存团名、昵称和点了什么，不要手机号、不要登录；24 小时自动删除。 - 可离线：不想用服务器就用链接模式，团的数据只在链接里。 - 开源可审计：零依赖，前端、CLI、同步服务都在这个仓库。
