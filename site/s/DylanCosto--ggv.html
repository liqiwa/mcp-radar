About ggv

GGV is a genome viewer for aligned reads, variants, gene annotations and signal tracks. It has three interfaces that share one implementation: a desktop application (ggv-desktop), a command-line tool (ggv), and a Model Context Protocol server (ggv mcp). A query at the same locus returns the same values from each of them.

A heterozygous 6.8 kb deletion in PacBio HiFi reads of HG002, grouped by haplotype. The reads carrying the deletion are all on haplotype 1. This locus is the first step of the demo.

Version 0.9 is a beta. It reads local files only. GGV displays and counts what is in the input files; it does not call variants.

Component Description ------ ggv-desktop Desktop application for BAM/CRAM, VCF/BCF, gene annotations and signal tracks. Rendering takes about 1 ms per frame. ggv Command-line queries at a base or region (TSV or JSON output), headless PNG/SVG rendering, and batch reports over a list of sites. ggv mcp MCP server exposing the same queries. It can attach to a running desktop application and use its current view.

System Package Requirements --------- Windows 10/11 (x64) ggv--windows-x64.zip DirectX 12 or Vulkan Linux (x8664) ggv--linux-x8664.tar.gz glibc 2.35+ (Ubuntu 22.04, Debian 12, Fedora 36 or newer), Vulkan or OpenGL macOS 11+ (Apple silicon and Intel) ggv--macos-universal.zip none

Unpack the archive and run the installer in that folder. Administrator rights are not required.
