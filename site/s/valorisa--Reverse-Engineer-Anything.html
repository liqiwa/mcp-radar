About Reverse-Engineer-Anything

Guide pédagogique non officiel, en français, pour comprendre et utiliser REA (Reverse Engineer Anything), un outil open source qui permet à un agent de code d'analyser des applications et des binaires, puis d'expliquer leur fonctionnement en montrant les preuves sur lesquelles il s'appuie.

Ce dépôt ne contient pas le code de REA. Le projet amont est morluto/rea, publié sous licence MIT. Ce guide est une documentation indépendante, rédigée en français, qui n'est ni affiliée ni approuvée par les auteurs de REA.

- Objectif de ce dépôt - Statut et avertissements - La rétro-ingénierie en bref - Présentation de REA - Concepts clés - Le modèle en trois temps - Plateformes et prérequis - Installation et démarrage rapide - Premier exercice guidé - Déroulé type d'une enquête - Fournisseurs d'analyse - Agents compatibles et configuration MCP - Observation web et Electron - Sécurité et confidentialité - Cadre légal et éthique - Bonnes pratiques - Limites et idées reçues - Glossaire - FAQ - Ressources - Contribuer - Licence

Ce dépôt a un but simple : expliquer, pas à pas et en français, ce qu'est la rétro-ingénierie assistée par agent, ce que fait REA, comment l'installer, comment l'utiliser sans se tromper et dans quel cadre légal et éthique il est raisonnable de le faire.

- les débutants, qui découvrent la rétro-ingénierie et veulent des définitions claires avant de toucher à un outil ; - les développeurs, qui veulent comprendre le comportement d'une application dont ils n'ont pas le code source ; - les curieux de l'IA agentique, qui s'intéressent à la façon dont un agent de code
