About free-search-api

Your own web search API. Free forever, no API keys, no quotas.

Self-hosted metasearch that queries DuckDuckGo, Brave, Bing, Yahoo, Wikipedia, and news feeds in parallel and merges the results into one clean JSON API. It works as a drop-in replacement for Tavily, Serper, the Brave Search API, and SearXNG, and ships with an MCP server for Claude, Cursor and other AI agents.

Quick start · API · Drop-in replacements · MCP · Config · How it works · FAQ

Recorded automatically by the Demo GIF workflow: a real search against live engines from a GitHub runner.

AI agents, RAG pipelines and scripts all need web search, and every search API charges per query:

Price Limits Self-hosted Open source --------------- Tavily paid after free credits monthly credits ❌ ❌ Serper / SerpAPI paid per 1k queries monthly credits ❌ ❌ Brave Search API paid plans monthly cap ❌ ❌ SearXNG free you run it ✅ ✅ (AGPL) FreeSearch API free none imposed by the software ✅ ✅ MIT

FreeSearch speaks the same request and response formats as the paid APIs, so you change one base URL and keep your code.

- No API keys anywhere. It queries public search pages and official public APIs. There's nothing to sign up for. - Several engines at once. Queries run in parallel and the results are merged with Reciprocal Rank Fusion, so a page that several engines rank highly comes first. Duplicates are removed, including www., tracking-parameter and trailing-slash variants. - Fast. Plain async HTTP with no headless browser, so a typical search takes well under a second. mode=fast returns as soon as one engine has enough result
