About revelix

The open reverse-engineering platform built for humans and AI agents. Decompile, explore and explain any binary — native code, Rust, .NET, Java/Android, iOS, Python, WebAssembly, Go, firmware and 300+ file formats — from one engine, served as an MCP server, a command line and a web interface.

▶ Watch the 2-minute demo · Website · Quick start · Use with AI · All 128 tools · 🇫🇷 Version française

Real software, real output. Every image on this page — and the demo video, a real recorded session with the mouse, the keyboard and the tools at work — was produced by Revelix itself on open-source programs (the Termux Android app, GPL-3.0; Rollup's Rust native module, MIT; esbuild, MIT) and on a harmless obfuscated PowerShell script written for the demo, by scripts/media.ts. Nothing is mocked.

- One engine, three faces. Every capability is a single tool definition served identically to an AI (MCP), to your terminal (revelix …) and to a local web UI. 128 tools, one behaviour. - Real decompilers, zero heavy dependencies. The Ghidra decompiler runs compiled to WebAssembly with 180 SLEIGH processor variants; a C, Java, Python, Hermes, BEAM, WebAssembly, ActionScript and Rust decompiler sit beside it. No Java, no Python, no IDA licence: npm install and go. - Made for AI agents. A compact default profile (47 tools + findtools / calltool to reach the rest), every result stamped with an evidence id (ev…) the model can re-read, content from targets flagged as untrusted, progress and cancellation over MCP. - Rust decompilation that checks itself. Panics rebuilt with file:line, &str literals
