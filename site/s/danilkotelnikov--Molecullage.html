About Molecullage

Molecullage makes figures of protein structures, sequences, contact maps, pipelines and plots for papers. You write each figure as an HTML page in millimetres, and the build prints it to a vector PDF and a 600 dpi PNG.

The gallery holds twelve figures from published open-access papers, redrawn with Molecullage from the papers' own data and from PDB entries. A few of them:

Folder What you do with it ------ kit/ Draw the figure in the page script: blocks, data labels, arrows, panel letters and maths in Arial. build/ Print a page to a one-page PDF with live text and to a 600 dpi PNG. palette/ Sample colours from a figure you are allowed to use, check them for colour-blind readers, and write a token file. plots/ Make matplotlib plots that sit in the page at exact millimetre positions, in the same colours. struct/ Render a PDB entry in ChimeraX in a flat style, crop the layers to one box, and list typed contacts. qa/ Measure a built figure (ink, empty space, type size, words, fonts, width) and give the two readers their instructions. templates/ Copy one of eight figure pages and edit it. claude/ Install the Claude Code skill, the MCP server and the two optional hooks. examples/ See each template built, most of them on public PDB entries, each with a how-made.md. docs/ Read the drawing rules, the palette notes, the ChimeraX notes, the kit reference, a glossary and field notes. gallery/ Look at twelve published figures redrawn with Molecullage, each with a script that fetches its data and a note on how it was made.
