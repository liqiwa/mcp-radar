About android-rpa

PC 端 Python 脚本通过 adb 控制安卓手机，自动执行 BOSS直聘打招呼、微信发消息 等 RPA 任务。

本项目零硬编码：adb 路径自动发现、设备序列号自动识别、坐标全部按屏幕比例计算， clone 后只需三步：

脚本会逐项检查 Python 版本、依赖、adb、设备连接，缺什么提示什么。 也可以手动来（效果等价）：

2. 按需改 config.py（全部可留空/用默认值） 配置 默认 说明 --------- ADBPATH 自动发现 环境变量 ANDROIDRPAADB 可覆盖 DEVICESERIAL 空=自动 多台设备时填序列号，或用 ANDROIDRPASERIAL WIFIDEVICES 空 无线 adb 设备列表，如 ["192.168.1.100:5555"]，见下 PACKAGES 已填常用 App 换目标 App 改这里 BOSS.greetings 通用示例 建议在 BOSS App 内设置「自动打招呼语」，脚本直接复用 WECHAT.targets 空 {联系人备注: 消息} RATE 已调好 频率/分神概率/单轮上限

多设备 / adb 不在 PATH：复制 configlocal.example.py 为 configlocal.py 填入 ADBPATH / DEVICESERIAL（该文件被 git 忽略，不会提交）；或用环境变量 ANDROIDRPAADB / ANDROIDRPASERIAL。

无线 adb（免插线）：手机与电脑连同一 Wi-Fi，两种方式任选： - Android 11+「开发者选项 - 无线调试」：端口随机，先在电脑上 adb pair IP:配对端口 配对 （配对码在手机无线调试页面），之后把「IP:端口」填入 WIFIDEVICES； - 任意 Android 版本：插一次 USB 执行 adb tcpip 5555 后拔线，填 手机IP 即可 （重启手机后失效，需重新执行）。

环境变量方式：ANDROIDRPAWIFI="192.168.1.100:5555,192.168.1.101"（逗号分隔，端口可省略默认 5555）。 任务启动时会自动 adb connect 列表里的设备，连接失败不影响 USB 设备。

老教程里的 atx-agent（Go 常驻代理）是 uiautomator2 v2.x 的机制，v3 已移除，本项目不依赖。
