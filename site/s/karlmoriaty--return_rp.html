About return_rp

栖羽 / QIYU 从探索、鸟种详情，到留下自己的观鸟手记。 9 页原生原型示例 · 文字、按钮与输入保留为独立元件 · 识别与统计使用演示数据 · 素材与案例说明

Studio 是一块 AI 和人都能编辑的自由画布。让 Agent 搭好第一版，再直接点选、改字、调整布局；也可以把局部交还 AI，继续探索另一种构图。

AI 起稿。 RP/1 或命令创作，按图层、语义和范围查询，局部改稿。 人来精修。 双击改字、Shift 框选、Option / Alt 悬停测距，撤销重做。 一起验证。 查看真实截图、运行交互场景，再交付原型。

RP/1 把页面、布局、组件、变量和交互写在一起。AI 改动有明确目标，设计也能保留结构、版本和继续迭代的起点。

从一个页面到完整流程，reviseprototype 继续改稿；已有原生修改也能在支持范围内合并回源码。

生成原生 .rp，在 Axure 中继续修改支持的文字、控件和布局。页面、变量、动态面板与跳转可以一起交付，源稿、预览和检查报告也一并保留。

从哪里继续 可以做什么 :--- :--- Studio 和 AI 共用设计文档、事务与撤销历史 Axure 打开原生工程，继续编辑元件与支持的交互 浏览器 运行预览；也可导出独立 HTML / CSS / JS

准备 Node.js 18+ 和 Python 3.10+。原生生成另需本机 Axure，以及你自己在 RP9 中保存的单页空白工程。

MCP 工具列表依赖可选依赖 @modelcontextprotocol/sdk（npm ci 会一并安装）。只跑 CLI 不装也能用；缺少依赖时 MCP 启动会提示在项目目录执行 npm ci --ignore-scripts，而不是静默返回空工具列表。

PATH 应包含安装了依赖的 Python；Node 不在默认路径时，command 也使用绝对路径。安装更新后重新连接 MCP。

做一个观鸟 App，包含探索、鸟种详情和手记。先在画布里设计，验证跳转和保存回显，再导出可编辑的 .rp。

Agent 从 studiodescribe({"topic":"workflow"}) 开始。导入已有 RP/1 可为 studioopenproject 指定 sourcePath；完整原生生成使用 generateprototype。局部创作和完整编译的支持范围分别记录。

原生生成默认目标 RP 11，也可用 target=9 或 AXURETARGETVERSION=9 切到 RP9。宿主证据覆盖 macOS + Axure RP9，以及 Windows + Axure RP9 / RP11（GUI 保存重开与预览往返）。部分效果采用嵌入位图，字体和预览可能受宿主影响。任意小数缩放清晰度、单画板海量节点仍有边界。

结构检查、浏览器行为与 Axure 保存重开分别验证。能力范围 · RP9 / RP11 能力对齐 · 验收层级 · 故障排查
