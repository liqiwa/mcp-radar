About phone-use

Let an AI agent use an Android phone or iPhone. Read the screen, tap, type, scroll, open apps and take screenshots, from any MCP client or a terminal.

Phone-Use gives an agent the same 11 tools on either phone. On Android, a small app on the phone does the work. On an iPhone, the computer it's plugged into does, through WebDriverAgent. The agent sees the phone as a numbered list of on-screen elements and can act on them. It works with Claude Code, Codex, Claude Desktop, Cursor and any other client that supports MCP over stdio. You don't need root, jailbreaks, or a cloud account.

On Android, the accessibility service supplies the visible elements and performs the gestures. Screenshots are optional and go through Android's screen-sharing consent prompt. A Stop pill stays on screen while an agent is reading or acting.

iOS doesn't let an app control other apps, so on an iPhone, WebDriverAgent (the UI test runner behind Appium) does the reading and tapping, started over USB by phone-use-mcp ios up. Locking the iPhone stops the agent, and only unlocking it resumes. Either way, the person holding the phone stays in control.

- Works with any app. Numbered elements with role, text, view ID, position and what you can do with them. Screenshots cover images, maps, games and canvas apps. - 11 MCP tools, plus the same actions from the terminal. - Android and iPhone, with the same tools, CLI and HTTP API. - Consent stays on the phone. You enable accessibility and approve screen sharing yourself; setup never grants either on your behalf. - Stop at any time. Tap Stop on Android, or lock
