About aseprite-mcp-live

通过 Model Context Protocol，在 Aseprite 中绘制、修改和预览像素画。

Aseprite MCP 将支持 MCP 的客户端如Codex，CluadeCode，DeepseekHarness等Agent与 Aseprite 连接起来，支持读取和编辑未保存画布、图片预览、撤销重做及可选基础动画，让你在同一文档中继续创作。同时保留 CLI 磁盘文件处理能力。

Windows Aseprite 1.3+ 验证；Aseprite 需自行安装，不随项目分发。

也可以从 uv 官方 Releases 下载对应 Windows 架构的压缩包，解压后将可执行文件所在目录加入 PATH。更多安装选项见 uv 官方安装说明。

1. 前往 GitHub Releases，下载与服务版本一致的 .aseprite-extension 文件。当前服务版本为 0.5.0。 2. 在 Aseprite 中打开 Edit → Preferences → Extensions → Add Extension，选择下载的扩展包，安装并启用。

3. 重启 Aseprite，首次连接时按权限提示允许扩展使用本机 WebSocket。

- 1.若MCP连接正常但获取不到工具状态，尝试重启Agent客户端，尽量先让Aseprite先启动。 - 2.Agent工作时，尽量不要在画布上绘制，以免干扰实时协作。

扩展默认自动连接 127.0.0.1:8765。在 File → Scripts → MCP: Connect / Settings 中可查看状态、调整端口或断开连接，无需选择连接文件。

以下适用于采用 mcpServers JSON 格式的客户端；其他客户端使用对应的 stdio 配置格式。

保存配置并重启客户端，然后打开 Aseprite。扩展与服务启动顺序不限，服务就绪后会自动连接。

dist/ 中会生成 Python wheel、源码包、.aseprite-extension、锁定生产依赖清单和摘要文件。你可以安装对应版本的 Release 扩展，或使用本地生成的扩展包。

将 source-path 替换为源码目录的绝对路径如C:/path/to/aseprite-mcp-live。选择一种服务配置即可，同一端口只运行一份服务。

功能 说明 -------------------- ------------------------------------------------------------- 实时协作 读取和编辑已经打开的文档，包括未保存画布 像素与图层 新建 RGB 画布、添加普通图层、调整不透明度、批量绘制像素和矩形 图片反馈 将预览作为 PNG 图片直接返回给支持图片内容的 MCP 客户端 撤销与重做 一个成功编辑批次对应一次撤销，沿用 Aseprite 原生历史 基础动画（可选） 追加或删除帧、设置帧时长、创建和管理动画标签 CLI 文件工具 单独启用磁盘文件处理，使用保留的上游工具进行批处理 自动连接 等待服务就绪，并在服务重启后自动重新连接
