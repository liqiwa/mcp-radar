About diacraft

DiaCraft is an open-source, pure-Rust diagramming application: stencils and masters, ShapeSheet formulas, smart connectors, the VSDX file formats, and the diagram formats people commonly use alongside them. It targets macOS, Windows, Linux, FreeBSD and the web, and everything a person can do can also be driven by an agent through a CLI and an MCP server.

DiaCraft opens and saves Visio drawings, stencils and templates (.vsdx, .vsdm, .vssx, .vssm, .vstx, .vstm), OpenDocument drawings and templates (.odg, .otg, .fodg) and its own .diacraft files, and exports a page as PNG, SVG or PDF.

Status: 0.2.1, an early release. Foundations are in place: a window laid out like a diagramming app (ribbon, Shapes window, rulers and grid, page tabs, status bar, File view) that opens on an empty drawing or on a .vsdx file or an OpenDocument drawing (.odg, .fodg) (diacraft FILE, or File, Open) and draws every page of it, a command engine, a control channel, a CLI and an MCP server. It can draw a small diagram by hand (drop shapes from the Shapes window, move and resize them, join them with connectors, type their labels, colour them, set their fonts, turn, flip, align and reorder them) and save it as .diacraft, .vsdx or .odg, and it opens the file again (a drawing that came from a file is saved in that file's format unless another is chosen); many of the window's other controls are drawn and not yet working.
