About google-multi-mcp

An open source MCP server that connects several Google accounts to your AI agent at once: Gmail, Google Calendar and Google Drive.

Website · Install · Docker · Tools · Privacy

Built-in AI connectors usually link one Google account each. This server links all of them, personal, work and side projects, to any agent that speaks the Model Context Protocol. Every tool takes an account parameter: an alias you choose (perso, work), an email address, or all for reads.

It runs on your own machine with your own OAuth client. Tokens stay in ~/.config/google-multi-mcp/ (mode 600), never in this repository, and no data goes through Cockpit servers.

- "Summarize my unread mail from this week on all my accounts." - "Show tomorrow's agenda, personal and work merged, and flag the conflicts." - "Draft a reply to Julie's last email from my work account." - "Find the 'roofing' quote in all my Drives and summarize it."

Reads can span every account: each one is queried in parallel, and one failing account never blocks the others. Writes are always explicit: sending an email or changing an event requires a single, named account, so a work email never leaves from your personal address by accident.

The server speaks MCP over stdio, so it works with Claude, Codex, Cursor, Gemini CLI, GitHub Copilot, Goose and any other MCP client. It also ships as a Docker image.
