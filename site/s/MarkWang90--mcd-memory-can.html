About mcd-memory-can

如果记忆也是一个罐头，我希望它不会过期。 可惜你每一顿麦当劳的订单上，都印着精确到秒的日期。

这是用麦当劳官方 MCP 拉取你自己的历史订单，再生成一套《重庆森林》质感的九幕图文长卷的小工具。 它不卖券、不算卡路里、不推荐你该吃什么 —— 它只做一件事：把你已经吃过的那几顿饭，讲成一个故事。

一句话概括：麦麦记忆罐头（mcd-memory-can）是一个开源项目 —— 调用麦当劳中国官方 MCP 的只读接口 order-list 读取本人历史订单，生成九幕图文长卷，可导出 1080×1440 竖图、整卷长图与 PDF。 由个人在 AI 编程助手 WorkBuddy 的协助下独立开发，Python 标准库实现、零第三方依赖，非麦当劳官方产品。

没有 MCP Token 也能玩：打开 网页版， 点一下「摇一个罐头」，浏览器里直接画出一卷可以下载的 PNG —— 零依赖、零上传、不需要登录。

每一幕都是 1080×1440 的竖图，可以直接发小红书；也可以整卷导出一张长图或一份 PDF。

幕 讲什么 ------ 01 序 你的第一条订单与最后一条订单，中间隔了多久 02 第一顿 第一次点的是什么，在哪，几点，星期几 03 跨度 从第一顿到今天，一共多少天 04 坐标 你去过几家门店，哪一家去得最多 05 执念 你重复点过最多次的那个组合 06 招牌菜 单品点单排行榜 07 分水岭 某一天之后，你的频率忽然变了 08 空窗 最长的那段没吃麦当劳的日子 09 尾声 把这一切收进一句话

不是每个人都会有九幕。 算不出来的那一幕会被整页丢掉 —— 数据里没有的东西，文案不会编。 所以有人拿到六页，有人拿到八页，这是对的。

--demo 全程不联网，用的是 examples/demo-stories.json 里那份虚构数据。

环境要求：Python 3.9+，加上本机已有的 Chrome / Edge / Chromium 之一（用来把 HTML 冲印成 PNG）。 不需要 pip install 任何东西 —— 整个项目只用标准库。

麦当劳的 order-list 接口只返回最近 10 单，官方固定上限，不支持分页，也不支持传时间范围。 这是接口本身的天花板，不是 bug。

想让时间线真的变长，就让它每天自动跑一次（脚本会自己处理去重，重复跑不会产生垃圾数据）：

- 只读。 整个项目不调用任何下单、支付、修改账户的接口。它读你的订单，然后就没有然后了。 - 不上传。 没有服务器，没有埋点，没有第三方 API。你的订单只留在你自己的硬盘上。 - 不替你分享。 图片生成在本地，发不发、发哪张，由你决定。

这三行是仓库的默认配置。assets/preview/ 里的展示图全部由 examples/demo-stories.json 那份虚构数据渲染而来 —— README 里你能看到的每一张图，都不是任何人的真实消费记录。

凤梨罐头的保质期是 1994 年 5 月 1 日。而你的订单里，每一行都带着一个精确到秒的时间戳 —— 那是真实发生过的、再也回不去的一顿饭。

技术上，这套视觉只用了七个颜色、三种字体、一个 CSS 布光系统， 不依赖任何设计软件和图片素材，--mode art 下零素材依赖，任何人 clone 下来都能跑出一样的质感。

Q：我只想看效果，不想给 Token。 用 --demo。全程离线，用虚构数据渲染，成品和真实跑出来的一模一样。
