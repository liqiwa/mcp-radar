About decisionkit

Fast, cheap, closed-form decisions for coding agents, scripts and CI. You ask a question about a piece of text: yes/no, pick one of a list, rate it on a scale, or rank candidates. A specialized decision API answers with probabilities, not paragraphs.

decisionkit is provider-neutral. It talks to:

- Claude, with the Claude Code login you already have (claude -p): no extra API key. Claude's probabilities are its own self-reported estimates, and it is slower (about 4 s per call). - OpenAI Decisions API (public beta), POST api.openai.com/v1/decisions - Jev by TypeSafe AI, POST api.typesafe.ai/v1/systemone, with a TypeSafe key - Jev via OpenRouter: the same Jev API at POST openrouter.ai/api/v1/systemone, with an OpenRouter key and billed by OpenRouter

You can use it as a CLI, as a Claude Code plugin, or as an MCP server for Codex, Cursor, VS Code, Gemini CLI, Claude Desktop, Windsurf and Zed.
