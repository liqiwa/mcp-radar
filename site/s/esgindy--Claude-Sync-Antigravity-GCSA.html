About Claude-Sync-Antigravity-GCSA

Unofficial tool, developed by Eslam Elgindy. Not affiliated with, endorsed by or sponsored by Anthropic or Google. Claude is a trademark of Anthropic; Antigravity is a trademark of Google.

GCSA (Claude Sync Antigravity) connects Claude and Google Antigravity in both directions. Claude is the brain: it plans the work and reviews the results. Antigravity agents are the muscle: they carry out the tasks. Sending the heavy execution work to Antigravity saves Claude tokens, and the tool picks a suitable model for each task.

- Claude to Antigravity: Claude Code and Claude Desktop send tasks to Antigravity through the csa-claude MCP server. - Antigravity to Claude: Antigravity asks Claude to review a result or take over a task through the csa-antigravity MCP server.

- Delegation with automatic model choice. The model is chosen by task size and type. If the preferred model is low on quota, the tool falls back to the next one. - Choice of any available model. You can name a model yourself instead of using the automatic choice. - Desktop-first auto target with safe CLI fallback (v3). agytask defaults to target="auto" (defaulttarget: "auto"). It checks whether the Antigravity Desktop app is running and reachable (agydesktopstatus check) and uses Desktop first (subject to allowdesktopautoexec, allowdesktopedit, and fail-closed safety checks); otherwise it falls back to agy CLI (agypath in config.json, %LOCALAPPDATA%\agy\bin\agy.exe, or PATH).
