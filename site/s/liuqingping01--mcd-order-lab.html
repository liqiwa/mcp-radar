About mcd-order-lab

输入你想吃的东西，告诉你买套餐还是单点更省，顺带把能用的券和活动摆出来，确认后直接下单。

基于麦当劳官方 MCP 实时数据 · 1024程序员节 · 麦当劳程序员创意开发大赛 参赛作品

https://mcd-order-lab.app.workbuddy.host/

线上实例已接好麦当劳官方 MCP，跑的是完整链路：实时菜单 → 官方算价 → 套餐 vs 单点对比 → 购物车相似方案 → 二次确认下单。

演示实例使用作者个人的 MCP Token，可能随时下线；要长期用请 clone 到本地跑（见下方「快速开始」）。 若提示「周边门店都已打烊」，是因为麦当劳 MCP 在门店非营业时间不返回菜单，换一个位置关键词即可。

手机端同样可用（触控目标 44px 级热区、底部弹出抽屉、输入框防 iOS 缩放）

麦当劳 App 里单品、套餐、优惠券、活动铺满一屏，真正难的不是"选什么"，而是：

官方渠道不会回答这个问题。它只列商品，不替你算"多花的钱换回了什么"。 本项目把麦当劳 MCP 开放的菜单、套餐组成、算价、券、活动编排成一条链路，直接给出结论。

套餐里有些组成项根本无法单点（实测「可乐中杯」「麦乐鸡4块」官方算价返回 productList: []）， 这类项不计入金额，只标注「套餐专属 · 无法单点」。因此净收益是保守下界，实际只会更划算。

商品卡片右上角点「+」加入购物车，右上角 🛒 打开抽屉可增减数量。 点「看看怎么买更省」，系统会扫描门店全部套餐，回答：这几样全买单品划算，还是换套餐划算？

套餐里多出来的东西（含无法单点的套餐专属品）视为"白送"，不计入抵扣， 因此省下的钱是保守下界。

购物车 全单点 换成套餐 结果 ------:---:--- 巨无霸 + 薯条 ¥41.0 巨无霸三件套 ¥37.5 省 ¥3.5，还多一杯可乐 巨无霸 ×3 ¥79.5 三件套 + 2 个单点 ¥90.5 不划算，判定"无更省方案"

- 唯一主入口：「我想吃…」可直接输入（支持模糊叫法），也可点下方大分类挑 - 右上角小图标：优惠券 / 活动，带数量徽章，点击右侧抽屉展开 - 有优惠的单品单独标注：商品卡左上角标「省 ¥X」，并划掉原价 - 活动默认只显示标题，点击才展开完整内容与配图，不长篇占屏 - 结算区：金额随选中的方案联动，可勾选「同时领取 N 张优惠券」

- 一句话出结论：填「巨无霸」→ 直接告诉你买三件套还是单点，多花多少、多得什么、净赚多少 - 方案对比可切换：单点与每个套餐各一张卡并排，点哪个看哪个的细节，不把信息全堆在一屏 - 价格以官方为准：全部取自 MCP calculate-price，不自造价格规则；菜单展示价与官方价冲突时显式提示差额，不静默给结论 - 扫描全量套餐：门店全部 56 个套餐类商品逐一比对组成，不是只挑几个推荐位 - 排序懂人情：不只看净收益——多人餐净收益绝对值往往最高，但偏离"我就想吃一个堡"。单人份、加价小的优先，净收益最高的作为「加价升级」备选另行展示 - 券与活动顺带带上：官方 App 本来就有的能力，这里只是搬到决策现场，不作为卖点 - 热量只在最后附一行：买麦当劳的人不会因为几十千卡改主意，所以营养不参与决策，仅
