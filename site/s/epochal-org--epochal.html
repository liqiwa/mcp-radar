About epochal

Clients for the Epochal API: Rust crates, Python packages, an MCP server and a CLI. epochal-api and epochal-sandbox are on both crates.io and PyPI under those names; epochal-mcp and epochal-cli are Rust only.

Their one module today is the Time Portal, which serves the web, and Linux sandboxes, as they stood at a past instant. Search and fetch return only what was published and crawled by then; a sandbox's clock starts there and its network sees nothing later. Use it to test an agent or a forecast against the past, with nothing from after that instant leaking in. In each package the Time Portal is named as such: client.timeportal(asof), Sandbox::timeportal(asof), epochal-mcp --time-portal, epochal time-portal.

Directory Package What it is --------- api/ epochal-api (Rust) One method per API call; for the Time Portal, web search, web fetch, and the raw sandbox calls sandbox/ epochal-sandbox (Rust) Sandboxes: build one, run commands, move files, serve its ports from your machine mcp/ epochal-mcp (Rust) epochal-mcp, an MCP server giving an agent websearch and webfetch at an instant cli/ epochal-cli (Rust) epochal: epochal time-portal runs an agent in a sandbox, or searches and fetches from the shell python/api/ epochal-api (Python) The API client, sync and async python/sandbox/ epochal-sandbox (Python) Sandboxes, sync and async, with examples

The pieces stack: the sandbox crates call the API crates; the MCP server uses the Rust API crate; the CLI uses all three Rust crates. Each directory's README has its setup and examples.
