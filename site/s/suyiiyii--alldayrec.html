About alldayrec

全天录是一个开源的全天录音设备加服务器，跑在你自己的机器上。戴一个录音设备（或者只带手机）从早录到晚，你的服务器在一分钟内把音频变成带说话人的转写，再整理成一天的时间线：对话摘要、认出的人、待办和每日回顾。原始录音一直留着，每句话都能点开回放核对；你的 Agent 通过 MCP 直接查你的每一天。没有订阅，对话也不放在别人的云上。（录音豆、心力球等产品名称归各自所有者，本项目与它们没有关联。）

:--::--: 今天：到期待办、昨天的回顾、今天的对话 一段对话的摘要：待办、决定、每个人的要点

- 全天录音：手机 App 录手机麦克风，或者连一个蓝牙录音设备；离线时在设备上排队，回来后补传。 - 两层转写：定稿交给云端语音识别（默认阿里云百炼千问，约 ¥0.05/小时音频），页面开着时几秒内出初稿；也可以 ENGINE=local 在本机转写。 - 认人：语音检测和声纹在本机 CPU 上跑，认得出你自己，记得你给别人起的名字。 - 记忆：对话摘要、待办和截止日期、每日回顾、全文搜索，「问 AI」的回答带出处对话的链接。 - 开放：网页、远程 MCP 端点（Claude Code、Codex、Cursor）、命令行；数据就是 SQLite 加原始录音，自己就能读。 - 什么音源都能接：已有的录音文件可以通过 HTTP 接口导入。

需要一把阿里云百炼（DashScope）北京区的 API key，语音识别和大模型可以共用这一把；用别的引擎见如何更换语音识别引擎。三种跑法任选一种。

只用手机也可以。全天佩戴可以自己做开源的蓝牙录音设备：LR-X1（Seeed XIAO nRF52840 Sense）或 LR-P3（ProMicro nRF52840，装在 3D 打印外壳里），一直往 SD 卡里录，连上手机就同步。 零件、接线和固件：录音设备硬件、hardware/lr-p3/、firmware/devkit/。

欢迎提 issue 和 PR。本地检查和提交说明见如何参与开发，代码边界、CI 和发布构建见 CONTRIBUTING.md（英文）。

录音会录到别人。请告知对方，需要时取得同意，遵守当地法律；有些地方要求所有参与方都同意。数据在你自己的服务器上，音频和文字会发给你选的语音识别服务和大模型，见隐私与数据去向。
