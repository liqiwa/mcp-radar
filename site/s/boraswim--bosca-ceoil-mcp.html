About bosca-ceoil-mcp

An MCP server that lets AI tools compose music in Bosca Ceoil Blue. Ask your AI tool for a song, and watch the notes appear in the app's window. Listen to it, undo anything with Ctrl+Z, and export it to WAV, MIDI, XM or MML.

This is an unofficial companion project, not affiliated with Bosca Ceoil Blue or its authors. You get the app separately, and it isn't modified.

You need Node.js 18 or newer, and Bosca Ceoil Blue unpacked somewhere on your computer.

Then connect your AI tool. In the examples below, replace:

- /path/to/bosca-ceoil-mcp with the folder you cloned. - /path/to/boscaceoil-blue with the app's executable or the folder it's in. Use forward slashes on Windows too.

Restart the AI tool afterwards, and ask it something like "Write me a cheerful 8-bar chiptune in Bosca Ceoil."

Add this to ~/.gemini/config/mcpconfig.json, or to .agents/mcpconfig.json in a workspace. In the IDE, you can open it from the MCP Servers panel, with Manage MCP Servers and then View raw config.

This is a standard MCP server over stdio, so any tool that supports those can use it, with the same command and arguments. The ChatGPT website and app only reach remote servers, so they can't use it.

Argument Environment variable What it does --- --- --- --app-path BOSCACEOILPATH Where the app is. Without it, the server looks through Downloads, Desktop, Applications, Games, Program Files and itch.io's folder for it. --headless BOSCACEOILHEADLESS=1 Runs the app with no window or sound.
