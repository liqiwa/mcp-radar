About order-flow-mcp

Live crypto order flow for any AI agent. An MCP server that streams trades, order books, open interest, funding and liquidations from 10 exchanges and gives agents the same analytics as the Order Flow Screener terminal: footprint candles, CVD, volume profile, VWAP bands, book imbalance and walls, block prints, absorption and iceberg detection, OI regimes, venue lead/lag and a multi-symbol screener.

Works with Claude Code, Codex, Cursor, Claude Desktop, VS Code, Windsurf, Gemini CLI, or any client that speaks MCP. You don't need API keys or an account, and there's nothing to configure.

Website: mcp.order-flow.zadescoxp.com has a setup guide for each agent. The charting app it is built on is at order-flow.zadescoxp.com.

Node.js 20 or newer is required. Pick your agent and paste one command or config block.

Cursor, Claude Desktop, Windsurf, Gemini CLI, Cline and others

Add this to the client's MCP config. The file is ~/.cursor/mcp.json for Cursor and claudedesktopconfig.json for Claude Desktop (Settings → Developer → Edit Config). Windsurf uses ~/.codeium/windsurf/mcpconfig.json and Gemini CLI uses ~/.gemini/settings.json.

Faster startup: the first npx run downloads the package, which can take 20–40 s. To skip that, install it once with npm install -g github:zadescoxp/order-flow-mcp and use order-flow-mcp as the command (no args).
