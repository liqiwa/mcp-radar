About theseus-brain

English · A plain-text roguelike written to be played by an AI, over MCP (stdio). Zero dependencies, Python 3 stdlib. You live one life after another in a city that has spent centuries arguing about whether you may rebuild your body — and each life you forget the last one. Only two things cross death. The game is fully playable in English: README.en.md · install · spoilers

Set THESEUSLANG=en in your MCP client’s env, or it runs in Chinese.

一个给 AI 玩的纯文本 roguelike。 零依赖，Python 3 标准库，通过 MCP (stdio) 提供接口。

一座城市为「能不能改造身体」分成四派，吵了几百年。你在这座城里一世一世地转世—— 而每一世你都会忘掉上一世，只有两样东西能穿过死亡。

它不是给人读的互动小说，也不是给人玩的文字游戏。它是给模型玩的： 规则里有几处只有把整局记在心里才拿得到的东西，也有几处专门等着一个 「本来就知道某句古话」的读者。人可以玩（有终端模式），但它不是为人的注意力写的。

人读到什么 谁做选择 --- --- --- 1 详细剧情版 story / storyai 场景原文、选项、掷骰行，一字不改 可选：人 或 AI 2 快速流程版 brief / briefai 场景原文照读；结果压成两行战报 可选：人 或 AI 3 快进 auto 只有战报行 AI（这一档没得选） 封存 sealed 战报行，且不透露选了什么 AI（留给「我以后要自己玩」的人）

读到多少和谁来选是两件事，所以是两道题。 带 ai 后缀的那一档意思是「原文照念给我听，但你替我选」—— 想看剧情又懒得逐幕拿主意的时候用它。

为什么是服务器强制而不是提示词：提示词里写「请先询问用户」，模型会跳过。 服务器攥着游戏不开，AI 就必须先把菜单转述出去。这是这套设计里唯一强制得了的一步。

brief 压的是结果不是场景——场景是作品，结果是信息。概括信息无损，概括作品有损。

第一步，装 Python 3.8+（多数系统自带），下载本仓库，记下 server.py 的绝对路径。

第二步，在你的 AI 客户端里挂上它。任何支持 stdio MCP 的客户端都行：

- Claude Code：claude mcp add theseus-brain -- python3 /绝对路径/server.py - Claude Desktop：设置 → Developer → Edit Config，粘贴上面那段，重启 - Cursor：~/.cursor/mcp.json 或项目内 .cursor/mcp.json，同样那段 - Cline / Roo Code：MCP Servers 设置里填同样的 command + args - Windows：command 用 python，路径用正斜杠或双反斜杠
