About antigravity-codex-monitor

面向 Google Antigravity 的原生 MCP Server / MCP App（Model Context Protocol）实时协作监控面板与 codex-worker 派单套件。

当你让 Antigravity（Gemini）统筹规划并把编码、重构、写脚本、补单测等任务派发给本地官方 OpenAI Codex CLI（codex exec） 执行时，以往 codex exec 只能在后台黑盒运行、看不到中间过程。装上本插件后，Antigravity 右侧辅助栏会自动弹出 Codex Monitor，以 0.8 秒 实时流式展示每一次派单的执行命令、语法高亮文件 Diff、模型档位、Token 与缓存命中统计——纯本地只读轮询，零额外 LLM 消耗，零 CDP 侵入，客户端升级不失效。

浅色暖纸模式（左侧会话列表 + 实时对话流 / 命令输出 / 语法高亮 Diff）

(本地也可直接用浏览器打开 plugin/ui/app.html?demo=1 或 ?demo=1&theme=dark 离线体验交互式演示界面。)

- 告别 codex exec 黑盒：派单瞬间自动弹出右侧栏面板，每 0.8s 实时流式呈现 Codex 正在执行的命令、退出码、语法高亮 Diff、推理模型与 Token / 缓存命中率，纯本地状态指纹轮询，不消耗任何模型额度。 - 原生 MCP App，不惧客户端更新：严格遵循 Antigravity 官方插件与 MCP Apps（SEP-1865）规范，不修改 .asar、不依赖 CDP 注入、不破坏客户端签名，官方更新后依然稳定可用。 - 一个插件，开箱即用：内置侧栏监控面板 + 跨平台派单脚本（Windows run-codex.ps1 / macOS & Linux run-codex.sh）+ 内嵌 codex-worker Skill，前端已预编译为单文件 HTML，最终用户安装无需 Node.js。 - 无工作区也能派单。省略目标路径时，启动器会在 ~/.gemini/antigravity/scratch/codex-tasks/ 下创建独立任务目录。可用 ANTIGRAVITYSCRATCHDIR 自定义 scratch 根目录。 - 默认隔离。只读和写任务的默认沙箱分别为 read-only 和 workspace-write。可信写任务可显式指定 -Sandbox full-access / --sandbox full-access。Git 写任务默认使用 --worktree，支持按 SESSIONID 续跑，最多两轮，合并与推送须由用户确认。 - 为什么用 codex exec + Monitor 而不是 codex mcp-server？

对比维度 antigravity-codex-monitor (codex exec) codex mcp-server :--- :--- :--- 执行过程可见性 右侧栏每 0.8s 实时直播命令、Diff 与 Token 黑盒阻塞，任务执行期间看不到实时过程 长任务稳定性 走 Antigravity 后台异步命令，5–10 分钟任务不断连 容易触发 MCP 单次 RPC 调用超时 隔离与档位控制 自动 Git --worktree 隔离 + low/medium/high/xhigh 档位 仅暴露基础调用，无内置 worktree 封装
