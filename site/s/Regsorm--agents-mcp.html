About agents-mcp

Published on Infostart: agents-mcp — MCP-сервер узких ИИ-агентов: агент — папка, модель — строка в конфиге

MCP-сервер платформы специализированных LLM-агентов. Каждый агент — папка agents// с prompt.md и config.toml; добавление нового агента не требует пересборки сервиса. В репозитории — только сам движок: агентов вы пишете сами (формат — в разделе «Добавление нового агента»).

- MCP-инструменты: вызов агентов — invokeagent, agentrun (пуск в фон без ожидания), waitagent, agentcancel; сведения — listagents, getagentinfo, agenthistory, health; управление службой — configreload, prepareshutdown; доска задач — taskcreate, tasksetstatus, artifactwrite, artifactread, eventappend; файловые — fsreadfile, fswritefile, fseditfile, fsmkdir, fslistdir; навыки — skillload. - Вызов без ожидания — agentrun: пуск возвращает callid и путь файла-итога сразу, проверка по callid отвечает мгновенно. Ни один из двух режимов не держит вызывающего, поэтому клиенту не нужен скрипт-посредник. - Отмена фонового вызова — agentcancel: строка вызова закрывается ошибкой, файл-итог дописывается, ждущий не зависает. - Поставщики моделей: прямые HTTP-подключения через [providers.direct.] бывают OpenAI-совместимыми (api = "openai", это значение по умолчанию) и Anthropic Messages (api = "anthropic", включая MCP-инструменты); Claude через Claude Code CLI (claude -p, со своими инструментами и MCP); OpenAI через Codex CLI.
