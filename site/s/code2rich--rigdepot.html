About rigdepot

Rigdepot is an open-source tool for software teams that use AI coding agents: it keeps the team's skills, MCP servers, workflows and agents in one Git repository and installs them into Claude Code, Codex and OpenCode on each person's computer, showing every change before it is written and undoing all of it on request. An optional self-hosted server adds access scopes, personal secrets, review, audit and feedback.

Live demo · Discord · Releases · Changelog

Status: 0.1.0, the first release, is out (2026-11-25). It contains the command line rgd (M0) and the team server rgd-server with its web console (M1). Windows is a preview in this version; see Status and the known limitations.

Once a team adopts Claude Code, Codex, OpenCode and the like, the same things happen everywhere:

- Every tool is configured separately. The same Jira MCP server has to be set up in five different formats. - Good skills stay on individual laptops and travel as zip files in chat groups. - The team has agreed on how to work, but the AI does not know. - Personal tokens end up pasted into config files, chats and repositories. - Nobody knows which shared resources are used, and which ones keep failing. - Switching tools means starting over.

None of this is a defect of any one tool. The tools live on individual machines, and engineering is a team activity. Rigdepot gives the team one reviewed place for these resources and writes each of them into every tool in that tool's own format.
