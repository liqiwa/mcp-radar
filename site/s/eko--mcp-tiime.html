About mcp-tiime

A Go MCP server to drive Tiime from Claude or any MCP agent: invoicing, banking, receipts, expense reports, VAT and exchanges with the accounting firm. 92 tools, MFA login included. Accounting firms using Tiime Expert can switch to an experimental expert mode (43 tools across their portfolio).

⚠️ Tiime does not publish an API. This server uses the internal API of the apps.tiime.fr web application (chronos-api.tiime-apps.com/v1). Routes and formats were extracted from the web application code and checked against a real account, but nothing is guaranteed: Tiime may change them without notice. This project is not affiliated with Tiime.

- Installation - Quick start - Example requests - Tools - Accounting firms (expert mode) - Write safety - Authentication and MFA - Configuration - Behaviors to know - Development - Contributing - License

Download mcp-tiime.mcpb from the latest release and double-click it: Claude Desktop installs the extension and asks for your Tiime email and password. It works on macOS and Windows, in chats and in Cowork. See the Claude Desktop extension guide.

Each release ships binaries for Linux, macOS and Windows (amd64 and arm64), with a checksums.txt file.

A multi-arch image (linux/amd64, linux/arm64) is published on GitHub Container Registry. The session cache and downloads live in /data, so keep it in a volume:

uploaddocument reads files from the container: mount the folder that holds your receipts (for instance -v "$HOME/Documents:$HOME/Documents:ro") and pass absolute paths. Mount a host folder on /data/downloads to get the downloaded PDFs on yo
