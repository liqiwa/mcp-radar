About copper-kicad-mcp

Copper connects your AI app to KiCad, so it can design real boards you can order: schematic, LCSC parts, PCB layout and routing, KiCad's own ERC and DRC, renders and JLCPCB fab files.

https://github.com/user-attachments/assets/cc8e8562-1004-438b-ba93-888a205910ff

If the player does not load, the same video is at docs/media/copper-release.mp4.

You use Do this ------ Windows, any AI app Run Copper-for-KiCad-1.1.0-Setup.exe from the latest release and tick your AI apps Claude Desktop Double-click copper-1.1.0.mcpb from the latest release Claude Code The two plugin commands below Cursor, VS Code, Windsurf, Codex, Zed and others npx -y copper-kicad setup (Node.js 18+), or add to Cursor / install in VS Code A terminal The one-line installer below

Windows is tested end to end. The macOS and Linux routes are new: if one fails, please open an issue.

Setup finds KiCad, brings your libraries and settings along, connects your AI apps and makes a test call. It asks before each step and backs up everything it changes. To paste a config instead, Cursor, Claude Desktop and Windsurf take this entry (docs/INSTALL.md has the others):

npx -y copper-kicad setup --demo runs the setup page on a throw-away folder, so you can look first. If something does not work, npx -y copper-kicad doctor (or copper doctor after the Windows or one-line install) names the fix. More in docs/INSTALL.md.
