About apk-sec-agent

APK 安全分析与代码审计工程 APK-SecAgent · Android Static Security Analysis & Code Audit Platform

面向 Android 应用包（APK）的静态安全分析、反编译源码检索与自动化代码审计工程实现。

本项目面向 Android 客户端应用包分析场景，主要用于 APK 逆向拆解、静态安全规则扫描、通信加解密调用链追踪及相关工程化研究。

将传统手工逆向分析中高频重复的「解包反编译 → Manifest 组件排查 → 硬编码密钥与密码学误用扫描 → 签名加解密交叉引用追踪」流程拆解并固化为可独立部署、便于维护和扩展的工程套件。

各子系统通过明确的数据结构与接口边界解耦，既可作为完整 Web 工作台运行，也可单独挂载 mcpserver/ 作为标准 MCP 工具服务供本地分析环境调用。

模块 / 文件 功能 ------ services/storage.py 分片上传（init / chunk / complete）、全文 SHA-256 内容寻址秒传幂等、ZIP 魔数校验及双层 Zip Slip 路径穿越拦截 services/taskqueue.py 基于 SQL 条件更新乐观锁（CAS）的异步任务状态机，支持跨阶段超时预算共享、指数退避重试与异常中断任务恢复 analyzer/decompiler.py 反编译调度器，按 JADX CLI → Apktool → 内置轻量解析器 三级回退提取 AndroidManifest.xml 与反编译源码树 analyzer/manifest.py 提取应用包名、版本、权限清单、入口 Activity 及导出组件（Activity / Service / Receiver / Provider） analyzer/rules/ 6 类 10 条静态安全检测规则，输出严重等级（CRITICAL ~ LOW）、CWE 编号、文件路径、行号与修复建议 services/report.py 按任务导出包含基本信息、加固特征、Manifest 组件表与风险代码片段的 Markdown / JSON 报告 app/middleware.py 纯 ASGI 滑动窗口限流、请求耗时追踪（X-Request-ID）、敏感凭据日志脱敏过滤与统一异常响应信封

2. MCP 代码审计工具与混合检索 (mcpserver/ & backend/agent/)

模块 / 文件 功能 ------ jadxcodemcp.py 封装包类枚举、关键词正则搜索、类源码按行读取、方法/常量交叉引用查找、Manifest 读取 5 个只读审计工具 agent/chunker.py 按 Java 包、类与方法边界切分反编译源码，保留包名、类名、方法签名与起止行号元数据 agent/rag.py 结合驼峰/下划线双粒度分词，实现 Okapi BM25 + 512 维特征哈希向量 + RRF (k=60) 混合检索重排 agent/guardrails.py 针对不可信反编译源码的三层边界防护（9 类注入模式行号扫描、 标签隔离、输出校验） agent/react.py 支持 OpenAI 兼容 Tool Calling 与内置确定性编排双模式，通过 SSE 流式输出工具调用与签名加密链路还原结论

模块 / 文件 功能 ------ views/TasksView.vue 拖拽分片上传、客户端增量 SHA-256 秒传预检、任务状态轮询与失败任务重试 views/DashboardView.vue 风险类别与严重度堆叠分布图、CWE Top 统计、加固识别状态、Manifest 导出组件清单与报告下载 views/CodeBrowserView.vue 反编译包/
