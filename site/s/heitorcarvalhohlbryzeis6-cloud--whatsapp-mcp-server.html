About whatsapp-mcp-server

wamcp is a WhatsApp MCP server that connects AI agents to WhatsApp through the Model Context Protocol, exposing 61 tools, 10 resources, and 12 real-time events that agents discover automatically on connect. It supports both Baileys (WhatsApp Web) and the Meta Cloud API behind a single interface, so the same agent code works against either backend. It's built for developers wiring WhatsApp into MCP-compatible frameworks like Claude, LangChain, or Google ADK without writing REST wrappers or webhook parsers. Written in TypeScript with Docker deployment and Redis-backed rate limiting to keep high-volume messaging within WhatsApp's limits.

Feature Description ------ 🔌 MCP-native Exposes WhatsApp over the Model Context Protocol using Streamable HTTP and stdio transports, so any MCP-compatible agent can connect without custom glue. 📱 Dual-channel backends Choose Baileys (WhatsApp Web) or the Meta Cloud API behind a single unified interface. 🧰 61 tools A broad, wa-prefixed tool surface spanning messaging, chats, groups, contacts, profile, presence, and more. 📚 10 resources Discoverable MCP resources for reading WhatsApp state alongside tool calls. 📡 12 real-time events Push notifications for incoming messages, presence/typing, connection changes, and other live activity. 🔄 Multi-instance Drive multiple WhatsApp numbers from one server process. 📨 Rich messaging Text, media, documents, polls, reactions, replies, edits, deletes, and view-once messages. 👥 Group management List groups, inspect participants, and manage membership and settings. 👤 Contacts & profile Number checks, contact
