About aislopmeter

Measure the AI slop on any website. Then fix it.

AI Slop Meter scores a website, a local app or a web project for slop: generic copy, the default AI-builder look, and unfinished details.

- It shows the evidence behind every point, down to the file and line. - It tells you what to do about each finding, with steps and a prompt you can hand to your AI. - Your own AI (Claude, Cursor, Gemini CLI and others) can then carry out the plan in your code.

It runs on your machine as an MCP server, a CLI and a bookmarklet. No API keys, no account, nothing sent anywhere except the requests to the site you asked it to scan.

1. Try it once, nothing to install: npx -y aislopmeter https://your-site.com --open 2. Add it to your AI (Claude Code, once for all projects): claude mcp add --scope user aislopmeter -- npx -y aislopmeter mcp 3. Ask: "Rescue my site from slop. Open the report when you're done." Answer the questions it asks; it fixes, re-scans and shows before and after.

The usage guide walks through it in order, with every command, the MCP tools, ready-made recipes (Lovable/Vite apps, Next.js, CI) and troubleshooting.
