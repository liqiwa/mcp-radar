About mcd-receipt-studio

MaiMen Diary — a McDonald's MCP powered receipt studio.

一句话，WorkBuddy 通过麦当劳 MCP 拉出你的真实订单明细，在三栏工作台里挑一条数据， 做一张可编辑、可装饰、可下载打印的手账向创意小票。

先看效果 · 在线体验 · 能做出哪些小票 · 怎么用 · MCP 怎么接的 · 参赛材料

⚠️ 本项目为麦当劳程序员节创意开发大赛参赛作品，由参赛者独立开发，非麦当劳官方产品。 生成的小票为创意虚构产物，仅用于个人手账与文创创作，不可用作任何真实消费凭证。

💡 想用它做自己的小票？ 两条路先分清： 只想看看效果 → 直接开在线体验（内置示例数据，零安装零 Token）； 想用自己的真实订单 → 需要先接一次麦当劳 MCP，见快速开始（约 1 分钟）。

打开就是自己的麦门档案 —— 数据在交付前就已全部内嵌，页面是静态快照（产物里的 fetch / XHR 出现 0 次）， 双击即用、不需要 Token、不需要联网、不需要装任何东西。

三张成品（均由仓库根目录的 index.html 直接生成，示例数据、门店为虚构）：

品项 / 单价 / 优惠合计 / 取餐码 / 我的备注 累计与已过期积分、能换几个巨无霸 门店足迹 / 常点 TOP / 饭点分布 / 跨度天数

视觉目前为结构占位级：版式层次、栏位、装饰槽都是真的，美术正式版式仍在接入中。 这也意味着二次开发成本很低 —— 换一套 template.html + template.css 就是一套全新小票（见模板开发）。

小票 数据来源 情绪钩子 --------- 历史点单小票 · 明细版 order-list → query-order 展示品项、数量、真实行金额；有套餐详情时再展开，取餐码和我自己写的订单备注按数据展示。缺少明细时降级为整单金额版式并明示 积分存折 query-my-account 累计积分 ≈ 能换几个巨无霸；已过期积分单独成行 麦门履历（趣味统计） 纯计算 门店足迹 / 最贵一单 / 常点 TOP / 饭点分布 / 时间跨度

当前只保留三类常用数据源。活动、联名周边、战利品已于 2026-10-14 从工作台和正式构建入口退役； 旧模板与维护说明归档在 archive/retired-data-sources/（仅本地留档，不随仓库发布），不参与 CLI、工作台与正式构建。

常见做法 麦门日记 --------- 数据 用户自己整理订单 MCP 直接拉，零导入；query-order 交付前逐单拉齐，打开即是完整档案 明细 只给整单金额 query-order 拿到单项原价 + 优惠明细 + 取餐码 + 我的订单备注 编辑 只能改文字 栏位开关 / 换纸色 / 换纸形 / 贴装饰 / 增删明细行 / 插文案

人群 用途 ------ 手账 / 拼贴 / 文创爱好者 快速获得可打印、可装饰的小票素材，贴进本子 麦门粉丝 记录"我吃过的那些顿"，晒图有梗 想纪念一顿饭的普通人 "第一次带娃吃麦麦""考完试那顿"

⚠️ 先分清两条路，别走岔了 —— 这两条用的不是同一份数据： - 只想看看它长什么样 → 走「看演示」：读仓库内置的示例订单（虚构门店），30 秒上手，什么都不用装 - 想生成属于自己的小票 → 走「正式使用」：需要先接一次麦当劳 MCP，之后才读得到你自己吃过的那些顿
