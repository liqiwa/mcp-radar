About milanote-api-mcp-server

Milanote API and MCP server, self-hosted

A Milanote API and a Milanote MCP server you run on your own computer, in Python, on the session of your own Google Chrome. 30 of the 31 Milanote tools we run in production at Cotlet: boards, notes, links, to-do lists with due dates, columns, labels, trash, comments, sharing and export.

Milanote has no public API and no official MCP server. This repo gives you both:

- MCP server for Claude Code, Claude Desktop, Cursor, Codex and any MCP client, over stdio or HTTP. Setup - REST API on http://127.0.0.1:8787/api/v1/milanote, with OpenAPI docs at /docs. Setup - Python: call("getboard", boardid="1XiqwC1Mir4d4N"), plus 9 ready scripts in examples/.

It is for technical people who want to run it themselves, for noncommercial use only (license). If you want it running 24/7 on a server, kept working when Milanote changes its app, for a team or a business, use the hosted version at cotlet.dev.

- How it works - Requirements - Install - Connect your Chrome - MCP server - REST API - Python and the example scripts - All 30 tools - Configuration - Security and your Milanote account - Errors - Self-hosted or hosted - FAQ - License

1. You sign in to Milanote in your own Chrome, the way you always do. 2. milanote-mcp connect attaches to that Chrome through the Chrome DevTools Protocol, reads the milanote.com cookies and your browser's time zone, and saves them to ~/.config/milanote-api-mcp/session.json, readable by your user only. It never sees or stores your password. 3. Reads are requests to the JSON endpoints of the Milanote web app on app.mil
