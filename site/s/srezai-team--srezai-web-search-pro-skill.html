About srezai-web-search-pro-skill

srezai-web-search-pro-skill — web access for AI agents over MCP

Кратко по-русски. MCP-сервер веб-доступа для ИИ-агентов: поиск, чтение страниц, обход сайтов, извлечение по JSON-схеме, проверка фактов с цитатами. Рунет — в первую очередь. 12 инструментов, 1 кредит = 0,10 ₽, ключ берётся в кабинете srezai.ru. Подробно — README.ru.md.

An MCP server and skill for AI agents: web search, page reading, site maps and crawls, screenshots, PDF, JSON-schema extraction and claim verification with quotes — Runet (Russian web) coverage first.

The skill tells an agent how to use the server: which tool fits which task, what a call costs, and what to do when one fails. Works with Claude Code, Cursor, Codex, any MCP client, or as a plain markdown skill file.

Topics: mcp · mcp-server · ai-agents · llm-tools · web-search · web-scraping · deep-research · russian-web · runet · claude-code · cursor · codex · rag · fact-checking

An agent that needs data from the outside world has four problems: it does not know which source to trust, it cannot read what it fetched, it cannot prove what it found, and it burns money by guessing. This repository is the procedure that answers all four against one MCP server at https://srezai.ru/api/mcp — 12 tools, documented to the credit.

- SKILL.md — the skill an agent loads: channel detection, task-to-tool map, cost ladder, error recovery, anti-patterns, and a Russian-web section. - src/tools.json — the single source of truth for those 12 tools, their limits and prices. - Machine-readable companions: docs/tools.md and llms.txt.
