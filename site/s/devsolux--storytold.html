About storytold

Claude Code & Codex plugin for the open-source ArtCraft Craft App Suite: one craft Skill drives 12 local, headless Craft MCP apps (photo, vector, video, RAW, PDF, layout, sheets, docs, slides, CAD, audio, motion) with staged copies and verified exports.

Thank you, ArtCraft team! Storytold is built on the Craft App Suite, which the ArtCraft team released as free, open-source software: twelve creative apps, each written from scratch. We're grateful for their generosity. None of this integration would exist without their work.

Local creative work. Native app engines. Verified file handoffs.

Storytold is Devsolux's local integration kit for twelve existing Craft CLI MCP servers. One compact craft Skill guides the host; the apps keep their own schemas, editing state, rendering and save semantics. Deterministic helpers install and pin the twelve CLIs on explicit command, stage files, generate evidence-bound config and verify artifacts within stated limits. No thirteenth MCP server or second AI agent.

The offline core suite, the official MCP SDK contract test, strict Claude manifest validation and Claude Code/Codex install with Skill discovery have been run, and setup has installed, probed and Sigstore-verified all twelve Craft CLIs on macOS, Linux and Windows runners as well as a developer Mac; read verification. Craft apps are not bundled: installing the plugin installs guidance, the reviewed release manifest and inactive templates, never binaries, permissions or running MCP processes.
