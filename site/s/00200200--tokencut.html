About tokencut

Smaller tool outputs, zero LSP daemons, with omitted context available on demand. A local CLI, MCP server, and macOS desktop HUD for Claude Code, Codex / ChatGPT Desktop, Antigravity, and Cursor.

Try in 1 Min · macOS Desktop Pet · Zero-LSP Code Intel · Architecture · Integrations

Requires Python 3.11+ and uv. Install this repository: the PyPI name tokencut belongs to another project.

The demo works outside a project and makes no model calls. It measures an authored log, checks the complete diagnostic tail, verifies recovery of the original, and confirms that unfamiliar output stays unchanged. Checks print PASS or FAIL; a failed check returns a nonzero exit code. Use tokencut demo --json for machine-readable results. Demo data uses a disposable cache.

Then try your own command: tokencut run -- , or connect Claude Code, Claude Desktop, Codex, or Antigravity. Smaller tool output is the measured benefit; subscription limits and task quality need separate evaluation.

Illustrative terminal demo. Run the fixture benchmark below for reproducible measurements.
