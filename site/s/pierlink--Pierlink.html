About Pierlink

- 一处登录，处处可用：内置 SSH 登录一次（密码、验证码都行），终端、文件、端口转发、同步、概况全部共用，不用反复输密码。 - 本机写代码，服务器上跑：服务器目录和 Windows 本地目录自动双向同步，用你习惯的编辑器改，改完服务器上马上就是新的。 - AI 干活，你来把关：Claude Code、Codex、Cursor 等 AI 助手可以操作你的终端和服务器；AI 跑在服务器上也能像装在 Windows 上一样改代码、编译运行。危险操作先问你；人不在电脑前，也能在手机上批准。

终端 - 服务器和本机终端：多标签、分屏、拖动换位置；切换页面后终端保持运行 - 广播输入（一次发给多个窗格）、命令片段（支持变量） - 命令预测：在服务器的 bash、zsh 和本机 Git Bash 里输入时，光标后浅色显示用过的命令，→ 补全；记录只存在这台电脑上 - Shift+Enter 换行不执行（shell、Claude Code、Codex 里都能用）；选中文字时 Ctrl+C 复制，Ctrl+V 粘贴；可以打开“右键复制粘贴” - Claude Code、vim 等复制的内容直接进本机剪贴板（在 tmux 里也行）；点终端里的链接用 Windows 的浏览器打开 - 从资源管理器把文件拖进本机终端，自动填上路径（PowerShell、命令提示符、WSL 各按自己的写法） - 在服务器终端里粘贴图片：图片传到服务器、粘贴路径，Claude Code 里显示成 [Image 1] - 服务器概况常驻在终端右上角：CPU、内存、交换、GPU、各挂载点磁盘、网速

连接 - 内置 SSH（CentOS 7 这样的老服务器也能连）；也可以按 ~/.ssh/config 用系统 OpenSSH 连接，并一键导入 - 端口转发：本地、远程、SOCKS 代理，断线后自动恢复 - 代理：跟随系统或自定义 HTTP / SOCKS5，连接服务器、检查更新和本机终端都用它 - 文件面板：浏览、上传、下载、重命名、删除、在线编辑文本文件；窗格之间拖动即可传文件

文件同步 - 基于 Syncthing，经 SSH 隧道传输：不开放任何端口，服务器上不需要 root - 首次同步前预览；冲突时对比两个版本再选；删除和覆盖的文件进旧版本，可以找回 - 一个本地目录可以同时同步到多台服务器；可以直接在 VS Code 里打开

AI 接入（MCP） - AI 跑在服务器上，像装在 Windows 上一样干活：Windows 不用装 Claude Code，服务器上的 AI 就能读写、按行修改、搜索你允许的 Windows 文件夹，在 Windows 上编译、运行、开后台任务；文件的编码和换行原样保留（GBK、UTF-16、CRLF 都行），长时间的编译不会被中途掐断 - AI 能查到自己能在哪些文件夹干活、有哪些 shell、同步的服务器路径对应 Windows 哪里；怎么做由 AI 自己决定 - AI 可以自己开一个看得见的终端干活，你随时能接管 - 危险操作（如 rm -rf、强制推送）要你确认；审批方式可选；每一步都有操作记录 - 一键添加到 Claude Code / Codex / Cursor，服务器上的 Claude Code / Codex / Gemini CLI 也能一键接上；标题栏随时看得到 AI 在不在操作、刚做了什么和命令输出，一键全部停止
