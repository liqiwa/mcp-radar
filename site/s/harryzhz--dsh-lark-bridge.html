About dsh-lark-bridge

dsh-lark-bridge 把 Claude Code / Codex / TRAE / DeepSeek Harness 接进飞书群：零公网暴露 · 懂分寸不刷屏 · 会记事与夜间复盘 · 能主动委派跟进

基于 DeepSeek Harness (DSH)（Desktop & Web）构建，受 dsh-superagent 与 botmux 启发。默认使用 DSH 原生预设与模型；一键安装脚本已配套 dsh-external-agents，开箱接入 Claude Code、Codex、Antigravity、TRAE CLI 等外部 Coding Agent，MIT 协议开源。

1. 零公网暴露，扫码 3 分钟跑起来 基于飞书官方 WebSocket 长连接，无需云服务器、公网域名或内网穿透。一行命令装齐环境，控制台扫码自动创建飞书应用、配齐权限并拉起长连接，拉进群自动启用并打招呼。 2. 多引擎无侵入，一个群一套配置 默认直接使用 DSH 原生预设与模型；搭配 dsh-external-agents 开箱支持 Claude Code / Codex / Antigravity / TRAE CLI。研发群、告警群、发布群可各自绑定代码仓库、运行时、模型与并发上限，支持 AI 一键生成定制角色和监听规则。 3. 懂分寸、不刷屏的智能分流与主动监听 轻量前置智能分流 + 逐成员/应用主动监听开关：同事日常沟通彻底静默；线上告警卡片一到秒开话题查本地代码库，按「止损 → 根因 → 后续行动」回复。支持飞书原生思考过程气泡与卡片底部一键跳回 DSH 接管同一会话，话题内追问免 @。 4. 越用越懂团队的跨运行时长期记忆 + Auto-Dream 不依赖单一 Agent 的私有文件，统一沉淀在 SQLite + FTS5 混合检索引擎与 Obsidian 风格关系图谱中，按全局 / 工作区 / 群聊三级隔离防串味。每晚 Auto-Dream 自动低优先级复盘增量对话、对照最新代码验真并双时态纠偏过时规则。 5. 说到做到的主动提醒、委派跟进与隔离修补 静默识别群内 A @ B 的明确指派与承诺，到期先核查群历史/MR/CI 真实状态——已闭环静默归档，未闭环才精准 @负责人 cc 发起人，夜间免打扰自动顺延至白天。开启主动代码优化后，可在 .worktrees/ 隔离分支改代码、跑单测并提审 PR/MR，绝不污染主工作分支。 6. 生产级驾驶舱可观测 + 免重启热更新 内置驾驶舱（概览 / 洞察 / 监控）看清消息吞吐、Token 结构与缓存命中率、分流减负漏斗、P50/P95 延迟与 SQLite WAL 健康度；Web 版支持从 GitHub Release 一键原地免重启热更新，不打断在途长任务。
