About stringers

我们每天采集 15 个库:独立产品经支付平台校验的真实收入、App Store 115 个区和 Google Play 的榜单、Meta / Google / TikTok 广告库、GitHub、Product Hunt、Hacker News、X 上几个圈子……在这上面写了约 90 个方向的判断,每个方向一篇长文、一个评级,每天复查。

网页上是写好的判断。接进你自己的 agent(Claude Code、Cursor、Codex、Trae……)之后,它能读这些判断,也能直接去查背后的库,再结合你自己的情况回答。

这个仓库是接入用的那一层:说明、Claude Code 插件、skill、命令行。采集和服务端不在这里。

English: Stringers (「什么值得做」, stringers.io) publishes daily, evidence-backed verdicts on which small-product directions are worth building for indie developers and small teams, drawn from 15 data libraries collected every day (payment-verified indie revenue, App Store / Google Play charts, Meta / Google / TikTok ad libraries, GitHub, Product Hunt, Hacker News, X). This repo connects it to your agent: a remote MCP server (https://stringers.io/mcp/{token}, tools today / directions / direction / data), a Claude Code plugin, an Agent Skill and a CLI. Content is in Chinese; get a token by logging in at stringers.io.

1. 打开 stringers.io,右上角登录(手机号 + 验证码,未注册的自动建号)。 2. 点配置 agent,复制那段话,发给你的 agent。 3. 它自己把配置加好。接通以后直接问。

这个地址就是你的 token,别发到公开的地方。泄露了在「配置 agent」里点「换一个新地址」,旧的立刻失效。

已经有 token(登录后「配置 agent」里那个地址,/mcp/ 后面 wt 开头的一段),在 Claude Code 里:

agent 改不了自己的配置,或者你想自己来,按客户端加一个远程 MCP 服务器:名字 stringer,类型 Streamable HTTP,地址填上面那个。

Trae / Windsurf / Cherry Studio 等:设置里添加 MCP 服务器,类型选 Streamable HTTP(或「可流式传输的 HTTP」),填地址。只认 JSON 的,用上面 Cursor 那段。

只支持本地命令(stdio)的客户端:装下面的命令行,配置成运行 stringer mcp。

- 最近有什么适合用来练手的独立开发项目? - 今天的头条是什么?跟我有没有关系? - 我想做一个给 Claude 用的 MCP 工具,这个方向现在谁在做、赚到钱了吗? - 最近 30 天收入涨得最快的 AI 视频类独立产品是哪几个?各自怎么获客的? - 按我的情况出一份今天的简报:只看适合 iOS 独立开发、不碰买量的方向。
