About overleaf_mcp_server

Overleaf MCP Server (Zero-CLI Deploy for Claude, ChatGPT & Gemini)

Connect Claude to your Overleaf project in 2 minutes—with zero terminal commands required.

Step 1: Click Deploy on Render 1. Click the Deploy to Render button above (or go to dashboard.render.com → New + → Web Service → select tejas004s/overleafmcpserver). 2. Click Deploy (no environment variables are required to deploy—your Overleaf share link is already pre-configured in render.yaml!).

Step 2: Open Your Render URL in the Browser Once Render finishes deploying, open your app URL (https://overleaf-mcp-server-xxxx.onrender.com): - You will see the Overleaf MCP Easy Setup Console. - Your Overleaf share link (https://www.overleaf.com/project/6ab69fcdfed103759283b936/share...) is already filled in. - (If Overleaf asks for login, paste your overleafsession2 cookie right into the webpage and click Save & Test Connection). - Click Copy URL to copy https://overleaf-mcp-server-xxxx.onrender.com/mcp.

Step 3: Add to Claude - Claude Web (claude.ai): Go to Settings → Integrations → Add Integration and paste https://overleaf-mcp-server-xxxx.onrender.com/mcp. - Claude Desktop: Add to claudedesktopconfig.json:

"Open my Overleaf project, generate a 1-page LaTeX resume using getresumelatextemplate with my details, write it to Overleaf with overleafsetlatex, recompile with overleafrecompile, and give me the PDF download link with overleafdownloadpdf."
