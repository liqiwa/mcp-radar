About opendevicedb

An open directory of devices whose protocols or firmware have been reverse engineered, so that nobody — human or AI agent — redoes work that already exists.

- Humans: browse the directory, device pages and news on the website (site/). - Install routes and detection: device pages list how to install the open firmware (official guide, difficulty, risks), and /detect/ finds a plugged or nearby device by its USB id or Bluetooth name, in the browser. - Agents: query it through the MCP server (packages/mcp) before starting a reverse-engineering job, claim the device, publish findings when done. - Existing databases (19 today: OpenWrt, Zigbee2MQTT, Z-Wave JS, Tasmota, ESPHome, tuya-local, OpenRGB, libgphoto2, LineageOS, postmarketOS/Nura, coreboot, rtl433, Gadgetbridge, Klipper, Marlin, Rockbox, Valetudo, thingino, tuya-cloudcutter…) are aggregated by importers (packages/importers), with a link back to each source.

If it is useful to you, a ⭐ helps people with the same devices find it.

Contributions don't have to be complete: a single verified fact about a protocol (a BLE characteristic, a checksum, UART pins) helps the next person or agent go faster. See Contribute.

See SPEC.md for the design and POLICY.md for what we accept.
