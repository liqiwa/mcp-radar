About sketchcraft

SketchCraft is a free, open-source push/pull 3D modeler for buildings, streets and anything with straight walls. It's written in Rust, runs as a desktop app on macOS, Windows and Linux, and is fully scriptable: every action is a JSON command, so scripts, the CLI and AI agents (over MCP) drive exactly what you drive with the mouse.

- Draw: lines that split edges, cut faces and close into faces; rectangles, circles, polygons, arcs, offsets. - Shape: push/pull (pull out, push in, carve windows and doors), Follow Me sweeps for trim, cornices and eaves, auto-fold when a move bends a face. - Transform: move, copy and arrays (x5, /5), rotate, scale, mirror. - Snap: endpoints, midpoints, edges, faces, guides and the red/green/blue axes, with "From Point" alignment and arrow-key axis locks. Type a number and press Enter for exact sizes. - Organize: groups and components (edit one, every copy updates), tags, hide/unhide, soft edges, an outliner. - Document: dimensions and text labels, saved views, section cuts, X-ray, shadows, parallel projection, headless PNG renders. - Library: doors, windows, garage doors, trees, palms, cars, streetlights, benches and hydrants, all built from editable command scripts. - Build blocks: walls along a path (or closed rooms), code-friendly stairs from a total rise, gable/hip/shed roofs on any top face, columns. - Textures: add a photo as a material, paint faces with it at a real-world tile size, or project it across a whole model from your view. - Units: meters, centimeters, millimeters, feet & inches, or inches. Type lengths any way: 12', 8'6", 250cm
