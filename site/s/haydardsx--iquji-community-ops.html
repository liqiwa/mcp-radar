About iquji-community-ops

简体中文 · Download installers · Report an issue

iQuji Ops is a desktop application for deploying and monitoring self-hosted services on Linux servers. Connect a server over SSH, build an application with Jenkins or deploy a container image, and follow its Docker Swarm replicas, routes and logs from the same workspace. The source is available under a personal, noncommercial license.

The screenshots show the English interface with fictional data. The app also supports Simplified Chinese.

Choose an installer for your operating system and processor from GitHub Releases. The release includes SHA256SUMS for verifying downloads.
