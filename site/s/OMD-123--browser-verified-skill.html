About browser-verified-skill

Explore once with an AI agent, prove the result with evidence, compile it to a plain Playwright script, replay it for free, and heal only the steps that break.

browser-verified-skill (CLI: bv) is an open-source Agent Skill for browser automation. Drop it into an agent — Claude Code, Hermes, or anything that speaks MCP or the CLI — and the agent can drive a real browser while every action passes a policy gate, every run leaves an auditable artifact, and the whole run compiles into a plain Playwright script that replays for free.

It exists for the case where an agent drives a real browser and you need the result to be provable, auditable and reproducible — not a transcript that claims it worked.

It is not a stealth tool. There is no fingerprint spoofing, no CAPTCHA solving, no proxy rotation and no bot-detection evasion. The user agent is honest, CAPTCHA and login walls trigger a human handoff, and robots.txt is respected.
