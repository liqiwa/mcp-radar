About AIDrive

Switch assistants. Keep the project moving. A local shared workspace for Claude Code, Codex and OpenCode.Versioned files. Decisions with sources. Handoffs that keep their context.

Why · Install · Quick start · Screens · How it works · Status · Reference

[!WARNING] Experimental source preview. Initial pilot testing has been completed. Final clean-machine package acceptance remains open. ROADMAP.md records what is verified and what is not. Read Limits before you rely on it.

[!IMPORTANT] Security fix after the pilot review (2026-11-26). The review found that any program on the computer could make itself the owner of a packaged install, and that an assistant's proposed rule could skip review. Both are fixed in v0.0.1-alpha.3 and aidrive-mcp-server 0.0.2: owner sign-in now needs a one-time link from aidrive open, and assistant rules wait for you. Do not use the older alpha.2 archives. Details: security review, P1 and P2.

Using two or three AI coding assistants on one project means each session starts cold, decisions get lost between tools, and one assistant quietly overwrites another's work. AIDrive gives them one shared, governed project state.

Keep work safe Carry context forward Stay in control :--- :--- :--- Every write names its source version. Stale writes are refused with HTTP 409. Handoffs and decisions cite exact sources. Changed evidence is flagged for review. Review proposals, assign per-key roles and inspect changes in one local workspace.
