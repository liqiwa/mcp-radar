About zig-anything

Port JavaScript, TypeScript and Python functions, and whole command-line programs, to Zig one piece at a time, and prove every port behaves exactly like the original.

Measured with zig-anything bench on examples/levenshtein-py. Regenerate with python scripts/makedemogif.py.

zig-anything records what a function in your existing code actually does (on generated edge cases, semantic traps and inputs you supply), scaffolds a Zig port of it, and replays every recorded case against the port until they all match. A single command, gate, decides when a port is done.

That mismatch is real: the first Zig port counted bytes, but JavaScript counts UTF-16 code units. The recording caught it.

- One static binary, about 0.4–0.8 MB, with no runtime dependencies. Written in Zig with only the standard library. - Language-agnostic replay. The original runs in its own runtime (Node or Python) through a small embedded recorder. The port runs as a native Zig harness. Results meet as JSON lines. - Semantic comparison. 1, 1.0 and 1e0 are equal, object key order is ignored, and NaN/±Infinity survive the round trip. Thrown errors match returned Zig errors. - Measured, not claimed. bench times both sides on the same recorded inputs and reports a verdict, including when the port is slower. - Agent-ready. zig-anything mcp exposes every command as a Model Context Protocol tool.
