About XIPU-MCP

连接西交利物浦大学 Learning Mall Core（Moodle）的本机 macOS App。AI 通过标准 MCP stdio 查询课程、下载附件和查看截止时间。

请按照 https://github.com/xyx-chn/XIPU-MCP/blob/main/skills.md，在这台 Mac 上编译安装 XIPU MCP，并接入你当前使用的 MCP 客户端。

skills.md 包含完整执行步骤；标准 SKILL.md 可作为支持 Skill 的客户端入口。需要 Apple Silicon Mac、macOS 13+。脚本自动准备经过校验的 Node／npm，不需要预先安装 Node 或 Homebrew；网络需能访问 GitHub、Node 官方站和 npm。

需要 DDL 桌面小组件时，在请求中加上“同时启用 DDL 桌面小组件”。小组件需要 macOS 14+ 和完整 Xcode；由接收者的 AI 在本机从源码编译并临时签名，不需要 Developer ID 证书、Apple Team ID 或公证凭据。

可选择 codex、claude-desktop、cursor 或 config-only。默认安装到 ~/Applications/XIPU MCP.app，无需 sudo；类型检查、测试和 MCP 初始化通过后完成部署。只修改所选客户端的 xipu-mcp 条目，保留其他设置，变更前创建私有备份。config-only 只导出 dist/mcp-config.json，其他客户端还需按其官方方法注册。

首次使用请本人在 App 中配置学校账户及可选邮箱，再点击“连接学校”；不要在 AI 对话中发送密码或授权码。AI 不需要你的账号就能编译安装。客户端可能需要重载 MCP 或重启才能加载工具。

若学校登录会话发生循环跳转，App 会重建本机学校会话并重新打开登录页，保留已配置的账户与密码。页面加载失败时，登录窗口会显示错误提示和“重新加载”入口；无需清除全部凭据。

1. 按上方源码部署方法安装 Apple Silicon（M 系列 Mac）的 ARM App，打开 ~/Applications/XIPU MCP.app。 2. 在“账户与邮箱”填写学校账户。希望自动取码时，再配置邮箱服务器、认证信息、收码地址及筛选规则。 3. 保存设置，测试邮箱连接，点击“连接学校”。自动流程未完成时会打开学校原始登录窗口，供人工操作。 4. 安装器会配置所选 MCP 客户端；也可在“AI 接入”生成配置，复制到支持 stdio 的客户端。安装后的 App 内置 Node，日常使用不依赖开发目录。

关闭主窗口后，App 继续运行本机桥接和下载任务；通过应用菜单退出才会停止后台服务。MCP 客户端可以自动启动已安装的 App。

课程列表优先展示名称以三个大写英文字母和三个数字开头的正式课程，例如 COS305、EEE335；消息发布页保留在后面。课件同时支持 Moodle 嵌入式预览和直接文件重定向，网页／视频以可打开的链接展示。

当前以源码部署为分发方式，接收者在自己的 Mac 编译安装。测试范围见 TESTING.md；邮箱验证码全链路和另一台 Mac 验收仍待完成。个人账户的联调记录不公开上传。
