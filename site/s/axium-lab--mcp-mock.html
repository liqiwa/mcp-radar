About mcp-mock

A mock MCP server for integration tests. Point your MCP client at it, keep your code.

mcp-mock speaks the Model Context Protocol faithfully enough that the official SDKs cannot tell it from a real server, in every spec revision from 2024-11-05 to 2026-07-28. Its tools return deterministic, believable data, and a test can force any answer, error or HTTP failure from the request itself, with nothing to register beforehand.

⚡ Zero install: a free public instance runs at public.mcp-mock.com. Point your MCP client at https://public.mcp-mock.com/mcp and start in seconds; no download, no signup, no API key.
