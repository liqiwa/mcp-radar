About SoundBit

A chiptune workstation for humans and AI agents.

Compose 8-bit and 16-bit music in a tracker-style editor, or let an AI agent write it for you through the Model Context Protocol. Both work on the same song at the same time: what the agent writes appears in the editor as it happens, and every change can be undone.

Install · What you get · AI agents · Tools · Wiki · Changelog

[!NOTE] SoundBit is pre-alpha. The editor, live playback, sound shaping, the MCP server and WAV export work; expect rough edges and breaking changes until 1.0.

- A tracker-style editor. One-bar patterns placed on tracks; a canvas arrangement view and piano roll; instruments, song settings, transport, undo and redo; five colour themes. - Chip voices. Pulse with four duty cycles, NES-style stepped triangle, sawtooth, sine, LFSR noise (long and metallic), Game Boy-style 4-bit wavetables and 4-operator YM2612-style FM with eight algorithms. - Sound shaping. Pitch envelopes for kicks, toms and lasers; delayed vibrato; up to four detuned unison layers for strings and choirs; a resonant low-, high- and band-pass filter that can follow the envelope; and a shared reverb room with a send per instrument. - 32 presets. Orchestral strings, brass, choir and timpani, a drum kit, chip leads and basses, FM keys and effects, stored as plain JSON in assets/presets. - Chip profiles. Optionally keep a song within what an NES, Game Boy, Commodore 64 or Genesis could play: track count, voice types per channel and notes at once. - An MCP server with 30 tools.
