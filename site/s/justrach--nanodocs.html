About nanodocs

Native 120 Hz GPU Markdown, HTML &amp; Mermaid Studio + Bidirectional Agent &amp; Harness Bridge Built in Zig 0.17 on nanoui · Zero Webviews · Streamable HTTP MCP (:7740/mcp) · Local Harness IPC (:27664)

Zero webviews, zero Electron, zero per-frame parsing: documents and Mermaid diagrams are pre-parsed into typed ASTs in 4.95 µs and drawn directly with Metal and CoreText on macOS (or nanoui's TrueType shaper and OpenGL / D3D11 / CPU renderer on Linux and Windows).

Editorial Paper Mode (Rendered) Obsidian Dark Mode (Split Edit · --dark) --- ---

Coding agents generate Markdown plans, architecture walkthroughs, and Mermaid diagrams constantly—and need human edits, approvals, or change requests back without copy-pasting walls of text.

nanodocs turns agent walkthroughs into an instant, interactive 120 Hz native loop:

1. Agents push visual walkthroughs in 45.9 µs over Streamable HTTP MCP (POST http://127.0.0.1:7740/mcp) or CLI (nanodocs show --split). 2. Humans edit Markdown & Mermaid live (⌘E): every keystroke re-parses the AST in a 4-slot arena ring (~10 µs) and updates the 120 Hz Metal GPU diagram on the right with zero flicker. 3. 1-Click Feedback Routes Back to Your Agent (Send ↵ / ✎ Request Changes / ✓ Approve Plan): - Direct Harness Bridge (ws://127.0.0.1:27664, Zero Login Required): pushes your review and live document path directly into any active Harness chat (QueueMessage / QueueCommand: run) or spawns a new local agent chat (graff, claude-code, codex, cursor, antigravity, grok, pi, opencode). - Reactive MCP & CLI Wakeup (waitforfeedback / nanodocs wait): lights u
