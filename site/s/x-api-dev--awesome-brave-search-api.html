About awesome-brave-search-api

Unofficial community list for the Brave Search API. Not affiliated with Brave Software. All trademarks belong to their owners.

A curated list of resources for the Brave Search API, the API that exposes Brave's independent web index to agents and chatbots with $5 in free monthly credits. Everything here is either published by Brave or documents something you will hit while integrating (such as keeping the key out of git). Each item says why it is worth opening.

Pairing search with generation? Try Synexa - one REST endpoint and a Python SDK for FLUX, video and audio models, pay per run. A hosted model API to sit next to your search calls.

- Brave Search API - the product page: plans, pricing, the $5 free monthly credits and the 50 queries per second capacity. - Developer docs - the endpoint, authentication and parameter reference, filed under the LLM context service. - Plans - choose between the Search plan and the Answers plan. - Use cases - Brave's own list of what people build with it. - Latest API news - the news category where plan and feature changes are announced.

- Get an API key - registration; free credits are applied automatically. - Log in - the dashboard for existing accounts. - How-to guides - step-by-step guides published by Brave. - Tools and integrations - the integrations Brave lists for the API.
