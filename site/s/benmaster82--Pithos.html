About Pithos

A dependency-free C inference engine for Liquid AI's LFM2 / LFM2.5 models. Terminal chat, an OpenAI-compatible server, a web agent and a terminal agent, all in one executable.

Quick start · Screenshots · Results · Terminal agent · MCP · Roadmap

------ About 1.9× faster than llama.cpp 17–22 tok/s against 11 tok/s with CUDA, on the same laptop and model (head-to-head) Runs a 13.5 GB model on 16 GB of RAM experts stream from disk, the hot ones live in a 4 GB GPU Agents included Pandora in the browser, and a terminal agent that runs commands, fixes code and checks its own work

Pithos is an inference engine written from scratch in C11 with no dependencies: no external libraries at build time, only the operating system API (Win32 or POSIX). It runs GGUF models of Liquid AI's LFM2 / LFM2-MoE architecture and is tuned for LFM2.5-24B-A2B-Q4KM.gguf (24 billion parameters, about 2 billion active per token) on an ordinary laptop.

Pithos is the engine and the server (in the myth, the pithos is Pandora's jar: it holds the model). Pandora is the agent in the web interface.

- CPU inference with AVX2 / NEON integer kernels that read the quantized weights in place. - Optional OpenCL GPU acceleration: hot experts and all dense layers in VRAM, with the remaining experts computed on the CPU in parallel. - Works with models larger than the free RAM (asynchronous read-ahead, expert prediction). - OpenAI-compatible HTTP server with prompt reuse across turns, also after a restart. - Pandora, a single-file web chat with an agent mode: web search, files, calculator and any MCP server. - A termin
