About amigent

Amigent connects your PC or Mac to your real Amiga over the home network. Then you can:

- let an AI agent do the work, for example Claude Code or Codex: install software, update programs, change settings, copy files, click through programs. Just tell it what you want. - use the Amiga yourself from your computer, as a remote desktop like TeamViewer or VNC: a window with the live screen, your own mouse and keyboard, file transfer and a shared clipboard. - and both of these quickly, even on a slow machine. Amigent is tuned for slow Amigas and slow networks: a 7 MHz 68000 sends its whole screen in under a second, and over a plipbox a click shows its result in a fraction of a second. How it stays fast.

Both at the same time: you see every click the agent makes and can take over at any moment.

1. Copy amigentd to the Amiga (amigentd.000 on a 68000), or unpack the archive from the releases.

2. Start it with amigentd SETUP in a Shell, or double-click its icon.

Install Amigent for me: run "pipx install amigent" (if pipx or Python 3.10 or newer is missing, install them first: Windows winget, macOS Homebrew, Linux the package manager). Then run amigent-setup; it finds my Amiga on the network by itself. Register the MCP server "amigent" with the command amigent-server, and run amigent-viewer --install so the remote desktop shows up as a program. Tell me if you need to be restarted.

The agent sets up the Amiga over the network; from then on amigentd starts with it.
