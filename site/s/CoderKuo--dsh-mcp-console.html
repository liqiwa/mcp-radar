About dsh-mcp-console

在 DeepSeek Harness 里集中管理 MCP 服务器：看状态、一键启停、让 AI 安装或手动添加、自动发现本机可接入的软件。

能力 说明 --- --- MCP 列表 侧栏新增「MCP」入口，列出当前 profile 配置的全部 MCP 服务器：名称、连接状态、传输方式、启动命令或地址、环境变量名、提供的工具、开源地址 启用 / 禁用 每个服务器一个开关，通过 DSH 官方插件管理器写入 profile 并立即生效，不用重启 删除 AI 安装或导入的服务器可以一键删除：通过官方插件管理器卸载插件包，并清理它在 mcp-bundles 目录里的配置文件（目录外的文件一律不碰） 一键导入 扫描到的其他客户端（Claude Desktop、Claude Code、Cursor、VS Code、Windsurf、Codex）里的 MCP，可以直接导入，不经过 AI 实时刷新 服务器连上、断开、启停时页面自动更新，不靠定时轮询 AI 快捷添加 填 MCP 服务器的来源（代码仓库、npm/PyPI 包名、Docker 镜像、README 里的启动命令或任意网页链接，可加补充说明），插件在默认工作区开一个新会话，让 AI 查清运行方式、安装、写好配置并接入，全程每一步安装都会先征求你同意 手动添加 已经知道怎么运行时直接填：本地命令（如 npx -y 包名、uvx 包名、docker run -i --rm 镜像）或远程服务地址，不经过 AI；添加前先在本机测试连接；密钥可以只写「读取哪个环境变量」，不保存明文；只支持 SSE 或需要 OAuth 登录的服务可以通过 mcp-remote 桥接 搜索 MCP 目录 从官方 MCP 目录搜索，选中后自动填好手动添加的表单（命令、环境变量、请求头） 编辑 / 导出 插件生成或 AI 安装的服务器可以用表单编辑；全部服务器可以导出成其他客户端通用的 mcpServers JSON（不含密钥） 选择供应商和模型 AI 快捷添加和联网分析都可以像模型选择器一样选供应商和模型，只对这次打开的会话生效，不改动你的默认模型 发现本机可接入的服务 扫描本机已安装的应用、后台服务、监听端口、Docker 容器，以及 Claude Desktop / Claude Code / Cursor / VS Code / Windsurf / Codex 里已经配置的 MCP；确认后交给 AI 联网检索哪些有 MCP 服务器，再问你要接入哪些 不泄露密钥 页面只显示环境变量和请求头的名字，参数里像密钥的值会被打码；扫描清单不含文件路径

安装后侧栏会出现「MCP」入口。新版本发布后 24 小时内按包名安装会被 DSH 的包管理器拒绝，可以改填 GitHub Release 的安装包地址：

DSH 的 MCP 客户端（@deepseek-ai/dsh-mcp-client）不对外提供连接状态，插件按能观察到的信息判断：

状态 含义 --- --- 已连接 正在运行，并且已经注册了 mcp 工具 连接中 正在启动，或已运行但还没有工具（也可能首次连接失败、或服务器本身不提供工具，详见 DSH 日志） 失败 加载失败（服务器配置了 failOnStartupError: true 时才会出现） 已禁用 在 profile 里被关掉了

开关调用 DSH 官方插件管理器的 setPluginEnabled，它会在 profile 的 cordis.patch.yml 里写 disabled: true/false 并立即生效。由插件包内置、或在别的配置层定义的服务器不能在这里切换，开关会显示原因。
