About foldline

Render HTML canvas animations to MP4, fast, on a Mac. With the full lemo-opuscar library of 66 film styles made in code.

Made for Unfold, an animated "What if" channel in a paper pop-up book style.

https://github.com/user-attachments/assets/05724852-c9ae-4762-90a9-634315b2b016

▶ Watch on YouTube · download the MP4 · read the deep dive on Medium Made with Foldline itself: every frame drawn in code, a local text-to-speech voice, music synthesised in code. It renders in 34 s. Source in examples/foldline-explainer.

Foldline turns a web page that draws a film in code into an H.264 MP4. You write an HTML page with a and a render(t) function. Foldline opens it in headless Chrome, draws every frame, and encodes the video inside the page with WebCodecs on the Mac's hardware encoder, so frames never leave the GPU. On an M1 Pro, an 8.4-minute 1080p 60 fps video renders in 161 s instead of 426 s (see Results). It's open source and free for non-commercial use, and it works well with coding agents like Claude Code.

Foldline is a project by Alireza Toghiani, built for the Unfold channel. It isn't a GitHub fork. It ships the full lemo-opuscar library by LemoLab:

- all 66 film styles in styles/, each with a style prompt and a demo film made in code - the toolkit in core/ (render, voice, music, mix) - the guides DIRECTOR.md, TECHNIQUE.md and MY-STYLES.md - lemo's Claude Code plugin in plugin/

lemo's original README is kept as LEMO-README.md. It has the style list, how to make a style your own, and the full requirements.
