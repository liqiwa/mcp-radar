About osxphotos-mcp

A slim MCP server that lets an AI assistant search, inspect and export your Apple Photos library. Seven tools, read-only by default.

It is a thin layer over osxphotos by Rhet Turnbull, which does all the real work of reading the Photos library. If this is useful to you, the credit belongs there.

Then give the app that runs the server (Claude, your terminal, ...) Full Disk Access under System Settings Privacy & Security. Without it, macOS blocks access to the library.

If the client cannot find uvx, use its full path (which uvx).

Each start of the server uses the latest version from this repository, so restarting the client updates it. To stay on one version, add its tag to the URL: git+https://github.com/rscholz98/osxphotos-mcp@v0.3.0.

Tool What it does ------ searchphotos Find photos by text, date range, album, person, keyword, place, favorite or media type, with paging getphoto Full details of one photo: metadata, albums, labels, camera, location, file paths listalbums Albums, including shared ones, with folder and photo count listpeopleandkeywords People and keywords with photo counts exportphotos Copy photos to a folder (edited version if there is one, never overwrites) osxphotoshelp Look up any osxphotos command and its options runosxphotos Run any osxphotos command, for everything the tools above don't cover

The first five are small and typed, so a model gets them right on the first try. The last two reach the rest of osxphotos on demand, without loading hundreds of options into every conversation.
