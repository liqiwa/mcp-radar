About polymarket-mcp-agent

MCP server that lets a local AI client read Polymarket markets and, when you turn live mode on, place orders with your wallet. Version 1.7.0. Node.js 20 or newer. MIT license.

The process starts in preview. Preview writes simulated trades to a local SQLite file and does not sign or send orders. Live mode signs CLOB orders with POLYPRIVATEKEY and posts them to https://clob.polymarket.com. One process, one database, one wallet. It is a single-operator tool.

Stdio is the transport for Claude Code, Cursor, and other local MCP clients. HTTP is optional and should stay on a private network.

Capability details: PERMISSIONS.md and SECURITY.md.

1. The client invokes a tool. Inputs are checked with Zod. 2. Read tools call the public Polymarket APIs, or ESPN when the tool is wta.discover. 3. Trade tools run the safety checks, then the daily budget check. 4. In preview, the trade row is stored as simulated. 5. In live, TradeExecutor builds a CLOB client, derives API credentials from the signing key, and calls createAndPostOrder. The position row is stored as executed only after the CLOB accepts the order.

config.golive flips the running process to live after confirm: true, and only if the live credentials are set. A restart returns to COPYMODE from the environment.

Claude Code, in ~/.claude/settings.json:

Copy .env.example to .env beside the package when you want a budget other than the defaults, or when you want live trading. The loader reads .env from the package root, not from the process working directory.
