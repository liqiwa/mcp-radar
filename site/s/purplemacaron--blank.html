About blank

Download blank &nbsp;·&nbsp; Releases &nbsp;·&nbsp; Source

A quiet, local-first agent harness for your desktop. White by default, blue accent, keyboard friendly, and built to span chat, code, tools, media, Paper, and remote control — not just one of them.

The first launch walks through connecting a provider and choosing a model. Nothing is sent until you add a key or start a local runtime.

Chat, live plans, tool runs and file cards — in English or Korean.

Agent loop Streaming responses, tool calls with per-tool approvals, a live plan rail, checkpoints, automatic context compaction, fallback models, subagents, skills, durable memory, and opt-in self-improvement notes after runs.

Models and providers - Built in: Anthropic, OpenAI, Google, OpenRouter, xAI, DeepSeek, Mistral, Groq, Together, Cerebras, Ollama and LM Studio. - Any OpenAI-, Anthropic-, or Gemini-compatible endpoint can be added with a base URL, protocol, and model list. One-click presets cover LiteLLM, vLLM, LocalAI, Open WebUI, and Jan. - Several API keys per provider, with labels, an active key, automatic rotation on 401/402/403/429, masked previews, and environment fallbacks (ANTHROPICAPIKEY, OPENAIAPIKEY, …). - Probe an endpoint to fetch its model list, and choose a fallback model used when the primary errors or rate-limits.

Tools Workspace-scoped read/write/edit, glob, grep, shell commands, web fetch, configurable web search (DuckDuckGo, Brave, Tavily, Exa, Serper, SearXNG), todo plans, memory, media, MCP, and computer use.
