About crowbar

Retrieve CVEs and index them inside your codebase.

Point it at a product and version. It pulls the CVEs that apply and indexes them locally, so any tool in your repo can query the answer.

Quick start · How crowbar works · What you can answer · Showcases · FAQ · Documentation

[!IMPORTANT] Get crowbar from kushvinth/crowbar, crowbar.kushvinth.com, or the crowbar-cli package. A similar repository name or copied README does not make a download official.

A codebase with no CVE index inside it makes people guess. crowbar is the index: it retrieves NVD, CISA KEV, EPSS, SSVC, the CVE List, Exploit-DB, Nuclei, Metasploit, OSV, Debian, MSRC and Apple advisories, and writes them into a local SQLite + FTS5 database you query from your terminal, your CI or your agent. It is offline and reproducible - the same query gives the same answer, no API, no rate limits - so a lookup costs milliseconds instead of a guess.

No web UI, no daemon, no third-party Python packages. Point it at a product and version and it tells you what is actually exploitable, ranks it by real-world risk, and links the proof-of-concept.

crowbar indexes public exploit and PoC data as data. It never clones, compiles, or runs it. Treat anything it surfaces as hostile code and detonate only in a disposable VM. Use it only against systems you own or may test. See DISCLAIMER.md.

Setup finds Claude Code, Codex, Cursor, Gemini CLI and opencode on your machine, shows exactly which configs it will change, and applies them only after you approve. It registers crowbar's MCP server, installs the skill, backs up every config
