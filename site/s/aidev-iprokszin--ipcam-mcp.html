About ipcam-mcp

An MCP server that lets Claude Code, or another MCP client, see through and control the IP cameras on your local network (ONVIF + RTSP): snapshots, video clips, pan/tilt and change detection, all handled locally.

Any ONVIF camera should work. See known cameras for what has been tested.

Once a camera is added, ask in plain words, for example:

- "Take a snapshot of the front door." - "Save this view as door-closed." Later: "Does the front door still look like door-closed?" - "Did anything change at the front door since the last snapshot?" - "Pan the office camera a bit to the left." - "Record 10 seconds from the garage." - "Show me what the garage cameras captured yesterday."

- Linux or WSL2, on the same network as the camera - uv on your PATH (it installs Python 3.13+ and the dependencies for you) - ffmpeg: sudo apt install ffmpeg - An ONVIF-capable IP camera with a local camera account (username and password), with ONVIF and RTSP enabled - Claude Code or another MCP client that supports stdio servers

Pick one. All of them run the ipcam-mcp package from PyPI and need ffmpeg and, except pipx, uv (see Prerequisites).

- Claude Code plugin (recommended for Claude Code): /plugin install ipcam --marketplace aidev-iprokszin/ipcam-mcp

On Claude Code older than 2.1.275, run /plugin marketplace add aidev-iprokszin/ipcam-mcp, then /plugin install ipcam@ipcam-mcp. The plugin runs the server from a lockfile (every dependency pinned with hashes). Update it with claude plugin update ipcam@ipcam-mcp, which also updates the server; a new server version reaches the plugin shortly after
