About qubehub-mcp

QubeHub for Claude: the QubeHub MCP connector

QubeHub is the sales platform for real estate developers: one live record for every unit feeds the CRM, price lists, offers, the agent portal and the developer's website.

The QubeHub MCP connector is a hosted Model Context Protocol server that lets Claude answer questions about a developer's leads, deals, pipeline and unit availability from live QubeHub data, read-only and under each person's own CRM role. A sales manager gets a briefing before a call, a head of sales gets a pipeline review, and anyone on the team can ask what is still available in a building.

- Nothing to install or host. QubeHub runs the Model Context Protocol (MCP) server at https://mcp.qubehub.ai/mcp. On plans that include external AI assistants, a workspace admin turns it on and each user adds it to Claude as a custom connector and signs in. - Works with Claude (web and Desktop), Claude Code and other desktop or command-line MCP clients. See Other MCP clients for requirements. - Safe to connect. Read-only, limited to one workspace, checked against the user's CRM role on every call, logged and revocable. See the security model.

Who it is for: real estate developers and home builders selling condos, townhomes, single-family homes or master-planned communities, including pre-construction (off-plan), directly and through brokers. Any staff member with a CRM role can connect; brokers use the QubeHub agent portal instead.
