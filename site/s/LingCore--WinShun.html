About WinShun

双击 Ctrl，搜遍整台电脑 —— 免费开源的 Windows 文件搜索、快速启动器 Press Ctrl twice, search your whole PC — a free, open-source file search and launcher for Windows

拼音秒搜文件 · 文件内容全文搜索（Word / Excel / PPT / PDF） · 应用和系统设置 · 网页搜索 · 收藏夹 · 插件 “打开 / 另存为”对话框搜索 · 剪贴板历史（代替 Win+V，图片文字也能搜） · 任务栏搜索框（代替 Win+S） · AI 助手 MCP Pinyin file search · full-text search in documents · apps and settings · web search · favorites · plugins · file dialog search · clipboard history with OCR · taskbar search box · MCP server for AI assistants

Win顺 是 Windows 上免费开源的快速搜索启动器：连按两下 Ctrl 弹出搜索框，边打字边出结果。按文件名或拼音秒找文件，搜 Word、Excel、PDF 里的文字，打开应用和系统设置，还有剪贴板历史、对话框搜索、任务栏搜索框、插件和给 AI 用的 MCP 搜索。

它直接读 NTFS 主文件表（MFT）建索引，三百多万个文件几秒建好，增删改名实时跟上，不用装 Everything。不需要账号，不上传数据。界面有简体中文和英文。

- 双击 Ctrl 打开，再按一次或 Esc 关闭；三百多万个文件里搜一次只要几毫秒。 - 拼音和首字母：ndbg → 年度报告，baog → 报告；多音字按常用读音。打错了同音字（年度报高）找不到时，自动按读音再找一遍。 - 搜整台电脑：所有本地磁盘，U 盘可选（没收录的 U 盘插着时，列表末尾会提示你顺手搜一下它）；NAS、内网共享文件夹（SMB） 也能加进来一起搜，服务器关机时收录过的照样能搜到。 - 排序懂你：自己的文件在前，系统目录、nodemodules 在后，名字完全一样的最前。每行显示修改日期，Ctrl+S 在最匹配、最新、最早之间切换。不输入时列出最近打开或最近修改的文件。 - 数字键直达：结果的图标上标着序号，Ctrl+1～Ctrl+9 打开第几行（也可改成 Alt）。 - 按类型找：选中 文件 后，下面一排是文件夹、文档、图片、视频、压缩包等类型，Tab 依次切换；点 + 或在设置里自己加类型。 - 拖出去就能用：结果直接拖进微信、邮件、资源管理器。 - 实时更新：读 USN 变更日志，改名、新建、删除马上搜得到；拔 U 盘不会提示“设备正在使用”。

搜索语法 含义 ------ 报告 2024 每个词都要有（空格分隔，顺序不限）；也可以在所在文件夹的名字里 ndbg、niandubaogao 拼音全拼、首字母，可以混用 "年度 报告" 引号内作为整体 !草稿、!nodemodules\ 排除文件名、排除文件夹 .pdf、报告?.docx 通配符 ext:pdf,docx 只要这些扩展名 项目\readme 在名字含“项目”的文件夹下 tools/out/、D:\My Files\ 路径直达：回车进去，列出里面的内容
