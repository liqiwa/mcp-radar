About better-dot-net

v0.2.1 is here: MCP Events automatic wake & recovery brings services back after the Dot cloud host sleeps, and v0.2.1 retunes the recovery limits from real-world testing — your 9C10G cloud host can now serve persistent public applications.

A tiny self-hosted gateway that runs on a single low-spec Oracle AMD micro VPS (1 GiB RAM, ~17.6 MiB combined RSS across all three Rust cores) and turns a Dot cloud host into a publicly reachable, self-healing backend:

1. Expose Dot cloud hosts publicly, run persistent external services, and auto-recover after sleep via MCP (Advanced, core capability) 2. Includes a standalone web proxy for AI agent cloud browsers (Basic, pure VPS, optional standalone deployment)

Advanced Server, Basic Server, and the static Agent Client are completely decoupled and released independently on GitHub Releases. Upgrading any module preserves credentials and connectivity.

Advanced: Public Exposure, Persistent Services & MCP Auto-Recovery for Dot

Built for Dot (multi-Dot supported) with one goal: keep the VPS invisible to application code, using bdn as unified network infrastructure — use a tiny 1 GiB micro VPS as your public edge while turning a 9C10G Dot cloud host into a persistent, self-healing public server via MCP Events auto-wake.

v0.2.1 long-run record: With the v0.2.1 defaults left running, the Dot cloud host drops roughly every 20 minutes and Dot recovers on its own in about 60 s, giving about 57 minutes of availability per hour, sustained indefinitely.
