About claude-for-everything

A community-maintained list of skills, plugins, MCP servers and rule files for Claude, organised by what you want to do. Each entry says what it is and links to its repo.

Free or freemium only: no paid-only tools. Contributions are welcome, see CONTRIBUTING.md. Install steps are left out on purpose: follow each repo's README.

Caution: entries are not security-audited. Review any skill, plugin or MCP server before installing it, see Security.
