About korea-data-mcp

AI가 한국 공공데이터를 직접 조회할 수 있게 해 주는 원격 MCP 커넥터입니다. 공공조달, 국방조달, 상권, 부동산 실거래, 땅, 공시지가, 기업, 공시, 수출입, 창업지원을 다룹니다.

- 설치가 없습니다. Streamable HTTP 방식의 원격 서버입니다. - 가입도 API 키도 없습니다. 주소만 넣으면 바로 물어볼 수 있습니다. - 읽기 전용입니다. 모든 도구는 조회만 합니다. - 무료로 공개 운영합니다.

이 저장소는 소개 문서만 담고 있습니다. 서버 소스 코드는 없으며, 공공데이터를 재배포하지도 않습니다. 커넥터는 공공기관이 공개한 자료를 정리해 조회하게 해 주는 서비스이고, 답마다 출처를 밝힙니다.

Claude (claude.ai / Claude 데스크톱) 설정 → 커넥터 → 사용자 지정 커넥터 추가 → 이름과 위 주소를 입력합니다. 인증 화면은 없습니다.

ChatGPT 웹(chatgpt.com)에서만 추가할 수 있고, 모바일 앱에서는 추가할 수 없습니다. 아래는 2026년 11월 OpenAI 안내 기준이며, 메뉴 이름은 영문 화면 기준입니다.

1. chatgpt.com/plugins(Plugins)로 갑니다. 2. 더하기(+) 버튼 → Add custom MCP server를 누릅니다. 3. 이름을 적고(설명은 선택), Connection의 서버 주소 칸에 https://datawatongchal.com/mcp 를 넣습니다. 4. 인증은 No authentication을 고릅니다. 5. 안내문을 읽고 I understand and want to continue에 표시한 뒤 Create as a plugin을 누릅니다. 6. 새 대화에서 입력창에 @를 치고 방금 만든 플러그인을 고른 다음 질문합니다.

OpenAI 안내에 따르면 사용자 지정 MCP 서버 연결은 Business·Enterprise·Edu 요금제에서 지원하고(워크스페이스에서는 관리자 권한이 필요할 수 있습니다), Pro는 읽기 전용 도구를 연결할 수 있습니다. 이 커넥터의 도구는 모두 읽기 전용입니다. 요금제와 메뉴는 바뀔 수 있으니 OpenAI 도움말을 함께 확인하세요.

그 밖의 클라이언트 Streamable HTTP 원격 MCP 서버를 지원하는 클라이언트라면 주소만 넣으면 됩니다. 설정 문법은 각 클라이언트 문서를 확인하세요.

도구가 불리지 않으면 커넥터 설정에서 도구 목록을 새로 고친 뒤 새 대화를 시작하세요.

통합 1개와 분야별 10개입니다. 도구 이름의 앞머리가 분야를 나타냅니다.
