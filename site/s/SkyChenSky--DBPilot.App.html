About DBPilot.App

自托管的 SQL Server 诊断系统，对标阿里云 DAS：持续采集性能数据，在浏览器中完成性能趋势、性能洞察、SQL 分析、索引诊断、锁与阻塞、慢日志、执行计划等日常 DBA 工作。

- 单进程部署 —— 一个 .NET 进程 + 一个平台库（SQL Server 自动建库建表），开箱即用 - 广泛兼容 —— 被监控实例支持 SQL Server 2008 ~ 2022 - 极低开销 —— 常规运行对被监控实例 ）， 把输出的哈希写入 app\appsettings.json 的 DBPilot:Auth:PasswordHash 后重启 4. 页面「实例管理」接入被监控实例（地址 + 账号密码，凭据加密存储）→ 连接测试 → 启用 5. 采集自动运行：实时类页面立即可用，历史类数据随运行时间积累

内置只读 MCP Server（/mcp，Streamable HTTP + API Key），把指标 / 慢SQL / 死锁 / 阻塞 / 索引证据以 11 个只读工具交给 AI agent。

常规运行 <1% CPU、零磁盘压力。采集只读 SQL Server 内存里的元数据视图（DMV）和扩展事件文件——不扫业务表、不产生物理 IO、不对用户对象加锁。秒级 DMV 轮询是业界标准做法（SQL Server 自带 systemhealth、阿里云 DAS、AWS Performance Insights 同款路径）。

- 本仓库的 app\appsettings.json 与两个工程（DBPilot.McpConsole / DBPilot.Scenarios）的 appsettings.json 均为脱敏模板，不含任何真实凭据 - DBPilot.McpConsole / DBPilot.Scenarios 的真实凭据放各自目录的 appsettings.Local.json（已被 .gitignore 排除，程序优先读取，模板文件保持占位符不用改） - app\appsettings.json 为标准 ASP.NET 配置：本地填入真实连接串后 git status 会显示已修改——请勿提交，防止凭据外泄 - 被监控实例的连接信息在页面「实例管理」维护，加密存储于平台库，不在配置文件里 - 建议设置环境变量 DBPILOTMASTERKEY（凭据加密密钥），否则重启后需重新登录

现象 处理 ------ 启动告警 平台库结构初始化失败 检查 DBPilot:ConnectionString 与 SQL Server 可达性 打不开 5200 端口 确认 scripts\run.bat 中 ASPNETCOREURLS 端口未被占用 登录后重启就掉线 未设置 DBPILOTMASTERKEY（预期行为） 性能洞察无数据 确认实例已启用且采集正常，采样满 1 分钟后生成 死锁/慢SQL 事件看不到 事件落盘有约 1 分钟缓冲延迟，稍等后刷新 想多进程部署（采集与 Web 分开） 配置 DBPilot:Roles（Web/Collector，默认双开）；只允许一个 Collector 连同一平台库，Web 可多实例

源码与开发指南见源码仓库。本仓库仅分发可运行的发布产物（Release 构建产物 + 脱敏配置 + 启动脚本）。
