MCP 是 AI 客户端（Claude Code / Codex / Cursor / Cline）的扩展协议。 装上去之后 AI 多了 15 个工具可以调用：查方法论、查踩坑记录、规划作战链、检查当前做法是否撞上禁令。

常见误解 实际 :--- :--- 要显卡 / 要跑模型 不需要。里面没有任何 AI 模型，就是词表匹配 要下载几十 GB 1.6 MB，一个 Python 脚本 + 两个 JSON 要联网才能用 装完之后全程离线，只有第一次同步索引需要网络 要 Docker / 数据库 都不要。pip install mcp 就够了 是个能聊天的 AI 不是。它是插件，得配合 Claude Code / Codex / Cursor 用

它是什么：一个 Python 脚本 + 两个 JSON 文件，python install.py 一条命令装完， Windows / macOS / Linux 通用，Python 3.10+ 即可。

适合 不适合 :--- :--- 用 Claude Code / Codex / Cursor 干活的人 只用网页版 ChatGPT 的（网页版装不了插件） 做逆向、渗透、CTF、安全研究 完全不碰这些领域的（装了也用不上） 被 AI「反复犯同一个错」烦过 想要一个能直接对话的 AI（这是插件不是模型） 想给团队沉淀经验的新人 期待开箱即用的成品工具（它给方法论，不给一键脚本）

就这一条。脚本干三件事：装依赖 → 跑自检 → 把该贴进客户端的配置直接打印出来（路径已填好）， 复制粘贴就能用，不用自己拼路径。

Python 3.10+。mcp 1.x 和 2.x 都支持，代码里做了双版本适配。

Windows 把 python 换成 python.exe 的绝对路径，路径分隔符用 / 或转义后的 \\。
