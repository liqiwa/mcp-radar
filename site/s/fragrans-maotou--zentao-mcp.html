About zentao-mcp

基于 Model Context Protocol (MCP) 构建的禅道项目管理工具集服务，采用按领域分层的模块化架构，支持 AI 助手（如 Antigravity、Claude 等）直接通过标准协议调用禅道 API。

本服务用 npx 从 GitHub 拉取并启动，使用前需要本机已安装 Node.js（≥ 18） 和 Git。安装这两个软件、以及拉取本公开仓库，都不需要 GitHub 账号，也不用登录。

1. 打开 https://nodejs.org/，下载 LTS 安装包（Windows 选 .msi）。 2. 一路下一步安装，保持勾选 Add to PATH。 3. 安装完成后重新打开终端或 MCP 客户端，执行：

1. 打开 https://git-scm.com/download/win，下载并安装 Git for Windows。 2. 安装选项保持默认即可（会自动加入 PATH）。 3. 不需要注册或登录 GitHub。本仓库是公开的，npx git+https://... 只是匿名拉取，不会要账号密码。若安装后弹出 GitHub 登录窗口，关掉即可。 4. 重新打开终端后执行：

环境变量说明： - ZENTAOBASE: 禅道访问根地址，例如 http://your-zentao-host/zentao（必填） - ZENTAOACCOUNT: 禅道登录账号（配置后，所有工具均支持自动静默登录） - ZENTAOPASSWORD: 禅道登录密码

保存配置后重启 MCP 客户端。首次启动时 npx 会从 GitHub 拉取仓库并安装依赖，之后走本地缓存。

当前未发布到 npm，所以仓库里会带上编译后的 dist/；改完源码后请先 npm run build，再把生成的 JS 一起提交。仓库更新后，使用方需重启 MCP，或清一次 npx 缓存后再启动。

login (登录获取 Token) - 说明：通过禅道账号与密码登录，自动将获取的 Token 存入当前会话，后续所有接口请求将自动在 Header 中携带 Token: 。 - 参数： - account (string, 必填)：禅道用户名/账号 - password (string, 必填)：密码 - 底层接口：POST {ZENTAOBASE}/api.php/v1/tokens

listproducts (查询产品列表) - 说明：获取当前账号有权限的产品列表与产品 ID，辅助创建或筛选需求时选择 product 参数。 - 参数： - page (number, 可选, 默认 1)：页码 - limit (number, 可选, 默认 20)：每页数量 - 底层接口：GET {ZENTAOBASE}/api.php/v1/products

getproduct (获取产品详情) - 说明：根据产品 ID 获取单个产品的详细信息。 - 参数： - productid (number, 必填)：产品 ID - 底层接口：GET {ZENTAOBASE}/api.php/v1/products/{productid}
