About StarryVT

一键部署，自动生成翻译和字幕 视频 → 中文字幕 → 中文配音 → 成片，全程在本机完成，视频不上传

星译是一款免费、功能完整的 Windows 本地视频翻译工具。导入一个视频文件、选择整个文件夹，或粘贴一条 YouTube / B 站链接，它会自动完成语音识别、AI 翻译、中文字幕生成、配音合成与字幕压制，一键生成可以直接发布的视频成片。

视频不上传。 识别、翻译、配音、压制全部在你本机完成；翻译和配音只调用你自己申请的 API Key，不经过作者的服务器，作者看不到你的视频，也看不到你的成品。

- 🎬 一键生成翻译和字幕：自动完成语音识别、AI 翻译、中文字幕生成、中文配音与字幕压制，一次完成。 - 🎨 字幕样式可调：字体、字号、字间距、描边、颜色、底部距离都能改，设置页里实时预览，点预览图可放大。 - 🔒 本地运行，保护隐私：视频处理在本机完成，不上传至作者服务器。翻译与配音通过你自己的 API Key 调用服务。 - 🎙️ AI 配音与音色替换：为外语视频生成中文配音，也可为中文视频重新合成配音。 - 📝 字幕检查与编辑：翻译完成后暂停，双语对照检查译文，改完再继续配音和压制（默认关闭，可在设置里开启）。 - 🌏 多语言支持：支持英语、日语、韩语、俄语、德语等语言的视频翻译。 - 📦 批量处理：支持整个文件夹及子文件夹批量处理，单个任务失败不影响其他任务。 - 🔗 链接直接导入：支持 YouTube / B 站视频链接，自动获取视频信息并进行处理。 - 🤖 AI Agent 接入：通过 MCP 让 Claude Code / DeepSeek Harness / Codex / WorkBuddy / Cursor / Trae / 豆包工作 直接启动翻译、查询进度、取消任务（安装包 6.0 起内置）。 - 🆓 免费且功能完整：不锁定功能、不添加水印、不限制处理次数。
