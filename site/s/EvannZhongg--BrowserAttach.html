About BrowserAttach

Drive the Chrome / Edge tabs you already have open and already signed in from an MCP client. BrowserAttach connects to the browser through a locally paired extension, keeps your existing sign-in state, and needs neither a remote debugging port nor a separate automation browser.

npm · Usage guide · Architecture · Agent integration · Test report · Issues · Contributing

- Discover multiple browser profiles, pick one precisely, claim a tab exclusively, and release it when done. - Read the accessibility tree, field values and supported editor models; click, replace-fill and type character by character through current snapshot refs or strict CSS/XPath locators. - Native pointer hover, stepped drags and conditional waits; select HTML options without opening a native popup. - Navigate and go back/forward, open or close tabs, handle JavaScript dialogs, upload local files, and capture the whole page or a single element. - Evaluate JavaScript expressions in the main page; read console, page-error and network lifecycle logs captured after claiming; opt in to bounded, redacted request/response details when XHR/fetch needs verification. - Standard stdio MCP with 22 tools. The Hub listens on loopback only and pairs with the extension through a random key.

- Node.js 22 or newer, plus npm. - Chrome / Edge 125 or newer with permission to load unpacked extensions. Latest stable is recommended. - An MCP client that speaks stdio MCP and can find Node/npm on PATH.
