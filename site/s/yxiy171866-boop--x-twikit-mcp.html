About x-twikit-mcp

本项目是基于 twikit 实现的 Model Context Protocol (MCP) 服务，专门为 AI 助手、大语言模型及各类 AI Agent 提供与 X (Twitter) 交互的能力。通过本服务，AI 能够自主调用工具完成状态感知、发推（含图片）、读写评论、收发私信、关注互动、趋势发现以及重点账号追踪等全流程操作。

服务通过普通账号的浏览器 Cookie（authtoken 与 ct0）与 X 官方 Web 端通信。所有工具统一采用结构化 JSON 响应，确保状态判定与字段解析的稳定性。

工具名称 功能描述 参数 :--- :--- :--- posttweet 发布新推文（支持带本地图片/媒体） text（推文文字）, mediapaths（可选，图片文件路径或路径列表） replytweet 回复指定推文或评论（支持带图片） tweetid（目标推文 ID）, text（回复文字）, mediapaths（可选） quotetweet 引用转发推文（Quote Tweet） tweetid（目标推文 ID）, text（评论文字）, mediapaths（可选） deletetweet 删除自己发布的推文 tweetid（推文 ID） favoritetweet 点赞指定推文 tweetid（推文 ID） unfavoritetweet 取消对推文的点赞 tweetid（推文 ID） retweet 转发/转推指定推文 tweetid（推文 ID） unretweet 取消对推文的转推 tweetid（原推文 ID） bookmarktweet 收藏指定推文到书签 tweetid（推文 ID） unbookmarktweet 从书签中移除指定推文 tweetid（推文 ID） getbookmarks 查看当前账号保存的书签推文列表 count（获取数量，默认 10，最大 40）

工具名称 功能描述 参数 :--- :--- :--- gettweetbyid 获取单条推文详情与全面统计（点赞、收藏、转推、回复、浏览量） tweetid（推文 ID） gettweetreplies 获取指定推文下方的评论与回复列表（定制 GraphQL 线程解析） tweetid（推文 ID）, count（获取数量，默认 10，最大 50） gettweetquotes 获取引用转发该推文的推文列表 tweetid（推文 ID）, count（获取数量，默认 10，最大 20） searchtweets 高级推文搜索（支持关键词、作者、时间范围及互动量门槛） query（关键词）, count（默认 10）, fromuser（可选作者）, sincedate（起始日期 YYYY-MM-DD）, untildate（截止日期）, minfaves（最低点赞数）, minretweets（最低转推数）, minreplies（最低回复数）
