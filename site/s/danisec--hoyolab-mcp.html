About hoyolab-mcp

HoYoLAB Genshin Battle Chronicle — MCP server

Read-only access to a Genshin Impact Battle Chronicle, exposed as MCP tools so a model can answer questions like "what are my Abyss stars this rotation?" or "which regions am I least finished with?".

Genshin Impact only — Star Rail, ZZZ and Honkai Impact 3rd are named by listgameaccounts but have no tools here.

Works with Open WebUI, Claude Code, Codex, and opencode.

[!WARNING] Unofficial. This project is not affiliated with, endorsed by, or supported by HoYoverse. It calls the same internal web endpoints the Battle Chronicle page uses. Those endpoints are undocumented and can change or be restricted at any time.

Handle credentials carefully. Access requires HoYoLAB session cookies, which are equivalent to being logged into the account — not a read-only token. Use a secondary account if you are unsure, and be aware that using unofficial clients may conflict with HoYoverse's Terms of Service. You accept that risk by using this software.

- Why this exists - Requirements - Quick start - Authentication: cookies, not OAuth - Tools - Failure modes are specific - Installation - Configuration - Connecting a client - Usage - Upgrading - Removing your data - Troubleshooting - Security - Limitations - Tests - Contributing - Credits and attribution - Licence

The page at act.hoyolab.com/app/community-game-records-sea/ is a web app, not an API. To let a model read that data it has to be turned into tools, which is what this server does: it calls the same endpoints the page calls and returns condensed JSON.
