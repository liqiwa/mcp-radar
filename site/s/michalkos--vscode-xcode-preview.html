About vscode-xcode-preview

SwiftUI previews in VS Code, rendered by Xcode itself.

Xcode 27 can run headless and exposes its tools over MCP, including RenderPreview. This extension asks it to render the Preview (or PreviewProvider) in your current Swift file and shows the image beside your editor. It re-renders when you save. Because Xcode does the rendering, the result matches Xcode's canvas, and the Xcode window never needs to be open.

- A ▶ Preview link above each Preview and PreviewProvider that opens that preview. - A tab for each preview in the file. Double-click a tab to jump to its code. - Re-renders when you save any Swift file in the workspace. - Pick the device, language, color scheme, Dynamic Type size, orientation and the other variants Xcode offers for the preview. - Interactive mode on simulators: the preview runs live for a moment before the snapshot, so content loaded in .task or onAppear and finished animations show up. - Supports Preview(arguments:) items and widget timelines. - Shows build errors as short File.swift:12: message lines, with the full log in the Xcode Preview output. - Export the rendered preview as a PNG, for PR descriptions, docs or App Store drafts. - Open in Xcode jumps to the selected preview in Xcode, when you want its live, interactive canvas. - Follows the active Swift editor.
