About santi

santi is a free, open-source agile tracker you host yourself. Teams plan work on Scrum or Kanban boards, groom a backlog, run sprints and track epics, all from a fast web UI backed by a documented JSON API. The server is written in Rust (axum, PostgreSQL), the UI in React, and the whole thing ships as one container image. No per-seat pricing, no telemetry.

Status: 0.1.0, the first release. It runs well on one machine for a team; public hosting needs HTTPS in front of it (see Running on another host). The HTTP API may still change before 1.0.

Backlog with the epic panel Issue dialog ------

- Boards: Scrum boards show the running sprint; Kanban boards show the flow and hide done work after a set number of days. Columns hold one or more statuses, take WIP limits, and cards move by drag and drop or by a keyboard "Move to…" menu. - Backlog and sprints: plan sprints by dragging issues between sections, edit rows in place, start and complete sprints; open work at completion goes to the backlog, a future sprint or a new one. - Issues: epics, stories, tasks, bugs and subtasks with status, assignee, priority, points, labels, parent, comments and a full issue page; delete for admins and the reporter. - Epics: a panel on the backlog to create epics, assign issues to them and filter by them. - Filters and search: assignee, "only my issues", recently updated, type, label, epic and text, all kept in the URL; a project search page and a search field in the top bar. - Keyboard: c creates an issue, j/k move between issues, o opens one, g b / g l jump to the board or backlog, ? lists the r
