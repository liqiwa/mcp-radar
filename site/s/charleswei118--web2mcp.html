About web2mcp

Turn any website or REST API into MCP tools — one tiny Cloudflare Worker, zero dependencies.

GitHub's 665 REST endpoints → 2 MCP tools, ~147,000 tokens of tool definitions → ~300 (catalog mode)

Every AI agent (Claude, ChatGPT, Cursor, your own bots…) now speaks the Model Context Protocol. But most websites and apps don't. web2mcp is the glue: describe an HTTP API in a few lines of config and it instantly becomes an MCP tool that any agent can call — hosted for free on Cloudflare's edge.

A public demo is running at https://web2mcp.cwei59969.workers.dev (tool list) with the MCP endpoint at:

Paste it into any client that supports remote MCP servers, or:

The demo is rate-limited by the free plan and has readerread disabled. Deploy your own for real use.

- Config, not code. A connector is a plain object: base URL, path, query, params. No SDK to learn. - Zero runtime dependencies. ~500 lines of readable JavaScript. Audit it in 10 minutes. - Token-friendly output. pick and fields trim giant JSON responses down to what the model needs. - Free hosting. Runs on the Cloudflare Workers free plan. Deploy in one click. - Safe by default. Requests are locked to each connector's host, arguments are type-checked, secrets stay server-side, optional bearer auth. - OpenAPI import. Convert any OpenAPI 3 spec into a connector with one command.
