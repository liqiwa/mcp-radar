About forge3d

A 3D-model toolchain any AI agent can drive. One MCP server, one agent skill, six interchangeable geometry engines, a validation layer that knows what "correct" means for print vs web vs game, and a Three.js viewer that turns a mesh into a single HTML file you can send to anyone.

Most "AI makes 3D" demos stop at a pretty mesh in a viewport. The hard parts are everything after: is it watertight, is it the right size in millimetres, will it survive a 60k-triangle budget, can the next agent pick up where this one left off without re-reading a megabyte of vertices. forge3d is built around those.

The whole flow, rendered by forge3d itself — createshape → validatemodel → makeviewer. Every frame comes from the library's own CPU renderer, so the GIF cannot show anything the code does not produce.

forge3d demo needs no Blender, no OpenSCAD, no API key and no network. It builds a shape from an equation, validates it, renders previews and writes a self-contained viewer page, then prints every path. Everything else in this README is optional on top of that.

Nothing in that image is stock: the geometry came from examples/proceduralchair.py and the render from forge3d.render — the same loop an agent runs. Open examples/chair.html for the interactive version.
