About fanqie-mcp

这是一个自行部署的番茄作者平台 MCP 服务。服务在本机运行，Codex、Claude Code 等 Agent Host 通过 HTTP 调用它；你在客户端用自然语言提出需求即可。服务也提供 REST API，供程序接入。

这是独立开发的早期项目，与番茄官方无隶属关系。当前版本以查询为主，写操作默认关闭。

- “列出番茄作家课堂的写作技巧课程，选一篇读给我。” - “确认当前登录的番茄账号是谁，再列出我的短故事作品。” - “查看我的作品经营数据，说明统计口径和数据截止时间。” - “读取这部作品的章节目录和草稿。” - “查看上一次保存的账号数据，不重新访问平台。”

能力 是否需要番茄登录 当前范围 ------------------------------ ---------------- ---------------------------------------------- 作家课堂目录与文章 否 五个分类、文章文字和图片链接；不转写视频或图片 官方活动 否 平台公开活动资料 本人短故事、长篇作品及经营指标 是 全分页读取、完整性检查、历史快照 本人章节目录与草稿 是 当前账号可访问的管理目录及草稿箱 本人章节、短故事正文 是 作者当前编辑版本；不证明与已发布正文一致 已保存数据与任务结果 有本地数据即可 明确标记为历史，不伪装实时数据 草稿维护、投稿与发布 是，且需独立能力 已有适配代码；默认关闭，真实投稿闭环尚未验证

查询能力已有真实平台读取记录，平台页面和接口变化后仍可能失效。部署后以 fanqiegetcapabilities 和本次任务结果为准；工具出现在列表里不等于当前一定可用。

推荐 Docker Compose。需要 Git、Node.js 22.13+、Yarn 1.22.22 和支持 Linux 容器的 Docker。

首次构建会下载依赖和浏览器镜像、准备固定测试资料并运行检查，可能需要数分钟。源码仓库的公开发行状态以 Release 为准。也可按固定版本镜像安装直接启动，无需本机 Node/Yarn；可用架构和固定 digest 以版本发行说明为准。

健康检查应返回 status: "ok"。接下来在 Agent Host 中连接：

配置项 值 -------------------- ------------------------------------ 传输 Streamable HTTP MCP 地址 http://127.0.0.1:18062/mcp 鉴权 Authorization: Bearer Token 所在文件 .secrets/api-token 建议单次工具等待时间 至少 135 秒

完整步骤看快速开始，客户端配置看接入教程。 服务 Token 只用于连接本服务；番茄账号登录通过本人扫码完成，两者是不同操作。

第一次使用可以照着完整演示完成连接 → 公开课程 → 扫码与身份核验 → 本人作品 → 历史读取；日常查询直接复制五份提示词。示例结果均使用合成数据。

登录了为什么显示 unknown？ 服务重启后，还没有实际检查登录时也会显示 unknown。让 Agent 调用 fanqiecheckloginstatus：它会访问平台核验，并返回账号昵称、ID 和检查时间。unknown 本身不代表已经退出登录。
