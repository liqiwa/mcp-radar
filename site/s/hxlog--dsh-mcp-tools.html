About dsh-mcp-tools

DeepSeek Harness 简洁、优雅的 MCP 工具管理器。 类 Cursor 风格的全局 MCP 控制：自由添加、停用、删除 MCP 接口与工具，适合 MCP 测试、按需请求、拓展上下文等场景。

一站式管理用户的 MCP Server，按需开关 MCP Tools。被停用的 MCP 工具不会注册进模型，既不占上下文，也无法被误调用。

能力 说明 --- --- 服务器管理 两种传输：streamable-http（URL + 请求头）与 stdio（命令 / 参数 / 环境变量 / 工作目录）；分字段填写，或直接粘贴 {"mcpServers": { ... }} 一次导入多个。 像 Postman 一样填密钥 请求头是键值对行而不是 JSON 文本框，默认带一行 x-mcp-key；值默认掩码、可逐行显示；名称重复就地报错。 真正的逐工具控制 每个工具是一个 chip，点击即从模型工具列表消失（不是注册了再报错）；支持搜索 / 全选 / 反选 / 全部停用，悬停查看完整描述。 连通性测试与事件日志 临时建连 initialize → tools/list → 关闭，回报耗时 / 协议版本 / 工具数，不影响运行中的服务器；「最近事件」记录连接、重载、测试与失败。 服务器开关与配置复制 关闭服务器即断开并注销其全部工具（不删配置）；一键复制该服务器的 mcpServers 片段。 与 DSH 原生一致 沿用 --dsw- 设计 token、平铺行与 32px 输入框，深浅色 / 中英文自适应；客户端是 classic script，无构建步骤。

需要 DeepSeek Harness 0.2.x（Web GUI dsh web 或 DSH Desktop）与 Node.js ≥ 22.13，包已发布到 npm：dsh-mcp-tools。

⚠️ 这是 DeepSeek Harness 插件，不是普通 npm 依赖库：npm i dsh-mcp-tools 只会下载包，运行时仍需装进 DSH profile。

1. 打开 DSH Web（或 DSH Desktop）→ 侧边栏 插件（Desktop 在 设置 → 插件）。 2. 点击安装，填入 dsh-mcp-tools，确认。 3. 启用新 bundle，刷新页面，打开 设置 → MCP。

1. 设置 → MCP → 添加服务器：远程服务器填 URL，把密钥粘贴进请求头行（默认 x-mcp-key）。 2. 点 测试连接，看到类似 已连接 · 95 个工具 · 478 ms 后保存，并打开服务器开关。 3. 在会话中直接让模型调用工具，DSH 会注册为 mcp；用不到的工具展开列表停用即可，启用的工具越少，每次请求里的 tool schema 越小。

- 启停生效于注册时而非调用时：停用的工具根本不出现在模型工具列表里。 - 状态存于 ~/.dsh/dsh-mcp-tools/state.json，原子写入；外部修改会被监听并热应用。 - REST 接口：GET /mcp-tools/api/state、POST /servers/{test,save,delete,toggle,refresh}、POST /tools/{toggle,bulk}、POST /import、POST /reload、GET /logs；详见 docs/API.md。
