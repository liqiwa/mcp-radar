About rev-core

Autonomous Reverse Engineering Engine & Model Context Protocol (MCP) Server in Systems Rust

Reverse engineer anything with agents, from app behavior down to native binaries. A lightweight, zero-dependency, memory-safe native CLI and Model Context Protocol server that gives AI coding agents (Claude Code, Hermes Agent, Cursor, Codex) deep analytical capabilities over closed binaries, desktop packages, and live memory.

Traditional reverse-engineering integrations rely on slow, multi-gigabyte runtime environments (Node.js wrappers, JVM-based Ghidra installations, or Python scripts). rev-core changes this paradigm by delivering an ultra-fast, zero-overhead systems engine in pure Rust:

1. Sub-Millisecond Agent Latency (7.2 score). Cryptographic Constant Matcher: Pattern-matches hardware and software crypto constants: - AES forward & inverted Rijndael S-Boxes - ChaCha20 quarter-round state ("expand 32-byte k") - SHA-256 round constant sequence ($K0..K3$) - MD5 state buffer initialization words ($A, B, C, D$)

4. Pure-Rust Electron & ASAR Unpacker Zero Node/npm runtime dependency Chromium Pickle and ASAR archive reader. Scans extracted Electron applications for IPC channels (ipcRenderer.send, ipcRenderer.invoke, ipcMain.handle, contextBridge.exposeInMainWorld). Audits webPreferences vulnerability risks (nodeIntegration: true, contextIsolation: false, webSecurity: false).
