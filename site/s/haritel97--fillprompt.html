About fillprompt

Free, ready-to-copy AI prompts for images, video and text, each with a sample result. Pick one, fill in the blanks, paste it into ChatGPT, Gemini, Claude or your video model. No account, no ads, no paywall.

Website · MCP server · Image prompts · Video prompts · Text prompts · Agent skills

Count Written for ------:--- Image prompts 5,002 Nano Banana, Nano Banana Pro, GPT Image, GPT Image 1.5, GPT Image 2, Seedream 4.5 and any image model Video prompts 933 Seedance, Seedance 2.0 and 2.5, Gemini Omni, MiniMax Hailuo 3, Grok Imagine Text prompts 3,657 ChatGPT, Claude, Gemini, any model (roles, system prompts, agents) Agent skills 67 Claude Code and other agents (links to their own repositories)

- Sample results. Image and video prompts show the output they produced, loaded from the original collection. - Fill in the blanks. Placeholders such as [OBJECT] or {argument name="subject"} become input fields, and the copy button gives the finished prompt. - Credit on every prompt. Each one names the collection it came from and its license, and its author and original post wherever the collection records them. - Built for agents too. A free MCP server and a Claude Code plugin let your AI assistant search the library and fill a prompt in for you. - Fast and light. A static site of about 10,000 pages, with a sitemap per content type and llms.txt for AI search.

fillprompt runs a free, read-only remote MCP server, so Claude, Cursor, VS Code, ChatGPT and other MCP clients can search every prompt and fill one in for you. No account or API key.
