About Amber

Your agent figured the workflow out once. Stop paying for it every run.

An open implementation of FlashScript (USC & Microsoft, 2026), with the operating loop around it.

Record Claude Code doing a task a few times. Amber compiles the recordings into a readable Python program that does the same job on the next input: plain code for the mechanical steps, one small llm() call where judgment is needed, replay tests generated from the recordings, and guards that stop the run when the world changes. When it breaks, the agent takes over from the failed step and Amber recompiles.

A real session on the weekly-report example, replayed with long waits shortened: compile three agent recordings, run on a week nobody recorded, rename a field in the shop API, watch the guard stop the run, the doctor recommend a fallback, the agent resume from the failed step, and the recompiled v2 verify 4/4.
