About carryon

Take your AI memory with you. Switch between ChatGPT, Claude and Gemini subscriptions without losing years of conversations: Carry-On imports the official data exports of all three into one searchable archive on your own hardware, and serves it over MCP so whichever assistant you use today can search what you discussed with the others.

Runs as a Home Assistant add-on or a plain Docker container (aarch64 / amd64), with optional built-in Tailscale Funnel so claude.ai and chatgpt.com can reach it without a domain or port forwarding.

Features - Official exports only — no browser extension, no scraping, no session cookies. Drop the export zip into a folder; re-export any time, imports are incremental. - Faithful parsing — keeps only the branch you actually ended on (edits/regenerations dropped), voice-chat transcripts, attachment text, Gemini Canvas code; merges Gemini Takeout across exports since Google deletes activity after 18 months. - CJK-friendly search — SQLite FTS5 with a trigram tokenizer: Chinese/Japanese work without word segmentation. - Works with web connectors — streamable HTTP; tools follow the ChatGPT connector search/fetch convention and also work in Claude custom connectors and any MCP client. - Small — ~1400 ChatGPT + ~900 Gemini conversations ≈ 130 MB database, ~220 MB RAM.

Or add https://github.com/shenyinzhe/carryon as a repository in the add-on store, then install Carry-On. A prebuilt image is pulled, so installing takes seconds. See carryon/DOCS.md for configuration, importing and connecting.
