About antigravity-conversation-renamer-mcp

一个面向 Google Antigravity 的轻量级 TypeScript / Node.js Stdio MCP Server。

在 Antigravity 中开启对话时，初始标题往往由第一条消息自动生成；随着讨论逐步展开，实际任务很容易偏离最初的标题。通过本 MCP，Antigravity 可以在话题明显转向、输入 /rename 或收到你的指令时，免辅助功能权限、无需重启客户端，自动无损地重命名当前或历史对话标题，并实时反映在界面与检索中。

如果你只想要 /rename 手动改名，不希望 AI 在话题偏离时自动改名，可以把上面那句话改成：...安装配置（加上 --no-rule，仅启用手动和 /rename）。

致正在阅读本文档的 AI Agent（Antigravity / Claude Code / Codex 等）：请严格按以下幂等步骤为用户完成安装，不要将本仓库克隆到用户当前的业务项目目录中，也不要覆盖用户原有的 mcpconfig.json 其他配置。

前置条件 - 需要 Node.js = 22.5.0（用于内置 node:sqlite，零原生编译依赖）。 - 在非交互 Shell 中（尤其是 macOS 使用 nvm / fnm / volta / Homebrew 的环境），请先探测并加入常见 Node 路径，确认 node -v 满足 = 22.5.0；若不满足，请暂停并告知用户先安装或切换到 Node.js 22.5+（推荐 Node 22 LTS 或 24+）。

1. 固定安装目录：使用 ~/.local/share/antigravity-conversation-renamer-mcp（若目录已存在则 git pull --ff-only，避免污染用户当前工作区）。 2. 安装依赖、跑沙盒测试并自动写入配置：直接运行 npm install && npm run setup。 - scripts/setup.mjs 会自动完成： - 校验 Node 版本 = 22.5.0； - 编译 TypeScript 并运行全部单元测试与沙盒 Stdio MCP 端到端测试； - 自动使用当前 node 绝对路径（process.execPath）增量合并写入 ~/.gemini/config/mcpconfig.json 中的 mcpServers["conversation-renamer"]，保留用户所有原有 MCP 配置； - 部署混合模式自动触发规则到 ~/.gemini/config/rules/conversation-auto-rename.md（若用户要求关闭自动触发则加 -- --no-rule）； - 部署 /rename 斜杠命令 Skill 到 ~/.gemini/config/skills/rename/SKILL.md（若不需要则加 -- --no-skill）。

安装后提示用户 执行成功后，向用户报告： 1. 安装目录、node 绝对路径以及写入的配置文件路径； 2. 提醒用户重启 Antigravity（或在 Additional Options ... → MCP Servers 中刷新）使配置生效； 3. 生效后可直接在对话框输入 /rename 或“根据内容更新当前对话标题”进行测试。

- 实时生效且防覆写：优先原子写入 ~/.gemini/antigravity/annotations/.pbtxt（Antigravity languageserver 运行期事实源），再同步更新 SQLite 与缓存，避免被内存中的旧标题覆盖。 - 零原生编译依赖：基于 Node.js 22.5+ 内置 node:sqlite（开启 readBigInts: true 无损保留
