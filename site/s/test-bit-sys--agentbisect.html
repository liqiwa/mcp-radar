About agentbisect

Git Bisect & Time-Travel Debugging for Autonomous AI Coding Agents. Stop restarting 40-step agent sessions from scratch. Pinpoint, diff, and fork the exact step where your agent broke the codebase.

💥 The Problem: "Compounding Agent Drift"

When you ask an autonomous coding agent (Claude Code, Cursor Agent, Google Antigravity, Devin, Cline, or Aider) to implement a multi-file feature or perform a large refactor, it executes 20 to 50 sequential steps (tool calls, file edits, bash commands).

Inevitably: 1. At Step 12, the agent makes a subtle semantic error (e.g., inverts an authorization check or changes a function signature). 2. Steps 13 to 40 turn into compounding hallucinations, writing broken patches on top of invalid assumptions. 3. At the end of the session, the test suite is completely broken.

Today, developers face a frustrating dilemma: - Guess manually by reading through a 2,000-line JSON transcript. - Or run git checkout . — wasting 40,000+ API tokens, $1.50+ in costs, and 30 minutes of waiting.

AgentBisect brings deterministic binary search and time-travel trajectory debugging to AI coding agents:

1. Non-Polluting Shadow Git Ledger: Automatically snapshots workspace checkpoints inside .agentbisect/shadowgit/ without polluting your real .git log or creating unwanted branches. 2. Binary Search Trajectory Engine (agentbisect find): Locates the exact first broken step in $\mathcal{O}(\log2 N)$ test executions (just 5 test runs for 32 steps). 3.
