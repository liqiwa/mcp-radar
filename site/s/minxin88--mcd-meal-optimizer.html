About mcd-meal-optimizer

一个跑在 WorkBuddy 上的开源 Skill：通过 麦当劳 MCP 获取菜单、营养和优惠券，再由本地 Python 引擎按预算、热量和蛋白质约束筛选候选套餐。真实方案需通过 MCP 核价。

只用 Python 标准库，无需 pip install。 下载仓库后，离线演示不需要联网、WorkBuddy 或麦当劳账号。

内置示例包含 29 个餐品、5 张优惠券，默认约束为预算 ≤ ¥45、热量 ≤ 1100 kcal、蛋白质 ≥ 35 g，可得到 1554 套满足约束的组合。这是示例数据，不是当前门店报价。

输出按三种目标排序：价格最低、营养目标匹配、每元蛋白质量。本地求解不调用大模型；理解需求和解释结果的模型交互另计。

English: A WorkBuddy skill combining McDonald's China MCP data with a local Python meal optimizer. Try the offline demo above with Python 3.9+: no MCP token or third-party Python packages required. Live integration setup is below.

优惠券是否划算取决于订单构成；同时考虑预算、热量和蛋白质时，手工比较容易遗漏。本项目把自然语言交互交给模型，把候选组合计算交给可检查的脚本。

当前边界：在代码设定的候选组合与已实现券规则内求解，为每个方案选择一张券；不支持任意数量、同款重复购买或任意叠券的全局穷举。门店、时段和账号优惠会影响真实结果，最终以下单前核价为准。

- 健身 / 控糖人群：想点麦当劳，但要卡热量和蛋白质。 - 上班族午休：预算固定，想在预算内吃到最划算的一餐。 - 多人拼单：两三个人一起吃，要凑券又不想浪费。 - 纯省钱党：手里攒了一堆券，想知道哪张该在哪单用。
