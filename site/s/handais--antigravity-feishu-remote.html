About antigravity-feishu-remote

简体中文 English Documentation (READMEEN.md) 更新日志 (CHANGELOG.md)

Remotely control your local Antigravity CLI/IDE from Feishu or Lark over WebSocket long connection (no public IP required), with CardKit 2.0 streaming, MCP push & cloud doc tools, and desktop completion handoff hooks. All secrets stay isolated outside the plugin folder (~/.config/antigravity-feishu/, mode 0600).

通过飞书 WebSocket 长连接，让你在手机（安卓 / iOS）飞书里直接向本机 Antigravity 发任务、实时看流式卡片进度、继续多轮上下文，并支持本地目录切换、模型/权限模式切换、MCP 主动推送和任务完成通知。

免公网 IP / 免内网穿透 / 分享不泄密 个人 App Secret 和授权用户白名单统一保存在本机 ~/.config/antigravity-feishu/config.json（Windows 为 %USERPROFILE%\.config\antigravity-feishu\config.json，0600 权限），插件目录内不含任何个人密钥，打包即可分享给朋友。

[!NOTE] 平台实测说明 - macOS（主力验证）：作者日常开发环境，已完整实机跑通长连接、launchd 开机常驻、/desktop 接管与离开感应。 - Linux / 原生 Windows（实验性支持）：已完成跨平台代码适配并通过 GitHub Actions 三平台 CI（ubuntu-latest / windows-latest / macos-latest）自动化冒烟测试，但作者暂未在真实 Linux / Windows 机器上做过完整端到端实测；遇到平台兼容问题欢迎附上 cli.mjs status / cli.mjs logs 提 Issue 或 PR。

如果你正在使用 Antigravity / Claude Code / OpenClaw 等具备终端能力的 AI 助手，不需要自己手动敲命令，直接把仓库链接交给它即可完成本地部署（提示：部署代理可以是 Claude Code / OpenClaw 等任意终端 AI，但运行时远程控制依赖本机已安装并登录 Antigravity CLI (agy)）。
