About webegg

WebEgg 是一个 Wails + Go + React + Manifest V3 的本地 AI 控制面。它通过浏览器插件驱动 Gemini 网页端，在本地执行真实的文件、目录、搜索、Git、Shell 和后台进程工具，并把对话与工具结果全部渲染在桌面端。

不注入 Gemini 页面 UI，不依赖第三方 API Key。浏览器只是网页 AI 传输适配器，聊天与项目数据留在本机。

- 本地 AI 聊天工作区：每个项目独立会话，支持多会话、归档、复活和本地历史。 - 自动浏览器控制：新建会话后自动创建 Gemini 网页对话并注入工具优先协议。 - 26 项真实编程工具：文件、目录、搜索、Git、Shell、后台进程和项目脚本。 - 全自动 / 需批准：读取自动，写入、删除、Shell 和进程可按策略请求本地批准。 - 结构化工具结果：Markdown、代码块、文件内容、目录表格、终端输出和 Git diff。 - 真实数据可视化：最近 7 天消息/工具调用趋势与工具能力分布。 - 可靠重连：扩展 alarms 保活、标签页唤醒、内容脚本自动重注入和任务租约恢复。 - 极简黑白主题：桌面、插件设置弹窗共享日间/夜间主题。

- Windows 10/11 x64 - Chrome、Edge 或其他 Chromium 浏览器 - 一个可以正常登录的 Gemini 网页账号

建议保持 Gemini 标签页打开。可以切到后台或最小化浏览器，但不要关闭网页。

- 推荐：WebEgg-windows-amd64.zip - 或单文件：WebEgg.exe

解压后运行 WebEgg.exe。如果 Windows SmartScreen 提示未知发布者，请确认文件来自本仓库 Release 后选择继续运行。

1. 打开 chrome://extensions/（Edge 为 edge://extensions/）。 2. 开启右上角「开发者模式」。 3. 点击「加载已解压的扩展程序」。 4. 选择 Release 包中的 extension 目录，或源码仓库的 extension/ 目录。 5. 将 WebEgg Monochrome 固定到浏览器工具栏。

1. 在 WebEgg 桌面端打开「项目」。 2. 点击「添加项目」，选择一个本地代码目录。 3. 项目会以目录授权方式登记，不会自动修改文件。 4. 根据信任程度选择： - 需批准：写入、删除、Shell、后台进程需桌面确认。 - 全自动：工具自动执行，适合完全信任的项目。

1. 打开「连接」。 2. 点击「生成令牌」。 3. 立即复制 we... 令牌。明文只显示一次。 4. 打开浏览器中的 WebEgg 扩展弹窗。 5. 填写： - MCP 地址：http://127.0.0.1:8787/mcp - 连接令牌：刚才生成的 we... 6. 点击「保存并检测连接」。 7. 打开 Gemini 页面并刷新一次。

1. 回到桌面端默认的「对话」工作区。 2. 在顶部选择项目和会话。 3. 点击 + 新建会话。 4. WebEgg 会自动： - 新建本地会话 - 驱动 Gemini 新建网页对话 - 注入工具协议 - 执行项目环境初始化 5. 看到「适配器在线」后，在底部输入任务。

- 参数和结果默认收束。 - 点击卡片标题展开。 - 文件读取显示路径、行数和哈希。 - 命令显示退出码、stdout、stderr 和耗时。 - 目录显示条目表格。 - 可使用「渲染 / 原文」切换结构化展示与原始 JSON。
