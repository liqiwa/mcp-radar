About GalCraft

获取 Studio · 试玩样例 · 教学样例 · 产品手册 · English

GalCraft 将创作工作台、制作工具和独立 Player 组织在同一作品中。创作者围绕剧情、舞台、页面与素材工作，审阅修改、保存内容，再构建发行物。

- 编写剧情与分支，在写作、演出和源码视图中编辑同一场景。 - 编排人物、背景、镜头、转场与可复用动画。 - 定制页面、菜单、阅读布局和 Player 的呈现。 - 导入并管理素材，保留稳定身份与明确版本。 - 比较制作候选，将选定成果采用为普通作品编辑。 - 制作角色配音，逐句管理正文、语言、音色输入与试听。 - 与外部 MCP 助手协作，操作同一作品与编辑事务。 - 从场景或当前语句试玩，构建独立发行物。

创作者从0.1.0 Release下载 Windows x64 安装器；这是推荐入口。Node 用户执行 npx --yes --package=@galcraft/studio@0.1.0 galcraft-studio 启动浏览器工作台。示例页面提供《今晚，让春天亮起来》试玩与教学包下载。

npm 入口首次执行时从本次 Release 自动安装完整应用到用户版本缓存，需要访问 GitHub 与 npm，下载约 326 MiB 及运行依赖；后续启动复用安装。发行说明分别标明轻量入口与完整应用的源码标签。

取得教学 .galproject 备份后，在 Studio 中恢复为独立副本，检查精确依赖，修改一句对白，保存并从此句试玩。持续维护的步骤见第一个作品。作者也可以从“标准”模板新建练习作品。

源码归档包含开发输入；Studio 安装器运行编辑器；独立准备的 npm 应用提供本机服务与浏览器界面；教学备份用于恢复可编辑作品。各产物在相应发行入口分别说明用途。

连续写作。作者在场景树、对白与说话者之间保持上下文。基本操作 安排阅读体验。作者对照作品画布编辑页面、组件与属性。Studio 指南

制作角色配音。作者准备文本、语言与声音输入，再审阅实际任务结果。样例教程 交付可玩的作品。独立 Player 使用同一剧情和作品呈现。试玩《今晚，让春天亮起来》

连接生成服务制作候选。 Studio 内置制作核心负责输入准备、配置冻结、调度、任务与候选。作者准备自己的服务、模型与凭据；ComfyUI、VoiceStudio 等服务在各自环境运行。作者比较文本、图像或声音，再采用成果。“应用”改变作品工作内容，“保存”写入磁盘。服务可用性、用量与费用沿所选提供方的实际能力和回执显示。

通过 MCP 编辑同一作品。 作者准备兼容的外部客户端与模型，启用 Studio 本机 MCP 服务，将协作绑定到作品与执行范围。助手通过与 Studio 相同的领域接口读取、编辑、预览和制作。作者可以检查调用、暂停后续动作，并在断连后查询已受理业务。工程规则见协作契约，操作入口见产品手册。

作者从场景或选定语句试玩，检查已保存作品后构建发行物。Web 发行物包含独立浏览器 Player，Windows 发行物包含独立 Windows Player。Player 随包携带已采用内容及精确运行依赖。

Android 构建器提供工程、APK、AAB，实际构建需要相应 JDK、Android SDK 与签名配置。当前本地检查覆盖调试签名的 Android 构建和 Windows 上的 Xcode 工程导出；Android 设备运行、iOS 归档、Apple 签名及真机运行由相应环境检查。详细范围见运行与发行边界。Studio 首发运行平台为 Windows x64。
