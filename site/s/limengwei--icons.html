About icons

基于 react-icons 与 Iconify 精选集合的桌面图标浏览器与检索工具——38 个图标集、73,552 个矢量图标，全部内嵌于单个可执行文件。 内置 MCP 服务器，可接入 AI 助手使用。

- 图标浏览 — 虚拟滚动网格 + 矢量渲染（任意缩放与 DPI 下清晰）；全部图标编译进二进制，无需下载，无首次部署 - 即时搜索 — 图标名与集合关键词的防抖子串搜索；结果超过 10,000 行时截断并在状态栏提示 - 集合侧栏 — 全部 38 个图标集（Font Awesome 6、Material Design、Tabler、Phosphor，以及 Iconify 精选的 Solar、HugeIcons、Iconoir、Fluent Color 等）及实时数量 - 详情与导出 — 棋盘格放大预览、SVG 一键复制、任意尺寸与颜色的 PNG 导出与剪贴板复制 - MCP 服务 — 内嵌 MCP 服务器（stdio + HTTP），供 AI 工具检索图标、获取 SVG、渲染 PNG - 托盘常驻 — 关闭窗口最小化到系统托盘，MCP 服务后台继续运行；TCP 端口锁保证单实例

层 技术 ---------- 语言 Go 桌面框架 nsgo（暗色外观、托盘） 数据集 react-icons v5.7.0 + Iconify 精选集合（2026-11-25 抓取），内嵌（按集合 gzip JSON） MCP modelcontextprotocol/go-sdk

内嵌 MCP HTTP 服务器随应用自动启动（默认端口 9393，可在设置中修改）。也可以运行 icons --mcp 启动独立的 stdio 服务器。

关闭窗口不会退出应用：最小化到系统托盘并继续提供 MCP 服务。点击托盘图标恢复窗口，右键菜单提供「显示窗口 / 退出」。

工具 说明 ------------ listsets 列出所有图标集（fa6、ri、tb、solar 等）及数据来源（react-icons / iconify）、图标总数 searchicons 按关键词搜索图标（图标名 + 集合关键词），可按集合过滤；最多返回 100 条，附未截断总数 geticonsvg 获取图标原始 SVG 标记，可选注入 CSS 颜色到根 fill exporticonpng 渲染图标为 PNG（base64 返回），可指定尺寸（默认 256）与颜色

纯 go build 也可用；图标资源来自 rsrcwindowsamd64.syso。

Windows CI 每次推送通过 go tool nsgo build 构建 NSIS 安装包，并在 v 标签上发布（见 .github/workflows/build-windows.yml）。
