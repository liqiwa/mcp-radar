About im-mcp

im-mcp (本地绿泡泡 & DuangDuang AI 检索 MCP Server)

基于 Model Context Protocol (MCP) 规范构建的本地 IM（绿泡泡 & DuangDuang）聊天记录与通讯录检索服务。 极简、只读、完全离线本地运行，让 Claude Desktop、Cursor、Cline、Pi 等 AI Agent 能够安全、高速地检索与总结你的工作沟通、群聊记录和知识库。

注：原底层参考项目以 Git Submodule 形式统一归档在 reference/ 目录下（reference/wechat-local-viewer 与 reference/dingwave-V3）。

- ⚡ 超低延迟：直接基于本地解密 SQLite 数据库，毫秒级响应。 - 🔒 纯本地与只读：所有数据均在本地，绝不上云；以只读方式运行，不破坏原始数据。 - 📦 按需安装（Optional Dependencies）：一个仓库，两套独立入口；支持只装绿泡泡、只装DuangDuang或全量安装。 - 💬 丰富格式解析： - 绿泡泡：支持普通文本、引用消息、富文本卡片、小程序、传输文件（PDF/Excel/Word等）。 - DuangDuang：支持多表分片聚合（tbmsg000~tbmsg127）、联系人实名映射、Markdown卡片、协同日程通知、文件附件提取。

平台 支持版本范围 实测验证版本 架构与平台 解密 / 同步原理 --------------- 绿泡泡 (WeChat) 绿泡泡 4.x 全系列(兼容 3.9.x) 4.1.15.13 (Windows 最新版)4.1.35.15 (macOS ARM64 最新版)4.1.15 (270115) (macOS x8664 实测验证)4.1.11.x 等 Windows x64macOS (Apple Silicon & Intel) Windows: 运行时扫描 Weixin.exe Config.Cipher 动态提取 Salt 密钥；macOS: 原生 CommonCrypto (CCCrypt) 零额外依赖解密，支持 passphrase PBKDF2 派生；离线 HMAC 校验并解密 WCDB SQLite DuangDuang (DingTalk) DuangDuang 7.x 全系列(涵盖 V2 与 V3) 7.6.0.x (最新版)7.5.x / 7.0.x Windows x64 / macOS 纯离线读取用户目录 userconfig，通过 PBKDF2-HMAC-SHA1 + MD5 推导 AES-128 密钥并合并 WAL 事务
