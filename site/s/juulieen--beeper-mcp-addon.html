About beeper-mcp-addon

Unofficial. Not affiliated with or endorsed by Beeper.

The missing tools for Beeper Desktop's MCP server: files, new conversations, catching up, reactions and edits.

Beeper Desktop ships a built-in MCP server, so an AI assistant can search and send messages across WhatsApp, Signal, Telegram, iMessage and more. It has a few gaps, though:

- It only handles text: the assistant can see that a message holds a video, but it can't open it, and it can't send a photo or a PDF. - It can only write in existing conversations. To message someone new, you have to send the first message yourself. - Catching up on many chats takes one call per chat, and it can't see who reacted, react, or fix a message already sent.

The Beeper Client API that runs alongside it already supports all of that. This small MCP server exposes it as ten tools:

Tool What it does ------ downloadattachment Saves a message attachment (video, image, audio, document) to disk and returns the local path; or every photo and video of a chat over a period, into one folder sendfile Uploads a local file and sends it to any chat, with an optional caption searchcontacts Finds people on an account (WhatsApp, Signal…), including ones you've never chatted with; phone numbers, emails and @usernames are looked up exactly startchat Opens a direct chat with someone and returns its chatID, reusing the existing chat if there is one deletemessage Deletes (unsends) a message, for everyone when the network allows it waitformessage Waits for an incoming message (a reply, say) and returns it, so the assistant doesn't have to poll getnewm
