About mcd-meal-ledger

只是想看踩坑记录？ 我用真实凭证跑通麦当劳 MCP 时踩了 7 个坑，其中 5 个不报错但结果全错 （菜单接口是两层结构、营养接口返回的不是 JSON、核价单位是「分」……）。 完整排查过程见 MCPINTEGRATION.md 第五节。

普通统计会告诉你的 麦门账本多告诉你的 --------- 1. 钱的账 你在麦当劳花了 ¥4,177 123 单 / 覆盖 98 天 / 平均客单价 ¥33.96 / 整体折扣率 17.3% 2. 画像 无 ⏳ 资深麦门老友、🔥 连击王、🍦 甜品治愈系 —— 每个标签都附数据依据 3. 审计 无 26 单按原价结的，按你自己的折扣水平本可省约 ¥241.38（估算） 4. 积分的账 「你有 46.5 积分」 同样花积分，换「18.8 元鸡腿堡两件套」每分 0.376 元，换「21.9 元可乐组合」只有 0.027 元 —— 差 13.7 倍 5. 往前看 无 说一句「巨无霸+薯条+可乐」，当场算怎么点最省，并让麦当劳官方核一次价；为了凑满减加购到底划不划算 6. 算到一年 无 从你的真实订单认出固定习惯，算出照这样点一年大约白花多少钱

打开 docs/demo.html 即可看到完整年报（离线样例数据，无需 Token）。

年报包含：核心数字看板 → 麦门人格（带证据）→ 消费节奏图表（内联 SVG）→ 常点榜单 → 套餐拆解榜 → 你实际吃成什么样（营养）→ 照你这样点一年大概花多少 → 券的实话 → 积分的账（换什么最划算）→ 你在哪些门店点过 → 账单审计（含优惠利用率评级）。

产物是自包含 HTML：内联样式 + 内联 SVG，零外部资源， 可以直接双击打开、直接截图分享，不会在别人手机上碎掉。

打开 docs/demo.html，你会看到一份基于 123 笔脱敏样例订单生成的完整年报。

1. 领取 MCP Token → 到 open.mcd.cn/mcp 手机号登录， 点右上角「控制台」→「激活」，一键复制 Token（免费）。

当场比价 + 官方核价：说清楚想吃什么，它会算怎么点最省，判断凑单划不划算， 最后让麦当劳自己算一遍价 —— 不是我们估的。

参数 说明 ------ --offline 使用内置脱敏样例，不需要 Token --out PATH HTML 输出路径（默认 docs/demo.html） --markdown 在终端打印文字简报 --json-out PATH 同时导出中间结果 JSON --ics-out PATH 把近期活动导成 .ics 日历（可导入手机） --wish "巨无霸:1,薯条" 当场比价 + 凑单判断 + 官方核价 --fit-calories / --fit-protein / --fit-budget 营养搭配的热量 / 蛋白质 / 价格约束 --pages N / --page-size N 历史订单拉取尝试次数与每页条数（默认 3 × 200） --store CODE 指定门店编码（影响门店券与菜单查询） --personas N / --top N 展示的人格标签数 / 常点榜单条数 --no-enrich / --enrich-limit N 跳过逐单补全 / 补全上限（默认 200） --bind-coupons 调用一键领券（⚠️ 会真实写入账户，默认关闭） -v 把每次 MCP 调用打印到 stderr（不污染管道输出）
