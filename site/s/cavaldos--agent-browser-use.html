About agent-browser-use

Let AI coding agents drive a real browser over MCP, while you watch every step live in a web page and can take over at any time.

Agent Browser Use is a single Go binary that runs one headless Chrome on your machine and exposes it as a set of Model Context Protocol tools in the style of Playwright MCP. Any MCP-capable agent (Claude Code, Codex, OpenCode, Pi, Cursor, VS Code…) can navigate, read the page, click, type and log in for you, while a web viewer shows the agent's cursor, the element it is acting on, and a log of every step.

Watch the agent work. Its cursor, a caption for every step and a log in the chat, with a one-click Take over or Block agent. Pick an element and share it. Copy its code for your coding agent, or post it in the room chat.

Share with a public link. One switch opens a built-in tunnel: copy the link (and password) and send it, no router setup. Switch off and the link stops working.

- Playwright-style MCP tools — browsersnapshot returns an accessibility outline with a ref for every element, and the action tools (click, type, scroll, drag, select…) use those refs. - Live viewer — watch the page stream in your browser, with the agent's cursor, captions and chat log. - Shared browser room — you and the agent use the same Chrome; take control at any time, or block the agent. - Pick an element — click the pick button, point at anything on the page and get a short code (e.g. el-1d2a).
