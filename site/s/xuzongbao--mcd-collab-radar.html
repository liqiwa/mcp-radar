About mcd-collab-radar

联名可以冲，账要先算清。 麦当劳限定联名的抢购参谋——把「窗口、价梯、渠道」三本账算明白，再甩你一张能晒的攻略卡。

当下最典型的场景：麦当劳 × PEACEMINUSONE（G-DRAGON）联名——韩式新品 + 周边多弹发售（小卡 → 徽章 → 丝巾）。输入你在追的联名，它还你一张结构化情报表 + 一张可截图分享的攻略卡。

🏷️ 麦当劳程序员创意开发大赛参赛作品 · 基于麦当劳中国官方 MCP（mcd-mcp）开发 · 使用 WorkBuddy 辅助开发

⚠️ 本项目为参赛者独立开发的非麦当劳官方产品，输出仅供参考；周边为消费品，不建议囤积炒作。

联名周边开售那天，小红书上一半人在喊"抢破头"，一半人在喊"没人买"——信息差才是真正的成本。麦麦联名雷达用 MCP 实时数据，把一次联名抢购拆成三个可执行的问题：

账本 回答什么问题 数据来自 --------- ⏰ 窗口 什么时候冲？开售/积分抢先购时刻、倒计时 campaign-calendar 实时活动日历 💰 价梯 怎么买最便宜？换购/加购/麦金卡/积分，哪条路径到手价最低 query-meals + calculate-price + 券 + 积分 📍 渠道 去哪买？附近门店雷达 + 痛店/冷店错位策略 query-nearby-stores + 门店券对比

点餐类 Skill 麦麦联名雷达 --------- 场景 日常用餐决策 限定联名抢购（一次性、强时效、信息差最大） 输出 菜单/优惠券 三本账 + 一张能晒出去的攻略卡 时效 随时 倒计时驱动，开售/积分抢先购窗口精确到分钟 数据 菜单快照 calculate-price 逐条实算 + 门店实时距离/营业状态

且不绑死任何单次联名——以 campaign-calendar 为活水源，下一个联名上线即自动纳入雷达。
