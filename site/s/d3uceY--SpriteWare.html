About SpriteWare

Pixel-art tooling an AI agent can actually use

SpriteWare runs an MCP server that lets an agent open a sprite, draw pixels, read the result back and export a PNG. It drives Aseprite for the agent: the window you have open, or a hidden Aseprite when none is.

I built the mascot sprite animations by hand. The other sprite assets in the app are AI, just to show what the MCP can do.

Platform File :-:------ Windows installer SpriteWare-windows-amd64-installer.exe Windows portable SpriteWare-windows-amd64.exe macOS (Apple Silicon and Intel) SpriteWare-macos-universal.dmg Linux binary SpriteWare-linux-amd64 Linux package SpriteWare-linux-amd64.deb

The builds are unsigned. Windows: SmartScreen → More info → Run anyway. macOS: right-click the app click Open. Linux binary: chmod +x it first. For Mac, you may need to allow apps from unidentified developers in System Preferences then Security & Privacy.

Aseprite 1.3+ is required. First launch asks for its executable. The Server screen starts the MCP server and writes the entry into your assistant's config (Claude Desktop and Claude Code, VS Code, Zed, Cursor, Windsurf, Cline, Gemini CLI, Codex, OpenCode, Kiro). I have not tested them all to check if the intalls work correctly but if there are any issues, please make an issue on GitHub.

No compiler needed: buy it on aseprite.org, Steam or Humble Bundle. A free trial is on aseprite.org.
