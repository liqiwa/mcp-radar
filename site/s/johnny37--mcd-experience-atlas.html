About mcd-experience-atlas

「我在成都，能办麦当劳生日派对吗？哪家店？多少钱？这周六还有位吗？」——一次查询就有答案。 基于麦当劳中国官方 MCP 的只读采集与可视化：生日派对、主题派对、亲子读书会、品鉴会、体验营在全国哪些城市、哪些门店、什么时段可以预约。

全国体验活动分布总览 —— 圆点大小 = 可体验的活动款数，右侧为数据洞察（含 2 款全国零城市可约的下架活动、体验丰富度中位数 18 款等独家指标）

「我在成都，能办麦当劳生日派对吗？哪家店？多少钱？这周六还有位吗？」——一次查询就有答案。

麦当劳的体验活动（生日派对 / 主题派对 / 品鉴会 / 亲子读书会 / 体验营）分散在 App 的深层路径里， 用户需要逐级确认「城市有没有 → 哪家门店能办 → 哪天可约 → 几点有场 → 还剩多少位」。 本项目把这条链路的数据一次拉通，做成一张可以点开的全国地图。

指标 数值 ------: 可预约城市 281 个（含行政区划码 + 经纬度） 可办活动门店 3664 家 场次样本 157 个（覆盖 79 个城市） 体验品类 SPU 26 款（商城 SPU 合计 50 款） MCP 工具（实测） 35 个 餐品营养表 160 项 当月营销活动 13 天 / 27 个事件 门店数 TOP5 城市 北京 365 · 上海 219 · 天津 136 · 佛山 118 · 成都 97

官方 App 里，上述五个问题需要逐级点开、逐个城市试才能回答，且没有任何横向对比视角。 本项目把这些数据一次拉通后，可以直接回答：

- 我所在的城市能办哪些麦当劳体验活动？ - 哪家门店能办？这周还有没有场次？多少钱？几个人起订？ - 全国范围内，哪些活动其实「一个城市都约不了」？ - 同样叫「生日派对」，不同城市能办到的款式差多少？

最后一条是本项目独有的指标——体验丰富度（按可体验 SPU 款数计）： 全国中位数 18 款，最少 8 款，最多 23 款（福州 / 龙岩 / 泉州并列第一）。

项 要求 ------ Python 3.8 及以上（实测 3.13） 第三方依赖 无。全部使用标准库实现 Node / 构建工具 不需要 操作系统 Windows / macOS / Linux 均可 MCP Token 仅采集时需要；查看地图和运行测试不需要

仓库根目录的 index.html 是数据完全内联的单文件版本， 因此可以直接用 GitHub Pages 托管，访客打开链接即可看到地图，无需 clone：

本仓库已启用 GitHub Pages，在线地址：。 本仓库的 dist/index.html 与根目录 index.html 内容相同，均可单独分享。

Token 在 用手机号登录后申请。本项目按以下优先级读取，不接受也不生成任何本地凭证文件：

1. 环境变量 MCDMCPTOKEN； 2. WorkBuddy 的 ~/.workbuddy/mcp.json 中 mcd-mcp 连接器已配置的凭证 （在 WorkBuddy 中接入过自定义连接器时自动生效，零额外配置）。

配置模板见 mcp-config.example.json（仅含 ${MCDMCPTOKEN} 占位符）。

本仓库同时是一个可被任意 MCP 客户端加载的 Agent Skill。将仓库路径加入客户端的技能目录即可， SKILL.md 已按 WorkBuddy 标准格式声明了所需的 9 个只读工具与使用约束。
