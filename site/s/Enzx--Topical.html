About Topical

Topical is a personal knowledge graph for tracking work. Every piece of work is a topic: a node with a summary, attributes, a todo list, typed references and a dated journal. Topics are linked into graphs called spaces, and the same topics can be looked at as a canvas, a board, a timeline or a full-screen document. The graph is also readable and writable by coding agents over an MCP server, and a git extension keeps a graph that describes a codebase honest as that code moves.

It is a desktop app built with Tauri 2, React 19 and TypeScript on the front, and Rust with SQLite behind. It currently runs on Windows only: the data directory, the MCP handshake file and the installer are all Windows-specific, and nothing has been tried elsewhere yet.

- Spaces. One graph per space, and spaces nest. A nested space appears as a node on its parent's canvas, and a portal is a topic that points at a topic in another space of the same tree. - Topics. Title, summary, an open attribute map, todos with due dates, refs, notes and blocks. Every topic gets a stable key such as KEY-12 that the omnibox and the MCP server can look up. - Refs. Typed external references spelled type:value: code: for a file, symbol or heading in a workspace, plus tag:, jira:, confluence:, email:, person: and link:. Code refs are resolved against the tree and reported when they dangle. - Links. A workspace-wide registry of link types, each with a name, an outward and an inward phrase, and whether it is directed and acyclic. related and parent are built in. - Four views of the same topics.
