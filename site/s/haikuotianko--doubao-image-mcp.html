About doubao-image-mcp

把豆包网页版（doubao.com）的生图能力封装成本地 MCP 服务：不需要官方 API Key，用你自己的网页登录态直接调用，Seedream 4.0 / 4.5 / 5.0 全系可用。附带一个桌面端（Wails + WebView2），负责扫码登录、多账号管理、测试生图与排障。

Local MCP server that exposes Doubao's web image generation as tools for Claude Desktop / Cursor / any MCP client — no API key, just your own web session.

- 它能做什么 - 环境要求 - 下载 - 版本与更新检查 - 安装 - 首次使用 - 接入 MCP 客户端 - 工具参考 - 多账号与自动排队 - 数据位置 - 排障 - 已知限制 - 跨平台说明 - 开发

工具 作用 --- --- doubaoimage 文生图 / 图生图。一次生成几张就返回几张：本地文件路径 + CDN 链接 + 尺寸 doubaologin 直接从 AI 客户端弹窗扫码：没有账号或登录态失效时调它，不用切到 GUI doubaomodels 列出可用模型、32 种风格 key、8 种比例 doubaoping 检查当前账号登录态是否有效（也能发现 IP 风控） doubaoaccounts 账号池：列出 / 切换默认 / 启用 / 停用 / 删除，输出带昵称与忙碌状态

doubaologin 的关键点：stdio 模式下 MCP 进程同样跑在你的桌面会话里，所以它能直接开一个 WebView2 扫码窗口（最多等 3 分钟，扫完自动保存账号并校验）。已经有可用账号时不会打扰你，直接返回「无需登录」。mac / Linux 因为没有内置浏览器，会提示改用 -set-session。

- 无水印直链：从 SSE 里挑 imageraw / dwm3 模板地址（手工改后缀会 400，签名覆盖整个 path，只能用服务端给的）。 - 多图全量：服务端一次可能给 1~4 张，全部返回；结构化解析漏掉的图会从原文按图补回。 - 比例修正：服务端经常忽略请求比例，默认用虚化背景补齐到目标比例（偏差 3% 内不动）。 - 双通道降级：新端点 /chat/completion 失败自动降级到旧的 samantha 通道。

- Windows 10 / 11：完整支持（GUI + 扫码登录），x64 / x86 / ARM64 都有预编译包。 - macOS / Linux：有预编译命令行版（MCP 功能完整），但没有 GUI、没有内置扫码登录，登录用 -set-session 手动导入（见安装 → 方式三）。想要 GUI 就在该平台上自己 wails build。 - Microsoft Edge WebView2 Runtime：仅 Windows 的扫码窗口需要；Win11 自带，Win10 若缺失程序会明确提示。 - 一个豆包账号（免费账号就能用 Seedream 5.0 Flash）。
