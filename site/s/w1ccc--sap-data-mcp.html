About sap-data-mcp

让 Claude 等 AI 助手只读查询 SAP S/4HANA 的 MCP 服务，RFC/BAPI、私有云 OData、公有云 API 都能接

一句话理解：如果把 AI 助手看成一位新同事，SAP Data MCP 就是给它开的一个只读账号，外加一本操作手册：订单、发票、库存、供应商未清项，它都能自己去 SAP 里查，再用一句话把结论告诉你；但它改不了任何数据，碰不到你的密码，查过什么也都有记录。

需要 Python 3.12，以及一个支持 MCP 的 AI 工具，例如 Claude Desktop、Claude Code 或 Cursor。下面以公有云 API 为例（Windows PowerShell）：

1. 打开 publiccloud\api\.env，填写系统地址 SAPAPIBASEURL，再选 Basic 认证（SAPAPIUSERNAME、SAPAPIPASSWORD）或 OAuth 客户端凭证（SAPAPIAUTH=oauth、SAPAPITOKENURL、SAPAPICLIENTID、SAPAPICLIENTSECRET）。私有云 OData 的做法一样，把目录换成 privatecloud\odata。 2. 把服务注册到 AI 工具，路径换成你的实际位置：

Claude Code 里一行就行：claude mcp add sappublicapi -- C:\sap-data-mcp\.venv\Scripts\python.exe C:\sap-data-mcp\publiccloud\api\server.py 3. 让 AI 先调用 healthcheck 和 testsapapiconnection(service="material") 确认连通，然后直接用中文提问，比如「PO 4500000417 的货款怎么还没到？」

本地部署和私有云如果走 RFC/BAPI，还需要 SAP NW RFC SDK 和 PyRFC，按 GOLDENPATH.md 配置。每个服务都从自己 server.py 所在的目录读取 .env、config/ 和 logs/，所以 AI 工具里只要写绝对路径。

你可能用过的做法 麻烦在哪里 SAP Data MCP 的不同 --------- 在 SAP GUI 里手工查（ME23N、MIR4、FBL1N…） 一个问题要开好几个事务码，单号来回复制，还会被「填写所有必填字段」拦下 用中文提问，AI 自己调用对应的标准读取接口，一次给出结论 自己写脚本调 RFC 或 OData 每个新问题都要写代码、处理认证和分页，脚本里还常常带着密码 三个服务共 412 个现成的只读 Tool，认证和分页都处理好了，凭证只放在本机 .env 给 AI 一个能写入的账号或接口 AI 理解错了就可能改到数据，事后也说不清它做过什么 只读白名单写在代码里，没有任何写入能力，每次调用都进审计日志 直接读底层数据库表 要懂表结构和字段含义，读出来的是原始数据，容易漏掉业务规则 优先走 SAP 标准业务接口（BAPI、标准 OData 服务、Released API），结果带着业务含义；RFC 服务里的查表 Tool 只作只读补充

- 不用记事务码：直接问「这张 PO 为什么还没付款」，AI 会自己查订单、发票和供应商未清项。 - 只读，改不了数据：RFC 调用必须通过 98 个标准读取函数的白名单，HTTP 只发固定的 GET 请求（唯一的 POST 是获取 OAuth token），没有任何创建、修改或过账的能力。 - 密码不经过 AI：密码、client secret 和 token 只放在本机的 .env 里，在错误信息和日志中显示为 [REDACTED]；Tool 不接受凭证、任意 UR
