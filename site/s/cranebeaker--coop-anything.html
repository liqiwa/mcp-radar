About coop-anything

Any single-player game. Your friends. Your agent does the work.

Quick start · How it works · What you can co-op · Games so far · Contribute · FAQ · Docs

Want to play a single-player game with your friends? Point your AI coding agent at this repo. It researches what exists, reverse engineers the game and its engine if it has to, builds or fixes the co-op, tests it with bots inside the game, and packages it so your friends install it in one click and join over Steam without port forwarding.

The sky is the limit. Every game that runs on your PC is a candidate.

Games being made co-op right now: Deus Ex (released) · Fallout: New Vegas · Zelda: Ocarina of Time (fully synced) · Dungeon Keeper · S.T.A.L.K.E.R. Shadow of Chernobyl · S.T.A.L.K.E.R. Clear Sky

Tell your agent (Claude Code, Codex, Gemini CLI, Cursor, OpenCode, ...):

The agent follows AGENTS.md and the skills in .agents/skills (also in .claude/skills for Claude Code).

The Co-op Anything MCP lets any agent search the co-op directory, detect a game's engine from its install folder, read the playbook and skills, and validate contributions. Claude Code picks it up from this repo's .mcp.json; for other agents:

Codex, Gemini CLI and Cursor setup: playbook/mcp.md. For the binary work, pair it with a reverse-engineering MCP such as REA (npx rea-agents setup): Co-op Anything knows what to do, REA looks inside the game.
