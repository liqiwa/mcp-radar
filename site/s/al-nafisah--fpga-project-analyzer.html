About fpga-project-analyzer

An AI agent skill that explains and reviews Vivado, Zynq and PYNQ projects - visually. Ask your agent; get a clickable Vivado-style diagram, plus the bugs that "timing met" hides.

▶ Try it live: the analyzer's diagram of a RISC-V SoC, with the same RTL running in your browser

Install the FPGA Project Analyzer from https://github.com/al-nafisah/fpga-project-analyzer and set it up for yourself, following its README.

Agent Setup ------ Claude Code /plugin install fpga --marketplace al-nafisah/fpga-project-analyzer (step 1 not needed) Claude Desktop add the JSON below to its MCP config Cursor add the JSON below to ~/.cursor/mcp.json Gemini CLI gemini mcp add fpga fpa mcp OpenAI Codex codex mcp add fpga -- fpa mcp VS Code (Copilot) add the JSON below to .vscode/mcp.json, with "servers" instead of "mcpServers"

Any other MCP-capable agent works the same way. Agents that load SKILL.md skills can use skills/ directly. Browser chats can't read your files; use the vendor's coding agent instead. Without AI: fpa build , then fpa view . Vivado is optional.

Open your project folder in your agent and ask:

Ask You get ------ "Explain this FPGA project" How the design works, as a clickable diagram "Review it for hardware bugs" Clock crossings, pins, resets, address map, PYNQ issues "Why did my build fail?" The root cause and the exact fix

In Claude Code these are also commands: /fpga:explain, /fpga:review, /fpga:debug.
