About claude-cloud-kit

让 Claude Code 跑在你自己的云服务器上，同时能操作你本地 Windows 或 Mac 电脑上的项目。

- 云上的 Claude 通过 DevSpace 读写你电脑上的项目、运行命令，用起来和本地差不多。 - SSH 断了自动重连，tmux 里的会话不丢；手机上也能接着用。 - 一台服务器可以同时连多台电脑（家里、公司、Windows 和 Mac），各用一个名字，互不影响。 - 可选：远程桌面、在 Windows Terminal 里直接粘贴截图。

- Claude 账号（Pro 即可） - AWS 账号（需要信用卡；新用户有赠送额度，最小规格的服务器够用） - （可选）一个域名和 Cloudflare 账号：不准备也能用。默认先用临时隧道（免费、不用注册，但每次电脑重启地址会变，启动脚本会自动处理）；想长期稳定使用再换成固定域名（首年不到 20 元） - Windows 10/11 或 macOS 电脑（Mac 版暂不含截图粘贴，并且还没在真实的 Mac 上完整跑过，遇到问题欢迎提 Issue）

提示：请遵守 Anthropic 和 AWS 的服务条款，账号的使用风险由你自己承担。

需要你本人操作的步骤（注册、网页后台、输入密码）它会停下来告诉你。想自己装也可以直接照着 SETUP-FOR-AI.md 做。

- 上篇：从零搭建 AWS 云服务器：注册、免费额度、创建服务器、SSH、Claude Code、远程桌面、费用 - 下篇：让云上的 Claude Code 操作本地电脑：DevSpace、Cloudflare 隧道和 Access、授权

路径 作用 ------ kit.config.example.json 配置模板，复制为 kit.config.json 后填写 docs/ 上下两篇详细教程（手动版） server/ 服务器端：初始化（bootstrap.sh）、接入 DevSpace（setup-devspace-mcp.sh） windows/connect/ 连接服务器：ssh-cloud.cmd、rdp-cloud.cmd、截图粘贴 image-paste.ahk windows/devspace/ 本地 DevSpace：安装、启动（start-devspace.cmd）、授权服务器 mac/ Mac 版：connect/（ssh-cloud、rdp-cloud、钥匙串保存 AWS 密钥）、devspace/（登录自启的 DevSpace）、tests/

本地状态和日志：Windows 在 %LOCALAPPDATA%\ClaudeCloudKit\（AWS 密钥也加密保存在这里），Mac 在 ~/Library/Application Support/ClaudeCloudKit/（AWS 密钥存在钥匙串）。

本地这一端用的是 DevSpace（@waishnav/devspace），隧道用的是 Cloudflare 的 cloudflared。
