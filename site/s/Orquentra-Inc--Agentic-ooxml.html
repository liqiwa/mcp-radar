About Agentic-ooxml

Let an agent edit the board deck. Know when a number moved.

Who a deck is for, where each figure came from and what must not change are stored inside the .pptx, .docx or .xlsx itself. The next edit starts with that context, and a number that moved gets flagged instead of silently trusted. See it on the project site, with a live demo of a stale number being caught.

Linux and macOS, no Rust needed; it installs agentic-ooxml and agentic-ooxml-mcp into ~/.local/bin after checking the release checksum. Windows, Cargo and Claude Code routes are under Install.

- The file notices when a number moves. Edit the workbook cell a slide quotes and the deck's source reports stale (externalclaimchanged), though the deck was never touched. Real output: examples/demo-output.txt. - Your original is safe by default. Through MCP, writes are off unless AGENTICOOXMLALLOWWRITE=1, produce a sibling .ao-proposed copy, and stay inside AGENTICOOXMLROOTS. Native package entries are copied byte for byte. - Every edit is reviewable, and it stays local. diff and validate show what changed and whether the package is sound; the core, CLI and MCP crates have no network dependency. Open source (MIT).

Agentic OOXML stores the context an agent needs to edit an Office file correctly, such as who it is for, how it should look, and where its numbers came from, as standard OOXML custom XML parts. A Rust library and command line read and write those parts, and report when a sourced number has changed since someone checked it.
