About admin-os

An open-source management dashboard for small businesses. It is built for restaurants first, and it is designed so that a hair salon or a car repair workshop can run on the same modules. No AI slop, no over-engineering: well designed, reusable at every level, and ready to be managed by an AI assistant through its own MCP server.

Open the live demo → It runs on Cloudflare Workers with the demo data of the mock adapter, in English, Spanish, German or French.

[!NOTE] admin-OS is in active development towards its first release (v0.1). Some modules below are built, others are in progress. See Status. The screenshots show the demo data that ships with the mock adapter.

Moving around. The top bar holds the business areas, the rail on the left the tools.

The bookings room. The floor plan switches between 2D, 2.5D and 3D; a table opens its booking, and the same service reads as an agenda or a list.

Themes, modes and languages. Five liquid-glass themes in light and dark, and the interface in English, Spanish, German and French.

On a phone. The same screens, with a bottom dock and bottom sheets.

Desktop, 1440 × 900. The images follow your GitHub theme (light or dark).

Every image is generated from the running app by npm run media (e2e/media/readme.capture.ts), so it stays in step with the code.
