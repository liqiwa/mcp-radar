About feronavi

Feronavi 项目协作，进入 Agent 时代。 为人和 Agent 而生的开源项目协作平台。从需求到交付，连接团队、知识与执行。 完整 MCP Server · 内置 RAG · 业务流程闭环 · 自托管

开始部署 · 产品亮点 · MCP 接入 · RAG 助手 · 更多界面 · 文档导航 · 问题反馈

一项需求背后，有计划、讨论、方案，也有一次次推动它向前的行动。Feronavi 把它们连成完整的工作流：团队在平台里协作，Agent 通过 MCP 参与执行，内置 RAG 为对话提供项目知识与来源依据。

核心能力 带来的改变 --- --- 完整 MCP Server 把业务能力交给 Agent，从发现上下文、执行操作到核验结果，走完业务流程 内置 RAG 助手 让项目知识进入对话，跨项目检索、结合业务分析，答案附有来源 贯穿交付的协作 需求、工作项、文档、迭代与版本相互关联，进展和决策都有迹可循 自主部署与接入 源码开放，数据、身份体系、模型供应商与集成由团队管理

从理解任务，到执行操作，再到确认结果。 Feronavi 为 Agent 提供可完成业务闭环的标准入口，让项目协作成为智能体可以实际参与的工作。

检查本次迭代的未完成事项，梳理发布风险。先给我调整建议，确认后更新指派和状态，整理发布文档，最后核对执行结果。

环节 Agent 可以做什么 --- --- 理解上下文 发现业务工具，读取项目、成员、字段与工作流，明确任务范围 推进业务 创建和更新工作项、推进状态、维护文档、管理迭代与版本 核验结果 写入后重新读取业务数据，确认持久化结果，处理版本冲突与安全重试

服务器提供 MCP 工具、资源和提示词，支持 Streamable HTTP 与 stdio。Codex、Claude Desktop、Cursor、VS Code 等支持 MCP 的客户端均可按协议接入，按任务动态发现所需能力。

平台界面、内置助手与 MCP 共用业务服务和权限规则。账号权限、令牌范围、幂等写入和操作审计贯穿执行过程；登录、2FA 等身份验证通过专门入口完成。

让积累下来的文档，成为此刻用得上的答案。 独立助手支持跨项目对话，也可以聚焦指定项目；检索项目文档，查询实时业务信息，把知识依据与当前进展带入同一次对话。

这个需求当时为什么这样设计？结合方案文档和当前迭代，帮我整理本次上线的风险，并注明依据。

- 答案有出处：引用可回到原文，检索范围遵循项目权限和文档访问规则。 - 对话够顺手：流式输出、Markdown、Mermaid 图表，多会话按账号保存在服务端。 - 分析能落地：查询分析直接执行，业务修改先展示操作内容，确认后执行并核验结果。

知识问答同时提供 MCP 工具与 OpenAPI 3.1 描述的公共 API，内置助手和外部 Agent 可以使用同一套检索与业务能力。配置自己的兼容模型与嵌入供应商后，即可使用。

从个人今天要做的事，到团队下一次要交付的版本，Feronavi 提供相互连接的工作视角。

工作环节 平台能力 --- --- 收集与拆解 想法、需求、任务、缺陷、子任务，保留讨论与附件 计划与推进 里程碑、迭代、版本；看板、表格、日历与时间线 沉淀与交接 项目文档、目录、版本历史、权限与回滚 规则与协作 自定义工作流、审批、自动化、SLA 与站内通知 洞察与统筹 个人工作台、燃尽图、累积流、项目集与审计记录
