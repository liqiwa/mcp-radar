About clojure-atlas

Built for agentic coding: a structural map of your Clojure codebase, served to your AI agent over MCP.

Before an agent edits Clojure, ClojureScript or .cljc code it should know who calls the function, which parameter set the function takes, which map keys each caller passes and the body reads, and which routes, re-frame events and tests are connected to it. clojure-atlas builds that map on your machine with clj-kondo and answers through 13 MCP tools. Every row cites file:line and says whether it is proven, heuristic or unknown.

Zero required npm runtime dependencies. Local analysis.

A personal project by Barış Can Ateş · MIT licensed · built on clj-kondo.

A text search finds a spelling. It does not tell a call from a callback, a map key from a keyword that happens to be spelled the same, or a handler reached through a re-frame event from one that is never registered. An agent that edits on a guess breaks a caller it never saw. Atlas gives it the relationships, with the evidence for each, before the edit.

The agent asks Atlas answers with MCP tools --------- Who calls this, and what could my change reach? Direct callers, value uses and callbacks, transitive dependents callers, blastradius Which parameter set does the function take, and what does each caller pass? Arities, destructured keys, :or defaults and optional keys, keyword arguments, the keys each call site passes signaturei
