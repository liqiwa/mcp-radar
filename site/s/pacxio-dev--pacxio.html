About pacxio

Describe your packaging in Claude Code or Codex. Build editable dielines, turn and fold them in 3D, and review the design in a local workbench. Use the pacxio cloud service for artwork composition, preflight and factory delivery files.

Website · Install · Docs · Structure library · Online generator · Examples · PyPI

Automatic updates apply only to a standard, unpinned uv tool install pacxio from PyPI. pip, pinned versions, editable/source installs and custom-source installations remain manual. Eligible installations check in the background when MCP starts. A verified update is used on a later startup; your current session keeps its version.
