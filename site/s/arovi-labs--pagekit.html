About pagekit

The content layer for your website. Stop building CMSs. Ship content in minutes.

PageKit is a developer-first content backend. It provides a Content API, a publishing dashboard, media management, SEO tools, draft workflows, and AI-agent access through the Model Context Protocol (MCP).

You write code. PageKit handles the content.

Package Description Install ------------------------------- @arovi/pagekit-core TypeScript client for the PageKit content API pnpm add @arovi/pagekit-core @arovi/pagekit-mcp MCP server — let AI agents manage your content pnpm add -g @arovi/pagekit-mcp @arovi/pagekit-next Next.js integration (server components, caching) pnpm add @arovi/pagekit-next @arovi/pagekit-cli CLI tooling for scaffolding and management pnpm add -g @arovi/pagekit-cli pagekit-core Python client for the PageKit content API pip install pagekit-core

PageKit exposes your content through the Model Context Protocol (MCP), enabling AI agents like Claude, Codex, and Cursor to read and write your content directly.
