About vertex-studio-oss

⚡ Vertex AI Studio & Gemini Web Bridge (v4.0 OSS)

Zero-Trust Bridge connecting AI Coding Agents (Antigravity, Cursor, Claude Code) directly to Gemini 4 Web & Google Cloud Studio — Fast, Free, and API-Key-Free.

Direct Chrome DevTools Protocol (Port 9222 ↔ Bridge Port 8765) • Native MCP Server • Smart Code Bundler (.txt) • Auto-Locale UI (🇹🇭/🇬🇧) • Visual Cockpit Dashboard (Port 5005)

Feature Description :--- :--- 🔌 Native MCP Server Built-in Model Context Protocol server (bridgemcpserver.py) with 5 standard tools: askargon, askcarbon, checkjob, bridgestatus, and extractlatest. ⚡ Fast Fire-and-Forget Dispatches prompts and local file attachments to the browser in under 2 seconds via Persistent Bridge (:8765) without blocking the agent. 🎫 Atomic Job Tickets Persists job states (latest.status.json) and answers (latest.md) using atomic writes (UUID + fsync) to prevent file corruption or stale reads. 📦 Smart Code Bundler Consolidates project files into a single .txt bundle with 3 modes (audit, feature, diff), reducing token overhead by 40% – 80%. 🛡️ Search & Replace Guardrails Supports dynamic markdown code fences (4–5 backticks) so nested code blocks and patches never break. 🌐 Auto-Locale UI (TH/EN) Automatically detects browser language (navigator.language) with an instant 🇹🇭 TH / 🇬🇧 EN toggle on the Bridge Control Panel. 🎛️ Visual Cockpit (Optional) Side-by-side green/red diff preview dashboard (server.py on port 5005) with Zero-Trust Read/Write scope separation.
