About TrustGate

TrustGate is an open-source AI gateway that routes, secures, and observes traffic between applications, AI agents, LLM providers, MCP servers, and other agents.

A security-first gateway for LLM, MCP, and agent-to-agent traffic, built in Go.

Documentation &nbsp;&nbsp; Quick start &nbsp;&nbsp; Examples &nbsp;&nbsp; Architecture &nbsp;&nbsp; Community

Applications, coding agents and autonomous agents call TrustGate instead of calling providers, tool servers and other agents directly. TrustGate decides who the caller is, where the call may go, which policies apply, and records what happened.

Traffic Plane What clients reach through it --------- LLM Proxy :8081 17 model providers, through the API dialect the client already speaks. MCP MCP :8082 Upstream MCP servers and OpenAPI services exposed as tools, aggregated behind one endpoint. Agents Agent :8084 Other agents over A2A (0.3 and 1.0), with pinned cards, task ownership and delegated identity.

All three share one admin API (:8080), one identity model, one policy engine and one telemetry pipeline.

- Any client dialect, any provider. OpenAI Chat Completions and Responses, Anthropic Messages, Gemini and Vertex AI, Cohere Chat and native Bedrock Runtime calls are translated to whichever provider serves the request, streaming included. Claude Code, Codex, the Gemini CLI and stock SDKs work by changing the base URL. - Routing that survives outages. Simple routing, fallback chains with triggers and an attempt budget, smart routing across two or three ordered models that keeps a conversation on one and upgrades the harder turns
