About iran-gold-mcp

iran-gold-mcp: live gold prices from Iranian gold platforms for AI agents

Compare the 18k gold price on Milli.gold, Wallgold, Melligold, Daric and Taline from your AI agent. An unofficial, read-only MCP server for Iranian online platforms that sell 18k melted gold (طلای آب&zwnj;شده): live buy and sell price per gram on each platform, the cheapest place to buy, the best place to sell, and Milli.gold's price history.

For AI agents · Quick start · Tools · Good to know · FAQ · فارسی

- What: unofficial MCP server (model context protocol) for the public prices of five Iranian online gold platforms: milli.gold, wallgold.ir, melligold.com, daric.gold and taline.ir. - Install: uvx iran-gold-mcp or claude mcp add iran-gold -- uvx iran-gold-mcp. Transport: stdio. Needs uv (Python 3.10+). - Auth: none, no API key or account. Optional IRANGOLDMCPPROXY (HTTP proxy URL, or a comma-separated list); system proxy settings are ignored. - Access: read-only, so no confirmation is needed before calling any tool. It cannot log in, trade or read a wallet. - Tools: 3, all prefixed gold. Typical sequence: goldprices - goldmillihistory. - Use when: the user asks what 18k melted gold costs per gram on these platforms, where it is cheapest to buy or best to sell, or how the Milli.gold price moved over a day, week or month. - Do not use when: the user wants to buy or sell gold, or wants dollar, coin or crypto prices (see tgju-mcp). - Output: compact JSON. goldprices is Toman per gram of 18k gold; goldmillihistory is Rial per milligram. Times are Tehran time.
