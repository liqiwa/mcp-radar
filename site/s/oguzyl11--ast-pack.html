About ast-pack

ast-pack is a Rust CLI and MCP server. It packs a repository into a hard token budget. Anything it leaves out keeps a stable fold id, and an agent can ask for that body later with unfold. Nothing is deleted. It is only deferred.

The Homebrew formula in homebrew/ast-pack.rb builds the main branch (brew install --HEAD). The npm package in npm/ runs a local ast-pack binary, or the path in ASTPACKBIN.

--focus that does not fit in the budget is an error. A directory prefix matches that tree (--focus src/auth matches src/auth.rs and src/auth/token.rs).

setup registers the MCP server with Cursor, Claude Code, Codex, and Gemini CLI. It copies each file it edits aside once. setup --remove puts those files back.

Level What you get --- --- L0 Full source L1 Signature, doc comment, and the full type (struct fields, interface members, enums, aliases) L2 Signature L3 Name L4 Omitted. The file stays in the tree

Fold ids are . A second overload in the same file is ~2, then ~3, in source order. If the file changed after the fold was written, unfold returns the current body and says so on stderr.

ast-pack mcp speaks JSON-RPC on stdin/stdout. It accepts a bare JSON line or a Content-Length frame.
