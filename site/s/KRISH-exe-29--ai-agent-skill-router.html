About ai-agent-skill-router

Stop your AI coding agent from guessing between 800 skills.

skill-router picks the right skills, subagents, plugins and MCP servers for each task. skill-audit finds the duplicates and dead weight, and cleans them up with your approval.

Works with Claude Code · OpenAI Codex · Cursor · Gemini CLI · GitHub Copilot · Google Antigravity · OpenCode · Windsurf / Devin Router-only fallback for Lovable and Google AI Studio

Quick start · Install · How it works · Audit · FAQ

You install a skill pack, a few plugins, five MCP servers, a design kit, a "superpowers" bundle… and now your agent has hundreds of skills it might use, many of which do the same job.

- It picks a different code-review skill every time, or none. - Three planning workflows fight over the same task. - Tool descriptions eat your context window on every turn. - You can't remember what you installed, let alone what you actually use.

The author's own setup had ~800 loaded skills, and only 17 had ever been invoked. That's what this project was built to fix.

What it does When it runs --------- 🧭 skill-router Classifies the task, picks the minimum set of skills + one subagent + the MCP tools it needs, announces them in one line, then invokes them. Automatically, before multi-step or ambiguous tasks. Skips quick questions. 🧹 skill-audit Inventories every skill, subagent, command, plugin, MCP server and connector. Finds overlap clusters and unused items, proposes disables, merges and routing rules, and applies only what you approve, one by one, with undo. Only when you run /skill-audit. Never on its own.
