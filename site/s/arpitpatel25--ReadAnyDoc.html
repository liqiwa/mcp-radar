About ReadAnyDoc

Parse and extract documents with vision models, on your own machine and your own model account. Open source, Reducto-compatible, built by Unmute. Website: https://arpitpatel25.github.io/ReadAnyDoc/

ReadAnyDoc reads every page of a PDF, scan, photo or Office file with a vision model (Claude Haiku 5.5 by default) and returns typed blocks, tables, Markdown, or the fields of your schema, each with the place on the page it came from. Around the model sits an engine that adds what a model alone does not give you: block types and positions, form fields, headers and footers, table checks, word-level citations. It runs as a Python library or as a server that speaks Reducto's HTTP API, so existing Reducto integrations work by changing one URL.

A real document, unedited: the US government's sample Loan Estimate, extracted in one call for about 1 cent. All 11 fields are right, and every box is a citation ReadAnyDoc returned. A yes/no answer that is not printed as one word is marked low confidence instead of pretending. A faded 1904 invoice is in the same folder: examples/showcase. If it looks useful, ⭐ star the repo.

Five public benchmarks (about 4,250 pages and 10 long documents), each scored with the benchmark's own grader (no AI judge). Same documents and same requests for all three systems. Details and caveats: BENCHMARKS.md.
