About sandbox-mcp

Give your AI agent a brand-new Windows PC. Then throw it away.

Not your desktop. Not a container pretending to be Windows. A real, disposable Windows 11 machine: boot it, deploy your app, drive the controls, catch the crash, keep the evidence, delete the PC. Run it directly with sbx; the optional MCP adapter exposes discoverable tools and inline images for clients that want them. Both interfaces use the same engine. The measured GUI samples take roughly 40-50 seconds end to end. See the website.

Real app, real guest: Haptics Everywhere's self-contained WPF/WinForms desktop app in a fresh, network-off Sandbox. UIA selects the Inspector, the guest switches light to dark, the app relaunches and exits, then the guest is destroyed. 10-second, 183 KB edited footage: light Inspector slowed for readability, repeated dark frames trimmed. Boot/teardown title cards summarize actual logs, not filmed boot/shutdown. No guest runtime installation or haptic-hardware claim. Fresh dark lab screenshot · Earlier light-theme inspector.

Give this to your bot. It checks the PC, verifies the download and asks before admin changes or a restart. The CLI works on its own; configure MCP only if your agent needs that interface:

Download v1.2.0: portable CLI + optional MCP server, bundled Node.js, guest agent and setup instructions. No Node/npm installation needed.

“Works on my machine.” Caught in 30 seconds.
