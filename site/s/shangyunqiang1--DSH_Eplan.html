About DSH_Eplan

把 Bochica 的 EPLAN 能力移植成 DeepSeek Harness 插件（bundle）： 在本机直接操控 EPLAN Electric P8 2025，并离线查阅 2025 / 2026 / 2027 / EEC Pro 文档，附带 5 个技能。

1. 新增 EPLAN P8 2025 的版本精确离线文档索引（API 参考 + 平台帮助两部分）。 Bochica 的托管文档只覆盖 2026 / 2027 / EEC Pro（rag2025.covaga.xyz 不存在），EPLANSkills 也写明「P8 2025 的接口应结合本机核对」。 本插件一方面解析本机安装的 Eplan.EplApi.u.xml（12 个程序集、36,493 个成员）生成 API 索引，另一方面 一次性爬取官方帮助站的 Plattform/2025 用户手册（2,691 页：对话框、设置、命令、概念、提示信息）——两者 都是版本精确、全程离线、每条结果带官方帮助页 URL。 2. 全部文档本地化（五套索引）。 2026 / 2027 / EEC Pro 原本依赖 Canary E-cad 的云托管 RAG 服务（查询会离开 本机）；本插件改为一次性爬取官方帮助站 www.eplan.help，写入本地 SQLite（data\eplan2026-help.sqlite 等）， 之后所有检索都在本机完成，不再联网。同时补上了原方案完全没有的 2025 平台用户手册（2,691 页）。

API 参考 ≠ 用户手册：eplan2025 只有 .NET 类型/成员（写脚本、做插件用），eplan2025guide 才是「这个对话框 在哪、这个选项什么意思、这个流程怎么走」的手册内容。提问时先分清是哪一类；查不到通常说明用错了服务，而不是 文档缺失。
