About DroidPath

Persistent A\ Symbolic UI Router, Headless Kotlin Shadow DOM Daemon & Standalone MCP Bridge for Android

DroidPath eliminates slow, token-heavy VLM screenshot-think-tap loops for Android automation. Instead of asking an LLM to inspect screenshots at every step, DroidPath streams a live Shadow DOM directly from Android Accessibility & Window APIs, compiles UI transitions into a persistent Spatial Graph, and navigates multi-screen workflows deterministically with A\ pathfinding in sub-second hops — with zero intermediate LLM roundtrips.

1. Layer 1 — Headless Kotlin Shadow DOM Daemon (android-daemon/): - Compiles into a standalone 631 KB single-DEX JAR (android-daemon.jar) launched via appprocess — zero companion APK install required. - Streams full snapshots and compact NDJSON incremental diffs over TCP (:27189) with event debouncing, configurable tree depth, and heartbeat/watchdog protection. - Deployed idempotently via SHA-256 verification (DroidPathManager / deploy.sh) and protected by automatic self-healing recovery if Android kills the process.

2. Layer 2 — Live Shadow DOM & Persistent Spatial Graph (AndroidShadowGraphKit): - ScreenLayoutHasher strips volatile timestamps, clocks (12:34), and dates so returning to Home or Settings hashes deterministically. - SpatialGraphEngine constructs a directed multigraph of screens (vertices) and UI gestures (edges), automatically compacts near-duplicate screens via Jaccard similarity (= 0.90), and persists to ~/.droidpath/shadowgraph.json.
