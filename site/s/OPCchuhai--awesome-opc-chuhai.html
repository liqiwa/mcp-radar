About awesome-opc-chuhai

一人公司要把 AI 产品卖到海外，从大模型与 MCP、到建站收款与获客，先看这里。

这是一份写给华人一人公司 / 独立开发者的出海清单。重点不是罗列所有 AI 套壳，而是一个人真正能做出来、卖出去的方向：AI SaaS、AI 网站、AI 游戏，以及搭建这些产品会用到的大模型 API、MCP、建站托管、跨境收款与获客渠道。每条都指向官方页面，并附一句适用场景。优先收录免费产品，或有公开文档可查的免费档。

价格、开通资格、模型能力和可用地区会变动，以各官网当时公布为准。本清单只整理公开资料，不提供法律、税务或投资建议。

1. 💡 选定产品形态 → Solo AI products（AI SaaS、网站或游戏） 2. 🧠 接上模型与工具 → LLMs & APIs · 🔌 MCP 3. ☁️ 上线并收款 → Hosting · 💳 Payments · 🏢 Company 4. 🚀 发布与获客 → Launch · ✍️ Content

需要起步代码时，再看 📦 开源模板。想先看看已经在向海外用户交付的 AI 产品，读 🌏 AI 出海项目。欢迎通过 Pull Request 补充或修正条目，提交前请阅读 CONTRIBUTING.md。

能支撑一种可售卖产品的框架、引擎和官方工具，而不是随机 AI 应用合集。常见路径：把模型做成订阅制 SaaS、用生成能力做网站产品，或用轻量引擎做能在网页 / itch.io 分发的 AI 游戏。

- Vercel AI SDK — 在 TypeScript / Next.js 里接入多家模型、流式输出和工具调用的官方 SDK，适合做 AI SaaS 的应用层，而不是绑死一家供应商。 - Next.js — 全栈 Web 框架，适合一人同时做产品站、营销页和 API 路由，是常见的 AI 网站与 SaaS 起点。 - v0 — Vercel 的 AI 界面生成工具，用自然语言先出 React 页面，适合快速搭 AI 产品的前端原型。 - Bolt.new — 浏览器里的全栈 AI 开发环境，适合用一句话先跑通可演示的网站，再迁到自己的仓库和域名。 - n8n — 开源工作流自动化，可把模型、表单和第三方服务串成可售卖的自动化或 Agent 流程，也可自托管。 - Godot Engine — 开源游戏引擎，授权宽松、体量适合单人开发，可用来做带 AI 角色或生成内容的独立游戏。 - Phaser — 浏览器 2D 游戏框架，适合把 AI 玩法做成即点即玩的网页游戏，降低下载和分发成本。 - Three.js — 网页 3D 渲染库，适合做可在浏览器里运行的 3D 场景、AI 角色展示或轻量 3D 游戏。 - itch.io — 独立游戏与数字内容分发平台，页面简单、起步门槛低，适合一人先把 AI 游戏或实验作品卖出去。 - ElevenLabs — 语音合成与克隆的官方平台，适合给 AI 网站、口播内容和游戏角色配多语言声音。 - Black For
