About keepcontext

One self-hosted memory for every AI app you use. Tell ChatGPT an idea, and Claude Code, Cursor and Gemini know it too. Start a task in Claude Code, and when it hits its usage limit, Codex continues from where it stopped.

KeepContext is a small server with a web dashboard and one MCP endpoint. ChatGPT, Claude (web, desktop, Claude Code), Gemini (web, CLI), Cursor, Codex, GitHub Copilot and Antigravity all connect to it. Your data stays on your machine or server.

Built for students, researchers and developers: anyone whose work is spread across several AI tools and who wants every one of them to know the same ideas, todos and project status.

▶ Watch the 2½-minute demo: setup with Docker, public access for web apps, GitHub, saving an idea in ChatGPT that Claude already knows, and a coding task that Copilot continues after Claude Code hits its limit.

What KeepContext keeps for you Example --- --- --- 🎓 Students Course notes, study plans, deadlines and todos, the same in every AI app Plan your week in ChatGPT, then ask Claude what's due on Friday 🔬 Researchers Hypotheses, reading notes, experiment decisions and open questions Save a paper idea in one chat; any assistant can recall it and build on it later 💻 Developers Project decisions, coding rules, GitHub progress, and multi-step tasks Claude Code hits its usage limit mid-task; Codex, Cursor or Copilot continues from the last checkpoint
