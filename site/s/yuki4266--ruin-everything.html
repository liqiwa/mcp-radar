About ruin-everything

English &nbsp;·&nbsp; 简体中文 &nbsp;·&nbsp; 日本語 &nbsp;·&nbsp; Español

Pick up a browser task where the last agent left it. Ruin connects to Chrome on your machine. A new CLI run or MCP client can find the same open application tab, finish a supported verification step, and check what the site actually confirmed.

Set up Chrome · Connect an MCP client · See what has been tested · Try your first MCP call · Contribute

In your browser What Ruin can do --- --- A Greenhouse application asks for an email code Match a fresh Outlook message to the application and fill the code. An Ashby tab closed after submission Look up a previously captured receipt by the exact job URL. A Workday tenant asks you to sign in Use the local profile and follow a supported account activation back to the job. You have phone numbers from several countries Choose a default in the offline identity editor.

For a new task, start the shared browser and open the target site. For an interrupted application, choose the site-specific watcher and pass the original job URL. Generic click tasks open a new tab.

Install from the repository directory with Python 3.11+ and Google Chrome:

Run ruin browser to start or reconnect to the project browser. Every CLI task uses Python Playwright over CDP. The default endpoint is http://127.0.0.1:9222. The runner launches Chrome with a dedicated profile at ~/.ruin-everything/canvas-browser when this port is free.
