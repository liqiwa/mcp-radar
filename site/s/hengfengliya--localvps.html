About localvps

运行一个程序，拿到一个公网地址和一个令牌。 Claude Code、Codex 不管在哪儿跑，都能远程在这台电脑上读写文件、执行命令。

Windows：下载 localvps-windows-x64.exe，双击运行。

运行后浏览器自动打开控制台，接入命令在「连接」页一键复制。不用注册，不用公网 IP，不用开端口，不用域名。

你的电脑上已经有你要的一切：代码、装好的工具链、登录好的命令行、本地数据库、显卡。可 AI 常常不在这台电脑上跑——在云端，在另一台机器，在你用手机遥控的会话里。

租一台 VPS 要按月付钱，还得把环境从头装一遍；自己搭内网穿透再写一个 MCP 服务，鉴权、权限、日志都得自己补。

- 云端或另一台电脑上的 Claude Code、Codex，直接改你本机的项目、读你本机的资料 - 让 AI 用只有你电脑上才有的东西：配好的开发环境、登录好的 CLI、内网里的服务、GPU - 把一台闲着的电脑当成几个 AI 会话共用的工作机，在控制台里看它们都干了什么 - 出门在外，用远程查看链接看家里那台电脑的状态和 AI 的每一次操作

- 一个文件，运行即用：macOS（Apple 芯片、Intel）和 Windows 单文件版，不用装 Node - 自带隧道：内置 Cloudflare 隧道，默认什么都不用填；想要固定地址，填上自己的域名 - 标准 MCP：Streamable HTTP 加 Bearer 令牌，Claude Code、Codex 和任何支持自定义请求头的 MCP 客户端都能接 - 三档权限：只读、工作目录读写、完全权限，控制台点一下就换，下一次调用就生效 - 每次调用都记着：工具、参数、耗时、成功失败，错误令牌的来访也记下来源 IP - 像云服务器后台的控制台：CPU、内存、网速、磁盘和近 5 分钟曲线 - 远程查看：一条只读链接，在别的设备上看这台电脑，泄露了也只能看 - 一键开关：暂停接受调用、重置令牌、换隧道地址，都在控制台里 - 不让电脑睡着：运行期间防休眠，退出时一起停 - 一键更新：有新版本时控制台会提示，点「更新并重启」自动下载、校验、替换，令牌和设置不变

1. 运行：用上面的一行安装，或者下载后直接运行。浏览器会打开 http://127.0.0.1:18788 的控制台。
