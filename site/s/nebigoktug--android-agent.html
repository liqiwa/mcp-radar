About android-agent

Let an AI agent use your Android phone and its apps — about 10× cheaper than screenshot-based tools.

Works from your computer (Windows, macOS, Linux) or directly on the phone (Termux, no PC needed). Plugs into Claude Code, Cursor, Claude Desktop and any other MCP client.

Most phone agents look at the screen as images (~1,500 tokens per look). android-agent reads it as a short numbered list from Android's accessibility tree, and after the first look sends only what changed:

That screen is ~150 tokens. The agent replies tap 5.

Screenshots are used only when text is not enough (games, Flutter apps, maps).

In a first test (6 everyday tasks: Settings, YouTube search, Calculator, Clock, Play Store, Maps) 19 screen reads cost ~2,700 tokens, versus ~28,500 as screenshots. See BENCHMARK.md.

- An Android phone with Developer options (Android 11+ for wireless; any version with a USB cable) - Python 3.10+ and adb (Android platform-tools) on the computer — or Termux on the phone - No other dependencies. Optional: Pillow (smaller fallback screenshots) and Tesseract (reads text from apps that expose none, e.g. games; set AAOCRLANG=eng+deu etc.)

1. Install adb: - Windows: winget install Google.PlatformTools - macOS: brew install android-platform-tools - Linux: sudo apt install adb 2. On the phone: Settings → About phone → tap Build number 7 times, then Developer options → turn on USB debugging. Xiaomi / Redmi / POCO: also USB debugging (Security settings) and Install via USB. 3.
