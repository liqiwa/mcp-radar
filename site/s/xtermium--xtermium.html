About xtermium

xtermium is a terminal with a session manager. Your SSH, RDP, VNC, telnet, serial, WinRM, website and BMC sessions live in one sidebar and open side by side, in one window.

Homepage · Docs · Screens · Download · Source

- One window, not ten programs. SSH here, RDP there, a VNC viewer, telnet for the switch, a browser for the console page: xtermium opens them all as tabs and split panes, and types into many at once. - Your logins stay locked. Everything on disk is encrypted with a key in your OS keychain. A recovery passphrase brings it back on a new computer. - An agent can use it too. AI assistants and scripts open sessions, run commands and read the output through the same tools you use, without ever seeing a password.
