About session-relay

Pick up where your teammate left off. Share coding-agent sessions across Claude Code, Codex, OpenCode, Gemini CLI, Copilot CLI, Cursor and ZCode. Your teammate continues in whichever tool they use, with the goal, decisions, next steps and recent conversation.

Handing off agent work means copy-pasting chat logs, or the next person starting from zero. With Session Relay:

- /share: the agent writes a handoff (goal, decisions, done, next steps, open questions) and shares it with the recent conversation and the files touched. - /pickup: the next person's agent finds it, reads it, checks the code and continues, in any of the supported agents. - Handoff chains: work picked up and shared again is linked, so every session shows who started it and who continued it. - Work live together (/live): when two people work at the same time, see who's on what and which files they touch, and send messages that reach each other's agent between steps. Agents show messages to you first, unless you let them act on their own. - Handoffs for someone: share "for Akshat" and it's first in their /pickup. Edit a share any time (next steps, title, who it's for). - Auto-share drafts (opt-in): every Claude Code, Gemini CLI and Copilot CLI session is saved as a private draft when it ends; publish it when it's ready. - Diff snapshots: attach your uncommitted changes to a share; the next person git applys them. - Handoff templates: admins decide what a handoff must include per repo ("Tests run", "Migration notes") in a guided editor with ready-made sections and a preview; /share follows it. - Comments: team
