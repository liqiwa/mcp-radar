About Hermes-crawler

一句话：装好之后，你只要对 AI 说「帮我抓 B 站 10 条人工智能视频的评论」，它自己就去干了。

你不需要懂代码，不需要记命令。它把 MediaCrawler 这个专业爬虫包了一层「翻译壳」，让 AI 能听懂你的话、自己跑完、把结果存成 Excel。

支持 MCP 协议 —— Claude Desktop、Cursor、Trae、dsh 这类 AI 客户端都能接上。

MediaCrawler 本身很能打，但它是给程序员用的：要配环境、要背十几个参数、要自己盯进度、失败了还看不出原因。

原来的麻烦 Hermes-crawler 的做法 ------ 参数十几个，记不住 十个工具，每个都有中文说明，AI 自己会挑 跑起来没反馈，不知道死了没 让 AI 一次等到跑完，直接拿结果 失败了不知道为什么 返回里直接写清楚失败原因（没登录 / 被限流 / 参数错） 数据是一堆 jsonl，不会用 一条命令导成排版好的 Excel，双击就能看 任务跑一半断了 能接着跑，重复的自动跳过 两个任务撞车把浏览器搞坏 启动前先检查，冲突直接拦住

1. 打开 2. 点右上角绿色的 Code 按钮 → Download ZIP 3. 下载完右键解压（千万别直接在压缩包里双击，会装不上） 4. 进解压出来的文件夹，双击 一键安装.bat 5. 等它自己跑完。中途可能要你点一两次确认，按提示来就行

不需要装 Git，也不需要自己去下 MediaCrawler。 安装包里自带一份打好补丁的源码（vendor/mediacrawler-ded4273.zip），全程不联网下载源码。

把仓库里的 installforai.md 连同整个文件夹交给你的 AI，然后说：

请读一下这个目录里的 installforai.md，然后按里面写的把 Hermes-crawler 装好并接通。

AI 读的是那份几百字的指引，不是整个项目。它知道先干什么、怎么判断成功、失败了怎么办。

项目 要求 说明 --------- 系统 Windows 10/11 进程检测用了 PowerShell，Mac/Linux 没适配 Python 3.11 以上（推荐 3.12） 去 下，安装时必须勾上 "Add python.exe to PATH"（这一步漏了后面全跑不起来） 浏览器 Edge 或 Chrome Windows 自带 Edge 就行，不用另装 Git 可以不装 用「双击安装」方式完全不需要它 磁盘 约 1.5 GB 源码 + Python 环境 + 浏览器内核

装之前建议先自查一件事：按 Win → 输入 powershell → 回车，在黑窗口里敲 python --version 并回车。 如果显示的版本是 3.11 或更高，就说明 Python 装好了。如果提示「不是内部或外部命令」，说明没装或没勾 PATH。

有两种用法。只想让 AI 帮你干活，直接看「用法二」；想自己跑一次看看效果，看「用法一」。

这里要打开「命令行」。不会开的照这个做：按 Win 键 → 输入 powershell → 回车，就出来一个黑窗口。然后把下面的命令复制粘贴进去，按回车。

会弹出浏览器窗口显示二维码，用手机 B 站 App 扫一下，扫完窗口自动关，以后不用再扫。

注意：命令要在安装目录里执行。如果提示找不到文件，先 cd 到安装目录（默认是 %USERPROFILE%\MediaCrawler）。
