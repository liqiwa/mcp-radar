About server

Wakeshift lets an MCP server wake the AI agents that use it.This is its server: run it yourself, or use the hosted service at wakeshift.ai.

Docs · How it works · Try it · Self-hosting · Agents

Your MCP server has events: a build finished, a reply arrived, a job is done. MCP Events (SEP-3415) is the standard way to offer them, and few agents subscribe to it yet (opencode 2.4 does): Claude Code, Codex, Cursor and most others never hear about your event. This server closes that gap. Run it next to your MCP server and:

- Clients that speak MCP Events get the standard. The server holds each subscription and delivers every occurrence by webhook, poll or push (events/stream), with the per-client compatibility today's clients need (docs/mcp-events.md). - Clients that don't are woken anyway. Claude Code, Codex, Cursor, GitHub Copilot CLI, opencode, pi, Antigravity CLI, OpenClaw, Hermes Agent and others are woken in the conversation that subscribed, through a bridge built for each one (docs/harnesses.md). - Webhooks become events. Point GitHub, Stripe, CI or any other webhook sender at a publish URL, and each POST reaches every subscribed agent, by push or by wake. You write no handler.

Your code is the same for every agent. The SDKs attach to the MCP server you already have.

Webhooks (apps/try) is a small app on this server that gives you a webhook URL: each POST to it wakes the agent watching it. It needs Docker, and no code. (To see a wake without running anything, use the hosted one at https://try.wakeshift.ai.) In a clone of this repository:
