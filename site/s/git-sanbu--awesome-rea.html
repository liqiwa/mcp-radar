About awesome-rea

Awesome REA — Reverse Engineer Anything 实践案例与用法

Real-world REA use cases, examples and AI-assisted reverse engineering case studies.

收录网上公开的 REA — Reverse Engineer Anything 实践：研究了什么、REA 具体帮了什么、最后做出了什么，以及哪些地方仍未验证。

这是独立社区案例集。首批 21 个案例均附公开原始来源，其中 5 个来自官方 Showcase，16 个来自社区项目。最后核对：2026-10-16。

这里的“已收录”表示已阅读来源并找到明确的 REA 使用说明。成果和测试数字按原作者报告转述，本仓库未独立复跑，不代表完整兼容或生产可用。

想找具体软件？打开 可搜索案例目录，输入 Ghostty、PowerToys、Electron、游戏移植 或 录屏。也可以按案例类别筛选。

- 想把老游戏搬到新平台： 看 Desktop Games、Snowball War。 - 想理解一个小功能并自己实现： 看 PowerToys 取色器、Aegis 验证码、Ghostty 终端外壳。 - 想做独立桌面应用： 看 Paper 无限画布、录屏工具、会计账本。 - 想研究协议或平台兼容： 看 声卡 DSP、Linux VR 串流。 - 想先判断 REA 靠不靠谱： 看 源码对照、Windows 对照评测、REA 分析自己。 - 想直接动手练习： 看 Electron 最小实践、CTF 检查器。

每个详情页都包含：目标问题 → REA 的作用 → 公开成果 → 局限 → 原始来源。官方案例中的历史重建成果与新 REA 检查分别注明。

案例 用 REA 干什么 成果与状态 --- --- --- DX-Ball：恢复声音左右声道计算 画面中的位置怎样转换成音效声像？ 来源记录：该函数通过 3,205 个原始 x86 差分用例，历史编译器重编译后的完整 63 字节匹配。 Notion：追踪 Electron 富文本剪贴板桥 网页编辑器如何通过桌面端写入富文本剪贴板？ 公开案例展示了 renderer → preload → IPC → main 的源码级解释，以及独立模块探针中的富文本标记与 Markdown 表格处理。 TH04：恢复 PC-98 弹幕环形角度算法 环形弹幕如何均匀展开，并叠加瞄准玩家的方向？ 案例给出 REA 新检查结果，并引用历史 Turbo C++ 检查：包含该辅助函数的 2,139 字节范围匹配。 Aegis：从 Android APK 找出动态验证码算法 每 30 秒变化的六位登录码是怎么计算的？ 官方页面报告：提取方法与独立实现对照 133 个用例，并核对 RFC 6238 的六个 SHA-1 参考样例。 DownUnderCTF：从二进制恢复 flag 检查方程 没有符号和源码，如何找出输入校验逻辑？ 官方记录了正确候选输出 Correct! / exit 0、错误候选输出 Incorrect! / exit 255；求解后再对照主办方源码与 metadata。

案例 用 REA 干什么 成果与状态 --- --- --- Desktop Games：把砸桌面小游戏移植到 macOS 和浏览器 怎样理解 Peter 解释器和程序树，并移植交互与资源？ 公开仓库包含 Swift macOS 版、浏览器版、反编译程序树及资源处理脚本。 Ski or Die：用 Rust 重建 Snowball War 怎样从旧 DOS 程序恢复投掷、碰撞、刷怪与计分规则？ 作者公开了 Rust + SDL2 可玩重建、行为规格、逆向笔记与资产提取工具。
