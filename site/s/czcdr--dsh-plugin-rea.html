About dsh-plugin-rea

把 REA — Reverse Engineer Anything 接入 DeepSeek Harness (dsh)： 一个纯配置型 Cordis bundle，复用官方 MCP 客户端插件 @deepseek-ai/dsh-mcp-client， 把本机已安装的 rea mcp（stdio）注册成原生工具。装载后模型直接拥有 mcprea 工具。

与上游的关系（重要） 本仓库是第三方适配封装，不是 REA 项目的组成部分，也不包含 REA 的任何源码， 更不由 REA 作者维护。它只做一件事：向 dsh 的配置组合里插入一条指向你本机 rea 安装的 MCP 服务器记录。 - 上游项目：REA — Reverse Engineer Anything — （MIT） - 上游文档： · 中文 · 站点 - 上游 npm 包：rea-agents - 本插件仓库： · npm：dsh-plugin-rea - 问题反馈：REA 本身的问题请提到上游；本插件的问题提到 本仓库 Issues。

What it does. This plugin performs no reverse engineering itself. It connects the upstream REA MCP server to DeepSeek Harness, so the tools REA ships become callable in a session as mcprea.

In upstream's own words, REA is "one MCP for reverse engineering across binaries, applications, and runtime behavior" — "see a feature you like. Understand how it works, down to the binary level." It connects your agent to tools for inspecting native binaries, JavaScript and Electron apps, .NET assemblies, and websites; analysis runs locally, and results include the evidence and limitations behind each conclusion. Native analysis can use an existing Hopper, Ghidra, or IDA installation, and static JavaScript analysis needs no native engine.

Upstream's own coverage list (README.mdwhat-you-can-analyze): native binaries — pseudocode, assembly, strings, symbols, calls and references; JavaScript/Electron apps — modules, imports, source maps, routes, IPC; websites — page structure, scripts, network observations, screenshots; .NET assemblies; Android APKs; Android devices over adb; JEB projects; Android resources; firmware; packages and assets; pro
