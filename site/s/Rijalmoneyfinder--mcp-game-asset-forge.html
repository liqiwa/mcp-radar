About mcp-game-asset-forge

MCP server that exposes game-asset generation to AI agents: characters with animation sets, weapons bound to hand bones, seamless textures, terrain and map layouts, VFX, HUD kits, and playable game kits assembled from modular capabilities. It's built for developers driving Claude Code, Cursor, Windsurf, VS Code, or any other MCP client who want assets landing in their repo rather than a chat window. Python, with tools covering the full pipeline from prompt or concept image through rigging, engine-specific snippets for Unity, Godot, Unreal and Three.js, and a searchable asset Library.

Capability What you get --- --- Animated characters Prompt in, rigged T-pose character out — with an idle/run/attack clip set and an engine-ready skeleton. Weapons attached The server locates the hand bone, scales the prop to the rig, closes the fist around the grip, and returns a bone-local bind plus Three.js, Unity and Godot snippets. Optional attached.glb export for mitten-hand rigs. Seamless textures Tileable material sets from a prompt or your own image, prepared with a seamless blend and a faithful upscale — no invented detail. Terrain & maps Playable room graphs, top-down layouts with spawns, sites and lanes, plus greybox reconstruction from reference material. VFX & HUD Animated effects with editable specifications, and themed HUD/health-bar kits exported for your engine. Playable game kits Modular gameplay kits assembled into a project with dependency resolution and a lockfile, delivered into Godot, Unity or Unreal, and playable from a browser URL. Everything in one Library Generated
