About Conector

Connect 1,178 apps once and use them from Claude, Codex, Cursor, Gemini CLI, GitHub Copilot and 42 more AI agents. Self-hosted and open source. Your credentials stay encrypted on your own server.

Quick start · Agents · Apps · Security · Add an app · About

AI agents can only use the tools they can reach. Wiring every agent to every app means juggling API keys, OAuth apps and config files on each machine, for each agent. Conector puts all of it in one place:

1. Connect an app once in the web panel, by signing in or pasting an API key. 2. Add Conector to your agents with one command or config snippet. 3. Every agent gets tools for every app you connected, over the Model Context Protocol.

1,178 apps GitHub, Gmail, Google Drive, Notion, Slack, Linear, HubSpot, Salesforce, Stripe, Microsoft 365, Jira and more. 107 connect with one click. The rest take an API key, a username and password, or nothing at all.

1,416 tools Every app gets an authenticated &lt;app&gt;request tool for its whole API. Many add specific tools such as outlooksearchmail, jirasearch or slacksendmessage.

47 agents The panel shows the exact command or config file for each agent, with a token already filled in. conector install &lt;agent&gt; writes it for you.

Built for teams Admins and members, invitation links, personal and shared connections, and per-agent tokens limited to the apps you choose.

Private by design Credentials are encrypted with AES-256-GCM and only sent to the app they belong to. The panel loads no external scripts, fonts or images.
