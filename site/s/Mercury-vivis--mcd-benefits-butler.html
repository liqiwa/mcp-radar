About mcd-benefits-butler

一个基于麦当劳官方 MCP 能力（mcd-mcp-server）的 WorkBuddy Skill / 开源工具。

官方只在你买单那一刻提醒你一次，之后便再无人提。它帮你回头翻历史订单，把还来得及的评价券扫出来。

麦当劳的微信小程序、官方 App、支付宝小程序，已经把积分兑换、领券、抽奖做得很完整（每月 8 号会员日、周一"麦麦省"、周六"麦金喜"等官方入口都很成熟）。这些事用官方 App 就够了，本项目不打算替代它们。

- "用餐后评价 → 领券"这个机制，官方只在你买单那一刻提醒一次，入口是三类被动触发：支付后的推送、桌贴/小票上的二维码、公众号回复； - 你没点、没扫、忘了，它就再也不会出现——官方没有任何入口会回头告诉你"你有哪些订单还没评价、还来得及领券"。

麦麦权益管家就补这一件事：扫描历史订单，把尚未评价、且奖励券仍可领取的订单挑出来，列成待办提醒你。

依据：麦当劳中国官网新闻《顾客反馈移动平台上线》（2017-01-23）与《5元换购券！分享用餐体验就能GET》证实中国区确有"用餐后评价→发放换购券"机制，入口为上述三类被动触发；在官方渠道与公开检索中，我们未见任何"回溯历史未评价订单"的入口。这正是本项目的立足点。

1. 用餐评价券扫描 🕵️（唯一主打 · 官方未见对应入口） 逐单扫描历史订单，挑出尚未完成评价、奖励券仍可领取的订单，一次性给出待办清单。

2. 积分盘点与兑换建议 💎（官方已有，我们补"排序 + 临期提醒"） 官方小程序 / App 内已有积分商城。本工具读取积分账户，按所需积分升序排列可兑商品并标注当前能否兑换，同时把已过期 / 临期风险摆到明处，专治"不知换啥、眼看过期"。

3. 活动与抽奖一屏聚合 📅（官方已有，我们补"聚合"） 官方 App 独占"周一麦麦省""周六麦金喜"等活动。本工具把当月活动日历、积分抽奖信息、可领券聚合到一屏，省去在多个入口来回翻。

事项 官方 App / 微信小程序 本工具 --------- 点餐、支付、常规领券 ✅ 完整，体验最好 ❌ 不做，也不打算做 积分查询与兑换 ✅ 已有积分商城 🔸 排序建议 + 临期提醒 活动 / 抽奖参与 ✅ 官方独占入口 🔸 一屏聚合展示 回溯"哪些订单还没评价" ❌ 未见官方入口 ✅ 本项目唯一主打

能力边界（不夸大）：评价券有领取窗口，错过后大概率不可补领——本工具的价值是在仍来得及的时候把待办挑出来，不会变出已经失效的券；且并非每笔订单都附带评价邀请，扫描结果为"本次未发现待评价订单"属正常情况。

1. 打开 WorkBuddy → 左侧「连接器」页，找到 mcd-mcp（麦当劳官方 MCP）； 2. 点「信任」启用，按提示填你的麦当劳 MCP Token（申请：https://open.mcd.cn/mcp）； 3. 把本仓库作为 Skill 接入（见 SKILL.md），或直接对我说： "用麦麦权益管家帮我扫一下，有没有还没评价的订单"

命令行、Token 管理、官方工具调用全部自动跑，无需任何代码基础。 想自己改代码 / 本地跑，见 docs/小白安装指南.md 与下方「快速开始」。

WorkBuddy 用户：将本仓库作为 Skill 接入（见 SKILL.md），MCP 配置参考 mcp-config.example.json，在连接器页对 mcd-mcp 点「信任」启用。
