About aptly

Model and reasoning recommendations for subagents, powered by the OpenAI Decisions API.

작업에 맞는 Claude Code·Codex 서브에이전트 모델과 effort를 선택하는 로컬 MCP입니다.

Aptly는 최소한의 작업 요약을 OpenAI Decisions API로 분류하고 허용된 실행 프로필을 추천합니다. 설치한 Hook은 명시 선택이 없는 새 일반 서브에이전트의 기본값을 자동으로 선택할 수 있습니다. 실제 실행과 권한 결정은 기존 호스트가 담당합니다.

자체 테스트에서 API 환산 비용이 약 52~58% 감소했습니다. 측정 조건과 상세 결과를 확인하세요.

Node.js 24 이상과 Claude Code 또는 Codex가 필요합니다. 처음 설치할 때는 다음 명령으로 최신 안정 버전을 전역 설치하고 설정하십시오.

aptly --version으로 설치된 버전을 확인하십시오. --allow-scripts=aptly는 지원하는 npm에서 Aptly의 설치 스크립트를 허용합니다. 이 옵션을 지원하지 않는 npm은 설치 안내의 명시적 설치·설정 절차를 따르십시오. Aptly 0.1.7부터 신규 등록의 자동 전송을 보류하며 aptly set default에서 OpenAI Decisions API 전송 범위를 선택합니다.

설치 시 postinstall은 기존 호스트 설정 디렉터리에 MCP와 PreToolUse Hook을 등록합니다. 명시적인 setup은 자동 등록을 건너뛰었거나 아직 설정 디렉터리가 없는 호스트에도 사용할 수 있습니다. 기존 다른 설정·Hook과 기존 Aptly 실행 명령·환경은 보존합니다.

분류용 OPENAIAPIKEY는 aptly set env OPENAIAPIKEY의 숨김 입력으로 OS 자격 저장소에 보관하거나 안전한 실행 환경에서 MCP 프로세스에 전달하십시오. 키를 명령행·요청·설정 JSON·저장소에 기록하지 마십시오. 호스트 또는 MCP를 재시작한 뒤, Codex에서는 /hooks에서 새 Hook을 검토하고 신뢰를 승인하십시오. 설치·키·등록 상세를 참고하십시오.

기존 전역 npm 설치의 Aptly 0.1.3 이상을 업데이트하려면 관련 호스트·MCP·CLI 쓰기 프로세스를 모두 중지하고 설치·업그레이드 안내의 원장 전환 및 수동 대체 절차를 확인하십시오. 기존 키 설정은 유지하므로 다시 입력할 필요가 없습니다. 명령 실행 후 재시작하십시오.

방식 동작 ------ 자동 Hook 새 호출의 제약을 검사하고 미지정 기본값을 추천합니다 직접 추천 recommendagent 또는 aptly recommend로 프로필을 받고 호스트에서 명시적으로 실행합니다 fixture 키·네트워크 없이 시험용 추천을 확인합니다. 실제 Decisions 결과가 아닙니다

Aptly 0.1.4부터 상속 호출도 추천을 평가합니다. Codex의 적용은 명시적인 forkturns: "none", Claude Code는 이력 제약 없는 일반 호출로 제한하며 명시한 필드는 보존합니다. 추천·Hook 인자 변경·실제 자식 실행은 별개입니다. 적용 조건은 가이드에서 확인하십시오.
