About ClouDrift_ROOM

✨ 最新动态 (v1.1.1)：重磅上线 🏡 2D 像素家园 & 痛墙/透明立牌 DIY、🎨 极简单行顶栏 & 独立「美化」面板（横竖双壁纸 2.5K 自适配 + 聊天背景自由拖放缩放）、☁️ 全站 SSOT 双端实时云同步（桌宠/天气/番茄钟/战绩/相框/角色隔空联动） 与多项防重/防打扰深度精修！详细改动请移步 👉 更新日志 CHANGELOG.md

⚡ 开工于2026.11.21，历时不到 16 小时爆肝打造出初版，后续持续更新中！ 一个本地优先（Local-First）、iOS 美学灵感驱动的 AI 虚拟陪伴读书室——既可开箱独立畅玩，也内置零依赖标准 MCP Server，支持把整座自习室无缝外接给你已有的任意 AI 陪伴大脑。融合 番茄钟深度专注 + 内置拟人化小手机 + 一角色一库物理隔离记忆 + 2D 像素家园痛房 + 共享阅读器 + 本地音频波形剪辑台 + 跨次元像素桌宠 + MCP 外部桥接，让屏幕两端的陪伴真正拥有“呼吸感”与“生活感”。

在这里，TA 不是冷冰冰的问答对话框，而是隔着云端与你跨屏连线的「自习室搭子」——能看见你书桌上的相框、天气、饮品和待办，能陪你一起读 PDF 文献并在页边偷偷写批注，会在你切屏摸鱼时谴责留言，甚至会在你请求切歌时严厉驳回✨

1. 🔌 独立运行 × 标准 MCP 三协议外接（双栖玩法！） 独立模式开箱即用：填入任意兼容 OpenAI 格式的 API（支持自由调节 Temperature、Top-P、话题发散/去复读惩罚、Max Tokens，自动解除 BLOCKNONE 限制），本地启动即可直接和 TA 开启连线陪伴。 零依赖标准 MCP Server 外接：不想割裂原本在其他框架里养了很久的角色？一键切换 MCP 模式，内置标准 JSON-RPC 2.0 桥接层，原生支持 Streamable HTTP（/mcp）、Legacy SSE（/mcp/sse） 与 本地 Stdio（mcp-stdio.js） 三种接入方式——完美兼容 AstrBot、Cherry Studio、Claude Desktop、Cursor 等外部框架，把整座自习室变成 TA 的「书桌感官与互动身体」！

2. 🧠 全局记忆共通 × 内置小手机深度陪伴 打破功能孤岛的「真·全局共通记忆」：自习室里发生的一切——线上通讯唠嗑、切歌申请、书页划线、便利贴留言、专注放弃、摸鱼抓包、桌宠互动——全都汇总在同一条角色时间轴里！ 💡 举个例子：上一秒你在留声机申请切歌被 TA 狠心驳回，下一秒点开「✉️ 通讯」小手机去撒娇求情，把 TA 哄开心了再回来切歌，说不定就能成功放行～ 专为长线陪伴打造的「轻量记忆系统」：不同角色记忆物理隔离 + 满值批量抛弃 + 不断更新的动态备忘录 + 多模态单轮直通 缓存，长情不失忆，拒绝烧 Token。
