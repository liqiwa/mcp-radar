About agent-kit

Backend SDK for creating and managing Web3 AI agents with auto-provisioned Abstraxn server wallets.

Docs · Examples · Dashboard · Report a bug

- Auto-provisioned server wallets — create an agent and its wallet in one call, or bring your own EVM/Solana address. - Spend policies — cap agent budgets per period, with hard-block or advisory enforcement. - Interaction policies — server-side guardrails on contracts, methods, recipients, and amounts that agents cannot bypass. - Autonomous transactions — queue, claim, sign, and broadcast on-chain intents from MCP clients. - ERC-8004 on-chain identity — register agent identity with a server or bring-your-own signer. - MCP-native & x402-aware — works with Cursor, Claude Desktop, and CLI; budgets paid MCP tools.

- Node.js = 18 - API Key from the Abstraxn Dashboard

Looking for runnable end-to-end apps? See the abstraxn-agent-examples repo — six agents you can clone and run in five minutes.
