About dsh-remote-dc

Remote DC for dsh 是面向 DeepSeek Harness 的 Desktop Commander 非官方社区集成。

在校外也想看实验日志，或想在家确认公司服务器上的构建结果？在有权使用的目标机器上运行 Desktop Commander 代理，再从 DeepSeek Harness 登录同一个账户。设备能够出站连接官方服务时，你就能在 dsh 对话里找文件、读日志、编辑文档或操作终端。账户模式无需在目标机器上配置公网 IP、开放入站端口或安装 SSH 服务。

兼容 dsh 0.2.2-rc.1 及以上。使用独立 CLI 时，宿主需要 Node.js 24.9 或以上。

桌面端打开 插件 → 安装已有插件，输入 dsh-remote-dc@0.1.1。Web profile 也可以用命令安装。

也可从 GitHub v0.1.1 Release 下载安装包，在包所在目录运行以下命令。

1. 打开 设置 → Remote DC for dsh → 连接账户 → 打开授权页面。在运行 dsh 的电脑上，用浏览器完成 Desktop Commander 登录与授权。 2. 在目标设备运行下方命令。用同一个 Desktop Commander 账户核对配对码，并让设备代理保持运行。

3. 回到设置页刷新设备列表。在对话里试一句「用 Remote DC for dsh 查看实验服务器上 /home/me/experiments 目录的最新日志。」

设置页的 管理与配对设备 会打开官方控制台，可查看设备状态、添加设备或撤销访问。如果设备处于离线状态，检查目标机器上的代理进程和出站网络。官方配对指南

- 文件、搜索、终端、设备管理、账户和调用记录等能力由官方 MCP 向当前账户公布。插件按原始 schema 动态注册这些工具，例如 mcpremotedesktopcommanderlistdevices，并将选择设备所需的 deviceId 等参数照常传给服务。工具可用性随上游账户和设备权限变化。 - OAuth grant 保存在 dsh 宿主的凭据存储中，跨重启恢复。设置页仅显示连接状态、已加载工具数和上游返回的设备信息。访问令牌失效时，插件尝试刷新。需要用户授权时，设置页显示重新连接入口。 - 断开连接 删除 dsh 中的授权凭据并卸载该账户的工具。要在 Desktop Commander 侧撤销授权或配对，请使用其官方控制台。 - Codex 插件 的宿主工具审核与权限界面由 OpenAI 提供。dsh 接入同一官方服务，并使用 dsh 自身的工具与权限界面。

1. 在每台被访问的电脑上安装 Desktop Commander，远端需要 Node.js 22.12+。上游独立升级，本版本使用 0.3.3 验证。

2. 在运行 dsh 的电脑上，为远端配置一个 OpenSSH 主机别名。以下配置中的主机名、账号和密钥路径按实际情况填写。先通过可信渠道确认服务器的主机密钥并保存到 knownhosts。

若命令在非交互会话中找不到 Node.js，配置远端的非交互 PATH，或将 executable 指向使用 Node.js 绝对路径的启动脚本。SSH 密钥使用系统配置或由 ssh-agent 解锁。只访问本机时无需此步骤。

3. 按上文安装插件。默认安装时设备列表为空。将 设备配置示例 另存为 rdc.patch.yml，填写设备并把相应的 enabled 改为 true。初次运行可以使用临时 overlay。
