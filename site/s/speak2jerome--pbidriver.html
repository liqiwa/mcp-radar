About pbidriver

Part of Zynxtech open source. Project page: zynxtech.in/projects/pbidriver.

WebDriver for Power BI Desktop. Let AI agents build, see and drive Power BI Desktop reports: create PBIP projects, pages and visuals; screenshots of pages, visuals and every view; the data behind visuals; blocking dialogs; slicers, tooltips, menus, bookmarks; refresh, DAX and Performance Analyzer. It all runs locally against Power BI Desktop, with no screen grabs and no publishing to the service.

Together with Microsoft's Power BI Modeling MCP, which edits the semantic model, it's a complete kit for agents to build Power BI reports end to end and check their own work. One command sets both up for Claude Code, VS Code (GitHub Copilot), Cursor and Codex:

(Not a data connector or ODBC driver: "driver" as in WebDriver, the thing that drives an app for automation.)

⚠️ Caution: pbidriver is a new tool (first released November 2026). It edits Power BI project files, saves through Power BI and drives its UI, and like any new software it can have bugs that damage a report. Work on a copy of your report, or keep it in git and commit before letting an agent change it, so you can always go back. pbidriver new --git starts new projects under git, and commands that change files add a caution note while a project isn't under version control. Found a bug? See Reporting bugs.

Documentation: speak2jerome.github.io/pbidriver, with building reports with agents, setup for Claude Code, Copilot, Codex and Cursor and a FAQ.
