About keyrealm

致力于 ALL IN ONE 的本地凭据管理与验证平台。 允许将红队渗透测试中获取的散落在各处的 API Key、云厂商 AK/SK、机器人 Token、邮箱授权码、登录态等集中加密保管、便捷验证与快速利用。

- AES-256-GCM 字段级加密，密钥由主密码经 PBKDF2-HMAC-SHA256 派生，仅存内存。 - 敏感字段与非敏感字段分列存放：列表展示不必解密，同时保证密钥类字段全程不落明文。 - 主密码没有任何找回途径（无后门、无恢复码）——详见安全说明。

- 单条 / 批量 / 定时三种方式。批量验证并发数与请求超时可在对话框里就地调整。 - 定时计划的验证范围可选多种范围，更加自由。 - 校验结果不只是「有效 / 无效」，更有针对专一凭据的特殊标注。 - 有写副作用或咱无法自动化的类型（如 DuckDNS、Telegram apiid/hash、短信网关）标记为不参与批量验证，只允许手动逐条验证，避免把人工判定的结果刷掉。

- 一个服务一个插件，现目前共有 64 个插件、10 个类别（见支持的服务）。 - 插件放在程序目录的 plugins/ 下，放入即加载、删除即卸载，无需安装器；临时停用无需删目录，在界面里禁用即可（状态记在 plugins/.state.json）。 - 禁用不动磁盘目录：名下凭据照常显示、可编辑、可导出，只是「操作」「验证」置灰、批量验证自动跳过，禁用≠删除，快速找回插件。

- 对话：对 LLM 凭据直接发一次简单对话（流式返回）。 - 表单：带写副作用的操作（如修改 DNS 解析记录、刷新令牌），提交前二次确认。 - 列表：可下钻的查询，如「云主机实例」「对象存储桶 → 对象浏览」「域名列表 → 解析记录」。

- 可维护多个代理，设一个全局默认；每条凭据可三选一：跟随上层设置 / 指定某个代理 / 直连。解析优先级为 本条凭据 该插件预设 所属类别预设 全局默认。 - 代理支持 http / https / socks4 / socks5 / socks5h。 - 任一代理可一键对照测试：同一批探测分别走直连与代理，比对出口 IP 归属与国内外站点可达性，直接给出「代理是否真的生效」的结论。 - 邮箱（SMTP / IMAP）走裸 TCP，不使用 HTTP 代理，会自动改用 SOCKS / HTTP CONNECT 隧道穿出去。

- 导出为单个 JSON 文件：加密导出（保留密文）或明文导出（可跨主密码导入）。

- 可选「全部（凭据 + 分组 + 代理 + 预设 + 定时计划 + 设置 + 保险库 KDF + MCP + 插件启停）」或「仅选中的凭据」。整库档自带盐（salt），文件自包含。

插件不存在或被禁用、含当前插件不认识的字段、缺少必填字段的条目会整条判失败、不写库，并逐条列出原因；

每次导入在 data/logs/ 下留一份完整导入日志与（有失败时）一份失败日志，结果弹窗里可一键打开便于人工补录。

- 换保险库也能还原：在另一台机器 / 新装的 Keyrealm 上导入整库备份时，会再问一次它当时的主密码，并用它 + 文档里的盐派生源密钥解开密文，再以当前库的密钥重新加密写回（当前库自己的盐/校验值不受影响）。

- 凭据简易操作、分组管理、6 套界面主题（3 浅 3 深）、侧边栏与凭据目录树顺序均可拖拽调整。 - 后台任务：下载 / 打包这类长操作登记为任务，可看进度、可取消，关掉弹窗照常跑；任务记录持久化到 data/tasks.json，重启后历史仍在（上次没跑完的标为「已中断」）。 - 独立日志页：级别可调、支持关键词搜索（含 traceback 的整条记录匹配）。 - 单实例：重复启动不会开出第二个窗口，而是把已运行的拉到前台。 - 开机自启动（默认关闭）。 -
