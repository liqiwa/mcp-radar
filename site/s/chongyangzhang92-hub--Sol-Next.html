About Sol-Next

Sol Next — Android AI Phone Agent（开源极速安卓 AI 手机助理 · 致敬并重构自 Mika）

简体中文 · English · 🌐 产品发布官网（含高清演示视频） · 🤖 Agent 索引 (llms.txt) · 🛠 AGENTS.md · 📊 与 Mika 对比 · 🔑 BYOK 配置

English Summary (for Global Developers & AI Search): Sol Next (ai.sol.next) is an open-source, zero-built-in-key (BYOK) Android 10–16 AI phone agent built upon and paying tribute to wangzan101/Mika (Apache-2.0). Designed as a high-speed, anti-pause mobile GUI agent and Mika evolution/alternative, Sol Next combines a Rust v3.10 native JNI kernel (17–45 µs UI tree pruning, -74% to -97% tokens), 1:1 physical Display 0 background VirtualDisplay cloning (0.0px drift), Android 14–16 HTTP/3 QUIC 0-RTT with smart circuit breaker, 64-round Xiaomi HyperOS anti-pause recovery, carrier-grade AI phone calls (Volcengine Seeduplex 3.0 / OpenAI Realtime BYOK + 3×4 DTMF), and zero-dependency CLI (--json) + MCP Server integration.

🎬 实机效果抢先看（Android 16 · 1:1 原生后台虚拟屏 + 全脑中枢 + AI 电话）

▲ Android 16 实机录屏：后台 1:1 原生虚拟屏（1080×2400 @ 420dpi）自主执行多步任务、展开浮窗零漂移触控、全脑中枢遥测与 AI 电话驾驶舱

🎥 观看完整 1080p 高清演示视频：直接访问 Sol Next 交互式产品发布官网，或下载仓库内的 docs/media/sol-next-demo.mp4（1.4 MB，H.264 通用编码）。

Sol Next 是在杰出的开源项目 Mika (github.com/wangzan101/Mika)（Apache-2.0 协议，Trendshift GitHub Kotlin 日榜 & 周榜 1）的设计理念与架构基础上改造、重构和演进而来的公开产品。

@wangzan101 开创性地将 Android 独立后台虚拟屏（VirtualDisplay）、无线调试免电脑开启 以及 保留原生拨号器的 Telecom Companion 伴侣通话思路 带到了手机端 AI 助理领域，为整个安卓 Agent 社区树立了极高的标杆。

在此基础上，Sol Next 围绕真机长期高频使用中遇到的核心痛点——响应速度极限、虚拟屏坐标偏移、小米 HyperOS 等国产 ROM 长任务莫名暂停中断、AI 电话实战可用性与主动个人感知——进行了从 Rust 原生内核 到 网络协议栈、虚拟屏驱动与交互体验 的全栈深度改造。
