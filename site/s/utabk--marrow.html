About marrow

A desktop GUI for REA, with a classic code browser and all 229 REA tools in one window.

Open an app. Read it down to the marrow.

Quick start · How Marrow works · What you can open · Showcase · Screenshots · FAQ · Development

[!NOTE] Marrow (formerly REA Studio) is an independent project. REA's authors don't make or endorse it. Marrow runs the REA you install and doesn't ship a copy of its own. Get REA from morluto/rea or the rea-agents npm package.

Marrow is a reverse engineering app for macOS, Windows and Linux, built on REA. REA does the analysis through its MCP server. Marrow gives it the windows a reverse engineer expects: a Listing with the disassembly, a Decompiler, a Function Graph, the Symbol Tree, Bytes, strings, references, bookmarks and search, laid out like the classic CodeBrowser many people already know.

Native binaries open in that CodeBrowser. Apple bundles, Electron apps, web pages, Android APKs, .NET assemblies, firmware, packet captures and version comparisons each have a window of their own, and the REA Tools window lists every REA tool with a form for each one.

Everything on screen comes from REA's answers, along with the evidence and limitations REA reported. Marrow doesn't parse files itself, and when a tool fails it shows the error REA returned. Analysis runs on your own computer.
