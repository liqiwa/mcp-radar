About githubcard-mcp

Let your AI assistant create GitHubCard images: profile and repository cards for READMEs, link previews and social posts, with live GitHub data.

- Hosted: https://githubcard.com/mcp (Streamable HTTP). Nothing to install. - Local: npx -y @ghcardhq/ghcard mcp (stdio), from the ghcard CLI. It can also edit a README on your disk.

Make a GitHubCard for my profile and add it to the top of my README.

Create a dark card for vercel/next.js I can use as a link preview.

Use the compact repo template, but with a 1e3a5f background and without the language widget.

Creating cards needs a free API key. Sign in at githubcard.com/dashboard and create one under API keys. It looks like ghclive….

Without a key, the server still lists templates, palettes and widget types, so you can try it before signing up.

Replace ghclive… with your key in the examples below.

There is also a Claude Code plugin that adds the server together with a GitHubCard skill: see ghcardhq/skills.

Settings → Connectors → Add custom connector, URL https://githubcard.com/mcp. Custom headers are not available there yet, so to pass your key, use the local server in claudedesktopconfig.json instead:

.vscode/mcp.json (VS Code asks for the key once and stores it securely):

Then export GHCARDAPIKEY=ghclive… in your shell.

Remote: Streamable HTTP at https://githubcard.com/mcp, header Authorization: Bearer ghclive….

Local (stdio): command npx, args ["-y", "@ghcardhq/ghcard", "mcp"], env GHCARDAPIKEY. Add --allow-file-writes to the args to enable updatereadme. Needs Node.js 20 or later.
