About wasche

Native WhatsApp Model Context Protocol (MCP) Server, Background Scheduler Sidecar & Multi-Account Engine

Wasche is a native Rust-powered Model Context Protocol (MCP) server and persistent background scheduler sidecar for WhatsApp. It enables AI agents (Claude, Cursor, Codex, Gemini, etc.) to safely orchestrate multiple WhatsApp phone numbers, query contacts, dispatch interactive media, and execute high-durability broadcast campaigns protected by human behavioral emulation heuristics.

- 20+ Native MCP Tools: Full programmatic control over direct messaging, QR/phone code linking, contact management, and anti-ban campaign automation. - Embedded Web Dashboard: Modern client-side SPA (Astro + SolidJS) on port 3030 providing live progress meters, speech bubble chat preview, WhatsApp Photo Studio, and Video Frame Trimmer. - Multi-Account Concurrency: Run multiple WhatsApp numbers simultaneously in a single daemon with automated load balancing and independent rate pacing. - Anti-Ban Heuristics: Proportional typing presence (Chatstate::Composing), randomized inter-recipient jitter (e.g. 25–90s), single-flight transaction locks, and 3-strike circuit breakers. - SQLite Persistence: Complete local storage for Noise E2EE session keys, campaign queues, contacts, and delivery audit logs with automatic WAL checkpointing.
