About Maurice-PaaS

A self-hosted deployment panel for one powerful server, built on rootless Podman.

Maurice (friends call it Marik) gives you the convenience of Coolify on a single bare-metal server where blockchain nodes, ClickHouse, databases and application services live side by side. It is not Docker with a different runtime underneath. It is built around what Podman does well: rootless isolation by Unix user, Quadlet and systemd as the lifecycle engine, auto-update with rollback, native secrets.

Status: Alpha. Workspaces, services from images or Dockerfiles, secrets, plans with apply, logs, live stats and a web UI work end to end on a real Podman host. Not for production yet: no proxy, TLS, auth or backups before MVP. The Alpha guide shows everything that works; progress is on the task board.

- Workspaces as system users with their own subuid range, home, network and systemd --user; deleting one leaves nothing behind. - Services from an image or from a Dockerfile in a git repository, rendered to Quadlet units; stateful services get a volume, every service a stable DNS name inside its workspace. - Plan / apply for every change, with the unit diff shown before anything is written and a confirmation step for destructive plans. - Secrets encrypted at rest, delivered through podman secret, never written to units or logs. - Closed ports by default; publishing binds to 127.0.0.1 unless told otherwise, and host port clashes across workspaces are refused. - Deploy waits for the health check; restart, stop, logs with follow, live CPU, memory and network, the unit file on disk. - Reboot-safe: d
