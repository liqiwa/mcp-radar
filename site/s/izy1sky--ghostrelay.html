About ghostrelay

prompt for a face, wired to three terminals"

Your agent, inside every machine you own. one MCP hub · nodes dial out · mac · linux · windows

A single binary, relay, that lets an agent on one host use the files and shell of other hosts that have no public address. A policy on the server decides what each agent may do, and asks a human when it should.

- relay serve runs on the one machine with a reachable address. - relay node runs on each resource host and dials out. It needs no open port. - The agent adds the server as an MCP server and gets one set of tools that works the same whatever OS a node runs (see One API for every OS):

Group Tools ------ Discover nodeslist, nodeinfo Run exec (argv = no shell, or command = the node's shell), joblogs, jobkill, jobslist Files fsread, fswrite, fsedit, fslist, fsstat, fsmkdir, fsmove, fsremove, fsglob, fsgrep Between nodes transfer

Get relay for each OS from Releases (or go build -o relay .).

Double-click relay (or run relay with nothing after it). A page opens in your browser and asks what this computer should do:

- Be the hub, once, on the machine the others can reach: pick its address and port (the same port goes into join codes, so they always match), how careful it should be, and whether it keeps running after restarts. Then it shows the join code and opens the console. - Share this computer, on every other machine: paste the join code (it is checked against the hub right away), choose folders, choose files only or files and programs.
