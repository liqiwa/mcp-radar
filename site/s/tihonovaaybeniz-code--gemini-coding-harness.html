About gemini-coding-harness

面向 Gemini 桌面端（Mac Gemini.app Task 任务模式 / 对话） 与 Gemini CLI 的受控本地编程 Harness MCP 服务。

项目借鉴 DeepSeek Harness（dsh） 的「Agent = Model + Harness」与 三角色解耦 思想，把工程纪律与安全护栏下沉为 MCP 服务端硬规则，而不是只靠 Prompt 约束模型。直接暴露裸 fs / bash 容易导致盲改覆盖、输出撑爆上下文或误操作宿主机；本项目通过高内聚工具与强约束策略，让通用桌面客户端具备可靠、可校验、可回滚的本地代码工程能力。

1. 三角色解耦（Interfaces ↔ Policy ↔ Provider） - MCP 协议层（src/mcp/）与底层执行引擎（src/providers/）通过 HarnessProvider 接口解耦，后续可平滑替换为 Docker 沙箱或外部编码子代理，无需改动任何工具契约。 2. 把“束缚”写进代码护栏 - 白名单与只读锁：仅访问显式启用的注册仓库，支持单仓库切换 readOnly 只读锁定；拦截 ..、绝对路径、符号链接逃逸、.git/ 内部元数据，以及 .env、.pem、.key、SSH 私钥、credentials.json 等敏感文件。 - 写前必读锁（Read-before-Edit）：记录每个已读文件的 sha256；未在当前会话读取或磁盘内容已变更的文件拒绝改/覆写/删，fileedit 失配时自动返回最接近代码行与行号辅助自纠。 - 命令、环境脱敏与 TTL：剥离宿主机 KEY/TOKEN/SECRET 等环境变量；支持高危黑名单（standard）与 命令前缀白名单（allowlist） 双模式；所有后台命令受 maxCmdRuntimeSec 硬超时约束。 - 上下文输出预算（Context Budgeting）：代码读取按完整行预算切分并输出 nextStartLine 精准续读；超长命令/diff 日志自动落盘至 runtime/logs/（7 天/100 份自动清理），支持 logread(logId) 分页回看。 - 磁盘持久化 Checkpoint：首次修改或删除任意文件前自动持久化原始快照到 runtime/checkpoints/，跨会话保留，随时通过 MCP 或控制台一键回滚。 3. 控制面与执行面分离 - 内置零依赖 本地可视化配置控制台（--ui，仅监听 127.0.0.1:18788），强制校验 Host、Origin 与随机 X-Harness-CSRF；LLM 永远无法通过 MCP 给自己扩容白名单或放宽安全限制。
