About stu-packet-tracer-mcp

A student-focused Model Context Protocol (MCP) server for Cisco Packet Tracer 9. Connect Claude, Antigravity, Cursor, VS Code, or Gemini CLI directly to your open Packet Tracer workspace to build topologies in a single turn, run Cisco IOS commands without --More-- truncation, generate crisp terminal-style CLI screenshots (SVG & PNG), verify lab objectives, and export submission-ready DOCX, print-to-PDF HTML, and Markdown lab reports in one command.

- Terminal-style CLI & PC Command Prompt screenshots (ptcapturecli, ptcapturepccommand, ptrenderterminal) — crisp vector SVG + 2x PNG rasterization via embedded @resvg/resvg-wasm and bundled DejaVu Sans Mono fonts (no Chrome or system font dependencies). - 5 built-in themes: pt-classic (Packet Tracer CLI tab chrome), dark, putty, high-contrast (print-ready), and pc-cmd (Windows Command Prompt). - One-command lab report export (ptexportreport) — collects the live topology screenshot, addressing table, ping matrix, IOS CLI captures, PC command outputs, and Before/After fault-fix sections into Microsoft Word (.docx), self-contained print-ready HTML, and Markdown. - Student workflow & troubleshooting tools — ptaddressingtable, ptpingmatrix (with automatic ARP warm-up so first pings do not false-fail), ptchecklab objective verifier, ptdiagnosefaults (study hints / fix commands / live auto-fix for common lab mistakes), pttracepath (bidirectional forward & return hop analyzer), ptbreaklab (exam practice fault injector), ptexplainoutput (offline IOS output explainer), ptsubnetcalc (IPv4 + VLSM planner), and ptlabtemplate (10 university
