About night-ferry

在线演示 · Live demo — 用手机打开效果最好；演示用的是自带的示范文章，留言和点题只存在当前页面里。

每天晚上，让你的 AI 给你写一篇三五百字的冷知识或科普，像睡前读的那种。你在页面上读，读完可以在文末留一句话，它下次醒来会看到，也可以回你。

这个仓库是一整套能跑起来的东西：给 AI 用的写作工具、自动配图的管线、和一个长得像航海日志的阅读页。

- 一天一篇。 AI 调用 nightferry 工具写今晚这篇：标题、正文、分类、天气、故事发生的地方、文末想对你说的一句话，再从壁纸里挑一张和内容最搭的。同一晚写第二篇会被拒。 - 你可以点题。 页面上有「想听的」清单和一行长期主题。AI 写之前会先看；写了你点的那条，清单上会划掉。 - 自动配图。 正文里单独一行 【图：想要什么画面 要求】 就是一张图的位置。服务器去 Wikimedia Commons 搜，让一个小模型看候选图挑一张、写图注，压好存下来，然后等 AI 自己过目：通过、换掉图注、给这张图留一句话，或者说明原因打回重找（最多四轮）。全部过目完才通知你。每张图都带作者和授权。 - 航海日志。 每篇文末有一块留言，你和 AI 都能写。AI 读过那一期才算读过你的留言。 - 阅读页。 一页一篇，米色纸浮在本期壁纸上；左右拖动翻往期，邻页跟着手指走；点图会冒出一朵云，是 AI 看完这张图说的话；图右下角的按钮把它放大到全屏，可以双指缩放拖动，也可以存到相册；滚到文末，一只锚带着麻绳落下来扎进沙里；右上角是按月的一览。 - 封面和进场。 封面是艾瓦佐夫斯基的月夜海，用 WebGL 做成活的：海面起伏、月光碎在水上、云在飘、船在晃。点「上船」，一只小船从画上划过去，正文在它的尾迹里展开。

只想看看样子的话不用装任何东西：直接双击 public/index.html，页面会用自带的示范数据跑（留言和点题只存在内存里，刷新就没了）。从磁盘直接打开时浏览器不让页面读图片的像素，所以封面是静止的画、进场动画会跳过；起了服务器（npm start）才是全套。

examples/write-tonight.js 是完整的一轮：先看你点了什么，写，等配图，看图，通过或打回。默认用 claude-opus-5-5 写、claude-haiku-5-5 挑图，可以用环境变量 NIGHTFERRYMODEL / NIGHTFERRYIMAGEMODEL 换。脚本里默认开了服务端的拒答回退（某一轮被安全分类器拦下时由回退模型接着跑），不想要就删掉注释标出的那两行。

没有 API key 时，文章照样能写能读，只是没有配图——或者走下面这条路，用订阅。

夜航船自带一个 MCP 服务（server/mcp.js，不需要额外安装任何包），把 nightferry 这个工具交给任何支持 MCP 的客户端。你已经在用的 Claude Code 或 Codex 就可以直接当写手，找好的图会作为图片内容回给它，它是真的看过图才通过或打回。

MCP 服务和网页服务读写同一个数据目录（NIGHTFERRYDATA，默认 ./data），可以同时开着。

配图管线里那个「看候选图挑一张」的小模型，也可以走订阅。用环境变量 NIGHTFERRYLLM 选：

值 用什么 说明 --------- anthropic Claude API 有 API key 时的默认值，最快 claude-code claude -p，走 Claude 订阅 每次调用起一个一次性的会话，约 5～10 秒一次 codex codex exec，走 ChatGPT 订阅 同上 none 不配图 没有 key 时的默认值
