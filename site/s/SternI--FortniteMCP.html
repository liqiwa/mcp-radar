About FortniteMCP

An in-process MCP server for Unreal Engine game research and automated testing.

FortniteMCP.dll is injected into an offline/private game build. It exposes a local MCP endpoint that MCP clients and coding agents can use to inspect memory, walk UE reflection, call UFunctions, drive keyboard/mouse input, and load helper DLLs.

Cool discord server to talk: https://discord.gg/x5NhV5h7BF

Authorized use only. Run this against an offline/private build you own, with anti-cheat disabled. The included loader only targets a game process you started locally; this project contains no anti-cheat bypass, no hardware-ID spoofing, and no remote/network injection. The matchmaking helpers are for private sessions you control, not public matches or other players. Memory writes and raw calls can crash the process. Nothing here is affiliated with Epic Games.

- Safe typed/hex/base64 memory reads and writes, tracked undo patches, IDA-style pattern scanning, pointer chains, and tracked allocations. - UE reflection: StaticFindObject/FindObject, GetObjectsOfClass, object inspection, properties, UFunctions, typed/raw ProcessEvent calls including the engine's uint64t return, raw function calls, and globals (GWorld/GEngine or the GEngine - GameViewport - World chain). - Game-thread dispatch for engine calls through a ProcessEvent hook, with a fast path and timeouts. - Names through a standard FNamePool/table or directly through the engine's FNameToString, with caching. - Game input: keys (press/hold/release), unicode text, relative/absolute mouse, buttons, wheel. - Load/unload helper DLLs in the game
