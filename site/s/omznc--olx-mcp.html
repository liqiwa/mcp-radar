About olx-mcp

MCP server za OLX.ba API. Omogućava Claudeu (i drugim MCP klijentima) da pretražuje OLX, objavljuje i uređuje oglase, upravlja slikama i sponzorstvima. 36 alata koji pokrivaju sve endpointe iz zvanične dokumentacije, plus pretragu oglasa.

Nekoliko primjera šta možete tražiti kad je server dodan:

Vi kažete Server odradi --- --- „Nađi polovni bicikl u Sarajevu do 400 KM.” olxsearchlistings „Koliko košta da sponzorišem oglas 4821990 na 7 dana?” olxsponsorprice „Objavi oglas za Trek bicikl, 340 KM, ove tri slike.” olxsuggestcategory → olxcreatelisting → olxuploadlistingimages → olxpublishlisting „Koji moji oglasi su istekli?” olxuserlistings „Obnovi oglas 4819774 ako je besplatno.” olxrefreshlimits → olxrefreshlisting

To je sve. Prvi put kad neki alat zatraži prijavu, server zatraži korisničko ime i lozinku kroz sam MCP klijent (Claude Code prikaže prozorčić), razmijeni ih za token, sačuva ga i nastavi prekinuti poziv. Nema posebne login komande ni restarta.

Ako vam više odgovara terminal, ili klijent ne podržava taj prozorčić:

Treća opcija je bez ikakve prijave: podatke stavite u konfiguraciju samog servera.

Server se tada prijavi sam pri prvom pozivu i sam obnovi token kad istekne. Razlika je gdje stoji lozinka: ovako ostaje zapisana u konfiguraciji MCP klijenta u čitljivom obliku, dok prozorčić i login sačuvaju samo token. Sva tri načina rade, birajte po tome šta vam više odgovara.

Radi sa Node.js 18+ ili Bunom. npx je samo najčešće dostupan; ako koristite Bun, bunx radi isto tako.
