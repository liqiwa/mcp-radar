About table-craft

Write the rules. Get the table. A server-authoritative 3D tabletop engine: describe any board or card game in one JavaScript module and get a physics-based table with multiplayer rooms, bots and an automated referee.

Live demo · Playground · Examples · Getting started · Documentation

Prototyping a tabletop game online usually means choosing between a spreadsheet-like UI that nobody enjoys and months of game-engine work. Tablecraft sits in between: you write the rules, it builds the table.

- One file per game. setup(), moves, view(), endIf(). State is plain JSON; randomness is seeded and replayable. - A real table. Cards arc, tilt and flip; dice are thrown with physics and land on the server's result; tokens toss and stack. - Fair by construction. Moves run on the host in a sandbox. Each player's view() contains only what they may see. - Bots and a referee for free. Export actions() and bots can play; the referee plays hundreds of games and reports rule bugs. - Mechanics in the box. Drafting, auctions, worker placement, majorities, trick-taking, set collection, deck-building, decision stacks, square and hex grids — 40+ mechanics as small, deterministic helpers on T. - Balance you can measure. The balance lab reports first-player advantage, game length, forced decisions, comebacks and dominant strategies — and sweeps a card count or point value to show what a change would do. - Followable. The Spotlight puts every card another player reveals or plays on stage; the game log keeps the whole story. - Play anywhere. In the browser against bots (no server), or on your own socke
