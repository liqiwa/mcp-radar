About kavero

From product data to beautiful experiences.

Kavero is an AI-native catalog and presentation builder. Bring your products — pasted, imported from any MCP server, or generated with AI — design them in a visual slide editor, animate them, and publish the same catalog as a PDF, an editable PowerPoint, JPG images, an MP4 video, a single HTML file or an animated website.

It's local-first: open it and start working, no account needed. Sign in to sync across devices, collaborate in workspaces, publish, and let AI agents build catalogs for you over MCP.

- Visual editor — text, images, shapes, product cards and grids, HTML blocks; snapping, groups, layers, undo/redo, autosave, and a PowerPoint-style Morph transition that moves shared elements between slides. - AI chat, generation and editing — start from a prompt on the home page, or chat with your model inside the editor: it knows the open catalog, remembers each catalog's conversation, and proposes slide edits you approve with a before/after preview. Built on the Vercel AI SDK. Works with Anthropic Claude, OpenRouter, OpenAI or local models — set on the server, or by each user with their own key in Settings → AI. A built-in planner takes over when no model is configured. - MCP both ways — import products from your store's MCP server; let Claude and other agents create, edit, preview, export and publish catalogs through Kavero's MCP server (29 tools incl. fonts, scoped tokens, audit log). - Motion — element animations and slide transitions that play the same in preview, on websites and in video. - Every format from one document —
