About mcp

PixelFlow is server-side conversion tracking for Meta and TikTok. No tag manager, and no developer needed.

The MCP server lets your AI agent do two things from the chat:

1. Set up conversion tracking. The agent walks you through the install, connects Meta or TikTok, and creates the triggers for the actions you want to track, such as a form submission, a booked call, or a purchase. You approve the changes. 2. Answer questions about your tracking and your data. PixelFlow returns the events themselves, so the agent can answer what you ask and build the report in the chat. What was attributed revenue last week? Which campaigns drove purchases? Why is Meta showing more leads than PixelFlow?

The server URL is https://api.pixelflow.so/mcp.

The client opens the PixelFlow login and the customer clicks Allow. No token is pasted.

--- --- Reads Events, attribution, journeys, and site status. Reads do not need approval. Edits Creating, editing, or deleting a trigger, a blocking rule, a site field, a pixel label, or an integration. Show the change and wait for one approval. Never touches The customer's ad account. The server does not change campaigns, budgets, or ads. Never touches The customer's website. The server does not edit it. A coding agent that already has the repo may place the snippet the install tool returned. Never touches Tokens, keys, and passwords. They are not returned and must not be typed into the chat. Never touches A visitor's raw email, phone, or name. Hashed values stay hashed. IP stays masked unless the customer asks for the full value. Never touches Deleting
